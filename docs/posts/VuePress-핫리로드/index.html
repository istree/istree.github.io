VuePress 핫리로드

VuePress에서 파일을 고치자 마자 바로 브라우저 탭에 반영되는 기능이 좋았는데 어느순간 동작하지 않았다.

다음과 같이 preinstall을 추가하고 resolutions 항목에 버전을 낮춰주니까 해결되었다.

  "scripts": {
    "preinstall": "npx npm-force-resolutions",
  },
  "resolutions": {
    "watchpack": "1.6.1"
  }

jekyll도 이게 되면 편리할듯 한데 아쉽다.
