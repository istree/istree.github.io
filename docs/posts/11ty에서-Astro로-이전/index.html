11ty에서 Astro로 이전

Jekyll에서 11ty로 옮긴 지 4년 가까이 되어 다시 Astro로 옮겼다. 그동안 엄두가 안났는데 AI를 도입해서 오랜만에 정리했다.

주소는 그대로

기존 링크가 깨지지 않게 11ty의 주소, 태그, 날짜 규칙을 그대로 옮겼다.
11ty로 한 번 빌드해 두고 Astro 결과와 페이지마다 비교했더니 210 페이지의 주소가 모두 같았다.

Liquid 대신 JS

11ty 때는 Liquid로 안 되는 것을 JS 필터로 만들어 붙였다.
Astro는 템플릿 자체가 JS라 그럴 일이 없다. 직접 만들었던 groupBy 같은 필터는 몇 줄짜리 함수가 됐다.

테마를 걷어냄

디자인을 할 줄 몰라 Jekyll 때부터 Minimal Mistakes 테마를 써 왔다.
이번에 걷어 내고 모양만 따라 CSS 파일 하나로 만들었다.

Data Cascade

폴더의 json으로 태그를 물려주던 11ty의 기능이 없다. 직접 만들어야 한다.

마크다운 차이

따옴표가 바뀌고, 본문의 URL이 링크가 되고, 코드 예시를 감싼 {% raw %} 가 그대로 보인다.
설정으로 맞추거나 원고를 고쳤다.

날짜

정리 글의 날짜가 파일 시각이라 CI에서 빌드하면 모두 배포한 날이 된다. 사실 11ty 때부터 그랬다.
git 커밋 날짜로 바꿨다.

GitHub Actions 도입

원고 저장소에서 GitHub Actions로 빌드해 GitHub Page 저장소에 push 한다.
push 할 때마다 돌리면 너무 잦아서 하루 세 번 예약으로 돌리고, 바뀐 것이 없으면 건너뛴다.
다른 저장소에 push 하는 권한은 PAT 대신 배포 키로 줬다. 원고를 고쳐 두면 알아서 올라간다.

그동안 작업한 내용을 정리해보았다.
