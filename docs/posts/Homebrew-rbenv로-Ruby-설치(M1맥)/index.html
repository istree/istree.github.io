Homebrew rbenv로 Ruby 설치(M1맥)

Homebrew가 arm64 공식 지원이 된지 꽤 되었다고 하여 ruby도 Homebrew로 설치해 보았는데 매끄럽게 잘 된다.

rbenv와 ruby-build 설치

brew install rbenv ruby-build

설치 가능한 ruby 버전 확인

rbenv install -l

3.1.2 설치하고 기본 버전으로 설정

rbenv install 3.1.2
rbenv global 3.1.2

설치된 버전 확인

rbenv versions

경로 설정을 위해 .zshrc에 한줄 추가한다. 3.1.2로 설정했다.

export PATH="$HOME/.rbenv/versions/3.1.2/bin:$PATH"

터미널을 재시작 하거나 .zshrc 설정을 다시 적용 한다.

source ~/.zshrc

루비 버전 확인

ruby -v

명령어가 잘 실행되어 버전이 표시되면 제대로 된 것이다.
