스크립트로 폼의 값을 읽고 쓰고, 값이 바뀌면 화면을 고치고, 보내는 동안 단추를 막는 일이다. 칸은 form.elements.이름 으로 찾고, 값은 칸의 종류에 따라 value · checked · selectedOptions 에서 읽는다. 아래 예는 이 폼에서 시작한다.

<form id="f">
  <input name="title" value="책 읽기">
  <input name="qty" type="number" value="3">
  <input name="due" type="date" value="2026-11-08">
  <label><input type="checkbox" name="tags" value="home" checked> 집</label>
  <label><input type="checkbox" name="tags" value="work"> 일</label>
  <label><input type="checkbox" name="tags" value="study" checked> 공부</label>
  <label><input type="radio" name="pri" value="low"> 낮음</label>
  <label><input type="radio" name="pri" value="high" checked> 높음</label>
  <select name="cat" multiple><option>a</option><option selected>b</option><option selected>c</option></select>
  <textarea name="memo">메모</textarea>
  <button>저장</button>
</form>

값 읽기

const f = document.getElementById("f");
const el = f.elements;

el.title.value;                  // "책 읽기"
el.qty.value;                    // "3" — 늘 문자열
el.qty.valueAsNumber;            // 3
el.due.valueAsDate;              // 2026-11-08T00:00:00.000Z (UTC 자정)
el.pri.value;                    // "high" — 같은 이름의 라디오는 묶여서 선택한 값이 나온다
el.memo.value;                   // "메모"

[...f.querySelectorAll("[name=tags]:checked")].map((c) => c.value);   // ["home", "study"]
[...el.cat.selectedOptions].map((o) => o.value);                      // ["b", "c"]
  • 같은 이름이 여럿이면 el.tags 는 RadioNodeList 다. 라디오는 .value 로 선택한 값이 나오지만 체크박스는 빈 문자열이라, :checked 로 찾는다
  • 체크박스 하나는 el.agree.checked(true · false) 로 읽는다

한꺼번에

const data = new FormData(f);
data.getAll("tags");             // ["home", "study"]
Object.fromEntries(data);
// {"title":"책 읽기","qty":"3","due":"2026-11-08","tags":"study","pri":"high","cat":"c","memo":"메모"}
  • Object.fromEntries 는 같은 이름 중 마지막 하나만 남긴다(tags 가 "study"). 여럿 받는 칸은 getAll 로 따로 읽는다
  • 객체로 바꿔 보낼 때는 숫자 · 배열을 직접 맞춘다
const body = { ...Object.fromEntries(data), qty: el.qty.valueAsNumber, tags: data.getAll("tags") };

값 쓰기

el.qty.valueAsNumber = 7;                       // value 가 "7"
el.pri.value = "low";                           // "low" 라디오가 체크된다
el.cat.add(new Option("새 분류", "new"));        // <option value="new">새 분류</option>
el.title.value = "바꿈";
el.title.defaultValue;                          // "책 읽기" — HTML 의 value 속성은 그대로
f.reset();                                      // 모두 처음 값으로 — title "책 읽기", qty "3"
  • value 는 지금 값, defaultValue · getAttribute("value") 는 처음 값이다. 둘을 견주면 고쳤는지 안다
  • 스크립트로 value 를 바꾸면 input · change 이벤트가 나지 않는다. 듣는 쪽이 알아야 하면 직접 보낸다: el.title.dispatchEvent(new Event("input", { bubbles: true }))

바뀔 때

f.addEventListener("input", (e) => {           // 칸마다가 아니라 폼에 하나 — 올라온다
  if (e.target.name === "qty") total.textContent = el.qty.valueAsNumber * price;
});
f.addEventListener("change", (e) => {          // 칸을 떠날 때 · 체크박스 · select 는 바로
  if (e.target.name === "tags") saveTags();
});

let dirty = false;
f.addEventListener("input", () => (dirty = true));
window.addEventListener("beforeunload", (e) => { if (dirty) e.preventDefault(); });   // 닫기 전에 묻는다

보내기

f.addEventListener("submit", async (e) => {
  e.preventDefault();
  const button = e.submitter;                  // 누른 단추
  button.disabled = true;                      // 두 번 보내지 않게
  try {
    const res = await fetch("/todos", { method: "POST", body: new FormData(f) });
    if (!res.ok) throw new Error(res.status);
    f.reset();
  } finally {
    button.disabled = false;
  }
});

f.requestSubmit();                             // 스크립트로 보내기 — 검사 · submit 이벤트를 거친다
  • f.submit() 은 검사도 submit 이벤트도 건너뛰고 바로 보낸다. 스크립트에서는 requestSubmit() 을 쓴다
  • disabled 인 칸은 보내지 않는다. 고치지만 못 하게 하고 보내려면 readOnly 다
  • 칸을 모두 막으려면 <fieldset disabled> 로 감싼다

파일

<input type="file" id="csv" accept=".csv,text/csv">
csv.addEventListener("change", async () => {
  const file = csv.files[0];                   // 선택하지 않고 닫으면 없다
  if (!file) return;
  file.name; file.size; file.type;             // "score.csv" 28 "text/csv"
  const rows = (await file.text()).trim().split("\n").slice(1).map((l) => l.split(","));
  // [["가","90"],["나","85"]]
});

img.src = URL.createObjectURL(file);           // 올리기 전에 미리보기 — blob:https://… 주소
img.onload = () => URL.revokeObjectURL(img.src);
  • 같은 파일을 다시 선택하면 change 가 나지 않는다. 처리한 뒤 csv.value = "" 로 비운다
  • 끌어다 놓기는 dragover 에서 preventDefault() 하고 drop 에서 e.dataTransfer.files 를 읽는다

예전에는

  • document.forms[0].elements[2] 처럼 번호로 칸을 찾았다. 지금은 form.elements.이름 이다
  • 값을 $("#f").serialize() 로 모았다. 지금은 new FormData(form) · new URLSearchParams(new FormData(form)) 다
  • 파일을 FileReader 의 onload 로 읽었다. 지금은 await file.text() · file.arrayBuffer() 다
