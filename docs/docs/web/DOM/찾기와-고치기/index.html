DOM 을 다루는 일은 요소를 찾고, 글자 · 속성 · 클래스를 바꾸고, 요소를 만들어 넣거나 빼는 것이다. 찾을 때는 CSS 선택자를 그대로 쓰는 querySelector 를, 글자를 넣을 때는 textContent 를 기본으로 쓴다. 아래 예는 이 HTML 에서 시작한다.

<ul id="todo">
  <li class="done" data-id="1">우유 사기</li>
  <li data-id="2">메일 <b>답장</b></li>
  <li data-id="3">운동</li>
</ul>

찾기

const ul = document.getElementById("todo");
const li2 = ul.querySelector('[data-id="2"]');               // 처음 하나 — 없으면 null
ul.querySelectorAll("li:not(.done)");                        // 모두 — data-id 2, 3
li2.closest("ul");                                           // 자기부터 위로 가장 가까운 것
li2.matches("li[data-id]");                                  // 맞는지 — true

ul.children.length;                                          // 3 — 요소만
ul.firstElementChild.textContent;                            // "우유 사기"
li2.previousElementSibling.textContent;                      // "우유 사기"
li2.nextElementSibling.dataset.id;                           // "3"
li2.parentElement.id;                                        // "todo"
  • querySelector 는 그 요소 아래에서만 찾는다. 범위를 좁히면 빠르고 다른 곳의 같은 클래스에 걸리지 않는다
  • children · firstElementChild 는 요소만, childNodes · firstChild 는 공백 글자 노드까지 센다. 보통 요소 쪽을 쓴다
  • querySelectorAll 의 결과는 찾은 때의 사진이다. getElementsByTagName · children 은 살아 있어서 요소를 더하면 같이 늘어난다 (하나를 더하면 4 · 3)

글자 · HTML

li2.textContent;                   // "메일 답장" — 태그를 뺀 글자
li2.innerHTML;                     // "메일 <b>답장</b>"

const li = document.createElement("li");
li.textContent = "<b>책</b>";      // 글자 그대로 — <li>&lt;b&gt;책&lt;/b&gt;</li>
  • 사용자가 넣은 값은 늘 textContent 로 넣는다. innerHTML 에 넣으면 그 안의 <img src=x onerror=…> 가 실행된다(XSS)
  • innerHTML 은 직접 쓴 틀에만 쓴다. 틀이 크면 <template> 을 쓴다

속성 · 클래스 · 스타일

li2.classList.add("on");
li2.classList.toggle("done");               // 있으면 빼고 없으면 넣는다
li2.classList.contains("done");             // true
li2.className;                              // "on done"

li2.dataset.dueDate = "2026-11-09";         // data-due-date="2026-11-09" — 이름이 바뀐다
li2.getAttribute("data-id");                // "2" — 값은 늘 문자열
li2.toggleAttribute("aria-current", true);

box.style.backgroundColor = "red";          // style="… background-color: red;"
box.style.setProperty("--x", "3");          // CSS 변수
getComputedStyle(box).width;                // "100px" — 실제로 적용된 값
box.hidden = true;                          // hidden 속성 — 화면에서 빠지고 offsetWidth 가 0
  • 모양은 CSS 의 클래스로 정해 두고 스크립트는 classList 로 클래스만 바꾼다. style 로 직접 바꾸는 것은 움직이는 위치 · 크기처럼 값이 계속 바뀔 때다
  • data-* 는 요소에 붙이는 내 값이다. 상태(data-state="open") 를 두면 CSS 의 [data-state="open"] 으로도 꾸민다

넣기 · 빼기

ul.append(li);                        // 끝에 — 여럿 · 글자도 받는다: ul.append(a, b, "글자")
ul.prepend(li);                       // 처음에
ul.children[0].after(li);             // 그 뒤에 (before 는 앞에)
ul.lastElementChild.remove();         // 빼기
ul.children[2].replaceWith("글자만");  // 바꾸기 — 글자 노드가 들어간다
ul.insertAdjacentHTML("beforeend", "<li>끝</li>");   // 틀을 HTML 로

<template> 의 내용은 화면에 그려지지 않고, 복사해서 채워 넣는다.

<template id="row">
  <li><span class="t"></span> <button class="del">삭제</button></li>
</template>
const row = document.getElementById("row").content.cloneNode(true);
row.querySelector(".t").textContent = "새 일";
ul.prepend(row);      // <li><span class="t">새 일</span> <button class="del">삭제</button></li>

여럿을 넣을 때는 모아서 한 번에 넣는다.

const frag = document.createDocumentFragment();
for (const t of items) frag.append(Object.assign(document.createElement("li"), { textContent: t }));
ul.append(frag);      // 화면은 한 번만 다시 그려진다 — ul.replaceChildren(...nodes) 는 비우고 넣는다

크기 · 위치

box.getBoundingClientRect();     // {x:8, y:179, width:100, height:50, top:179, right:108, bottom:229, left:8} — 화면 기준
box.offsetWidth;                 // 100 — 테두리까지의 폭
window.scrollY + box.getBoundingClientRect().top;   // 문서 기준 위치
box.scrollIntoView({ behavior: "smooth", block: "center" });
  • 위치 · 크기를 읽으면 브라우저가 배치를 바로 계산한다. 읽기와 쓰기를 번갈아 하면 느려지므로, 읽기를 모아 하고 쓰기를 모아 한다

언제 실행하나

<script type="module" src="app.js"></script>   <!-- 문서를 다 읽은 뒤 실행 — 요소가 다 있다 -->
<script defer src="app.js"></script>           <!-- 모듈이 아닐 때 같은 효과 -->
  • <head> 의 그냥 <script> 는 그 아래 요소가 아직 없어 null 이 나온다. defer · type="module" 을 쓰면 DOMContentLoaded 를 기다릴 일이 없다

예전에는

  • 브라우저마다 달라 $("#a .b") · .addClass() 같은 jQuery 로 감쌌다. 지금은 querySelectorAll · classList 다
  • parentNode.insertBefore(n, ref.nextSibling) 으로 뒤에 넣었다. 지금은 ref.after(n) 이다
  • 클래스를 className += " on" 처럼 문자열로 붙이고 정규식으로 뺐다. 지금은 classList 다
