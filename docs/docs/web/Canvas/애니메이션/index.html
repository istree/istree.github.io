캔버스의 애니메이션은 "상태를 조금 바꾸고 · 지우고 · 다시 그리기" 를 화면이 바뀔 때마다 되풀이하는 것이다. 되풀이는 requestAnimationFrame 으로 하고, 움직인 양은 지난 장면에서 흐른 시간에 비례하게 계산한다. 아래는 이 글의 공 튀기기를 쪽에서 실제로 돌린 것이다. 지우는 대신 반투명 흰색을 덮어 꼬리가 남고, 누르면 다시 시작한다.

장면 되풀이

const balls = [{ x: 40, y: 30, vx: 120, vy: 60, r: 10, c: "#4E79A7" }, /* … */];
const G = 300;                                   // 중력 — px/s²

function update(dt) {
  for (const b of balls) {
    b.vy += G * dt;                              // 속도는 px/s — 시간을 곱한다
    b.x += b.vx * dt;
    b.y += b.vy * dt;
    if (b.x < b.r || b.x > W - b.r) b.vx *= -1;  // 벽에 튕기기
    if (b.y > H - b.r) { b.y = H - b.r; b.vy *= -0.9; }   // 바닥 — 조금씩 힘을 잃는다
  }
}

function draw() {
  ctx.fillStyle = "rgb(255 255 255 / .25)";     // clearRect 대신 반투명 덮기 — 꼬리
  ctx.fillRect(0, 0, W, H);
  for (const b of balls) {
    ctx.beginPath();
    ctx.arc(b.x, b.y, b.r, 0, Math.PI * 2);
    ctx.fillStyle = b.c;
    ctx.fill();
  }
}

let last;
function frame(t) {                              // t — 쪽을 연 뒤 지난 ms
  const dt = Math.min((t - (last ?? t)) / 1000, 0.05);   // 초 — 탭을 오래 숨겼다 돌아와도 0.05 까지만
  last = t;
  update(dt);
  draw();
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
  • requestAnimationFrame 은 화면을 다시 그리기 직전에 한 번 부른다. 60Hz 화면은 1 초에 60 번, 120Hz 는 120 번이라, 장면마다 같은 양을 움직이면 화면에 따라 빠르기가 달라진다. 그래서 dt 를 곱한다
  • 탭을 숨기면 멈춘다. setInterval 과 달리 보이지 않는 탭에서 전기를 쓰지 않는다
  • 멈추려면 돌려받은 번호로 cancelAnimationFrame(id) 한다

마우스 · 터치

canvas.addEventListener("pointerdown", (e) => {
  const x = e.offsetX, y = e.offsetY;            // 캔버스 안 CSS 좌표
  const hit = balls.find((b) => Math.hypot(b.x - x, b.y - y) < b.r);
  if (hit) { drag = hit; canvas.setPointerCapture(e.pointerId); }   // 캔버스 밖으로 나가도 계속 받는다
});
canvas.addEventListener("pointermove", (e) => { if (drag) Object.assign(drag, { x: e.offsetX, y: e.offsetY, vx: 0, vy: 0 }); });
canvas.addEventListener("pointerup", () => (drag = null));
  • 원은 거리로, 사각형은 좌표 비교로, 복잡한 모양은 Path2D 와 isPointInPath 로 맞았는지 본다
  • 터치 화면에서 끌 때 쪽이 스크롤되지 않게 캔버스에 touch-action: none 을 준다

크기 따라가기

new ResizeObserver(([entry]) => {
  const { width, height } = entry.contentRect;
  canvas.width = width * dpr;
  canvas.height = height * dpr;
  ctx.scale(dpr, dpr);                           // 크기를 바꾸면 상태가 지워지므로 다시
  W = width; H = height;
}).observe(canvas);

빠르게

  • 바뀌지 않는 배경은 캔버스 하나에 한 번만 그리고, 움직이는 것은 그 위에 겹친 다른 캔버스에 그린다
  • 같은 그림(공 · 글자) 은 미리 작은 캔버스에 그려 두고 drawImage 로 찍는다. 매번 경로 · 글자를 그리는 것보다 빠르다
  • 무거운 그리기는 canvas.transferControlToOffscreen() 으로 Worker 에 넘긴다. 화면(메인 스레드) 이 버벅이지 않는다
  • 개발자 도구의 Performance 탭에서 한 장면이 16ms(60fps) 안에 끝나는지 본다
  • 움직임 줄이기를 켠 사용자(matchMedia("(prefers-reduced-motion: reduce)").matches) 에게는 멈춘 장면을 보인다

예전에는

  • setInterval(draw, 16) 으로 돌렸다. 화면과 박자가 맞지 않아 끊기고, 숨긴 탭에서도 돌았다
  • 장면마다 같은 양을 움직여, 느린 컴퓨터에서는 게임 전체가 느려졌다
