캔버스에 그리려면 getContext("2d") 로 붓(컨텍스트) 을 받아, 색 · 굵기를 정하고 사각형 · 경로 · 글자를 그린다. 경로는 beginPath() 로 시작해 점과 선을 적은 뒤 fill() · stroke() 로 칠한다. 아래는 이 글의 예제를 쪽에서 바로 그린 캔버스다. 하트 위에 마우스를 올리면 「Path2D」 절의 isPointInPath 로 맞았는지 본다.

하트 위에 마우스를 올려 보세요

시작 · DPI 대응

<canvas id="c" style="width: 396px; height: 220px"></canvas>
const canvas = document.getElementById("c");
const dpr = window.devicePixelRatio || 1;          // 레티나는 2
canvas.width = 396 * dpr;                          // 실제 픽셀 수 — 792
canvas.height = 220 * dpr;
const ctx = canvas.getContext("2d");
ctx.scale(dpr, dpr);                               // 그리는 좌표는 CSS 픽셀 그대로
  • canvas.width · height 는 픽셀 수, CSS 의 width · height 는 화면 크기다. 둘이 다르면 그림이 늘어나 흐려진다
  • 레티나 화면에서 픽셀 수를 devicePixelRatio 배로 늘리지 않으면 글자 · 선이 번진다
  • width · height 를 다시 넣으면 그림과 상태(scale 포함) 가 모두 지워진다. 크기를 바꾼 뒤에는 처음부터 그린다

사각형 · 경로

ctx.fillStyle = "#4E79A7";
ctx.fillRect(15, 15, 70, 50);                      // 칠한 사각형 (경로 없이 바로)
ctx.strokeRect(15, 15, 70, 50);                    // 테두리
ctx.clearRect(0, 0, canvas.width, canvas.height);  // 지우기 — 투명

ctx.beginPath();
ctx.roundRect(100, 15, 70, 50, 10);                // 둥근 사각형
ctx.fill();

ctx.beginPath();
ctx.arc(215, 40, 25, 0, Math.PI * 2);              // 원 — 가운데 · 반지름 · 시작각 · 끝각(라디안)
ctx.fill();

ctx.beginPath();                                   // 부채꼴
ctx.moveTo(290, 40);
ctx.arc(290, 40, 25, -Math.PI / 2, Math.PI * 0.75);   // 12 시 방향부터 시계 방향
ctx.closePath();
ctx.fill();
메서드 그리는 것
moveTo(x, y) · lineTo(x, y) 펜 옮기기 · 직선
arc(x, y, r, a0, a1) · ellipse(…) 원호 · 타원
quadraticCurveTo(cx, cy, x, y) 2 차 곡선
bezierCurveTo(c1x, c1y, c2x, c2y, x, y) 3 차 곡선
rect · roundRect 사각형 경로
closePath() 처음 점으로 닫기
  • beginPath() 를 빠뜨리면 앞의 경로까지 다시 칠해진다. 도형마다 새로 시작한다
  • 각도는 라디안이고 0 은 3 시 방향, 시계 방향으로 커진다

선 · 색

ctx.strokeStyle = "#4E79A7";
ctx.lineWidth = 4;
ctx.lineJoin = "round";                           // 꺾인 곳
ctx.lineCap = "round";                            // 끝
ctx.setLineDash([8, 5]);                          // 점선 — [] 로 되돌린다

const g = ctx.createLinearGradient(255, 95, 255, 165);   // 위에서 아래로
g.addColorStop(0, "#4E79A7");
g.addColorStop(1, "#A0CBE8");
ctx.fillStyle = g;
ctx.fillRect(255, 95, 60, 70);

ctx.globalAlpha = 0.5;                            // 그 뒤로 그리는 것 모두 반투명
ctx.shadowColor = "rgb(0 0 0 / .3)"; ctx.shadowBlur = 6;   // 그림자
  • 1px 선이 흐릿하면 좌표를 0.5 에 둔다(moveTo(10.5, 0)). 선이 픽셀 경계에 걸쳐 두 픽셀에 반씩 칠해지기 때문이다

변환 · save · restore

ctx.save();                                       // 지금 색 · 굵기 · 변환을 저장
ctx.translate(355, 40);                           // (0,0) 을 별의 가운데로
ctx.rotate(Math.PI / 10);                         // 18° 돌리기
ctx.beginPath();
for (let i = 0; i < 10; i++) {                    // 바깥 25 · 안 10 을 번갈아 — 별
  const r = i % 2 ? 10 : 25, a = (i * Math.PI) / 5 - Math.PI / 2;
  ctx.lineTo(r * Math.cos(a), r * Math.sin(a));
}
ctx.closePath();
ctx.fill();
ctx.restore();                                    // 저장한 때로 — 다음 그림에 변환이 남지 않는다
  • 변환 · 색을 바꾸는 그림은 save() · restore() 로 감싼다. 짝이 안 맞으면 그 뒤 그림이 모두 엉뚱한 곳에 그려진다
  • ctx.setTransform(dpr, 0, 0, dpr, 0, 0) 은 쌓인 변환을 지우고 DPI 배율만 남긴다

Path2D

경로를 객체로 만들어 두고 여러 번 그린다. SVG 경로 문자열도 그대로 받는다.

const heart = new Path2D("M10 30 A20 20 0 0 1 50 30 A20 20 0 0 1 90 30 Q90 60 50 90 Q10 60 10 30 Z");
ctx.save();
ctx.translate(330, 95);
ctx.scale(0.6, 0.6);
ctx.fill(heart);
ctx.isPointInPath(heart, 360 * dpr, 130 * dpr);   // true — 마우스가 하트 위에 있는지
ctx.restore();
  • 캔버스에는 요소가 없어 도형마다 클릭을 받을 수 없다. 캔버스의 click 에서 isPointInPath 로 어느 도형인지 찾는다
  • isPointInPath 의 점은 변환이 적용되지 않은 캔버스 픽셀 좌표다. 마우스는 e.offsetX * dpr 로 바꿔 넣는다

글자

ctx.font = "bold 15px sans-serif";               // CSS font 와 같은 형식
ctx.textAlign = "center";                         // x 를 가운데로 — left · right · start · end
ctx.textBaseline = "middle";                      // y 를 세로 가운데로 — top · alphabetic(기본) · bottom
ctx.fillText("캔버스에 그린 글자", 198, 200);
ctx.measureText("캔버스에 그린 글자").width;      // 111.7 — 글자 상자 · 말줄임에 쓴다
  • 줄바꿈은 없다. 폭을 measureText 로 재며 직접 나눈다
  • 웹 글꼴은 받기 전에 그리면 기본 글꼴로 나온다. await document.fonts.load("15px Pretendard") 뒤에 그린다

예전에는

  • roundRect 가 없어 arcTo 네 번으로 둥근 사각형을 그렸다
  • 레티나 화면이 나오기 전에는 canvas.width 를 CSS 크기와 같게 두었다. 그 코드를 지금 화면에서 보면 흐리다
