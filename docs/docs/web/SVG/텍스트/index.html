SVG 의 글자는 <text> 로 적고, 위치는 글자의 기준선(baseline) 왼쪽 끝을 x · y 로 준다. HTML 과 달리 저절로 줄이 바뀌지 않아, 여러 줄 · 일부만 다른 꾸밈은 <tspan> 으로 나눈다. 아래 그림은 이 글의 예제다. 그림은 쪽에 바로 넣은 SVG 라서, 개발자 도구로 도형마다 속성을 들여다볼 수 있다.

위치 · 맞춤

<text x="110" y="30" text-anchor="start">start</text>    <!-- x 에서 오른쪽으로 -->
<text x="110" y="60" text-anchor="middle">middle</text>  <!-- x 가 가운데 -->
<text x="110" y="90" text-anchor="end">end</text>        <!-- x 에서 끝난다 -->

<text x="50" y="50" text-anchor="middle" dominant-baseline="central">가운데</text>   <!-- 세로도 가운데 -->
  • y 는 글자의 아래(기준선) 다. 위쪽에 맞추려면 dominant-baseline="hanging", 세로 가운데는 central 이다
  • 글꼴 · 크기 · 굵기는 속성(font-size="14") 이나 CSS(font: bold 14px sans-serif) 로 준다. 색은 color 가 아니라 fill 이다

tspan

<text x="20" y="150" font-size="16">합계
  <tspan font-weight="bold" fill="#E15759">1,280</tspan>
  <tspan font-size="11" fill="#888" dy="-6">원</tspan>
</text>

<text x="20" y="40">                       <!-- 여러 줄 -->
  <tspan x="20" dy="0">첫째 줄</tspan>
  <tspan x="20" dy="1.4em">둘째 줄</tspan>
</text>
  • dx · dy 는 앞 글자에서 얼마나 옮길지, x · y 는 어디로 옮길지다. 줄을 바꿀 때는 x 로 왼쪽을 다시 맞추고 dy 로 내린다
  • 긴 글을 상자 폭에 맞춰 감아야 하면 <foreignObject> 안에 HTML 을 넣는다

경로를 따라

<path id="arc" d="M240 120 A80 80 0 0 1 400 120" fill="none"/>
<text font-size="15">
  <textPath href="#arc" startOffset="50%" text-anchor="middle">곡선을 따라 흐르는 글자</textPath>
</text>
  • 글자는 경로의 방향으로 흐른다. 반원 아래쪽에 쓰려면 경로를 반대 방향(오른쪽 → 왼쪽, 방향 깃발 0) 으로 그린다

돌리기 · 세로쓰기

<text x="320" y="200" text-anchor="middle" transform="rotate(-20 320 200)">돌린 글자</text>   <!-- (320,200) 을 중심으로 -->
<text x="30" y="20" writing-mode="vertical-rl">세로쓰기</text>
  • 차트의 세로축 이름은 transform="rotate(-90)" 으로 돌린다. 중심점을 주지 않으면 (0,0) 을 중심으로 돌아 그림 밖으로 나간다

배경색

SVG 글자에는 background 가 없다. 글자 상자를 재서 뒤에 rect 를 그리거나, 필터로 칠한다.

const box = text.getBBox();                         // {x: 20, y: 27.5, width: 104.3, height: 16.5}
const bg = document.createElementNS("http://www.w3.org/2000/svg", "rect");
for (const [k, v] of Object.entries({ x: box.x - 4, y: box.y - 2, width: box.width + 8, height: box.height + 4, fill: "#FFF59D" }))
  bg.setAttribute(k, v);
text.before(bg);                                    // 앞에 넣어야 글자 아래에 그려진다
<filter id="bg" x="-5%" y="-10%" width="110%" height="120%">
  <feFlood flood-color="#FFF59D"/>           <!-- 필터 영역을 노랗게 칠하고 -->
  <feComposite in="SourceGraphic"/>          <!-- 그 위에 글자를 얹는다 -->
</filter>
<text x="20" y="190" filter="url(#bg)">배경색이 있는 글자</text>
  • getBBox 는 글꼴을 다 받고 화면에 그려진 뒤에 잰다. display: none 안에서는 0 이 나온다

접근성

<svg role="img" aria-labelledby="t1">
  <title id="t1">요일별 걸음 수</title>
  …
</svg>
  • SVG 의 <text> 는 진짜 글자라 검색 · 선택 · 화면 읽기가 된다. 글자를 경로로 바꿔(아웃라인) 내보내면 그것이 사라진다
  • 꾸밈용 아이콘은 aria-hidden="true" 로 화면 읽기에서 뺀다

예전에는

  • 글자마다 위치를 정하려고 x="10 20 30" 처럼 여러 값을 썼다. 지금은 대부분 textPath · tspan 으로 한다
  • SVG 1.1 의 textArea 는 브라우저가 지원하지 않았다. 줄 감기는 지금도 foreignObject 로 한다
