SVG 의 그림은 기본 도형(rect · circle · ellipse · line · polyline · polygon) 과, 무엇이든 그리는 path 로 만든다. 기본 도형은 속성으로 위치 · 크기를 적고, path 는 d 속성에 "여기로 가서 · 선을 긋고 · 곡선을 그린다" 는 명령을 늘어놓는다. 아래 그림은 이 글의 예제다. 그림은 쪽에 바로 넣은 SVG 라서, 개발자 도구로 도형마다 속성을 들여다볼 수 있다.

기본 도형

<rect x="15" y="15" width="70" height="50" rx="8"/>        <!-- 왼쪽 위 · 크기 · 모서리 둥글기 -->
<circle cx="140" cy="40" r="25"/>                          <!-- 가운데 · 반지름 -->
<ellipse cx="225" cy="40" rx="40" ry="22"/>                <!-- 가로 · 세로 반지름 -->
<polygon points="330,15 355,65 305,65"/>                   <!-- 점들을 연결해 닫는다 -->
<line x1="375" y1="15" x2="405" y2="65" stroke="#2c4a6b"/> <!-- 선 — stroke 가 없으면 안 보인다 -->
<polyline points="15,170 45,130 75,150 105,115 135,140" fill="none" stroke="#59A14F"/>   <!-- 점들을 연결하되 닫지 않는다 -->
  • 모양을 정하는 속성(x · cx · r · width) 은 CSS 로도 바꿀 수 있다: circle { r: 30px; }
  • fill 의 기본은 검정이다. 꺾은선은 fill="none" 을 주지 않으면 안쪽이 검게 칠해진다

path 명령

명령 뜻 예
M x y 펜을 들고 옮긴다 M170 160
L x y · H x · V y 직선 · 가로선 · 세로선 H400
C x1 y1, x2 y2, x y 3 차 곡선 — 조절점 둘 C170 110, 240 110, 240 140
S x2 y2, x y 앞 곡선에 매끄럽게 이어지는 3 차 곡선 S300 175, 300 130
Q x1 y1, x y · T x y 2 차 곡선 — 조절점 하나 Q50 0, 100 50
A rx ry 회전 큰호 방향 x y 원호 A10 10 0 0 1 410 120
Z 처음 점으로 닫는다 Z
  • 대문자는 절대 좌표, 소문자는 지금 점에서 얼마나 가는지(상대 좌표) 다. h20 v10 은 오른쪽으로 20, 아래로 10 이다
  • 그림의 곡선은 (170,160) 에서 시작해 조절점 (170,110) · (240,110) 쪽으로 당겨지며 (240,140) 에 닿고, S 가 앞 조절점을 뒤집어 매끄럽게 이어 간다

원호

A rx ry x축회전 큰호 방향 x y 는 지금 점에서 (x,y) 까지 반지름 rx · ry 의 원호를 그린다. 두 점을 지나는 원호는 넷이라 두 깃발로 하나를 정한다.

깃발 0 1
큰호(large-arc) 180° 보다 작은 쪽 큰 쪽
방향(sweep) 시계 반대 시계 방향 
<!-- 둥근 모서리 말풍선 — 모서리마다 반지름 10 의 1/4 원호 -->
<path d="M330 110 H400 A10 10 0 0 1 410 120 V150 A10 10 0 0 1 400 160
         H360 L345 178 L348 160 H340 A10 10 0 0 1 330 150 Z"/>
// 도넛 차트의 한 조각 — 가운데 (cx,cy), 반지름 r, a0 ~ a1 라디안
function arc(cx, cy, r, a0, a1) {
  const [x0, y0] = [cx + r * Math.cos(a0), cy + r * Math.sin(a0)];
  const [x1, y1] = [cx + r * Math.cos(a1), cy + r * Math.sin(a1)];
  const large = a1 - a0 > Math.PI ? 1 : 0;
  return `M${x0} ${y0} A${r} ${r} 0 ${large} 1 ${x1} ${y1}`;
}
  • 시작과 끝이 같은 점이면 원호가 그려지지 않는다. 원 전체는 circle 을 쓰거나 원호 둘로 나눈다

길이 · 상자

polyline.getTotalLength();            // 175.1 — 선의 길이 (선 그리기 애니메이션에 쓴다)
arcPath.getPointAtLength(125.7);      // {x: 320, y: 40} — 반원의 한가운데
circle.getBBox();                     // 그림 좌표의 상자
circle.getBoundingClientRect();       // 화면 좌표의 상자 — viewBox 로 커진 크기
  • 안이 칠해지는 범위는 fill-rule 로 정한다. 도넛처럼 안에 구멍을 낸 path 는 fill-rule="evenodd" 를 준다
