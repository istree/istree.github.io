SVG 는 CSS 애니메이션 · SVG 자체의 애니메이션 요소(SMIL) · JavaScript 세 가지로 움직인다. 돌리기 · 색 바꾸기 · 선 그리기는 CSS 로, 경로를 따라 움직이기는 animateMotion 으로, 데이터에 따라 바뀌는 차트는 JavaScript 로 한다. 아래 그림은 이 글의 예제다. 같은 파일을 <img> 로 넣어도 움직인다. 그림은 쪽에 바로 넣은 SVG 라서, 개발자 도구로 도형마다 속성을 들여다볼 수 있다.

CSS

<style>
  .spin {
    transform-box: fill-box;          /* 기준을 도형 자신의 상자로 */
    transform-origin: center;         /* 그 가운데를 중심으로 */
    animation: spin 1s linear infinite;
  }
  @keyframes spin { to { transform: rotate(360deg); } }
</style>
<circle class="spin" cx="60" cy="65" r="28" fill="none" stroke="#4E79A7" stroke-width="7" stroke-dasharray="50 200"/>
  • SVG 도형의 transform-origin 은 기본으로 그림의 (0,0) 이다. transform-box: fill-box 를 주지 않으면 엉뚱한 곳을 중심으로 돈다
  • fill · stroke · opacity · transform 과 r · cx 같은 모양 속성도 CSS 로 움직인다

선 그리기

점선의 간격을 선 길이만큼 벌리고, 그 시작점을 밀어 두었다가 0 으로 당기면 선이 그려지는 것처럼 보인다.

.draw {
  stroke-dasharray: 300;             /* 선 길이(175) 보다 길게 — 긋기 300 · 띄우기 300 */
  stroke-dashoffset: 300;            /* 띄운 부분이 보이게 밀어 둔다 — 안 보인다 */
  animation: draw 2.5s ease-in-out infinite alternate;
}
@keyframes draw { to { stroke-dashoffset: 0; } }
const len = line.getTotalLength();   // 175.1 — 정확한 길이로 맞출 때
line.style.strokeDasharray = line.style.strokeDashoffset = len;
  • pathLength="1" 을 주면 실제 길이와 상관없이 선 길이를 1 로 셈해, stroke-dasharray: 1; stroke-dashoffset: 1; 로 어떤 선이든 같은 CSS 를 쓴다

SMIL

<path id="track" d="M290 95 C290 20, 400 20, 400 95" fill="none"/>
<circle r="8" fill="#E15759">
  <animateMotion dur="2s" repeatCount="indefinite" keyPoints="0;1;0" keyTimes="0;.5;1" calcMode="linear">
    <mpath href="#track"/>                     <!-- 이 경로를 따라 갔다가 돌아온다 -->
  </animateMotion>
</circle>

<rect x="320" y="110" width="50" height="14" rx="7">
  <animate attributeName="width" values="10;50;10" dur="1.6s" repeatCount="indefinite"/>
</rect>

<circle r="20">
  <animate attributeName="r" to="30" dur=".3s" begin="mouseover" fill="freeze"/>   <!-- 마우스를 올리면 시작, 끝 값에 멈춤 -->
</circle>
요소 움직이는 것
animate 속성 하나 — width · r · fill · d(같은 명령 꼴끼리)
animateTransform transform — type="rotate" from="0 50 50" to="360 50 50"
animateMotion 경로를 따라 위치 — rotate="auto" 면 방향도 따른다
set 시간이 되면 값을 바꾼다
  • 경로를 따라 움직이기 · 모양(d) 바꾸기는 SMIL 이 가장 쉽다. CSS 로는 offset-path: path("…") 로 된다
  • 스크립트 없이 파일 하나로 도는 로딩 그림을 만들 때 알맞다

JavaScript

// Web Animations API — CSS 애니메이션을 스크립트로
bar.animate([{ transform: "scaleY(0)" }, { transform: "scaleY(1)" }],
            { duration: 400, easing: "ease-out", fill: "both" });

// 값을 직접 바꾸며 — 데이터가 바뀌는 차트 · 게임
let start;
function frame(t) {
  start ??= t;
  const p = Math.min((t - start) / 600, 1);           // 0 → 1
  needle.setAttribute("transform", `rotate(${p * 120 - 60} 100 100)`);
  if (p < 1) requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
  • 움직임 줄이기를 켠 사용자는 멈춘다: @media (prefers-reduced-motion: reduce) { .spin, .draw { animation: none; } }
  • 도형이 수천 개면 SVG 는 느려진다. 그때는 Canvas 로 그린다

예전에는

  • Chrome 이 SMIL 을 없애겠다고 했다가(2015) 거둬들였다. 지금 모든 주요 브라우저가 지원한다
  • transform-box 가 없어 도형마다 transform-origin 을 그림 좌표로 계산해 적었다
