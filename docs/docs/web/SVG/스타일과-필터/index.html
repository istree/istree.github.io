SVG 도형은 안쪽 칠(fill) 과 테두리 선(stroke) 으로 꾸민다. 단색 말고도 그러데이션 · 무늬로 칠하고, 잘라 내기(clipPath) · 가리기(mask) · 필터(그림자 · 흐림) 를 건다. 꾸밈은 속성으로 적어도 되고 CSS 로 적어도 된다. 아래 그림은 이 글의 예제다. 그림은 쪽에 바로 넣은 SVG 라서, 개발자 도구로 도형마다 속성을 들여다볼 수 있다.

칠 · 선

<rect fill="#4E79A7" fill-opacity=".8" stroke="#2c4a6b" stroke-width="2"/>
<line stroke-width="6" stroke-linecap="round"/>              <!-- 선 끝: butt(기본) · round · square -->
<line stroke-dasharray="10 5"/>                              <!-- 10 긋고 5 띄우기 -->
<polyline stroke-linejoin="round" fill="none"/>              <!-- 꺾인 곳: miter(기본) · round · bevel -->
<path vector-effect="non-scaling-stroke"/>                   <!-- 키워도 선 굵기는 그대로 -->
  • 선은 도형의 테두리 가운데에 걸쳐 그려진다. stroke-width="6" 이면 안팎으로 3 씩이라, 그림 끝에 붙은 도형은 선이 반쯤 잘린다
  • 투명은 opacity(도형 전체) · fill-opacity · stroke-opacity 로 준다

CSS 로

<svg class="chart">
  <rect class="bar" … />
</svg>
<style>
  .bar { fill: var(--accent, #4E79A7); transition: fill .15s; }
  .bar:hover { fill: #F28E2B; }
  .icon { fill: currentColor; }        /* 글자색을 따른다 */
</style>
  • 속성(fill="red") 은 우선순위가 가장 낮아서 CSS 가 이긴다. style="fill: red" 는 CSS 보다 이긴다
  • <img> 로 넣은 SVG 는 바깥 CSS 가 닿지 않는다. 바꿔야 하면 HTML 안에 넣는다

그러데이션 · 무늬

<defs>
  <linearGradient id="sky" x1="0" y1="0" x2="0" y2="1">      <!-- 위에서 아래로 -->
    <stop offset="0" stop-color="#4E79A7"/>
    <stop offset="1" stop-color="#A0CBE8"/>
  </linearGradient>
  <radialGradient id="ball" cx=".35" cy=".35" r=".65">       <!-- 왼쪽 위가 밝은 공 -->
    <stop offset="0" stop-color="#fff"/>
    <stop offset="1" stop-color="#E15759"/>
  </radialGradient>
  <pattern id="dots" width="8" height="8" patternUnits="userSpaceOnUse">
    <circle cx="4" cy="4" r="1.6" fill="#59A14F"/>
  </pattern>
</defs>
<rect fill="url(#sky)" … />
<circle fill="url(#ball)" … />
<rect fill="url(#dots)" … />
  • 그러데이션의 좌표는 기본으로 도형 상자의 비율(0 ~ 1) 이다. 그림 좌표로 쓰려면 gradientUnits="userSpaceOnUse" 를 준다
  • 차트에서 색만으로 구분하기 어려울 때 무늬(pattern) 를 겹치면 흑백 인쇄 · 색약에도 구분된다

잘라 내기 · 가리기

<clipPath id="round"><circle cx="350" cy="45" r="32"/></clipPath>
<g clip-path="url(#round)"> … </g>                       <!-- 원 밖은 잘린다 — 프로필 사진 -->

<mask id="fade">
  <rect width="100%" height="100%" fill="url(#white-to-black)"/>
</mask>
<image href="photo.jpg" mask="url(#fade)"/>              <!-- 흰 곳은 보이고 검은 곳은 사라진다 -->
  • clipPath 는 안 · 밖 두 가지, mask 는 밝기에 따라 반투명까지 된다

필터

<filter id="shadow"><feDropShadow dx="2" dy="3" stdDeviation="2.5" flood-opacity=".35"/></filter>
<filter id="blur"><feGaussianBlur stdDeviation="3"/></filter>

<rect filter="url(#shadow)" … />
<circle filter="url(#blur)" … />
필터 요소 하는 일
feDropShadow 그림자
feGaussianBlur 흐리게
feColorMatrix 색 바꾸기 — 흑백 · 채도
feFlood · feComposite 단색 칠 · 겹치기 — 글자 배경
feMorphology 두껍게 · 가늘게 — 글자 테두리
feTurbulence · feDisplacementMap 잡음 · 일그러뜨리기 — 종이 질감
  • 흐림 · 그림자는 도형 밖으로 번진다. 잘리면 필터 영역을 넓힌다: x="-20%" y="-20%" width="140%" height="140%"
  • 여기서 만든 필터는 HTML 요소에도 건다: img { filter: url(#blur); }

예전에는

  • 그림자 하나에 feGaussianBlur · feOffset · feMerge 를 늘어놓았다. 지금은 feDropShadow 한 줄이다
  • 꾸밈을 모두 속성에 적어 파일이 길었다. 지금은 CSS 클래스 · 변수로 모아 테마 · 다크 모드를 바꾼다
