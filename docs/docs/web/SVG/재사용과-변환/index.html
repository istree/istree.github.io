같은 모양을 여러 번 그릴 때는 <defs> · <symbol> 에 한 번 적고 <use> 로 불러 쓴다. 묶음 <g> 와 transform 으로 옮기고 돌리고 키우면, 좌표를 다시 계산하지 않고 그림을 짜 맞출 수 있다. 아래 그림은 이 글의 예제다. 그림은 쪽에 바로 넣은 SVG 라서, 개발자 도구로 도형마다 속성을 들여다볼 수 있다.

defs · use

<defs>                                         <!-- 여기 적은 것은 그려지지 않는다 -->
  <circle id="dot" r="4"/>
</defs>
<use href="#dot" x="20" y="20" fill="#4E79A7"/>
<use href="#dot" x="40" y="20" fill="#E15759"/>
  • use 는 가리킨 요소를 그 자리에 복사해 그린다. 원본에 fill 이 없으면 use 에 준 fill 을 따른다 — 원본에 색을 적으면 바꿀 수 없다
  • use 안의 복사본은 그림자 트리(shadow tree) 라 CSS 선택자가 닿지 않는다. 바꿀 것은 CSS 변수로 넘긴다: 원본에 fill="var(--c)", use 에 style="--c: red"

symbol — 아이콘 묶음

<svg style="display: none">
  <symbol id="star" viewBox="-10 -10 20 20">
    <polygon points="0,-9 2.6,-3.4 8.6,-2.8 4.2,1.4 5.3,7.3 0,4.4 -5.3,7.3 -4.2,1.4 -8.6,-2.8 -2.6,-3.4"/>
  </symbol>
  <symbol id="trash" viewBox="0 0 24 24">…</symbol>
</svg>

<button><svg width="16" height="16" fill="currentColor"><use href="#star"/></svg> 즐겨찾기</button>
  • symbol 은 자기 viewBox 를 가져서, use 의 width · height 에 맞춰 커진다. 아이콘을 한 파일(스프라이트) 에 모아 두는 방법이다
  • 다른 파일의 것도 가리킨다: <use href="/icons.svg#star"/> (같은 출처만)

g · transform

<g transform="translate(250 45)">                     <!-- 이 묶음의 (0,0) 을 (250,45) 로 -->
  <rect x="-20" y="-15" width="40" height="30" transform="rotate(30)"/>      <!-- (0,0) 을 중심으로 30° -->
</g>
<g transform="translate(340 45)">
  <rect x="-20" y="-15" width="40" height="30" transform="scale(1.4 .7)"/>   <!-- 가로 1.4 배 · 세로 0.7 배 -->
</g>
변환 뜻
translate(x y) 옮기기
rotate(각 cx cy) (cx,cy) 를 중심으로 돌리기 — 중심을 빼면 (0,0)
scale(sx sy) 키우기 — (0,0) 을 기준으로
skewX(각) · skewY(각) 기울이기
matrix(a b c d e f) 위 모두를 행렬 하나로
  • 여럿을 적으면 오른쪽 것부터 적용된다. translate(100 0) rotate(45) 는 제자리에서 돌린 뒤 옮기고, 순서를 바꾸면 돌린 방향으로 옮겨진다
  • 돌리고 키울 도형은 (0,0) 을 가운데에 두고 그린 뒤 translate 로 옮긴다. 위 사각형이 x="-20" 인 까닭이다
  • 묶음의 fill · stroke · font-size 는 안의 도형이 물려받는다. 공통 속성은 g 에 한 번 적는다

marker — 화살표

<marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5"
        markerWidth="7" markerHeight="7" orient="auto-start-reverse">
  <path d="M0 0L10 5L0 10Z"/>
</marker>

<line x1="110" y1="142" x2="168" y2="142" stroke="#555" marker-end="url(#arrow)"/>
<path d="M350 160 V180 H70 V161" fill="none" stroke="#888" marker-end="url(#arrow)"/>
  • refX · refY 는 화살표의 어느 점을 선 끝에 맞출지다. 끝(10,5) 근처를 주면 화살촉이 선 끝에 닿는다
  • orient="auto" 는 선의 방향으로 돌린다. auto-start-reverse 는 marker-start 에 쓸 때 반대로 뒤집어, 양쪽 화살표를 하나로 만든다

예전에는

  • use · textPath 가 가리킬 때 xlink:href 를 썼고, 파일 머리에 xmlns:xlink 를 적었다. 지금은 href 다
  • 아이콘을 아이콘 글꼴(Font Awesome 의 글꼴판) 로 넣었다. 지금은 SVG symbol · 컴포넌트로 넣는다 — 선명하고 화면 읽기가 이상한 글자를 읽지 않는다
