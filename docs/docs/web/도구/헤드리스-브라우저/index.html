    • 헤드리스 브라우저

헤드리스 브라우저는 창 없이 도는 브라우저다. 진짜 브라우저 엔진이 쪽을 열고 스크립트를 실행하므로, 명령줄 · 스크립트로 화면 찍기 · PDF 만들기 · 데이터 모으기 · 자동 시험을 한다. 깔린 Chrome 에 --headless 를 주면 되고, 클릭 · 입력처럼 여러 단계를 다루려면 Puppeteer · Playwright 로 짠다. 아래 그림은 이 글의 Puppeteer 예제가 할 일 쪽에 두 개를 더하고 첫째를 누른 뒤 찍은 화면이다.

명령줄

$ CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
$ "$CHROME" --headless --screenshot=shot.png --window-size=1280,800 https://example.com
$ "$CHROME" --headless --print-to-pdf=page.pdf --no-pdf-header-footer http://127.0.0.1:8766/todo.html
22923 bytes written to file page.pdf
$ "$CHROME" --headless --dump-dom https://example.com > page.html    # 스크립트가 돈 뒤의 DOM
옵션 뜻
--window-size=1280,800 창 크기
--force-device-scale-factor=2 레티나처럼 두 배로 찍기
--virtual-time-budget=5000 타이머 · 애니메이션을 5 초 앞당겨 돌린 뒤 찍기
--force-dark-mode 다크 모드로
--user-data-dir=/tmp/prof 새 프로필 — 평소 Chrome 과 섞이지 않게
  • --dump-dom 은 스크립트의 비동기 작업(fetch · IndexedDB) 이 끝나기를 기다리지 않는다. 기다려야 하면 Puppeteer 로 한다
  • 판에 따라 옵션이 바뀐다. 옛 헤드리스는 chrome-headless-shell 이라는 따로 된 프로그램으로 나뉘었다

Puppeteer

$ npm i puppeteer            # 맞는 Chrome 을 함께 받는다 — 깔린 Chrome 을 쓰려면 puppeteer-core
import puppeteer from "puppeteer-core";

const browser = await puppeteer.launch({
  executablePath: "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",
});
const page = await browser.newPage();
page.on("console", (m) => console.log("페이지 콘솔:", m.text()));     // 페이지 콘솔: 준비됨
await page.setViewport({ width: 400, height: 190, deviceScaleFactor: 2 });
await page.goto("http://127.0.0.1:8766/todo.html", { waitUntil: "networkidle0" });

await page.type("input[name=title]", "우유 사기");
await page.click("button");
await page.waitForSelector("#list li");                              // 300ms 뒤에 생긴다 — 기다린다
await page.type("input[name=title]", "책 읽기");
await page.keyboard.press("Enter");
await page.waitForFunction(() => document.querySelectorAll("#list li").length === 2);
await page.click("#list li:first-child");

await page.$eval("#count", (el) => el.textContent);                  // "2 개"
await page.$$eval("#list li", (els) => els.map((li) => li.textContent + (li.classList.contains("done") ? " (끝)" : "")));
// ["우유 사기 (끝)", "책 읽기"]
await page.screenshot({ path: "todo.png" });
await page.pdf({ path: "todo.pdf", format: "A4" });
await browser.close();
  • $eval · evaluate 에 넘긴 함수는 브라우저 안에서 돈다. 바깥의 변수를 쓰려면 인자로 넘긴다: page.evaluate((n) => …, n)
  • 고정된 sleep 대신 waitForSelector · waitForFunction 으로 기다린다

Playwright

$ npm i -D @playwright/test && npx playwright install chromium     # 시험 도구 · 브라우저
import { chromium } from "playwright";   // 시험 없이 다룰 때 — 깔린 Chrome 은 channel: "chrome"

const browser = await chromium.launch({ channel: "chrome" });
const page = await browser.newPage();
await page.goto("http://127.0.0.1:8766/todo.html");
await page.getByLabel("새 일").fill("우유 사기");                     // 화면에 보이는 이름으로 찾는다
await page.getByRole("button", { name: "더하기" }).click();
await page.getByRole("listitem").filter({ hasText: "우유 사기" }).click();   // 생길 때까지 저절로 기다린다
await page.locator("#count").textContent();                          // "1 개"

await page.route("**/api/todos", (route) => route.fulfill({ json: [] }));   // 서버 응답을 가짜로
await browser.close();
// tests/todo.spec.js — npx playwright test
import { test, expect } from "@playwright/test";
test("할 일을 더한다", async ({ page }) => {
  await page.goto("/todo.html");
  await page.getByLabel("새 일").fill("우유 사기");
  await page.getByRole("button", { name: "더하기" }).click();
  await expect(page.locator("#count")).toHaveText("1 개");          // 될 때까지 다시 확인한다
});
Puppeteer Playwright
만든 곳 Chrome 팀 Microsoft (Puppeteer 를 만든 사람들)
브라우저 Chrome · Firefox Chromium · Firefox · WebKit(Safari 엔진)
기다리기 waitFor… 를 직접 동작마다 저절로
찾기 CSS 선택자 중심 역할 · 이름(getByRole) 중심
알맞은 곳 화면 찍기 · PDF · Chrome 만 다루는 스크립트 여러 브라우저 자동 시험
  • 시험은 Playwright 가 편하다. 실패한 시험의 화면 · 동영상 · 단계 기록(trace) 을 남기고, npx playwright codegen 이 내 클릭을 코드로 적어 준다

쓰는 곳 · 조심할 것

  • 화면 찍기: 문서 · 블로그 그림을 만들고, 화면이 바뀌었는지 견주는 시험(visual regression) 을 돌린다
  • PDF: HTML 로 만든 견적서 · 영수증을 인쇄 CSS(@media print) 로 꾸며 PDF 로 만든다
  • 데이터 모으기: 스크립트가 그리는 쪽에서 글을 꺼낸다. 사이트의 이용 약관 · robots.txt 를 지키고 요청 간격을 둔다
  • 헤드리스 Chrome 은 navigator.webdriver 가 true 이고 User-Agent 에 HeadlessChrome/156.0.0.0 이 들어간다. 사이트는 이런 흔적으로 자동화를 알아본다
  • 서버(Linux · Docker) 에서는 한글 글꼴(fonts-noto-cjk) 을 깔아야 한글이 네모로 나오지 않는다

예전에는

  • 헤드리스 브라우저는 PhantomJS(따로 만든 WebKit) 였다. 2017 년 Chrome 이 헤드리스를 넣자 개발이 멈췄다
  • 시험 자동화는 Selenium(WebDriver) 이 표준이었다. 지금도 쓰지만 새로 짜면 Playwright 가 많다
  • Chrome 의 옛 헤드리스는 진짜 Chrome 과 따로 만든 것이라 다르게 그리는 곳이 있었다. 2023 년 새 헤드리스(--headless=new) 가 진짜 Chrome 과 같은 코드가 되고 지금은 기본이다
