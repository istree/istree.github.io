웹을 만들 때는 브라우저 자체가 가장 중요한 도구다. 개발자 도구로 DOM · CSS · 네트워크 · 성능을 들여다보고, 화면 없이 도는 헤드리스 브라우저로 화면 찍기 · PDF 만들기 · 자동 시험을 스크립트로 돌린다.

리소스

  • Chrome DevTools — 패널마다 사용법
  • Firefox DevTools — Firefox 개발자 도구 안내서
  • Puppeteer — Chrome 을 스크립트로 다루는 Node 라이브러리
  • Playwright — Chromium · Firefox · WebKit 자동 시험 도구
