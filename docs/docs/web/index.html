웹 쪽은 HTML 로 내용과 구조를 적고, CSS 로 꾸미고 배치하고, JavaScript 로 DOM 을 고쳐 움직인다. 그림은 SVG(벡터 · 요소) 와 Canvas(픽셀) 로 그리고, 서버와는 HTTP 로 주고받으며, 저장 · 백그라운드 작업 · 장치 기능은 브라우저가 여는 웹 API 로 쓴다. 표준은 WHATWG · W3C 가 판 번호 없이 계속 고치고, 브라우저들이 함께 맞춰 간다.
