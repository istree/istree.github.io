HTML 문서는 <!doctype html> 로 시작하고, <head> 에 문서 정보(글자 집합 · 제목 · CSS · 스크립트) 를, <body> 에 보이는 내용을 둔다. 새 문서는 아래 틀에서 시작한다.

기본 틀

<!doctype html>                                   <!-- 표준 모드 — 빼면 옛 브라우저 흉내(quirks) 로 그린다 -->
<html lang="ko">                                  <!-- 문서 언어 — 화면 읽기 · 번역 · 글꼴 선택에 쓴다 -->
<head>
  <meta charset="utf-8">                          <!-- head 맨 앞에 -->
  <meta name="viewport" content="width=device-width, initial-scale=1">   <!-- 휴대폰에서 실제 폭으로 -->
  <title>메모</title>
  <meta name="description" content="할 일을 적는 메모">
  <link rel="icon" href="/favicon.svg" type="image/svg+xml">
  <link rel="stylesheet" href="/css/app.css">
  <script type="module" src="/js/app.js"></script>      <!-- 모듈은 늘 defer 처럼 — HTML 을 다 읽은 뒤 돈다 -->
</head>
<body>
  <h1>메모</h1>
  <p>할 일을 적는다.</p>
</body>
</html>
  • viewport 가 없으면 휴대폰이 화면을 980px 폭으로 그려 작게 줄여 보인다
  • lang 이 없으면 한글 · 일본어 · 중국어가 섞인 글자에서 글꼴이 엉뚱하게 선택된다

스크립트 불러오기

쓰기 받기 실행
<script src> HTML 읽기를 멈추고 받는다 받자마자
<script defer src> 함께 받는다 HTML 을 다 읽은 뒤, 적은 순서대로
<script async src> 함께 받는다 받자마자 (순서 없음) — 분석 도구 같은 독립 스크립트
<script type="module" src> 함께 받는다 defer 와 같다
  • 옛 코드는 <script> 를 </body> 바로 앞에 두어 늦게 돌렸다. 지금은 <head> 에 defer · module 로 둔다

공유 · 검색 정보

<meta property="og:title" content="메모">               <!-- 메신저 · SNS 미리보기 -->
<meta property="og:description" content="할 일을 적는 메모">
<meta property="og:image" content="https://example.com/og.png">
<link rel="canonical" href="https://example.com/memo">   <!-- 같은 내용의 주소가 여럿일 때 대표 주소 -->
<meta name="theme-color" content="#4E79A7">              <!-- 모바일 브라우저 주소창 색 -->

자주 쓰는 요소

요소 쓰는 곳
h1 ~ h6 제목 — 차례를 건너뛰지 않는다 (h2 다음 h4 로 가지 않는다)
p · br · hr 문단 · 줄 바꿈 · 주제 바꿈
ul · ol · li · dl · dt · dd 목록 · 순서 목록 · 용어 목록
a href 링크 — 새 창은 target="_blank" (rel="noopener" 는 지금 기본)
img · picture · figure · figcaption 그림 · 화면에 맞는 그림 선택 · 그림과 설명
table · thead · tbody · th · td · caption 표 — 배치에는 쓰지 않는다
div · span 뜻 없는 묶음 (블록 · 줄 안) — 맞는 태그가 없을 때만
code · pre · kbd · mark · time 코드 · 그대로 보이기 · 키 · 강조 · 날짜 
<img src="chart.png" alt="11 월 걸음 수 막대 그래프" width="640" height="360" loading="lazy">

<picture>                                                  <!-- 화면 · 형식에 맞는 그림 선택 -->
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="바다" width="800" height="600">
</picture>
  • img 에 width · height 를 적으면 그림을 받기 전에 자리를 잡아 화면이 밀리지 않는다
  • 화면 밖 그림은 loading="lazy" 로 늦게 받는다

특수 문자

&lt; &gt; &amp; &quot; &nbsp; &copy;     <!-- < > & " 공백(줄바꿈 없는) © -->
  • <meta charset="utf-8"> 이면 한글 · 기호는 그대로 쓴다. < · & 만 바꿔 쓴다

예전에는

  • <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd"> 처럼 긴 doctype 을 썼다. HTML5 부터 <!doctype html> 이다
  • <meta http-equiv="Content-Type" content="text/html; charset=utf-8"> 은 <meta charset="utf-8"> 로 줄었다
  • 배치를 table 로 짜고 꾸밈을 font · center · bgcolor 로 했다. 지금은 구조는 HTML, 모양은 CSS 로 나눈다
  • XHTML 처럼 <br /> 로 닫았다. HTML 에서는 <br> 이다(닫아도 오류는 아니다)
