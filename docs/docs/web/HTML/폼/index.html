폼은 사용자에게 값을 받아 서버로 보내는 HTML 이다. 입력 타입 · required · pattern 같은 속성만으로 브라우저가 값을 검사하고, 휴대폰은 타입에 맞는 키보드를 띄운다. 아래는 이 글의 가입 폼이 실제로 돌아가는 것이다. 칸을 비우거나 틀리게 넣고 가입을 눌러 보면 브라우저가 검사하고, 맞게 넣으면 서버로 보낼 값을 아래에 보인다(실제로 보내지는 않는다).

알림

폼 만들기

<form id="signup" action="/signup" method="post">
  <label>이메일
    <input type="email" name="email" required autocomplete="email" placeholder="me@example.com">
  </label>
  <label>비밀번호
    <input type="password" name="password" required minlength="8" autocomplete="new-password">
  </label>
  <label>나이
    <input type="number" name="age" min="14" max="120" value="30">
  </label>
  <label>전화
    <input type="tel" name="phone" pattern="01[016789]-?\d{3,4}-?\d{4}" title="010-1234-5678 꼴">
  </label>
  <fieldset>
    <legend>알림</legend>
    <label><input type="checkbox" name="notify" value="mail" checked> 메일</label>
    <label><input type="radio" name="freq" value="daily" checked> 매일</label>
    <label><input type="radio" name="freq" value="weekly"> 매주</label>
  </fieldset>
  <label>도시
    <input list="cities" name="city">
    <datalist id="cities"><option value="서울"><option value="부산"></datalist>
  </label>
  <button>가입</button>
</form>
  • 보낼 값은 name 이 있는 칸만 간다. name 을 빠뜨리면 조용히 빠진다
  • 입력 칸을 label 로 감싸거나 <label for="id"> 로 연결하면, 글자를 눌러도 칸에 포커스가 가고 화면 읽기 프로그램이 이름을 읽는다
  • 체크박스는 체크했을 때만 보내진다. 라디오는 같은 name 끼리 하나만 선택된다
  • autocomplete 를 맞게 주면 브라우저 · 비밀번호 관리자가 채워 준다(email · new-password · current-password · tel · postal-code …)

입력 타입

타입 받는 것 · 휴대폰 키보드
text · search 글자
email · url · tel 꼴을 검사 · 맞는 키보드
number · range 숫자 · 슬라이더 (min · max · step)
date · time · datetime-local · month 날짜 · 시간 선택
password 가린 글자
checkbox · radio 체크 · 하나 선택
file 파일 (accept="image/*" · multiple) — 폼은 enctype="multipart/form-data"
color · hidden 색 · 숨은 값
  • select · textarea 도 같은 방식으로 name · required 를 쓴다
  • datalist 는 선택할 값을 보여 주되 다른 값도 받는다. 정해진 값만 받으려면 select 다

검사

브라우저는 보내기 전에 required · 타입 · min · max · minlength · pattern 을 검사하고, 맞지 않으면 그 칸에 메시지를 띄우며 보내지 않는다. 스크립트에서도 같은 결과를 읽는다. 위 폼이 이 쪽에 있으므로, 개발자 도구 콘솔에서 아래 코드를 그대로 돌려 볼 수 있다.

const form = document.getElementById("signup");
form.checkValidity();                         // false — 비어 있는 필수 칸이 있다

const email = form.elements.email;
email.value = "geon";
email.validity.typeMismatch;                  // true
email.validationMessage;                      // "이메일 주소에 '@'를 포함해 주세요. 'geon'에 '@'가 없습니다."

form.elements.age.value = "10";
form.elements.age.validationMessage;          // "값은 14 이상이어야 합니다."

email.setCustomValidity("이미 쓰는 이메일이다");   // 서버에서 받은 오류를 그 칸의 메시지로
email.setCustomValidity("");                      // 다시 맞게
input:user-invalid { border-color: #E15759; }    /* 사용자가 손댄 뒤에만 — :invalid 는 처음부터 빨갛다 */
  • minlength · maxlength 는 사용자가 친 값만 검사한다. 스크립트로 value 에 넣은 짧은 값은 tooShort 가 false 다
  • 메시지는 브라우저 언어로 나온다. 바꾸려면 setCustomValidity 로 직접 넣는다
  • 브라우저 검사는 사용자를 돕는 것이다. 서버에서 늘 다시 검사한다

보내기

<form action="/search" method="get">    <!-- 값이 주소에 붙는다 — /search?q=… (검색 · 거르기) -->
<form action="/signup" method="post">   <!-- 값이 본문에 간다 (가입 · 저장) -->

스크립트로 보낼 때는 FormData 로 값을 모은다.

form.addEventListener("submit", async (e) => {
  e.preventDefault();                                  // 쪽을 옮기지 않는다
  const data = new FormData(form);
  Object.fromEntries(data);
  // {"email":"geon@example.com","password":"12345678","age":"30","phone":"010-1234-5678","notify":"mail","freq":"daily","city":""}
  await fetch(form.action, { method: "POST", body: data });   // multipart/form-data 로 간다
});
  • 값은 모두 문자열이다. 숫자는 받는 쪽에서 바꾼다
