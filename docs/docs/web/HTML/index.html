HTML 은 웹 문서의 내용과 구조를 적는 언어다. 태그로 제목 · 문단 · 목록 · 링크 · 그림 · 입력 칸을 표시하면, 브라우저가 그 구조(DOM) 를 만들어 CSS 로 꾸미고 JavaScript 로 움직인다. 태그를 뜻에 맞게 쓰면 검색 엔진 · 화면 읽기 프로그램이 문서를 제대로 이해한다. 지금 표준은 WHATWG 의 HTML Living Standard 하나이고, 판 번호 없이 계속 고친다.

  • W3C Markup Validation Service — 문법 검사
