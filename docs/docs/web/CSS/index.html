CSS 는 HTML 요소의 모양(색 · 글꼴 · 여백) 과 배치(Flexbox · Grid) 를 정하는 언어다. 선택자로 요소를 선택하고 속성을 적으며, 같은 요소에 규칙이 여럿 걸리면 우선순위(specificity) 와 나중에 적은 것이 이긴다. 지금은 변수 · 중첩 · 컨테이너 쿼리 · :has() 까지 브라우저가 지원해, 예전에 Sass 같은 도구로 하던 일을 CSS 만으로 한다.
