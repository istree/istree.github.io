선택자는 규칙을 걸 요소를 선택하는 식이다. 태그 · 클래스 · ID · 속성 · 상태 · 관계로 선택하고, 같은 요소에 규칙이 부딪치면 우선순위가 높은 쪽, 같으면 나중에 적은 쪽이 이긴다.

기본 선택자

p { }                       /* 태그 */
.note { }                   /* 클래스 */
#save { }                   /* ID */
.btn.primary { }            /* 둘 다 가진 요소 */
h1, h2 { }                  /* 여럿 */
* { }                       /* 모두 */

a[href^="https"] { }        /* 속성이 이것으로 시작 */
a[href$=".pdf"] { }         /* 이것으로 끝남 */
input[type="checkbox"] { }  /* 속성 값이 같음 */
[data-state="open"] { }     /* data- 속성으로 상태 표시 */

관계

nav a { }                   /* nav 안의 모든 a (자손) */
ul > li { }                 /* 바로 아래 자식만 */
h2 + p { }                  /* h2 바로 뒤의 p 하나 */
h2 ~ p { }                  /* h2 뒤의 형제 p 모두 */
.card:has(img) { }          /* img 를 가진 card — 부모 · 앞 형제를 선택한다 */
form:has(:invalid) button { opacity: .5; }   /* 잘못된 칸이 있는 폼의 단추 */
  • :has() 는 오랫동안 CSS 로 못 하던 "자식에 따라 부모 선택하기" 다. 지금 모든 주요 브라우저가 지원한다

상태 · 순서 (가상 클래스)

선택자 선택하는 것
:hover · :active · :focus 마우스를 올림 · 누르는 중 · 포커스
:focus-visible 키보드로 온 포커스 — 테두리는 여기에
:checked · :disabled · :invalid · :user-invalid 폼 상태
:first-child · :last-child · :nth-child(odd) · :nth-child(3n+1) 순서
:not(.done) 아닌 것
:is(h1, h2, h3) · :where(…) 여럿 중 하나 — :where 는 우선순위 0
:empty · :target · :root 비었음 · 주소의 #id · 맨 위(html) 
li:nth-child(odd) { background: #eee; }      /* 홀수 줄 */
.note:not(.done) { font-weight: bold; }      /* 끝나지 않은 것만 굵게 */

가상 요소

a[href^="https"]::after { content: " ↗"; }  /* 요소 뒤에 글자 */
.required::before { content: "* "; color: red; }
::placeholder { color: #999; }
::selection { background: #FFF59D; }
li::marker { color: #4E79A7; }

우선순위

선택자 점수 (ID · 클래스 · 태그)
p 0 · 0 · 1
.btn · [type] · :hover 0 · 1 · 0
.btn.primary 0 · 2 · 0
#save 1 · 0 · 0
style="…" 무엇보다 높다
!important 그것도 이긴다 
#save { color: red; }             /* 1·0·0 — 이긴다 */
.btn.primary { color: green; }    /* 0·2·0 */
button { color: blue; }           /* 0·0·1 */

.box { color: gray !important; }  /* #x { color: black } 보다 이긴다 */
  • 왼쪽 자리부터 견준다. 클래스를 아무리 많이 붙여도 ID 하나를 못 이긴다
  • 우선순위 싸움을 피하려면 스타일은 클래스로만 걸고, ID · !important 는 쓰지 않는다
  • 라이브러리 CSS 를 덮어쓰기 쉽게 하려면 @layer 로 층을 나눈다. 뒤에 선언한 층이 이긴다: @layer reset, lib, app;

중첩

.card {
  padding: 12px;
  & h2 { margin: 0; }              /* .card h2 */
  &:hover { border-color: #888; }  /* .card:hover */
  .dark & { background: #222; }    /* .dark .card */
}
  • CSS 중첩은 2023 년부터 모든 주요 브라우저에 있다. 예전에는 Sass · Less 로만 됐다

JavaScript 에서 같은 선택자

document.querySelector("ul > li.note:last-child");   // 처음 하나
document.querySelectorAll(".note:not(.done)");      // 모두
el.matches(".btn.primary");                          // 이 요소가 맞는지
el.closest(".card");                                 // 가장 가까운 조상

예전에는

  • 부모를 선택할 수 없어 JavaScript 로 클래스를 붙였다. 지금은 :has() 다
  • 중첩 · 변수가 없어 Sass · Less 를 썼다. 지금은 CSS 만으로 된다
  • 포커스 테두리를 :focus { outline: none } 으로 지워 키보드 사용자가 길을 잃었다. 지금은 :focus-visible 에만 테두리를 그린다
