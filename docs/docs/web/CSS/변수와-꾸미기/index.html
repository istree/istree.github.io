CSS 변수(사용자 정의 속성) 로 색 · 간격 · 둥글기를 한 곳에 모아 두면 테마 · 다크 모드를 변수만 바꿔 처리한다. 그 위에 전환(transition) · 필터 · 그림자로 꾸민다.

변수

:root {
  --gap: 8px;
  --accent: #4E79A7;
  --radius: 6px;
}
.btn {
  background: var(--accent);
  border-radius: var(--radius);
  padding: calc(var(--gap) * .75) calc(var(--gap) * 1.5);
}
.danger { --accent: #E15759; }       /* 이 요소 아래에서만 다른 값 — .btn.danger 는 빨강 */

@media (prefers-color-scheme: dark) {
  :root { --accent: #76B7B2; }        /* 다크 모드는 변수만 바꾼다 */
}
getComputedStyle(document.documentElement).getPropertyValue("--gap");   // "8px"
document.documentElement.style.setProperty("--accent", "#59A14F");      // 테마 바꾸기
  • 변수는 상속된다. 부모에서 바꾸면 그 아래 모두가 바뀐다
  • 없는 변수를 쓰면 그 속성이 통째로 무효가 된다. 기본값을 준다: var(--accent, #4E79A7)
  • 색을 섞을 때는 color-mix(in srgb, var(--accent), black 20%)(20% 어둡게) 를 쓴다

전환 · 애니메이션

.btn {
  transition: background-color 150ms ease, transform 150ms;   /* 바뀌는 속성 · 시간 */
  cursor: pointer;                                             /* 손 모양 커서 */
}
.btn:hover {
  background: color-mix(in srgb, var(--accent), black 20%);
  transform: translateY(-1px);
}

@keyframes spin { to { transform: rotate(360deg); } }
.loading { animation: spin 1s linear infinite; }

@media (prefers-reduced-motion: reduce) {                      /* 움직임 줄이기를 켠 사용자 */
  * { transition: none !important; animation: none !important; }
}
  • 움직일 때는 transform · opacity 를 바꾼다. 브라우저가 다시 배치하지 않아 부드럽다. width · top 을 움직이면 버벅인다
  • transition: all 은 쓰지 않는다. 뜻밖의 속성까지 움직이고 느려진다
  • display: none 은 전환되지 않는다. 나타나고 사라지는 것은 opacity · visibility 를 함께 바꾸거나, @starting-style 을 쓴다

필터 · 그림자

.card { box-shadow: 0 2px 8px rgb(0 0 0 / .15); }         /* 상자 그림자 */
.icon { filter: drop-shadow(0 2px 2px rgb(0 0 0 / .4)); }  /* 투명한 그림 · SVG 의 모양을 따라 그림자 */
.disabled { filter: grayscale(1) opacity(.6); }
.glass { backdrop-filter: blur(8px); background: rgb(255 255 255 / .6); }   /* 뒤를 흐리게 */
  • box-shadow 는 상자 모양으로, drop-shadow 는 그림의 실제 모양으로 그림자를 그린다. 아이콘 · PNG 에는 drop-shadow 를 쓴다
  • 더 복잡한 효과는 SVG 필터를 만들어 filter: url(#my-filter) 로 건다

초기화

.reset { all: revert; }        /* 이 요소의 모든 속성을 브라우저 기본 스타일로 */
button.plain { all: unset; }   /* 기본 스타일까지 지운 맨 상자 */
  • all: unset 으로 지운 단추는 포커스 테두리도 사라진다. :focus-visible 테두리를 다시 준다

글자

body {
  font-family: system-ui, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif;
  line-height: 1.6;
  word-break: keep-all;          /* 한글을 낱말 단위로 줄바꿈 */
  overflow-wrap: anywhere;       /* 긴 주소 · 영문은 아무 데서나 */
}
@font-face {
  font-family: "Pretendard";
  src: url("/fonts/Pretendard.woff2") format("woff2");
  font-display: swap;            /* 받는 동안 기본 글꼴로 보인다 */
}

예전에는

  • 색을 파일 곳곳에 되풀이해 적고, 바꿀 때 찾아 바꿨다. Sass 변수는 빌드할 때 굳어 실행 중에 바꿀 수 없었다. CSS 변수는 실행 중에 바뀐다
  • 브라우저마다 -webkit- · -moz- 접두사를 붙였다. 지금은 대부분 필요 없다(빌드 도구의 Autoprefixer 가 맡는다)
