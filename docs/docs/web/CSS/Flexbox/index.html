Flexbox 는 자식을 한 줄(가로 또는 세로) 로 늘어놓는 배치다. 메뉴 · 단추 줄 · 입력 칸과 단추 · 카드 줄처럼 한 방향으로 놓고, 남는 자리를 나누고, 세로 가운데를 맞추는 일에 쓴다. 두 방향(행과 열) 을 함께 맞춰야 하면 Grid 를 쓴다. 아래는 이 글의 예제를 실제 HTML · CSS 로 넣은 것이다. 상자의 오른쪽 아래 모서리를 끌어 폭을 바꾸면 남는 폭이 나뉘고 카드가 감기는 모습이 보인다.

justify-content: space-between · align-items: center
로고메뉴로그인
.input { flex: 1 } — 남는 폭 차지
아이콘입력 칸검색
.last { margin-left: auto } — 오른쪽으로 밀기
저장취소삭제
flex-wrap: wrap · flex: 1 1 100px — 폭을 줄이면 감긴다
카드 1카드 2카드 3카드 4

기본

.row {
  display: flex;
  gap: 8px;                          /* 자식 사이 간격 */
  flex-direction: row;               /* 기본 — 가로. column 이면 세로 */
  justify-content: space-between;    /* 주축(가로) 으로 나누기 */
  align-items: center;               /* 교차축(세로) 맞추기 */
}
속성 값
justify-content flex-start · center · flex-end · space-between · space-around · space-evenly
align-items stretch(기본 — 높이를 맞춰 늘림) · center · flex-start · flex-end · baseline
flex-wrap nowrap(기본) · wrap — 넘치면 다음 줄로
gap 자식 사이 간격 (row-gap · column-gap)
  • justify-content 는 늘어놓는 방향(주축), align-items 는 그 직각 방향이다. flex-direction: column 이면 둘의 방향이 바뀐다

자식의 크기

.search .input { flex: 1; }          /* 남는 폭을 모두 — 아이콘 · 단추는 제 크기 */
.cards > div { flex: 1 1 100px; }    /* 기본 100px, 남으면 늘고 모자라면 준다 */
.sidebar { flex: 0 0 240px; }        /* 240px 고정 */
.toolbar .last { margin-left: auto; }   /* 이것부터 오른쪽 끝으로 밀기 */
flex 뜻
flex: 1 1 1 0 — 남는 자리를 같은 몫으로
flex: 0 0 240px 늘지도 줄지도 않는 240px
flex: 1 1 100px 100px 에서 시작해 늘고 준다 — wrap 과 함께 카드 줄
flex: none 제 크기 그대로
  • 세 값은 flex-grow(남는 자리를 얼마나 가져갈지) · flex-shrink(모자랄 때 얼마나 줄지) · flex-basis(시작 크기) 다
  • 긴 글자가 든 자식이 줄지 않고 넘치면 min-width: 0 을 준다. flex 자식의 최소 폭이 기본으로 내용 폭이라서다
  • 자식 하나만 다르게 맞추려면 align-self: flex-end · 순서만 바꾸려면 order: -1 이다(화면 읽기 순서는 HTML 순서대로라 조심한다)

자주 쓰는 배치

/* 가로 · 세로 가운데 */
.center { display: flex; justify-content: center; align-items: center; }

/* 아래에 붙는 꼬리 — 본문이 짧아도 footer 가 화면 아래에 */
body { display: flex; flex-direction: column; min-height: 100dvh; }
main { flex: 1; }

/* 단추 줄 — 오른쪽 정렬 */
.actions { display: flex; justify-content: flex-end; gap: 8px; }

예전에는

  • 가로로 늘어놓으려고 float: left · display: inline-block 을 썼다. 세로 가운데 맞추기는 table-cell · line-height 꼼수였다
  • 간격을 자식의 margin 으로 주고 마지막 것만 빼는 :last-child { margin-right: 0 } 을 붙였다. 지금은 gap 이다
