모든 요소는 상자다. 안쪽부터 내용(content) · 안쪽 여백(padding) · 테두리(border) · 바깥 여백(margin) 이 겹겹이 있고, 요소의 크기와 서로의 간격은 이 넷과 display 로 정해진다. 크기 계산을 쉽게 하려고 거의 모든 사이트가 box-sizing: border-box 를 기본으로 둔다.

flowchart LR
  M["margin"] --> B["border"] --> P["padding"] --> C["content<br/>(width · height)"]

box-sizing

.a { width: 200px; padding: 20px; border: 5px solid; }                         /* 화면 폭 250px */
.b { width: 200px; padding: 20px; border: 5px solid; box-sizing: border-box; } /* 화면 폭 200px */
box-sizing width 가 뜻하는 것
content-box (기본) 내용만 — 여백 · 테두리가 더해진다
border-box 테두리까지 — 여백을 넣어도 크기가 그대로다 
*, *::before, *::after { box-sizing: border-box; }   /* 처음에 한 줄 */

margin

.mx { width: 300px; margin: 0 auto; }      /* 블록을 가로 가운데로 */
.card { margin: 8px 16px; }                /* 위아래 · 좌우 */
.card { margin: 4px 8px 12px 16px; }       /* 위 · 오른쪽 · 아래 · 왼쪽 (시계 방향) */

세로 margin 은 겹친다(margin collapsing). 위 상자의 margin-bottom: 30px 와 아래 상자의 margin-top: 20px 사이는 50px 이 아니라 30px 이다.

  • 첫 자식의 margin-top 은 부모를 뚫고 나가 부모를 함께 내린다. 부모에 display: flow-root · padding · border 를 주면 갇힌다
  • Flexbox · Grid 의 자식끼리는 겹치지 않는다. 간격은 gap 으로 준다

display

값 놓이는 법
block 한 줄을 다 차지한다 (div · p · h1)
inline 글자처럼 줄 안에 — width · height · 세로 margin 이 안 듣는다 (span · a)
inline-block 줄 안에 놓이되 크기 · 여백이 듣는다
flex · grid 자식을 배치하는 상자
none 없앤다 (자리도 없다) — visibility: hidden 은 자리는 남긴다
flow-root 안쪽을 따로 가둔다 — float · margin 이 새지 않는다

넘침

.scroll { max-height: 200px; overflow: auto; }          /* 넘치면 스크롤 */
.ellipsis {                                              /* 한 줄 말줄임 */
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
.clamp { display: -webkit-box; -webkit-line-clamp: 3; -webkit-box-orient: vertical; overflow: hidden; }   /* 세 줄 말줄임 */
.media { max-width: 100%; height: auto; }                /* 그림이 상자를 넘지 않게 */

단위

단위 기준
px 화면 픽셀(CSS 픽셀)
rem 맨 위(html) 의 글자 크기 — 보통 16px
em 자기(글자 크기) · 부모(그 밖) 의 글자 크기 — 겹치면 커진다
% 부모의 크기
vw · vh · dvh 화면 폭 · 높이의 1% (dvh 는 모바일 주소창을 뺀 높이)
ch 글자 "0" 의 폭 — 글 폭 맞추기(max-width: 65ch)
  • 글자 크기 2em 안에서 1.5rem 은 24px, 1.5em 은 48px 이다. 겹쳐 커지지 않게 글자 크기는 rem 으로 준다

float

img.left { float: left; margin-right: 12px; }   /* 글이 그림을 감아 흐른다 */
  • 지금 float 는 글이 그림을 감는 용도로만 쓴다. 배치는 Flexbox · Grid 다

예전에는

  • 단을 나누려고 float: left 를 늘어놓고, 부모가 높이를 잃으면 clearfix(::after { content: ""; display: table; clear: both; }) 를 붙였다. 지금은 Flexbox · Grid 와 display: flow-root 다
  • 가운데 맞추기를 position 과 음수 margin 으로 했다. 지금은 display: grid; place-items: center; 한 줄이다
