반응형은 화면 폭에 따라 배치를 바꾸는 것이다. 좁은 화면(휴대폰) 을 기본으로 짜고, 넓어질 때 미디어 쿼리로 칸을 늘린다(모바일 먼저). 요즘은 화면 폭 대신 그 컴포넌트가 놓인 상자의 폭에 맞추는 컨테이너 쿼리와, 쿼리 없이 크기가 따라오는 clamp · auto-fill 을 함께 쓴다.

시작

<meta name="viewport" content="width=device-width, initial-scale=1">
  • 이 줄이 없으면 휴대폰이 쪽을 980px 폭으로 그려 작게 줄인다. 미디어 쿼리도 맞지 않는다

미디어 쿼리

.cards { display: grid; gap: 8px; grid-template-columns: 1fr; }          /* 기본 — 한 열 */

@media (min-width: 640px) { .cards { grid-template-columns: repeat(2, 1fr); } }   /* 640 이상 — 두 열 */
@media (min-width: 960px) { .cards { grid-template-columns: repeat(3, 1fr); } }   /* 960 이상 — 세 열 */
화면 폭 열
500px 1
700px 2
1000px 3
  • 모바일 먼저(min-width) 로 쓰면 규칙이 덧붙기만 해서 읽기 쉽다
  • 나누는 폭은 기기가 아니라 내용이 깨지는 폭에 둔다. 640 · 960 처럼 몇 개면 충분하다
  • 범위는 @media (640px <= width < 960px) 처럼 비교식으로도 쓴다

사용자 설정

:root { color-scheme: light dark; }                        /* 폼 · 스크롤바도 다크 모드에 맞춘다 */
@media (prefers-color-scheme: dark) { :root { --accent: #76B7B2; } }
@media (prefers-reduced-motion: reduce) { * { transition: none !important; animation: none !important; } }
@media (hover: none) { .tooltip { display: none; } }       /* 터치 화면 — 마우스 올리기가 없다 */
@media print { nav, .ads { display: none; } }              /* 인쇄 */
matchMedia("(prefers-color-scheme: dark)").matches;      // 스크립트에서 같은 조건

컨테이너 쿼리

같은 카드가 넓은 본문에도, 좁은 사이드바에도 놓이면 화면 폭으로는 맞출 수 없다. 카드가 놓인 상자의 폭에 맞춘다.

.card { container-type: inline-size; }                      /* 이 상자의 폭을 잰다 */

.card .body { display: block; }
@container (min-width: 280px) {                             /* 카드가 280px 이상이면 */
  .card .body { display: flex; gap: 8px; }                  /* 그림과 글을 나란히 */
}
  • 컨테이너 쿼리 안에서는 cqi(컨테이너 폭의 1%) 단위를 쓴다: font-size: clamp(14px, 4cqi, 20px)

쿼리 없이

h1 { font-size: clamp(18px, 2vw + 12px, 32px); }    /* 최소 18 · 최대 32 사이에서 화면 폭을 따라 — 500px 에서 22px, 1000px 에서 32px */
.cards { grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); }   /* 들어가는 만큼 열 */
.media { max-width: 100%; height: auto; aspect-ratio: 16 / 9; object-fit: cover; }
.content { max-width: 65ch; margin-inline: auto; }  /* 읽기 좋은 글 폭 */

그림

<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1600.jpg 1600w"
     sizes="(min-width: 960px) 33vw, 100vw"
     alt="바다" width="800" height="600">
  • 브라우저가 화면 폭 · 화소 밀도에 맞는 파일을 선택한다. sizes 는 그림이 화면에서 차지할 폭이다

확인하기

  • Chrome 개발자 도구의 기기 모드(⌘⇧M) 로 폭 · 기기를 바꿔 본다
  • 렌더링 패널에서 prefers-color-scheme · prefers-reduced-motion 을 바꿔 본다

예전에는

  • 데스크톱용 쪽과 모바일용 쪽(m.example.com) 을 따로 만들었다
  • 컴포넌트를 화면 폭으로만 맞출 수 있어, 놓이는 자리마다 클래스(.card--sidebar) 를 따로 만들었다. 지금은 컨테이너 쿼리다
  • 글자 크기를 폭마다 미디어 쿼리로 바꿨다. 지금은 clamp() 한 줄이다
