Grid 는 행과 열을 함께 정하는 2 차원 배치다. 쪽의 큰 틀(머리 · 메뉴 · 본문 · 꼬리), 카드 목록, 폼처럼 칸을 맞춰야 하는 곳에 쓴다. 부모에서 칸을 정하고 자식은 그 칸에 들어가므로, HTML 을 바꾸지 않고 CSS 만으로 배치를 바꾼다. 아래는 이 글의 예제를 실제 HTML · CSS 로 넣은 것이다. 상자의 오른쪽 아래 모서리를 끌어 폭을 바꾸면 카드의 열 수가 바뀌고, 틀은 좁아지면 한 열로 바뀐다(글 안이라 화면 폭 대신 상자 폭을 재는 @container 로 했다).

grid-template-areas — 300px 아래면 한 열

nav
main
footer

칸 정하기

.cards {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;   /* 열 셋 — 200px, 남는 것을 반씩 */
  grid-template-rows: auto 1fr;           /* 행 둘 */
  gap: 8px;
}
값 뜻
1fr 남는 자리의 한 몫
repeat(3, 1fr) 같은 열 셋
minmax(90px, 1fr) 최소 90px, 최대 한 몫
auto 내용 크기
repeat(auto-fill, minmax(90px, 1fr)) 들어가는 만큼 열을 만든다 — 미디어 쿼리 없이 반응형
  • auto-fill 은 남는 자리에 빈 열을 남기고, auto-fit 은 빈 열을 접어 있는 카드를 늘린다. 카드가 적을 때 차이가 난다

영역 이름

.layout {
  display: grid;
  grid-template-columns: 120px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "nav    main"
    "footer footer";
  gap: 6px;
  min-height: 100dvh;
}
header { grid-area: header; }
nav    { grid-area: nav; }
main   { grid-area: main; }
footer { grid-area: footer; }

@media (max-width: 640px) {             /* 좁으면 한 열로 — HTML 은 그대로 */
  .layout {
    grid-template-columns: 1fr;
    grid-template-areas: "header" "nav" "main" "footer";
  }
}

자식 놓기

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(90px, 1fr));
  gap: 6px;
}
.cards > .wide { grid-column: span 2; }       /* 두 칸 차지 */
.hero { grid-column: 1 / -1; }                /* 첫 줄부터 끝 줄까지 — 한 행을 통째로 */
.box { grid-column: 2 / 4; grid-row: 1; }      /* 2 번 선부터 4 번 선까지 */
  • 두 칸짜리가 들어갈 자리가 없으면 다음 줄로 넘어가 빈칸이 남는다(위 카드를 좁혀 보면 1 옆이 빈다). 부모에 grid-auto-flow: dense 를 주면 뒤의 작은 칸이 그 빈자리를 채운다 — 순서가 바뀌므로 순서가 뜻이 있는 목록에는 쓰지 않는다
  • 번호는 칸이 아니라 칸 사이의 선이다. 열이 셋이면 선은 1 ~ 4 이고, -1 은 마지막 선이다
  • 칸 안의 맞춤: justify-items · align-items(모두), justify-self · align-self(하나). place-items: center 는 둘을 한 번에 정한다

폼

.form {
  display: grid;
  grid-template-columns: max-content 1fr;   /* 이름 칸은 가장 긴 이름만큼, 값 칸은 나머지 */
  gap: 8px 12px;
  align-items: center;
}

subgrid

카드마다 제목 · 본문 · 단추의 높이를 줄끼리 맞추려면 자식 그리드가 부모의 행을 물려받게 한다.

.cards { display: grid; grid-template-columns: repeat(3, 1fr); }
.card  { display: grid; grid-row: span 3; grid-template-rows: subgrid; }   /* 제목 · 본문 · 단추가 카드끼리 같은 높이 */

Flexbox 와 Grid

Flexbox Grid
방향 한 방향 행과 열
크기를 정하는 쪽 자식(내용) 부모(칸)
알맞은 곳 단추 줄 · 메뉴 · 입력 칸 + 단추 쪽의 틀 · 카드 목록 · 폼 · 대시보드
  • 둘을 섞어 쓴다. 쪽 틀은 Grid, 그 안의 머리줄은 Flexbox 로 한다

예전에는

  • 12 칸 그리드를 Bootstrap 의 .col-md-4 같은 클래스로 흉내 냈다. 지금은 CSS Grid 하나로 된다
  • IE 10 · 11 은 옛 문법(-ms-grid) 만 알아 같이 적었다. 지금은 필요 없다
