브라우저에 값을 저장하는 곳은 크기와 쓰임에 따라 정한다 — 작은 설정은 localStorage, 탭 하나에서만 쓸 임시 값은 sessionStorage, 많은 데이터 · 파일은 IndexedDB, 오프라인용 응답은 Cache API 다. 모두 출처(scheme · host · port) 마다 따로 있어서 다른 사이트가 읽지 못한다.

저장소 크기 꼴 쓰는 곳
localStorage 출처마다 5MB 쯤 문자열 키 · 값, 동기 테마 · 화면 설정 · 최근 검색어
sessionStorage 5MB 쯤 같음 — 탭을 닫으면 사라진다 쓰던 글 · 단계별 폼
IndexedDB 디스크 여유에 따라 GB 단위 객체 · Blob, 색인, 비동기 오프라인 데이터 · 받은 파일 · 큰 목록
Cache API 같음 요청 → 응답 서비스 워커의 오프라인 응답
OPFS 같음 파일 · 폴더 큰 파일 · SQLite(Wasm)
쿠키 4KB 쯤 요청마다 서버로 간다 로그인 세션 — 서버가 읽을 값

localStorage

localStorage.setItem("theme", "dark");
localStorage.setItem("count", 3);
localStorage.getItem("theme");          // "dark"
typeof localStorage.getItem("count");   // "string" — 숫자도 문자열로 저장된다
localStorage.getItem("none");           // null
localStorage.removeItem("theme");

localStorage.setItem("obj", { a: 1 });  // "[object Object]" — 객체는 망가진다
localStorage.setItem("settings", JSON.stringify({ fontSize: 16, tags: ["a"] }));
JSON.parse(localStorage.getItem("settings"));   // {fontSize: 16, tags: ["a"]}

try {
  localStorage.setItem("big", "x".repeat(6 * 1024 * 1024));
} catch (e) {
  e.name;                               // "QuotaExceededError" — 5MB 를 넘었다
}
  • 객체는 JSON.stringify · JSON.parse 로 넣고 뺀다. 읽을 때 null · 깨진 JSON 을 대비해 기본값을 둔다
  • 동기라서 큰 값을 자주 쓰면 화면이 멈춘다. 몇 KB 넘는 데이터는 IndexedDB 에 둔다
  • 다른 탭에서 바꾸면 이 탭에 storage 이벤트가 온다: addEventListener("storage", (e) => console.log(e.key, e.newValue))
  • 사생활 보호 모드 · 쿠키 차단 설정에서는 막히거나 탭을 닫으면 지워진다. 꼭 남아야 할 값은 서버에 둔다

IndexedDB

// 열기 — 판(1) 이 오르면 onupgradeneeded 에서 저장소 · 색인을 만든다
const db = await new Promise((resolve, reject) => {
  const r = indexedDB.open("todo", 1);
  r.onupgradeneeded = () => {
    const store = r.result.createObjectStore("todos", { keyPath: "id", autoIncrement: true });
    store.createIndex("due", "due");
  };
  r.onsuccess = () => resolve(r.result);
  r.onerror = () => reject(r.error);
});
const req = (r) => new Promise((ok, no) => { r.onsuccess = () => ok(r.result); r.onerror = () => no(r.error); });

// 쓰기 — 트랜잭션 하나에 여럿
const tx = db.transaction("todos", "readwrite");
tx.objectStore("todos").put({ title: "우유 사기", due: "2026-11-10", done: false });
tx.objectStore("todos").put({ title: "책 읽기", due: "2026-11-08", cover: new Blob([…], { type: "image/png" }) });
tx.objectStore("todos").put({ title: "운동", due: "2026-11-09", done: true });
await new Promise((r) => (tx.oncomplete = r));

// 읽기
const store = db.transaction("todos").objectStore("todos");
await req(store.get(1));        // {title: "우유 사기", due: "2026-11-10", done: false, id: 1}
await req(store.count());       // 3
await req(store.index("due").getAll(IDBKeyRange.upperBound("2026-11-09")));
// [{title: "책 읽기", due: "2026-11-08", cover: Blob, …}, {title: "운동", due: "2026-11-09", …}] — 날짜 순
  • 객체 · 배열 · Date · Blob · File 을 그대로 저장한다. JSON 으로 바꾸지 않아도 된다
  • 콜백 API 라 번거롭다. 실제로는 idb(await db.get("todos", 1)) 나 Dexie 로 감싼다
  • 저장 구조를 바꿀 때는 판을 올리고 onupgradeneeded 에서 옮긴다. 다른 탭이 옛 판으로 열고 있으면 blocked 가 난다

Cache API · OPFS

const cache = await caches.open("v1");
await cache.add("/store.html");                     // 요청해서 응답을 저장
(await cache.match("/store.html")).status;          // 200

const root = await navigator.storage.getDirectory(); // OPFS — 이 출처만의 숨은 파일 시스템
const fh = await root.getFileHandle("notes.txt", { create: true });
const w = await fh.createWritable();
await w.write("안녕");
await w.close();
await (await fh.getFile()).text();                  // "안녕"

얼마나 · 지워지나

const { usage, quota } = await navigator.storage.estimate();   // 쓴 양 · 쓸 수 있는 양 (바이트)
await navigator.storage.persisted();                          // false — 공간이 모자라면 브라우저가 지울 수 있다
await navigator.storage.persist();                            // 지우지 말라고 요청 — 브라우저가 판단한다
  • 디스크가 모자라면 브라우저는 오래 안 쓴 출처의 저장소부터 통째로 지운다. Safari 는 7 일 동안 찾지 않은 사이트의 스크립트 저장소를 지운다(홈 화면에 추가한 앱은 예외)
  • 개발자 도구 Application 탭에서 저장된 값을 보고 지운다

예전에는

  • 저장소가 쿠키뿐이라 설정까지 쿠키에 넣었고, 그 값이 요청마다 서버로 갔다
  • Web SQL(브라우저 안의 SQLite) 이 있었지만 표준이 되지 못하고 사라졌다. 지금은 IndexedDB 이고, SQL 이 필요하면 SQLite Wasm + OPFS 다
  • 오프라인용으로 AppCache(manifest 속성) 가 있었다. 동작을 다루기 어려워 없어지고 서비스 워커 + Cache API 로 바뀌었다
