브라우저는 화면 · 장치 · 운영체제의 기능을 API 로 연다. 요소가 화면에 보이는지 · 크기가 바뀌었는지 · DOM 이 바뀌었는지는 관찰자(Observer) 로 받고, 주소 · 뒤로 가기는 History API 로, 클립보드 · 알림 · 위치는 사용자의 허락을 받아 쓴다.

IntersectionObserver

요소가 화면(또는 스크롤 상자) 에 들어오고 나가는 것을 알린다. scroll 이벤트로 위치를 재는 것보다 가볍다.

const io = new IntersectionObserver((entries) => {
  for (const e of entries) {
    if (!e.isIntersecting) continue;
    e.target.src = e.target.dataset.src;          // 보이기 직전에 그림 받기
    io.unobserve(e.target);
  }
}, { rootMargin: "200px" });                       // 200px 앞에서 미리
document.querySelectorAll("img[data-src]").forEach((img) => io.observe(img));
// 처음: lazy:false → 스크롤해 다가가면: lazy:true, src 가 채워진다
  • 그림만이면 <img loading="lazy"> 한 줄로 된다. 관찰자는 무한 스크롤(목록 끝의 표시 요소가 보이면 다음 쪽 받기) · 보이면 움직이기 · 본 횟수 세기에 쓴다
  • 처음 observe 할 때 지금 상태를 한 번 알린다(false 도 온다)

ResizeObserver

const ro = new ResizeObserver(([e]) => {
  const { width, height } = e.contentRect;         // 200x100 → 320x100
  chart.resize(width, height);
});
ro.observe(box);
  • 창 크기가 아니라 그 요소의 크기다. 사이드바를 접어 본문만 넓어져도 알린다. 차트 · 캔버스를 다시 그릴 때 쓴다

MutationObserver

const mo = new MutationObserver((records) => {
  for (const r of records) console.log(r.type, r.addedNodes, r.attributeName);
  // "childList" [li] · "attributes" "data-state"
});
mo.observe(list, { childList: true, attributes: true, subtree: true });
mo.disconnect();
  • 내가 만들지 않은 코드(위젯 · 확장 프로그램) 가 DOM 을 바꾸는 것을 알아챌 때 쓴다. 내 코드가 바꾸는 것은 그 자리에서 처리한다
  • 알림은 바꾼 즉시가 아니라 그 작업이 끝난 뒤 모아서 온다

History API

쪽을 다시 읽지 않고 주소를 바꾼다. 탭 · 필터 상태를 주소에 남기면 새로 고침 · 링크 공유 · 뒤로 가기가 된다.

history.pushState({ tab: "done" }, "", "?tab=done");   // 주소만 바뀐다 — 기록이 하나 쌓인다
history.replaceState({ tab: "all" }, "", "?tab=all");   // 기록을 쌓지 않고 바꾼다 — 검색어 입력처럼 자주 바뀌는 것
addEventListener("popstate", (e) => render(e.state));    // 뒤로 · 앞으로 — 앞 상태 null, 주소 /feat.html
  • pushState 는 popstate 를 일으키지 않는다. 화면은 직접 바꾼다
  • 서버도 그 주소를 받아야 한다. /todos/7 로 새로 고침하면 서버가 같은 쪽(index.html) 을 돌려주게 설정한다

허락이 필요한 기능

기능 API 조건
클립보드 await navigator.clipboard.writeText("…") · readText() 쪽에 포커스 — 읽기는 허락
알림 await Notification.requestPermission() → new Notification("저장했다") 허락 — 클릭 같은 동작 안에서 묻는다
위치 navigator.geolocation.getCurrentPosition(ok, fail) 허락
카메라 · 마이크 await navigator.mediaDevices.getUserMedia({ video: true }) 허락
전체 화면 el.requestFullscreen() 클릭 같은 사용자 동작 안
공유 await navigator.share({ title, url }) 사용자 동작 안 — 주로 모바일 
await navigator.permissions.query({ name: "geolocation" });   // {state: "prompt"} — 아직 안 물었다 · granted · denied
Notification.permission;                                       // "default"
await navigator.clipboard.writeText("x");
// NotAllowedError: Failed to execute 'writeText' on 'Clipboard': Document is not focused.
  • 모두 https(보안 컨텍스트) 에서만 된다. isSecureContext 로 확인한다
  • 쪽을 열자마자 묻지 않는다. 사용자가 그 기능을 누를 때 묻는다 — 처음에 거절하면 다시 묻기 어렵다
  • 거절 · 미지원일 때 돌아갈 길을 둔다: 클립보드가 안 되면 글자를 선택해 두고 ⌘C 로 복사하라고 안내한다

그 밖

document.visibilityState;               // "visible" · "hidden" — 탭을 숨기면 동영상 멈춤 · 갱신 멈춤
addEventListener("visibilitychange", () => document.hidden ? pause() : resume());
navigator.onLine;                       // true — false 면 확실히 끊김, true 라도 인터넷이 된다는 뜻은 아니다
addEventListener("offline", showBanner);
matchMedia("(prefers-color-scheme: dark)").matches;   // false
navigator.wakeLock?.request("screen");  // 화면 꺼짐 막기 — 요리법 · 발표

예전에는

  • 보이는지 알려고 scroll 마다 getBoundingClientRect 를 재 쪽이 버벅였다. 지금은 IntersectionObserver 다
  • 크기 변화는 window.resize 만 받을 수 있어, 요소 크기는 타이머로 재곤 했다
  • 주소를 바꾸려고 #!/todos/7 처럼 해시 뒤에 경로를 적었다(해시뱅). 지금은 History API 로 진짜 경로를 쓴다
