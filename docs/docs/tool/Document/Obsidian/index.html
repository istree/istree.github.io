Obsidian

헤더 크기 조절

옵시디언에서 문서의 # 헤더 크기를 조정하고 싶은 경우가 있다. 사용자 CSS(사용자 스타일시트) 를 사용한다.

  • 옵시디언에서 CSS 편집 활성화
    • 설정(Settings) → 모양(Appearance) → 고급 옵션(Advanced)에서
      **"개별 CSS 파일 사용(Use custom CSS snippets)"**을 활성화 한다.
  • CSS 스니펫 폴더 열기
    • 같은 화면에서 "스니펫 폴더 열기(Open snippets folder)" 버튼을 클릭해 폴더를 연다.
  • 새 CSS 파일 생성
    • 예: custom-headings.css 라는 이름의 파일을 만들고, 다음과 같이 편집한다.
/* 모든 헤더에 동일한 스타일 */
h1, h2, h3, h4, h5, h6,
.cm-s-obsidian .cm-header-1,
.cm-s-obsidian .cm-header-2,
.cm-s-obsidian .cm-header-3,
.cm-s-obsidian .cm-header-4,
.cm-s-obsidian .cm-header-5,
.cm-s-obsidian .cm-header-6 {
  font-weight: 600 !important; /* semi bold */
}

h1, .cm-s-obsidian .cm-header-1 { font-size: 15pt !important; }
h2, .cm-s-obsidian .cm-header-2 { font-size: 14pt !important; }
h3, .cm-s-obsidian .cm-header-3 { font-size: 13pt !important; }
h4, .cm-s-obsidian .cm-header-4 { font-size: 12pt !important; }
h5, .cm-s-obsidian .cm-header-5 { font-size: 11pt !important; }
h6, .cm-s-obsidian .cm-header-6 { font-size: 10pt !important; }
  • 옵시디언에서 스니펫 활성화
    • 다시 설정 > 모양 > CSS 스니펫 메뉴로 가서, 방금 만든 custom-headings 스니펫을 활성화 한다.
