11ty 때는 빌드해서 GitHub Page 저장소에 복사하고 push 했다. 이번에는 GitHub Actions 로 한다.

원고 저장소에 push 할 때마다 배포하면 너무 잦아서 하루 세 번 예약으로 돌린다.

cron 은 UTC 라서 한국 시간에서 9시간을 뺀다.

on:
  schedule:
    - cron: "0 20 * * *"   # 5:00
    - cron: "30 2 * * *"   # 11:30
    - cron: "30 8 * * *"   # 17:30
  workflow_dispatch:

바뀐 것이 없으면 건너뛴다.

배포 커밋 메시지에 원고 저장소의 커밋을 적어 두고, 다음에 그 커밋 뒤로 바뀐 것이 있는지 본다.

git commit -m "Deploy from life" -m "Source: istree/life@${GITHUB_SHA}"
last=$(git -C site log -1 --grep='^Source: istree/life@' --format=%B | grep -oE 'istree/life@[0-9a-f]{40}' | cut -d@ -f2)
git -C life diff --quiet "$last" HEAD -- page/dev note/dev/page && echo "건너뜀"

다른 저장소에 push 하려면 권한이 필요하다. PAT 대신 배포 키를 사용했다. 그 저장소 하나에만 쓸 수 있고 만료가 없다.

ssh-keygen -t ed25519 -N "" -f deploykey
gh repo deploy-key add deploykey.pub -R istree/istree.github.io --allow-write
gh secret set PAGES_DEPLOY_KEY -R istree/life < deploykey
- uses: actions/checkout@v4
  with:
    repository: istree/istree.github.io
    ssh-key: ${{ secrets.PAGES_DEPLOY_KEY }}

처음 돌렸을 때 npm ci 가 실패했다. package-lock.json 에 Linux 에서 쓰는 패키지가 빠져 있었다. 잠금 파일을 새로 만들어 해결했다.
