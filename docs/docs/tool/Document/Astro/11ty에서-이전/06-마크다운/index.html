Astro 7 은 Sätteri 라는 자체 마크다운 처리기가 기본이다.

11ty(markdown-it)와 결과를 맞추려고 몇 가지를 바꿨다.

import { satteri } from "@astrojs/markdown-satteri";

markdown: {
  syntaxHighlight: "prism",
  processor: satteri({ features: { smartPunctuation: false } }),
},
  • 따옴표와 대시를 바꾸는 smartPunctuation 이 기본으로 켜져 있다. 끈다.
  • 문법 강조는 Shiki 가 기본이다. 쓰던 Prism 테마를 그대로 쓰려고 prism 으로 바꾼다.

달라지는 것도 있다.

  • 본문에 그냥 적은 URL 이 링크가 된다. (GFM)
  • 언어를 적지 않은 코드 블록에 language-plaintext 가 붙는다.
  • 마크다운 속 이미지는 webp 로 줄여서 /_astro/ 로 옮긴다.

Liquid

11ty는 마크다운을 Liquid 로 먼저 처리한다.

그래서 코드 예시를 {% raw %} 로 감싸 두었는데 Astro에서는 그대로 보인다. 감싼 줄을 지웠다.

마크다운 안에서 Liquid 로 글 목록을 만들던 곳은 frontmatter 로 바꾸고, 레이아웃이 목록을 붙이게 했다.
