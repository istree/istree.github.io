11ty는 폴더의 폴더이름.json 에 적은 tags 를 아래 글에 병합해준다. (Data Cascade)

Astro에는 이런 기능이 없어서 직접 만든다.

파일 이름은 index.json 으로 바꿨다. index.md 와 짝이 맞고, 폴더 이름을 바꿔도 같이 바꿀 일이 없다.

import.meta.glob 으로 json 을 모두 읽고, 글의 경로를 위에서부터 따라가며 태그를 쌓는다.

const dirData = import.meta.glob("../../../../../page/dev/**/*.json", { eager: true });

function tagsFor(kind, id, own) {
  // posts/programming/글 → posts, posts/programming
  const dirs = [kind, ...id.split("/").slice(0, -1).map((_, i, a) => `${kind}/${a.slice(0, i + 1).join("/")}`)];
  const out = [];
  for (const d of dirs) out.push(...asList(dirData[`${DIR}/${d}/index.json`]?.default.tags));
  out.push(...asList(own));
  return [...new Set(out)];
}

예를 들어 docs/language/JavaScript/React 하위의 글은 다음 태그를 가진다.

tags: [정리, Javascript, React]

11ty 컬렉션 이름(all 등)이 태그 목록에 섞여 나오던 것은 이참에 뺐다.
