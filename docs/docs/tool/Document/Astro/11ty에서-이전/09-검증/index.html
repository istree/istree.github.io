옮기기 전에 11ty 로 한 번 빌드해 두고, Astro 결과와 페이지마다 비교했다.

공백과 줄바꿈 차이는 무시하고 태그, 속성, 글자를 맞대었다.

210 페이지의 주소가 모두 같았고, 다른 곳은 마크다운 처리기 차이뿐이었다.

링크는 파일이 있는지만 보면 놓친다. 끝 / 문제가 그랬다.

미리 보기 서버를 띄워서 페이지마다 링크를 실제로 요청해 보는 편이 확실하다.

npm run build
npx astro preview
