05 글로벌 데이터

Jekyll로 작업된 파일을 그대로 옮기면 참조하는 변수들이 없어서 오류가 난다.

예를 들어 site.baseurl 등의 변수가 없기 때문에 일단 돌리기 위해 빈값이라도 만들어 준다.

Jekyll과 동일하게 _data 라는 디렉토리 이름을 사용한다.

_data 디렉토리를 만들고 site.js 파일을 만든다.

_data/
├─ site.js

site.js를 작성한다.

module.exports = {
  locale : 'ko',
  title: 'any site',
  email: 'mail@anysite.domain',
  baseurl: 'anysite.domain'  
};

js로 하는 이유는 좀더 유연하게 사용할 수 있고 async로 빌드 시점에서 외부의 데이터를 가져올 수 도 있다. json으로 작성해도 된다.

서브 디렉토리로 확장도 가능하다.

site.data.navigation 식으로 가져오는 경우

_data/
├─ site/
│  ├─ data/
│  │  ├─ navigation.js

디렉토리 계층과 같은 구조로 만들어 사용한다.

헷갈릴 수 있으나 직접 해보면 바로 알 수 있다.
