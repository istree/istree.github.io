10 태그

11ty는 tags 로 게시물을 분류한다.

예를 들어 posts의 모든 게시물을 '기록' 이라는 태그로 분류하고 싶다면

posts.json을 다음과 같이 작성한다.

{
  "tags": "기록"
}

태그를 여러개 지정할 경우 배열 연산자로 묶어준다.

---
tags: [11ty, Jekyll]
---

tags에 Data Cascade 가 적용될 경우 배열을 병합한다.

만약 위 게시물이 posts 하위에 있다면 실제 태그는 다음과 같다.

---
tags: [ 기록, 11ty, Jekyll]
---
