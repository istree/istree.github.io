03 레이아웃

11ty에서 레이아웃은 Jekyll과 달리 _includes 하나로 통일되어 있다.

Jekyll은 _layouts와 _includes로 쪼개져 있다.

11ty는 _includes만 있기 때문에 _includes 밑에 _layouts 디렉토리를 layouts로 넣는다.

예를 들어 아래 구조와 같다면

_includes/
├─ layouts/
│  ├─ archive.liquid
│  ├─ default.liquid
│  ├─ single.liquid

YAML일 경우 다음과 같이 사용한다.

---
layout: layouts/archive.liquid
---
