09 계산된 데이터

앞서 제목 필터 만들어 사용하는 경우

{{ page | title }}

페이지마다 매번 이런식으로 사용하기 귀찮다.

Computed Data(계산된 데이터) 기능을 사용하면 title을 미리 처리해 놓을 수 있다.

예를 들어 posts 디렉토리 내에 모든 제목을 미리 필터로 처리하고 싶다면

posts.json을 만들어서 다음과 같이 작성한다.

{
  "eleventyComputed": {
    "title": "{{ page | title }}"
  }
}

title 필터가 적용된 title이 항상 존재한다. 간혹 index.md 같은 특수한 파일은 빈값으로 나오기 때문에 제목을 꼭 명시해주는 것이 좋다.

{{ title }}
