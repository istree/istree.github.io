02 실행

실행

다음 명령어로 서버를 실행한다.

npx @11ty/eleventy --serve

아무 옵션 없이 실행하면 알아서 8080 포트를 선택한다.

접속

테스트 http://localhost:8080

아무것도 없어서 Cannot GET / 이라고 표시된다.

index.md를 만들어서 내용을 넣으면 결과가 _site 디렉토리에 출력된다.

echo "Hello 11ty" > index.md

브라우저가 갱신되고 Hello 11ty가 표시된다.

옵션

--port

포트를 지정한다.

--input

대상 디렉토리를 지정한다. 각종 스크립트와 문서를 디렉토리로 구분해서 사용 할 경우

--quite

11ty가 파일 갱신 시 Writing 로그를 출력하지 않는다. 켜놓으면 디버깅 할때 본인이 출력한 console.log를 확인하기 편하다.

예) source 디렉토리의 내용을 빌드하고 8081 포트로 서버를 실행하며 Writing 로그를 출력하지 않는다.

npx @11ty/eleventy --serve --port=8081 --input=source --quiet
