Mac 은 Apple 의 macOS 를 쓰는 컴퓨터다. Unix 바탕이라 터미널에서 리눅스와 비슷한 명령 · 셸을 쓰고, 개발 도구는 Homebrew 같은 패키지 관리자로 깐다. 단축키 · 창 배치 · 키보드 동작처럼 운영체제가 정해 둔 것은 자동화 앱(Hammerspoon) 이나 키 바꾸기 앱(Karabiner-Elements) 으로 손에 맞게 바꾼다.
