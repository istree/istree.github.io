Hammerspoon 을 설치하고 ~/.hammerspoon/init.lua 에 Lua 로 설정을 적는다. 고친 설정은 다시 불러와야 적용된다.

설치

brew install --cask hammerspoon
  • 처음 띄우면 손쉬운 사용 권한을 묻는다. 「시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용」 에서 Hammerspoon 을 켜야 단축키 · 키 이벤트가 동작한다
  • 메뉴 막대 아이콘의 Preferences 에서 「Launch Hammerspoon at login」 을 켜 두면 로그인할 때 함께 뜬다

init.lua

hs.hotkey.bind({'cmd', 'alt', 'ctrl'}, 'H', function()
	hs.alert.show('Hello World')
end)
  • Hammerspoon 은 시작할 때 ~/.hammerspoon/init.lua 하나만 읽는다. 다른 파일은 require('이름') 으로 불러오고, ~/.hammerspoon/이름.lua 를 찾는다
  • 메뉴 막대 아이콘의 Console 에 print 출력과 오류가 나온다. 콘솔 아래 입력칸에 Lua 를 쳐서 바로 돌려 볼 수 있다
  • 와처 · 타이머처럼 계속 살아 있어야 하는 객체는 전역 변수에 담는다. init.lua 도 끝나면 사라지는 한 범위라, local 에 두면 가비지 컬렉션으로 언젠가 멈춘다

다시 불러오기

메뉴 막대 아이콘의 Reload Config 를 누르면 init.lua 를 처음부터 다시 읽는다. 터미널에서 하려면 hs.ipc 를 불러오고 hs 명령을 깐다.

require('hs.ipc')                    -- init.lua 에

hs.ipc.cliInstall('/opt/homebrew')   -- 한 번만, 콘솔에서. /opt/homebrew/bin/hs 를 만든다
hs -c 'hs.reload()'                            # 다시 불러오기
hs -c 'return hs.keycodes.currentSourceID()'   # 값 보기
  • cliInstall 의 기본 위치는 /usr/local 이다. Apple Silicon 맥에서는 Homebrew 와 같은 /opt/homebrew 를 주면 이미 PATH 에 있다
  • hs.ipc 를 불러오기 전에는 hs 가 can't access Hammerspoon message port 로 실패한다. 처음 한 번은 Reload Config 로 불러온다
  • hs.reload() 로 다시 불러오는 동안에는 연결이 끊겨 잠깐 같은 오류가 난다

저장하면 다시 불러오기

hs.pathwatcher 로 설정 폴더를 지켜보다가 .lua 가 바뀌면 다시 불러온다.

local function reloadOnLua(paths)
	for _, path in ipairs(paths) do
		if path:sub(-4) == '.lua' then
			hs.reload()
			return
		end
	end
end

configWatcher = hs.pathwatcher.new(hs.configdir, reloadOnLua):start()
  • hs.configdir 은 ~/.hammerspoon 이다
  • configWatcher 는 전역이다. local 이면 언젠가 지켜보기가 멈춘다

설정 파일을 dotfiles 저장소에 두고 ~/.hammerspoon/init.lua 를 링크로 걸어 쓰면, 저장소의 파일을 고쳐도 링크가 있는 ~/.hammerspoon 에는 알림이 오지 않는다. 알림은 실제 파일이 있는 폴더에만 온다. 실제 폴더를 찾아 함께 지켜본다.

local realConfigDir = hs.fs.pathToAbsolute(hs.configdir .. '/init.lua'):match('(.*)/')
configWatchers = { hs.pathwatcher.new(hs.configdir, reloadOnLua):start() }
if realConfigDir ~= hs.configdir then
	table.insert(configWatchers, hs.pathwatcher.new(realConfigDir, reloadOnLua):start())
end
  • hs.fs.pathToAbsolute 는 링크를 따라가 실제 경로를 돌려준다
