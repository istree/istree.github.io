키 바꾸기

목록 · Hammerspoon
  • 개요
  • 시작하기
  • 키 바꾸기
  • 입력기 전환
  • 원격 데스크톱

macOS 는 hidutil 명령으로 키를 다른 키로 바꿀 수 있다. 따로 프로그램을 깔지 않아도 되지만, 재부팅하면 풀린다. Hammerspoon 이 시작할 때마다 다시 걸면 늘 바뀐 채로 쓴다.

hidutil

# 오른쪽 Cmd → F18
hidutil property --set '{"UserKeyMapping":[
  {"HIDKeyboardModifierMappingSrc":0x7000000E7, "HIDKeyboardModifierMappingDst":0x70000006D}
]}'

hidutil property --get "UserKeyMapping"          # 지금 걸린 것
hidutil property --set '{"UserKeyMapping":[]}'   # 모두 풀기
  • --set 은 목록을 통째로 바꾼다. 여러 키를 바꾸려면 한 번에 모두 적는다
  • --get 은 코드를 10진수로 보여 준다. 30064771303 이 0x7000000E7(오른쪽 Cmd) 이다
  • 코드는 0x700000000 에 HID 사용 코드를 더한 값이다
키 코드 키 코드
Caps Lock 0x700000039 오른쪽 Ctrl 0x7000000E4
왼쪽 Ctrl 0x7000000E0 오른쪽 Shift 0x7000000E5
왼쪽 Shift 0x7000000E1 오른쪽 Option 0x7000000E6
왼쪽 Option 0x7000000E2 오른쪽 Cmd 0x7000000E7
왼쪽 Cmd 0x7000000E3 F13 · F18 · F19 0x700000068 · 0x70000006D · 0x70000006E
  • F13 ~ F20 은 맥 키보드에 없는 키라 다른 단축키와 겹치지 않는다. 남는 키를 여기로 바꾸고, Hammerspoon 에서 그 키에 기능을 연결한다

Hammerspoon 에서 걸기

foundation_remapping 은 키 이름을 HID 코드로 바꿔 hidutil 을 불러 준다. foundation_remapping.lua 를 ~/.hammerspoon/ 에 받아 둔다.

local FRemap = require('foundation_remapping')
local remapper = FRemap.new()

remapper:remap('lctrl', 'capslock')
remapper:remap('capslock', 'lctrl')
remapper:remap('rcmd', 'f18')
remapper:register()
  • init.lua 에 두면 Hammerspoon 이 시작하거나 다시 불러올 때마다 다시 걸린다
  • remapper:unregister() 는 건 것을 모두 푼다
  • FRemap.new({vendorID = …, productID = …}) 로 키보드 하나에만 걸 수 있다
  • Hammerspoon 을 끝내도 바뀐 키는 재부팅할 때까지 남는다

시스템 설정으로 되는 것

Caps Lock · Ctrl · Option · Cmd · Globe 끼리 바꾸는 것은 「시스템 설정 › 키보드 › 키보드 단축키 › 보조 키」 에서도 된다. 재부팅해도 남고, 키보드마다 따로 정한다. 왼쪽 · 오른쪽을 가리지 못하고, F18 처럼 보조 키가 아닌 키로는 바꾸지 못한다.
