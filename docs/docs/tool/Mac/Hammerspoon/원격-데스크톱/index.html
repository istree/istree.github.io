원격 데스크톱

목록 · Mac

    • 원격 데스크톱

크롬 원격 데스크톱으로 다른 맥에 들어가 있을 때 한영 키를 원격 맥에 넘긴다. 두 맥 모두 Hammerspoon 으로 한영 전환을 하면, 이 맥의 Hammerspoon 이 한영 키를 먼저 잡아 버려서 원격 맥에는 아무 키도 가지 않는다. 원격 데스크톱 창이 앞에 있을 때만 키를 원격 맥이 받을 수 있는 형태로 바꿔 넘긴다.

왜 안 되나

  • 이 맥에서 오른쪽 Cmd 는 hidutil 로 F18 이 되고, Hammerspoon 의 F18 단축키(hs.hotkey) 가 그 키를 가져간다. 단축키로 잡힌 키는 앱에 가지 않으므로 원격 데스크톱도 받지 못한다
  • 단축키를 끄고 F18 을 원격 데스크톱에 넘기면, F18 은 원격 맥까지 간다 (원격 맥에서 hs.eventtap 으로 기록해 확인했다). 그런데 원격 맥의 F18 단축키가 원격으로 들어온 F18 을 잡지 못한다
  • 원격 맥의 hidutil 매핑은 실제 키보드에만 걸린다. 원격으로 들어온 오른쪽 Cmd 는 F18 로 바뀌지 않는다

그래서 원격 맥이 단축키로 잡을 수 있는 흔한 조합키 Ctrl+Option+Shift+K 를 한영 키로 보낸다.

원격 데스크톱 가려내기

local remoteDesktopApps = {
	['com.google.Chrome.app.cmkncekebbebpfilplodngbpllndjkfo'] = true, -- Chrome 원격 데스크톱
}

local function isRemoteDesktop()
	local app = hs.application.frontmostApplication()
	return app ~= nil and remoteDesktopApps[app:bundleID()] == true
end
  • 크롬 원격 데스크톱을 크롬 앱으로 설치해 따로 된 창으로 띄우면, 크롬과 다른 번들 ID 를 가진 앱이 된다
  • 번들 ID 는 앞에 있는 앱으로 본다. 콘솔에서 바로 치면 앞에 있는 앱이 콘솔이 되므로, 3초 뒤에 찍게 하고 그사이 원격 데스크톱 창을 누른다
hs.timer.doAfter(3, function() print(hs.application.frontmostApplication():bundleID()) end)
  • 브라우저 탭으로 띄우면 앱이 크롬이라 이 방법으로는 가려내지 못한다

키 넘기기

local function passThrough(hotkey, mods, key)
	local event = hs.eventtap.event
	hotkey:disable()
	for _, mod in ipairs(mods) do
		event.newKeyEvent(mod, true):post()
	end
	event.newKeyEvent(mods, key, true):post()
	hs.timer.usleep(20000)
	event.newKeyEvent(mods, key, false):post()
	for i = #mods, 1, -1 do
		event.newKeyEvent(mods[i], false):post()
	end
	hotkey:enable()
end
  • 보낼 키와 같은 이 맥의 단축키를 끄고 보낸다. 켜 둔 채 보내면 이 맥이 자기가 보낸 키를 다시 잡는다
  • hs.eventtap.keyStroke({'ctrl', 'alt', 'shift'}, 'k') 로 보내면 원격 맥에 k 만 입력된다. keyStroke 는 K 이벤트에 보조 키 표시(flags) 만 붙이는데, 원격 데스크톱은 그 표시를 보지 않고 보조 키를 누르고 떼는 이벤트를 따로 센다
  • newKeyEvent('ctrl', true) 처럼 보조 키 이름만 주면 그 보조 키를 누르는 이벤트가 된다. 보조 키를 누르고, 키를 누르고 떼고, 보조 키를 거꾸로 뗀다

한영 키

local remoteABCMods = {'ctrl', 'alt', 'shift'}
local remoteABCKey = 'k'

local inputSourceHotkey
local remoteABCHotkey

-- 이 맥의 입력기만 바꾼다
local function switchABC()
	local current = hs.keycodes.currentSourceID()
	if (current == inputEnglish) then
		hs.keycodes.currentSourceID(lastSource)
	else
		lastSource = current
		hs.keycodes.currentSourceID(inputEnglish)
	end
end

-- F18(오른쪽 Cmd) — 원격 데스크톱이면 조합키로 바꿔 넘긴다
local function toggleABC()
	if isRemoteDesktop() then
		passThrough(remoteABCHotkey, remoteABCMods, remoteABCKey)
		return
	end
	switchABC()
end

-- Ctrl+Space — 원격 데스크톱이면 그대로 넘긴다
local function toggleInputSource()
	if isRemoteDesktop() then
		passThrough(inputSourceHotkey, {'ctrl'}, 'space')
		return
	end
	if (lastSource == inputKorean) then
		lastSource = inputJapanese
	else
		lastSource = inputKorean
	end
	hs.keycodes.currentSourceID(lastSource)
end

inputSourceHotkey = hs.hotkey.bind({'control'}, 'space', toggleInputSource)
hs.hotkey.bind({}, 'f18', toggleABC)
-- 이 맥이 원격 맥일 때 받는 한영 키
remoteABCHotkey = hs.hotkey.bind(remoteABCMods, remoteABCKey, switchABC)
  • 두 맥에 같은 init.lua 를 둔다. 들어가는 쪽은 F18 을 조합키로 바꿔 보내고, 들어온 쪽은 그 조합키로 입력기를 바꾼다
  • 조합키에는 toggleABC 가 아니라 switchABC 를 건다. toggleABC 를 걸면 원격 데스크톱 창이 앞일 때 자기가 보낸 조합키를 받아 다시 조합키를 보내기를 끝없이 되풀이한다
  • Ctrl+Space 는 원격 맥의 단축키가 그대로 잡으므로 바꾸지 않고 넘긴다

원격 데스크톱이 앞에 오면 영어로

remoteDesktopWatcher = hs.application.watcher.new(function(_, event, app)
	if event == hs.application.watcher.activated and app and remoteDesktopApps[app:bundleID()] then
		local current = hs.keycodes.currentSourceID()
		if current ~= inputEnglish then
			lastSource = current
			hs.keycodes.currentSourceID(inputEnglish)
		end
	end
end):start()
  • 한글을 치는 것은 원격 맥의 입력기다. 이 맥이 한글 입력 중이면 조합 중인 키가 원격 데스크톱에 제대로 가지 않을 수 있어, 이 맥은 영어로 둔다
  • 원격 데스크톱에서 나와 오른쪽 Cmd 를 누르면 lastSource 로 돌아간다
  • remoteDesktopWatcher 는 전역이다. local 이면 가비지 컬렉션으로 언젠가 멈춘다
