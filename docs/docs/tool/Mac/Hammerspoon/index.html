Hammerspoon

목록 · Hammerspoon

Hammerspoon 은 macOS 를 Lua 스크립트로 다루는 앱이다. ~/.hammerspoon/init.lua 에 단축키 · 키 이벤트 · 입력기 · 창 · 앱 · 파일 감시 같은 것을 적으면, 메뉴 막대에 떠 있으면서 그대로 동작한다. 기능은 hs.hotkey · hs.keycodes 처럼 모듈로 나뉘어 있고, 남이 만든 설정 묶음(Spoon) 을 받아 쓸 수도 있다.

여기서는 키를 바꾸고 한영 전환을 직접 하는 데 쓴다. 예제는 Hammerspoon 1.0 · 1.1, macOS 15 기준이다.
