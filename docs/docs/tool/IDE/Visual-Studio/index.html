단축키

현재 파일을 솔루션 탐색기에서 찾기

  • 기본 단축키: Ctrl + [ , S
    (영문 키보드 기준: Ctrl + [를 누른 후 S를 누름)

설정

현재 보는 파일을 자동으로 솔루션 탐색기에서 선택 (Track Active Item in Solution Explorer)

  1. 메뉴에서 Tools > Options로 이동
  2. 좌측 트리에서 Projects and Solutions > General 선택
  3. "Track Active Item in Solution Explorer" 체크박스 활성화
