Vim 의 설정은 홈 폴더의 ~/.vimrc 에 명령을 한 줄씩 적은 것이다. 띄울 때 이 파일을 차례로 실행하므로, :set … 으로 맞춰 본 것을 그대로 옮겨 적는다. 옵션(set) · 키 매핑(nnoremap) · 파일 종류마다의 설정(autocmd FileType) 이 대부분이고, 플러그인은 ~/.vim/pack/*/start/ 에 내려받아 두면 저절로 읽힌다. ~/.vimrc 가 없으면 Vim 은 기본 설정(defaults.vim) 으로 뜬다.

시작용 vimrc

" ~/.vimrc
set nocompatible
filetype plugin indent on
syntax on

set expandtab shiftwidth=4 tabstop=4 softtabstop=4
set number relativenumber
set ignorecase smartcase incsearch hlsearch
set clipboard=unnamed
set mouse=a
set scrolloff=5
set wildmenu
set hidden
set undofile undodir=~/.vim/undo
set encoding=utf-8 fileencodings=utf-8,cp949

let mapleader = " "
nnoremap <leader>w :w<CR>
nnoremap <leader>d "_dd
nnoremap <Esc><Esc> :noh<CR>

augroup my
  autocmd!
  autocmd FileType yaml,json setlocal shiftwidth=2 softtabstop=2
  autocmd FileType make setlocal noexpandtab
augroup END

옵션

옵션 뜻
expandtab · shiftwidth=4 · tabstop=4 · softtabstop=4 탭 키 · >> 가 빈칸 4 칸을 넣고, 지울 때도 4 칸씩
number · relativenumber 줄 번호, 다른 줄은 지금 줄에서 몇 줄인지 (5j 를 셈하기 쉽다)
ignorecase · smartcase 소문자 패턴은 대소문자를 가리지 않고, 대문자가 섞이면 가린다
incsearch · hlsearch 입력하는 동안 검색하고, 찾은 곳을 하이라이트한다
clipboard=unnamed y · p 를 OS 클립보드로 (리눅스는 unnamedplus)
mouse=a 마우스로 커서 이동 · 창 크기 조정
scrolloff=5 커서 위아래로 늘 5 줄을 보인다
wildmenu 명령줄에서 탭으로 이름을 채울 때 목록을 보인다
hidden 저장하지 않은 버퍼를 두고 다른 버퍼로 간다
undofile 껐다 켜도 실행 취소 기록이 남는다 (undodir 폴더를 미리 만든다)
fileencodings=utf-8,cp949 파일을 열 때 UTF-8 로 읽고, 안 되면 CP949 로 (한글 윈도우 파일)
list · listchars=tab:»·,trail:· 탭 · 줄 끝 빈칸을 보인다
paste 붙여 넣는 동안 자동 들여쓰기를 끈다 (터미널에서 붙여 넣기)
  • 지금 값은 :set shiftwidth?, 어디서 정했는지는 :verbose set shiftwidth? 로 본다
  • :set 은 모든 창에, :setlocal 은 지금 버퍼에만 건다. 파일 종류마다의 설정은 setlocal 로 쓴다
  • :set ff=unix 는 줄 끝을 LF 로, :set fenc=utf-8 은 저장할 인코딩을 바꾼다. :w 해야 파일에 들어간다

키 매핑

명령 뜻
nnoremap · inoremap · vnoremap · xnoremap 노멀 · 삽입 · 비주얼과 선택 · 비주얼 모드의 매핑
let mapleader = " " <leader> 를 빈칸으로
nnoremap <leader>w :w<CR> 빈칸 w 로 저장
inoremap jk <Esc> 삽입 모드에서 jk 로 나오기
nnoremap <C-h> <C-w>h Ctrl-h 로 왼쪽 창
:nmap <leader> · :verbose nmap <leader>w 매핑 목록 · 그 매핑을 정한 파일과 줄
:unmap · :nunmap 매핑 삭제
  • noremap 형태를 쓴다. nnoremap 의 nore 는 매핑 안의 키를 다시 매핑으로 풀지 않는다는 뜻으로, nmap 처럼 다른 매핑과 엉켜 반복되지 않는다
  • <leader> 는 빈칸이나 , 처럼 기본 명령이 없는 키로 정한다
  • 특수 키는 <CR> · <Esc> · <Tab> · <C-x>(Ctrl) · <M-x>(Alt) · <S-x>(Shift) · <F5> 로 쓴다

파일 종류마다

명령 뜻
autocmd FileType python setlocal … 그 종류의 파일을 열 때
autocmd BufWritePre *.py %s/\s\+$//e 저장하기 전에 줄 끝 빈칸을 삭제한다
autocmd BufRead,BufNewFile *.conf setfiletype dosini 파일 이름으로 종류를 정한다
:set filetype? · :set ft=yaml 지금 종류 보기 · 바꾸기
~/.vim/after/ftplugin/python.vim 그 종류의 설정을 파일로 따로 둔다
  • autocmd 는 augroup 으로 감싸고 첫 줄에 autocmd! 를 둔다. 그래야 :source ~/.vimrc 로 다시 읽을 때 같은 명령이 겹쳐 쌓이지 않는다

플러그인 — 패키지

Vim 8 부터는 플러그인 관리자 없이, 정해진 폴더에 두면 읽는다.

mkdir -p ~/.vim/pack/plugins/start
git clone https://github.com/tpope/vim-commentary ~/.vim/pack/plugins/start/vim-commentary
자리 읽히는 때
~/.vim/pack/<이름>/start/<플러그인> 늘
~/.vim/pack/<이름>/opt/<플러그인> :packadd <플러그인> 할 때만
명령 뜻
:scriptnames 읽힌 스크립트 목록 — 플러그인이 읽혔는지 본다
:helptags ALL 플러그인의 도움말을 :help 로 보게 만든다
git pull (그 폴더에서) 플러그인 업데이트
플러그인 하는 일
vim-commentary gcc 줄 · gc + 이동 · 텍스트 객체로 주석 넣기 · 빼기
vim-surround cs"' 따옴표 바꾸기 · ysiw) 단어를 괄호로 감싸기
fzf.vim 파일 · 버퍼 · 글자를 퍼지 검색(fuzzy) 으로 연다
vim-plug 플러그인 관리자 — vimrc 에 목록을 적고 :PlugInstall

설정 옮기기

  • ~/.vimrc 와 ~/.vim/ 를 dotfiles 저장소에 두고, 새 기계에서 받아 링크를 건다(ln -s ~/dotfiles/vimrc ~/.vimrc)
  • 서버에는 플러그인을 깔지 않고 옵션 몇 줄만 둔다. 손에 익은 키는 기본 키로 쓴다
  • Neovim 은 ~/.config/nvim/init.vim(또는 init.lua) 을 읽는다. source ~/.vimrc 한 줄로 같은 설정을 쓸 수 있다
