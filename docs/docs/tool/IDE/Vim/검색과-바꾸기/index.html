Vim 에서 검색은 / 로, 바꾸기는 :s 로 한다. :s 는 앞에 범위(% 는 파일 전체) 를, 뒤에 플래그(g 줄의 모두 · c 하나씩 묻기) 를 붙인다. 패턴은 Vim 의 정규식이고, 기본 「magic」 모드에서는 + · ( · | · { 앞에 \ 를 붙여야 특수 문자가 된다. 앞에 \v 를 붙이면 다른 언어의 정규식처럼 쓴다. :g 는 패턴이 있는 줄마다 명령을 실행하고, :%! 는 줄들을 외부 프로그램에 넘겨 나온 것으로 바꾼다.

검색

키 뜻
/패턴 · ?패턴 아래로(순방향) · 위로(역방향) 검색
n · N 다음 · 이전 검색 결과로
* · # 커서 아래 단어를 아래로 · 위로 검색
g* · g# 단어의 일부로도 검색
/\<id\> 단어 경계 — id 는 맞고 idle 은 안 맞는다
/패턴\c · /패턴\C 이번만 대소문자를 가리지 않는다 · 가린다
/패턴/e 찾은 곳의 끝에 커서를 둔다
:noh 검색 하이라이트(hlsearch) 를 끈다
Ctrl-r Ctrl-w (명령줄에서) 커서 아래 단어를 명령줄에 넣는다
  • set ignorecase smartcase 면 소문자로만 친 패턴은 대소문자를 가리지 않고, 대문자가 섞이면 가린다

바꾸기

:s/old/new/          " 지금 줄의 처음 하나
:s/old/new/g         " 지금 줄의 모두
:%s/old/new/g        " 파일 전체
:%s/old/new/gc       " 하나씩 묻는다 — y · n · a(모두) · q(그만) · l(이것만 하고 그만)
:%s/old/new/ge       " 맞는 곳이 없어도 오류(E486) 를 내지 않는다
:%s#/usr/local#/opt#g    " / 가 들어가면 구분자를 바꾼다
범위 뜻
(없음) 지금 줄
% 파일 전체
1,10 · .,$ · .,+5 1 ~ 10 줄 · 지금부터 끝 · 지금부터 5 줄 아래까지
'<,'> 비주얼 모드로 선택한 곳 (선택하고 : 를 누르면 들어간다)
/start/,/end/ 패턴 start 줄부터 end 줄까지
바꾸는 쪽 뜻 예
& 찾은 글자 전체 :%s/ERROR/[&]/ → [ERROR] db timeout
\1 ~ \9 그룹에 담긴 것 :%s/\v(\w+) (\w+)/\2 \1/ → 두 단어를 맞바꾼다
\r 줄바꿈 :s/, /,\r/g → 쉼표마다 줄을 나눈다
\u · \U · \L 다음 글자 · 뒤를 대문자로 · 소문자로 :s/\w\+/\u&/g → 단어 첫 글자를 대문자로
\= Vim 식의 값 :%s/\d\+/\=submatch(0)*10/g → 숫자를 10 배로

정규식 — magic 과 \v

기본(magic) \v 뜻
. · * . · * 아무 글자 · 없거나 여럿
\+ · \= · \? + · = · ? 하나 이상 · 없거나 하나
\{2,3} · \{-} {2,3} · {-} 2 ~ 3 번 · 가장 짧게
\(a\) · \%(a\) (a) · %(a) 그룹 · 캡처하지 않는 그룹
\< · \> < · > 단어 처음 · 끝
\d \s \w \a · ^ $ 같다 숫자 · 빈칸 · 단어 글자 · 알파벳 · 줄 처음 · 끝
\zs · \ze 같다 찾은 곳의 시작 · 끝을 옮긴다
  • 「또는」 은 기본 모드에서 a\|b, \v 에서는 a|b 로 쓴다
  • :%s/"id": \d+/X/ 는 바뀌는 것이 없다. magic 모드에서 + 는 그냥 글자라 \d\+ 로 쓰거나 \v 를 붙인다
  • \zs 는 앞쪽을 조건으로만 쓴다. :%s/"id": \zs\d\+/0/ 는 "id": 는 두고 숫자만 바꾼다
  • .* 는 가장 길게 맞는다. 짧게는 .\{-}(\v 면 .{-}) 다

식으로 바꾸기

:%s/"id": \zs\d\+/\=submatch(0)*10/
" "id": 1 · 2 · 3 → "id": 10 · 20 · 30

:let n = 0
:g/"time"/let n += 1 | s/"time": ""/\='"time": "09:0' . n . '"'/
" "time" 이 든 줄마다 "09:01" · "09:02" · "09:03"
  • submatch(0) 은 찾은 전체, submatch(1) 은 첫 그룹이다
  • 앞 줄의 값이 필요하면(늘어나는 번호) 변수를 두고 :g 로 줄마다 올린다

:g — 패턴이 있는 줄마다

명령 하는 일
:g/^ERROR/d ERROR 로 시작하는 줄을 삭제한다
:v/ERROR/d · :g!/ERROR/d ERROR 가 없는 줄을 삭제한다 (로그에서 오류만 남기기)
:g/^$/d 빈 줄을 삭제한다
:g/TODO/normal A ! 찾은 줄마다 노멀 명령 (줄 끝에 !)
:g/TODO/m$ 찾은 줄을 파일 끝으로 옮긴다
:g/^/m0 줄 순서를 뒤집는다
:g/pattern/y A 찾은 줄을 레지스터 a 에 모은다 (먼저 qaq 로 비운다)
:g/^def /p · :g/x/# 찾은 줄만 보기 · 줄 번호와 함께
  • :g 는 찾은 줄에 먼저 표시를 해 두고 차례로 실행한다. 줄을 삭제하거나 옮겨도 건너뛰는 줄이 없다

외부 프로그램으로

명령 하는 일
:%!sort · :1,3!sort -r 전체 · 1 ~ 3 줄을 정렬한 것으로 바꾼다
:%!jq . JSON 을 보기 좋게
:%!python3 fill.py 파일 전체를 Python 스크립트로 고친다
!!date (노멀) 지금 줄을 date 의 출력으로
:r !date 명령의 출력을 아래 줄에 넣는다
:sort · :sort u · :sort n Vim 안의 정렬 · 겹친 줄 빼기 · 숫자로 
# fill.py — "time" 줄에 9 시부터 1 분씩 늘린 시각을 넣는다
import sys, datetime
t = datetime.datetime(2015, 12, 12, 9, 0)
for line in sys.stdin:
    if '"time"' in line:
        t += datetime.timedelta(minutes=1)
        line = line.replace('"time": ""', f'"time": "{t:%H:%M}"')
    sys.stdout.write(line)
  • 정규식으로 어려운 일은 이렇게 아는 언어에 맡긴다
  • :py3 로 Vim 안에서 Python 을 돌릴 수도 있지만 Vim 이 +python3 으로 빌드돼 있어야 한다(vim --version 으로 본다). macOS 의 Vim 은 -python3 이다. :%! 는 어떤 빌드에서도 된다

여러 파일에서

명령 하는 일
:vimgrep /OLD/ **/*.py 찾은 곳을 quickfix 목록에 모은다 (** 는 하위 폴더까지)
:grep OLD -r . 외부 grep 으로 같은 목록을 만든다 (파일이 많으면 빠르다)
:copen · :clist 목록 창 열기 · 목록 보기
:cn · :cp 다음 · 이전 항목으로 
:cdo s/OLD/NEW/ | update          " 목록의 곳마다 바꾸고 저장
:cfdo %s/OLD/NEW/g | update       " 목록에 나온 파일마다 바꾸고 저장
:argdo %s/OLD/NEW/ge | update     " 인자로 연 파일(vim *.py) 마다
