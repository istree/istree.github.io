Vim 은 모드를 오가며 쓴다. 노멀 모드에서는 키가 곧 명령이고, i · a · o 로 삽입 모드에 들어가 글자를 넣은 뒤 Esc 로 돌아온다. 편집 명령은 연산자(operator) 와 대상으로 이루어진다. 연산자(d 삭제 · c 변경 · y 복사) 뒤에 이동 명령(w · $ · f;) 이나 텍스트 객체(iw · i" · a() 를 붙이면 그 범위에 연산자가 적용되고, 앞에 숫자를 붙이면 그 수만큼 반복한다. 마지막 편집은 . 으로 반복한다.

모드

키 들어가는 곳
i · a 커서 앞 · 뒤에 삽입
I · A 줄의 첫 글자 앞 · 줄 끝에 삽입
o · O 아래 · 위에 새 줄을 넣고 삽입
s · S 글자 하나 · 줄을 지우고 삽입
v · V · Ctrl-v 글자 · 줄 · 블록 단위 비주얼 모드
R 바꾸기 모드 (덮어쓰기)
: 명령줄
Esc · Ctrl-[ 노멀 모드로
명령 뜻
:w · :w 이름 저장 · 다른 이름으로 저장
:q · :q! · :wq · :x 끝내기 · 버리고 끝내기 · 저장하고 끝내기 · 바뀐 것이 있으면 저장하고 끝내기
:e! 저장한 상태로 되돌린다
:w !sudo tee % 권한 없이 연 파일을 sudo 로 저장

이동

키 이동하는 곳
h j k l 왼쪽 · 아래 · 위 · 오른쪽
w · b · e · ge 다음 단어 처음 · 앞 단어 처음 · 단어 끝 · 앞 단어 끝
W · B · E 빈칸으로만 나눈 단어(WORD) 로 같은 일
0 · ^ · $ 줄의 맨 앞 · 첫 글자 · 끝
f; · t; · F; · T; 줄 안의 다음 ; 로 · 그 앞으로 · 거꾸로 (; · , 로 반복)
gg · G · 12G · :12 첫 줄 · 끝 줄 · 12 번째 줄
{ · } 이전 · 다음 단락 (빈 줄)
% 짝이 맞는 괄호로
* · # 커서 아래 단어를 아래로 · 위로 검색
H · M · L 화면의 위 · 가운데 · 아래 줄
Ctrl-d · Ctrl-u · Ctrl-f · Ctrl-b 반 화면 아래 · 위, 한 화면 아래 · 위
zz · zt · zb 지금 줄을 화면 가운데 · 위 · 아래로
`` · Ctrl-o · Ctrl-i 최근 점프 전 자리 · 점프 목록의 이전 · 다음 자리
ma · `a 지금 자리를 마크 a 로 · 마크 a 로 점프
gd 커서 아래 이름이 정의된 곳
  • w 는 기호도 한 단어로 본다. msg = "hello, " + name 에서 msg 다음 w 는 = 에 선다
  • W 는 빈칸만 단어의 경계로 본다. "hello, 위에서 dw 는 " 하나를, dW 는 "hello, 를 삭제한다

연산자

연산자 뜻
d 삭제 (삭제한 것은 p 로 붙여 넣는다)
c 변경 — 삭제하고 삽입 모드로
y 복사
> · < · = 들여쓰기 · 내어쓰기 · 자동 정렬
gU · gu · g~ 대문자 · 소문자 · 대소문자 전환
  • 연산자를 두 번 쓰면(dd · cc · yy · >> · ==) 지금 줄이 대상이다
  • D · C 는 줄 끝까지(d$ · c$), Y 는 줄 전체(yy) 다
키 하는 일
d2w · 2dw 단어 둘을 삭제한다. 2d3w 는 여섯 (숫자는 곱해진다)
dt; · df; ; 앞까지 · ; 까지 삭제한다
dj · 3dd 지금 줄과 아래 줄 · 세 줄을 삭제한다
gUiw 단어를 대문자로 (name → NAME)
xp · ddp 두 글자 · 두 줄을 맞바꾼다
yyp 줄을 바로 아래에 복제
>G · =G 끝 줄까지 들여쓰기 · 자동 정렬

그 밖의 편집

키 하는 일
p · P 커서 뒤 · 앞에 붙여넣기 (줄을 복사했으면 아래 · 위 줄로)
x · X 커서 글자 · 앞 글자 삭제
r 글자 하나 바꾸기 (r9)
J · gJ 다음 줄과 연결 · 빈칸 없이 연결
~ 커서 글자의 대소문자 전환

텍스트 객체

연산자 뒤에 i(안쪽) · a(둘레까지) 와 객체를 쓰면, 커서가 객체 안 어디에 있든 객체 전체가 대상이다.

객체 뜻
w · W 단어
s · p 문장 · 단락 (빈 줄로 나뉜 덩어리)
" · ' · ` 따옴표
( ) b · { } B · [ · < 괄호
t HTML · XML 태그
커서 자리 · 키 전 → 후
(name, age) 안 · ci( + who greet(name, age) → greet(who)
(name, age) 안 · da( greet(name, age): → greet:
"hello, " 안 · ci" + bye msg = "hello, " + name → msg = "bye" + name
"hello, " 안 · da" msg = "hello, " + name → msg = + name (뒤 빈칸도)
msg 위 · diw · daw 단어만 · 단어와 뒤 빈칸
단락 안 · dap 단락과 뒤 빈 줄
<b>x</b> 안 · cit 태그 안을 바꾼다
  • ci" · ci( 는 커서가 따옴표 · 괄호 앞(같은 줄) 에 있어도 그 줄의 다음 것으로 건너가 바꾼다
  • 「안쪽 변경」(ci…) 을 가장 자주 쓴다

반복 · 실행 취소

키 뜻
. · 3. 마지막 편집을 반복 · 세 번 반복
u · U · Ctrl-r 실행 취소 · 그 줄의 변경을 모두 취소 · 다시 실행
& 마지막 :s 를 지금 줄에 반복
  • 한 번 고친 뒤 자리를 옮겨 . 을 누르는 방식으로 많이 쓴다. >> 뒤 j. 는 다음 줄도 들여쓴다
  • 설정 없이는 >> 가 탭 하나(8 칸) 를 넣는다. 빈칸 4 칸은 set expandtab shiftwidth=4 다

비주얼 모드

키 하는 일
v + 이동 → 연산자 선택한 곳에 연산자를 적용한다 (d · y · c · > · ~ · gU)
V 줄 단위
Ctrl-v → I 글자 Esc 여러 줄 앞에 한꺼번에 삽입 (Ctrl-v 2j I# Esc → 세 줄 앞에 # )
Ctrl-v → $ A 글자 Esc 여러 줄 끝에 한꺼번에 추가
gv 마지막 선택 영역을 다시 선택한다
o 선택 영역의 반대쪽 끝으로
: 선택한 줄에 명령 (:'<,'> 가 저절로 들어간다)
  • 블록 삽입(I · A) 은 Esc 를 누른 뒤에 다른 줄에도 들어간다
