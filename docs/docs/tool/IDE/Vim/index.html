Vim 은 터미널에서 도는 글자 편집기다. 거의 모든 리눅스 · macOS 서버에 깔려 있어, SSH 로 들어간 서버의 설정 파일을 그 자리에서 고칠 때 쓴다. 글자를 넣는 삽입 모드와, 키 하나하나가 명령인 노멀 모드를 오가며 쓰는 것이 다른 편집기와 다르다. 편집 명령은 연산자 뒤에 이동 명령이나 텍스트 객체를 붙여 쓴다 — 연산자 d(삭제) 에 이동 w(다음 단어) 를 붙이면 단어를 삭제하고, 연산자 c(변경) 에 텍스트 객체 i"(따옴표 안) 를 붙이면 따옴표 안을 지우고 새로 쓴다. 그래서 연산자 몇 개와 이동 명령 · 텍스트 객체를 익히면 조합으로 많은 일을 한다. 마지막 편집은 . 으로 반복하고, 손으로 하기 번거로운 일은 매크로 · 정규식 바꾸기 · 외부 명령으로 한다. 지금 판은 9.1 이고, 같은 계열의 Neovim 도 널리 쓴다.
