Vim 에서 삭제 · 복사한 글자는 레지스터에 담긴다. 이름 없는 레지스터("") 하나만 쓰면 삭제할 때마다 복사한 것이 덮이므로, 이름 붙은 레지스터("a ~ "z) 에 따로 담거나 복사한 것만 남는 "0 에서 꺼낸다. "+ 는 OS 의 클립보드다. 매크로는 누른 키를 레지스터에 기록해 두었다가 반복하는 것으로, 여러 줄을 같은 방식으로 한 번에 고친다.

레지스터

레지스터 담기는 것
"" 마지막으로 삭제하거나 복사한 것 (p 가 붙여 넣는 것)
"0 마지막으로 복사한 것 (삭제해도 덮이지 않는다)
"1 ~ "9 삭제한 줄, 최근 것부터
"- 줄 안에서 삭제한 짧은 것
"a ~ "z · "A ~ "Z 이름 붙여 담기 · 대문자면 뒤에 덧붙이기
"_ 블랙홀 — 담지 않고 버린다
"+ · "* OS 클립보드
". · ": · "/ · "% 최근 삽입한 글자 · 최근 명령줄 · 최근 검색 패턴 · 현재 파일 이름
키 하는 일
"ayy · "ap 줄을 a 에 복사 · a 를 붙여넣기
"Ayy a 의 뒤에 줄을 덧붙인다
"0p 그 뒤에 무엇을 삭제했든, 마지막으로 복사한 것을 붙여 넣는다
"_dd 레지스터를 건드리지 않고 삭제한다
"1p . . 삭제한 것을 최근 것부터 차례로 붙여 넣는다 (. 마다 "2 · "3)
"+yy · "+p 클립보드로 복사 · 클립보드에서 붙여넣기
Ctrl-r a (삽입 모드 · 명령줄에서) 레지스터 a 를 그 자리에 넣는다 (Ctrl-r + · Ctrl-r /)
:reg · :reg a 담긴 것 보기
  • 복사한 것을 여러 곳에 바꿔 붙여 넣을 때 자주 걸린다. 붙여 넣을 곳의 글자를 삭제하는 순간 "" 가 삭제한 것으로 바뀐다. "0p 로 붙이거나 지울 때 "_d 를 쓴다
  • :reg a 의 l "a apple^J 에서 l 은 줄 단위, ^J 는 줄바꿈이다

클립보드

경우 쓰는 법
macOS 의 Vim (+clipboard) "+y · "+p. set clipboard=unnamed 면 그냥 y · p 가 클립보드다
리눅스 데스크톱 "+(Ctrl-c 쪽) · "*(마우스로 선택한 쪽) 둘이 다르다. vim-gtk3 같은 +clipboard 판을 깐다
-clipboard 빌드 "+ 가 없다. :w !pbcopy · :r !pbpaste(맥) 처럼 외부 명령으로
SSH 로 들어간 서버 서버의 Vim 은 내 컴퓨터의 클립보드에 닿지 않는다. 터미널에서 마우스로 선택해 복사하거나, 터미널이 지원하면 OSC 52 플러그인을 쓴다
  • vim --version | grep clipboard 로 +clipboard 인지 본다

매크로

키 하는 일
qa … q 레지스터 a 에 기록 시작 · 끝
@a · 3@a 한 번 · 세 번 실행
@@ 최근 실행한 매크로를 다시 실행
:%normal @a · :'<,'>normal @a 줄마다 실행
:let @a = "I- \<Esc>j" 매크로를 글자로 바로 넣는다
"ap → 고침 → 0"ay$ 매크로를 붙여 넣어 고친 뒤 다시 담는다 
qa          a 에 기록 시작
I- <Esc>    줄 앞에 '- '
j           다음 줄로
q           기록 끝
100@a       끝까지
apple          - apple
banana    →    - banana
cherry         - cherry
  • 끝에 다음 줄로 가는 이동(j) 을 넣어 두면 100@a 로 끝까지 실행한다. 이동이나 검색이 실패하는 줄에서 멈춘다
  • :%normal @a 는 줄마다 따로 실행해, 한 줄에서 실패해도 다음 줄로 넘어간다. 예를 들어 , 를 ; 로 바꾸는 매크로(0f,r;) 를 a,1 · b · c,3 에 실행하면, 100@a 는 b 에서 멈추고 :%normal @a 는 b 만 건너뛰고 c;3 까지 바꾼다
  • 기록하기 전에 커서를 줄의 같은 자리(0 · ^) 에 두는 키부터 넣으면, 어느 자리에서 실행해도 같은 결과다

예: CSV 를 SQL 로

:let @q = "0iINSERT INTO t VALUES (\<Esc>A);\<Esc>"
:2,$normal @q
id,name             id,name
1,kim        →      INSERT INTO t VALUES (1,kim);
2,lee               INSERT INTO t VALUES (2,lee);
  • 줄마다 형태가 같으면 :s 로도 된다(:2,$s/.*/INSERT INTO t VALUES (&);/). 매크로는 검색 · 이동 · 여러 줄에 걸친 편집처럼 정규식 하나로 적기 어려운 일에 쓴다
