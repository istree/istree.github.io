함수를 경우마다 나눠 쓰는 문법이다. 값의 모양으로는 패턴 매칭, 조건으로는 가드로 나누고, where · let 으로 계산에 이름을 붙이고, 식 안에서는 case 로 나눈다.

패턴 매칭

경우마다 함수 줄을 따로 쓴다. 위에서부터 맞는 줄을 고른다.

lucky :: Int -> String
lucky 7 = "LUCKY NUMBER SEVEN!"
lucky x = "Sorry, you're out of luck."

리스트 · 튜플은 모양을 풀어서 받는다.

head' :: [a] -> a
head' []    = error "빈 리스트"
head' (x:_) = x                       -- 첫 값 x, 나머지는 _ (쓰지 않음)

addVectors :: (Double, Double) -> (Double, Double) -> (Double, Double)
addVectors (x1, y1) (x2, y2) = (x1 + x2, y1 + y2)

firstLetter :: String -> String
firstLetter all@(x:_) = all ++ " 의 첫 글자는 " ++ [x]   -- all@ 로 통째도 받는다
  • 맞는 줄이 없으면 실행 중에 오류가 난다. 마지막에 모든 값을 받는 줄을 둔다

가드

값이 아니라 조건으로 나눈다. | 뒤에 조건을 쓰고, 마지막은 otherwise.

bmiTell :: Double -> String
bmiTell bmi
  | bmi <= 18.5 = "저체중"
  | bmi <= 25.0 = "정상"
  | bmi <= 30.0 = "과체중"
  | otherwise   = "비만"

where

가드에서 여러 번 쓰는 계산에 이름을 붙인다. 함수 맨 뒤에 둔다.

bmiTell' :: Double -> Double -> String
bmiTell' weight height
  | bmi <= normal = "정상 이하"
  | otherwise     = "정상 위"
  where bmi    = weight / height ^ 2
        normal = 25.0

let

let … in … 은 식이라 어디서나 쓴다. 리스트 조건제시 안에서도 쓴다.

cylinder :: Double -> Double -> Double
cylinder r h =
  let side = 2 * pi * r * h
      top  = pi * r ^ 2
  in  side + 2 * top

fatBmis :: [(Double, Double)] -> [Double]
fatBmis xs = [bmi | (w, h) <- xs, let bmi = w / h ^ 2, bmi > 25]

case

패턴 매칭을 식 안에서 한다.

describeList :: [a] -> String
describeList xs = "이 리스트는 " ++ case xs of
  []  -> "비었다"
  [_] -> "하나뿐이다"
  _   -> "여럿이다"
