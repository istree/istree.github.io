Haskell 은 모든 식의 타입을 컴파일할 때 정한다. 타입을 적지 않아도 컴파일러가 찾아내고(타입 추론), GHCi 의 :t 로 볼 수 있다.

타입 보기

ghci> :t 'a'
'a' :: Char
ghci> :t "hello"
"hello" :: String              -- [Char] 와 같다
ghci> :t (True, 'a')
(True, 'a') :: (Bool, Char)

함수 타입 적기

함수 위에 이름 :: 인자 타입 -> … -> 결과 타입 을 적는다. 적어 두면 읽기 쉽고 오류도 빨리 잡는다.

factorial :: Integer -> Integer
factorial n = product [1..n]

circumference :: Double -> Double
circumference r = 2 * pi * r
  • Int — 크기가 정해진 정수
  • Integer — 한없이 큰 정수 (factorial 50 도 된다)
  • Float · Double — 실수
  • Bool · Char · String

타입 변수

어떤 타입이든 되는 자리는 소문자로 쓴다. 다른 언어의 제네릭과 비슷하다.

ghci> :t fst
fst :: (a, b) -> a
ghci> :t zip
zip :: [a] -> [b] -> [(a, b)]

타입 클래스

=> 앞은 "이 타입은 이런 동작을 할 수 있어야 한다" 는 조건이다.

ghci> :t (==)
(==) :: Eq a => a -> a -> Bool
  • Eq — 같은지 비교 (== · /=)
  • Ord — 크기 비교 (< · compare)
  • Show — 글자로 바꾸기 (show)
  • Read — 글자에서 읽기 (read "5" :: Int)
  • Num — 수 (+ · *), Integral · Floating 은 그 안의 정수 · 실수
max' :: Ord a => a -> a -> a
max' a b = if a <= b then b else a
