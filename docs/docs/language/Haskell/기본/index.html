Haskell 코드는 대부분 함수와 리스트로 이뤄진다. 함수 정의 · if 식 · 리스트 · 튜플을 다룬다.

함수

이름 · 인자 · = · 몸통 순서로 쓴다. 부를 때는 괄호 없이 띄어 쓴다.

doubleMe x = x * 2
doubleUs x y = doubleMe x + doubleMe y
ghci> doubleUs 3 4
14

if 는 식이다

if 는 값을 내는 식이라 else 를 빼먹을 수 없다. 식이므로 다른 식 안에 넣을 수 있다.

doubleSmall x = if x > 100 then x else x * 2
doubleSmallPlus x = (if x > 100 then x else x * 2) + 1

리스트

같은 타입의 값을 늘어놓는다. 글자열(String) 은 글자의 리스트다.

ghci> [1, 2, 3] ++ [4]       -- 잇기
[1,2,3,4]
ghci> 0 : [1, 2]             -- 앞에 붙이기
[0,1,2]
ghci> head [5, 6, 7]         -- 첫 값 (tail · last · init · length · reverse …)
5
ghci> [1, 2, 3] !! 1         -- 1 번째 (0 부터)
2

범위

ghci> [1..5]
[1,2,3,4,5]
ghci> [2, 4..10]             -- 간격
[2,4,6,8,10]
ghci> take 3 [7, 14..]       -- 끝없는 리스트도 필요한 만큼만 계산한다
[7,14,21]

리스트 조건제시

수학의 집합 표기처럼 "어디서 꺼내 · 어떤 조건으로 · 무엇을 만든다" 를 한 줄에 쓴다.

ghci> [x * 2 | x <- [1..10], x * 2 >= 12]
[12,14,16,18,20]
ghci> [(a, b) | a <- [1..3], b <- "ab"]
[(1,'a'),(1,'b'),(2,'a'),(2,'b'),(3,'a'),(3,'b')]

튜플

크기가 정해진 묶음이다. 서로 다른 타입을 함께 담는다.

ghci> fst (8, "eight")
8
ghci> zip [1, 2, 3] "abc"
[(1,'a'),(2,'b'),(3,'c')]
