Haskell 은 순수 함수형 언어다. 함수는 같은 입력에 늘 같은 결과를 내고, 값은 바뀌지 않는다. 필요할 때까지 계산을 미루는 게으른 계산, 컴파일러가 알아서 찾아 주는 강한 타입이 특징이다. 컴파일러는 GHC 를 쓴다.

여기에는 Learn You a Haskell 을 따라 공부한 기본(설치 · 문법 · 타입 · 재귀) 을 정리한다.
