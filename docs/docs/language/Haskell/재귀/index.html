Haskell 에는 for · while 이 없다. 반복은 재귀로 쓴다. "가장 작은 경우의 답" 과 "하나 줄인 경우로 답을 만드는 법" 두 줄이면 된다.

기본 모양

빈 리스트(가장 작은 경우) 와 첫 값 + 나머지(줄인 경우) 로 나눈다.

maximum' :: Ord a => [a] -> a
maximum' []     = error "빈 리스트"
maximum' [x]    = x
maximum' (x:xs) = max x (maximum' xs)

리스트 함수 직접 만들기

표준 함수를 재귀로 다시 만들어 보면 모양이 익는다.

replicate' :: Int -> a -> [a]
replicate' n x
  | n <= 0    = []
  | otherwise = x : replicate' (n - 1) x

take' :: Int -> [a] -> [a]
take' n _ | n <= 0 = []
take' _ []         = []
take' n (x:xs)     = x : take' (n - 1) xs

zip' :: [a] -> [b] -> [(a, b)]
zip' [] _          = []
zip' _ []          = []
zip' (x:xs) (y:ys) = (x, y) : zip' xs ys

elem' :: Eq a => a -> [a] -> Bool
elem' _ []     = False
elem' a (x:xs) = a == x || elem' a xs

끝없는 리스트

끝나는 경우가 없는 재귀도 게으른 계산 덕분에 필요한 만큼만 쓸 수 있다.

repeat' :: a -> [a]
repeat' x = x : repeat' x
ghci> take 3 (repeat' 'z')
"zzz"

퀵 정렬

첫 값보다 작은 것 · 큰 것을 나눠 각각 정렬하고 잇는다.

quicksort :: Ord a => [a] -> [a]
quicksort []     = []
quicksort (x:xs) =
  let smaller = quicksort [a | a <- xs, a <= x]
      bigger  = quicksort [a | a <- xs, a > x]
  in  smaller ++ [x] ++ bigger
