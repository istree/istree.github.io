Java 의 값은 원시 타입(int · double · boolean …) 과 참조 타입(객체 · 배열 · 문자열) 으로 나뉜다. 지역 변수는 var 로 타입을 추론하고, switch 는 값을 돌려주는 식으로 쓰며, 패턴 매칭으로 타입을 확인하면서 꺼낸다.

타입

int count = 3;
long big = 3_000_000_000L;      // int 를 넘으면 L
double price = 1500.5;
boolean ok = true;
char c = '가';                  // UTF-16 한 글자

var name = "geon";              // String 으로 추론 — 지역 변수에만
var list = new ArrayList<String>();
final int fixed = 1;            // 다시 대입할 수 없다
타입 크기 쓰는 곳
int · long 4 · 8 바이트 정수 — 크기가 플랫폼과 상관없이 같다
double 8 실수
boolean — true · false (정수와 바꿀 수 없다)
char 2 UTF-16 한 단위
Integer · Long · Double … 객체 원시 타입을 감싼 것 — 컬렉션에 넣을 때 
7 / 2;                         // 3 — 정수끼리는 몫만
7 / 2.0;                       // 3.5
(int) 3.9;                     // 3 — 잘린다

int max = Integer.MAX_VALUE;
max + 1;                       // -2147483648 — 넘치면 조용히 돈다
Math.addExact(max, 1);         // ArithmeticException: integer overflow — 넘침을 잡을 때

0.1 + 0.2;                                                       // 0.30000000000000004
new BigDecimal("0.1").add(new BigDecimal("0.2"));                // 0.3 — 돈은 BigDecimal 로

Integer a = 127, b = 127, x = 128, y = 128;
a == b;                        // true  — 작은 수는 캐시된 같은 객체라
x == y;                        // false — 객체끼리 == 는 같은 객체인지 본다
x.equals(y);                   // true  — 값 비교는 equals
  • 감싼 타입(Integer …) 과 문자열은 == 가 아니라 equals 로 비교한다. 작은 수에서 우연히 맞아 실수를 늦게 알아챈다
  • 감싼 타입이 null 인데 원시 타입으로 바꾸면 NullPointerException 이 난다(int n = map.get("x");)

문자열

String 은 바꿀 수 없는 객체다. 고치는 메서드는 새 문자열을 돌려준다.

String s = "Hello, Java";
s.length();              // 11
s.substring(7);          // "Java"
s.indexOf("Java");       // 7 — 없으면 -1
s.contains("lo");        // true
s.toUpperCase();         // "HELLO, JAVA"
" x ".strip();           // "x"
"ab".repeat(2);          // "abab"
String.join(",", "a", "b");      // "a,b"
"a,b,,c".split(",");             // ["a", "b", "", "c"] — 인자는 정규식이다

"%s님 %d건 %.1f%%".formatted("geon", 3, 12.345);   // "geon님 3건 12.3%"

var sb = new StringBuilder();                      // 반복해서 이어 붙일 때
for (int i = 0; i < 3; i++) sb.append(i).append(',');
sb.setLength(sb.length() - 1);                     // "0,1,2"

String json = """
    {
      "name": "geon",
      "age": 30
    }
    """;                                           // 텍스트 블록 — 공통 들여쓰기는 빠진다
  • 문자열 비교는 s1.equals(s2) 다. new String("hi") == "hi" 는 false 다
  • "합: " + 1 + 2 는 "합: 12" 다. 문자열이 앞에 오면 뒤의 + 가 모두 이어 붙이기가 된다. 계산은 괄호로 먼저 한다
  • 숫자로 바꾸기: Integer.parseInt("42") · Double.parseDouble("1.5"). 실패하면 NumberFormatException: For input string: "4x"

배열

int[] nums = {5, 3, 8};
int[][] grid = new int[2][3];      // 0 으로 채워진다
Arrays.sort(nums);                 // [3, 5, 8]
Arrays.toString(nums);             // "[3, 5, 8]" — 배열을 그냥 출력하면 주소 같은 글자가 나온다
nums.length;                       // 3 — 메서드가 아니라 필드
nums[3];                           // ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3

for (int n : nums) IO.print(n + " ");
  • 크기가 바뀌는 목록은 배열 대신 List 를 쓴다

switch 식

-> 로 쓰면 갈래끼리 내려가지 않고, 값을 돌려준다. 모든 경우를 다루지 않으면 컴파일 오류다.

int day = 6;
String kind = switch (day) {
    case 6, 7 -> "주말";
    case 1, 2, 3, 4, 5 -> "평일";
    default -> throw new IllegalArgumentException("요일: " + day);
};

패턴 매칭

타입을 확인하면서 그 타입의 변수로 꺼낸다.

Object o = 42;
if (o instanceof Integer i && i > 10) IO.println("큰 정수 " + i);   // 캐스팅 없이 i 를 쓴다

String describe(Object t) {
    return switch (t) {
        case null -> "null";
        case Integer i when i > 0 -> "양의 정수 " + i;      // when — 조건 더하기
        case Integer i -> "정수 " + i;
        case String s -> "문자열 " + s.length();
        case List<?> l -> "목록 " + l.size();
        default -> "그 밖 " + t;
    };
}
  • record · sealed 와 함께 쓰면 데이터 모양마다 갈래를 나누는 코드가 짧아진다

제어문

for (int i = 0; i < 3; i++) { … }
while (left > 0) { … }
do { … } while (retry());

outer:                                   // 이름 붙은 반복 — 바깥 반복을 끊는다
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++) {
        if (j == 1) continue outer;
        if (i == 2) break outer;
    }

예전에는

  • switch 는 case 6: case 7: kind = "주말"; break; 처럼 썼고 break 를 빠뜨리면 아래로 내려갔다. Java 14 부터 -> 와 식이다
  • if (o instanceof Integer) { Integer i = (Integer) o; … } 로 확인하고 캐스팅했다. Java 16 부터 패턴으로 한 번에 한다
  • 여러 줄 문자열을 "…\n" + "…" 로 이었다. Java 15 부터 텍스트 블록이다
  • 지역 변수 타입을 늘 적었다. Java 10 부터 var 다
