Java 코드는 javac 가 바이트코드(.class) 로 컴파일하고, java 가 JVM 에서 돌린다. 파일 하나 · 몇 개짜리는 컴파일 없이 java Hello.java 로 바로 돌린다. 여기의 예제는 Java 25 (LTS) 로 돌렸다.

파일 하나로 시작하기

Java 25 부터 클래스 · static · String[] args 없이 main 하나로 쓴다(compact source file).

// Hello.java
void main() {
    IO.println("Hello, Java!");
    String name = IO.readln("이름? ");
    IO.println("안녕, " + name);
}
$ java Hello.java          # 컴파일 없이 바로 — 메모리에서 컴파일해 돌린다
Hello, Java!
이름? geon
안녕, geon
  • IO.println · IO.readln 은 Java 25 의 java.lang.IO 다. System.out.println 과 같고 import 가 필요 없다
  • java.base 의 패키지(java.util · java.io …) 는 import 없이 쓴다. 스크립트 · 연습 코드에 쓴다
  • 컴파일 오류는 실행 전에 나온다: Bad.java:1: error: incompatible types: String cannot be converted to int

패키지가 있는 프로그램

보통의 프로그램은 클래스 하나가 파일 하나이고, 폴더가 패키지다.

src/com/example/app/Main.java
src/com/example/util/Text.java
// src/com/example/app/Main.java
package com.example.app;

import com.example.util.Text;

public class Main {
    public static void main(String[] args) {
        System.out.println(Text.shout(args.length > 0 ? args[0] : "world"));
    }
}
// src/com/example/util/Text.java
package com.example.util;

public final class Text {
    private Text() {}                                  // 만들지 못하게 — 도우미 함수만 둔다
    public static String shout(String s) { return s.toUpperCase() + "!"; }
}
javac -d out $(find src -name '*.java')       # out/ 에 .class 를 패키지 폴더대로
java -cp out com.example.app.Main geon        # GEON!
jar --create --file app.jar --main-class com.example.app.Main -C out .
java -jar app.jar                             # WORLD!
java src/com/example/app/Main.java multi      # MULTI! — 같은 소스 폴더의 다른 파일도 찾아 컴파일한다 (Java 22+)
  • public 클래스의 이름은 파일 이름과 같아야 한다
  • 패키지 이름은 도메인을 뒤집어 쓴다(com.example.app). 폴더 구조가 같아야 한다
  • 파일이 여러 개 · 외부 라이브러리가 있으면 직접 javac 하지 않고 Maven · Gradle 로 빌드한다

JShell

한 줄씩 넣고 결과를 바로 보는 REPL 이다.

$ jshell
jshell> int x = 2 + 3
x ==> 5
jshell> x * 10
$2 ==> 50
jshell> "abc".repeat(2)
$3 ==> "abcabc"
jshell> /exit
  • API 를 시험해 볼 때 쓴다. /imports · /vars 로 지금 상태를 본다

예전에는

  • public class Hello { public static void main(String[] args) { System.out.println(…); } } 처럼 클래스 · static · String[] args 를 늘 썼다. 지금도 큰 프로그램은 이렇게 쓴다
  • 소스 파일을 바로 돌리는 것은 Java 11(파일 하나) · 22(여러 파일) 부터다. 그 전에는 늘 javac 하고 java 했다
  • Scanner sc = new Scanner(System.in) 으로 입력을 읽었다. 파일 하나짜리 프로그램에서는 IO.readln 이 짧다
