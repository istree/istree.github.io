HTTP 요청은 Java 11 부터 들어 있는 java.net.http.HttpClient 로 보낸다. 동기 · 비동기 · HTTP/2 를 지원하고 따로 받을 라이브러리가 없다. 저수준 통신은 Socket · ServerSocket 으로 하고, 시험용 HTTP 서버는 JDK 의 HttpServer 로 띄운다.

HttpClient

import java.net.URI;
import java.net.http.*;
import java.time.Duration;

HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(5))
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();                                           // 만들어 두고 다시 쓴다

HttpRequest get = HttpRequest.newBuilder(URI.create("http://localhost:8090/api/notes"))
    .header("Accept", "application/json")
    .timeout(Duration.ofSeconds(10))                    // 응답 시간 제한
    .build();

HttpResponse<String> res = client.send(get, HttpResponse.BodyHandlers.ofString());
res.statusCode();                                       // 200
res.headers().firstValue("content-type");               // Optional[application/json; charset=utf-8]
res.body();                                             // [{"id":1,"text":"hello"}]

HttpRequest post = HttpRequest.newBuilder(URI.create("http://localhost:8090/api/notes"))
    .header("Content-Type", "application/json")
    .POST(HttpRequest.BodyPublishers.ofString("{\"text\":\"world\"}"))
    .build();
client.send(post, HttpResponse.BodyHandlers.ofString()).statusCode();   // 201

client.sendAsync(get, HttpResponse.BodyHandlers.ofString())             // CompletableFuture
      .thenApply(HttpResponse::body)
      .join();

client.send(get, HttpResponse.BodyHandlers.ofFile(Path.of("notes.json")));   // 바로 파일로
  • 404 · 500 도 예외 없이 응답으로 온다. statusCode() 를 꼭 본다
  • 연결하지 못하면 ConnectException 이, 시간을 넘기면 HttpTimeoutException 이 난다. 둘 다 IOException 이다
  • HttpClient 는 스레드 여럿이 함께 써도 된다. 요청마다 새로 만들지 않는다
  • JSON 을 객체로 바꾸는 것은 들어 있지 않다. Jackson · Gson 같은 라이브러리를 쓴다

주소 만들기

String q = URLEncoder.encode("정규식 책", StandardCharsets.UTF_8);     // 정규식+책 → %EC%A0%95…
URI uri = URI.create("https://example.com/search?q=" + q);
uri.getHost();       // example.com
uri.getQuery();      // q=정규식+책 — 풀어서 돌려준다
  • 쿼리 값 · 경로의 한 칸은 늘 인코딩해서 붙인다. 공백 · & · 한글이 그대로 들어가면 주소가 깨진다

시험용 HTTP 서버

JDK 의 com.sun.net.httpserver 로 라이브러리 없이 작은 서버를 띄운다. 테스트 · 도구용이고, 서비스는 Spring Boot 같은 프레임워크로 만든다.

import com.sun.net.httpserver.HttpServer;

HttpServer server = HttpServer.create(new InetSocketAddress(8090), 0);
server.createContext("/api/notes", ex -> {
    byte[] out = "[{\"id\":1,\"text\":\"hello\"}]".getBytes(StandardCharsets.UTF_8);
    ex.getResponseHeaders().set("Content-Type", "application/json; charset=utf-8");
    ex.sendResponseHeaders(200, out.length);           // 맞는 경로가 없으면 서버가 404 를 준다
    try (var os = ex.getResponseBody()) { os.write(out); }
});
server.setExecutor(Executors.newVirtualThreadPerTaskExecutor());   // 요청마다 가상 스레드
server.start();
// …
server.stop(0);
  • 같은 포트를 이미 쓰고 있으면 BindException: Address already in use 다
  • JDK 의 jwebserver 명령은 폴더를 정적 파일 서버로 띄운다: $JAVA_HOME/bin/jwebserver -p 8000 -d $(pwd)/site

소켓

TCP 로 바이트 · 줄을 주고받는다. 서버는 ServerSocket.accept() 로 연결을 받고, 클라이언트는 Socket 으로 연결한다.

try (var server = new ServerSocket(9090)) {
    Thread.ofVirtual().start(() -> {                          // 클라이언트
        try (var s = new Socket("localhost", 9090);
             var out = new PrintWriter(new OutputStreamWriter(s.getOutputStream(), StandardCharsets.UTF_8), true);
             var in = new BufferedReader(new InputStreamReader(s.getInputStream(), StandardCharsets.UTF_8))) {
            out.println("안녕");
            IO.println("client got " + in.readLine());        // client got echo: 안녕
        } catch (IOException e) { e.printStackTrace(); }
    });

    try (Socket c = server.accept();                          // 연결이 올 때까지 기다린다
         var in = new BufferedReader(new InputStreamReader(c.getInputStream(), StandardCharsets.UTF_8));
         var out = new PrintWriter(new OutputStreamWriter(c.getOutputStream(), StandardCharsets.UTF_8), true)) {
        out.println("echo: " + in.readLine());
    }
}
  • 연결마다 스레드 하나로 받으면(가상 스레드) 코드가 위에서 아래로 읽힌다. 연결이 아주 많으면 그래도 가상 스레드가 감당한다
  • 줄 단위로 주고받을 때는 양쪽 문자 집합을 맞추고, PrintWriter 의 두 번째 인자(true) 로 줄마다 내보낸다
  • 읽기가 영영 멈추지 않게 s.setSoTimeout(5000) 으로 시간 제한을 준다

예전에는

  • HttpURLConnection 으로 요청했다. 스트림을 직접 열고 닫고 상태 코드를 따로 읽었다. Java 11 부터 HttpClient 다
  • 연결이 많은 서버는 스레드가 모자라 NIO(Selector · SocketChannel) 나 Netty 로 짰다. Java 21 부터는 가상 스레드로 연결마다 스레드를 써도 된다
  • URLEncoder.encode(s, "UTF-8") 처럼 문자 집합을 문자열로 줘서 checked 예외를 처리했다. Java 10 부터 StandardCharsets.UTF_8 을 받는다
