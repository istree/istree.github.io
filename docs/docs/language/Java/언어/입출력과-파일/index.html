파일은 java.nio.file 의 Path(경로) 와 Files(파일 일을 하는 정적 메서드) 로 다룬다. 작은 파일은 한 번에 읽고 쓰고, 큰 파일은 줄 단위 스트림이나 버퍼로 흘려 읽는다. 글자를 읽고 쓸 때 문자 집합을 주지 않으면 UTF-8 이다.

경로

Path dir = Path.of("data");
Path notes = dir.resolve("notes.txt");          // data/notes.txt — 경로 붙이기
notes.getFileName();                            // notes.txt
notes.getParent();                              // data
notes.toAbsolutePath();                         // 실행한 폴더 기준 절대 경로
Path.of("data/../data/notes.txt").normalize();  // data/notes.txt

Files.exists(notes);
Files.isDirectory(dir);
Files.size(notes);                              // 바이트
  • 상대 경로는 프로그램을 실행한 폴더(user.dir) 기준이다
  • 경로를 문자열로 이어 붙이지 않고 resolve 로 붙인다. 구분자(/ · \) 를 OS 에 맞춘다

한 번에 읽고 쓰기

Files.createDirectories(dir.resolve("logs"));                    // 중간 폴더까지
Files.writeString(notes, "1,장보기\n2,운동\n");                   // 없으면 만들고 있으면 덮는다
Files.writeString(notes, "3,청소\n", StandardOpenOption.APPEND);  // 덧붙이기
Files.write(dir.resolve("list.txt"), List.of("a", "b"));          // 줄 목록

String all = Files.readString(notes);
List<String> lines = Files.readAllLines(notes);                  // [1,장보기, 2,운동, 3,청소]
byte[] bytes = Files.readAllBytes(dir.resolve("b.bin"));

큰 파일

파일 전체를 메모리에 올리지 않고 줄씩 읽는다.

try (Stream<String> lines = Files.lines(notes)) {          // 스트림도 닫아야 한다
    lines.filter(l -> l.startsWith("2")).toList();          // [2,운동]
}

try (var reader = Files.newBufferedReader(notes)) {
    String line;
    while ((line = reader.readLine()) != null) { … }
}

try (var writer = Files.newBufferedWriter(dir.resolve("big.txt"))) {
    for (int i = 0; i < 3; i++) {
        writer.write("line " + i);
        writer.newLine();
    }
}
  • Files.lines · Files.list · Files.walk 가 돌려주는 스트림은 파일을 열고 있다. try-with-resources 로 닫는다

이진 데이터

try (var out = new DataOutputStream(new BufferedOutputStream(Files.newOutputStream(dir.resolve("rec.bin"))))) {
    out.writeInt(42);
    out.writeUTF("펜");
    out.writeDouble(1.5);
}
try (var in = new DataInputStream(new BufferedInputStream(Files.newInputStream(dir.resolve("rec.bin"))))) {
    in.readInt();          // 42 — 쓴 순서대로 읽는다
    in.readUTF();          // "펜"
    in.readDouble();       // 1.5
}
  • 스트림은 감싸서 쓴다: 파일(newOutputStream) → 버퍼(BufferedOutputStream) → 형식(DataOutputStream). 버퍼 없이 바이트씩 쓰면 아주 느리다
  • 다른 프로그램 · 언어와 주고받는 데이터는 JSON · CSV 같은 글자 형식을 쓴다

폴더 다루기

Files.copy(notes, dir.resolve("logs/copy.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.move(dir.resolve("logs/copy.txt"), dir.resolve("logs/moved.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.delete(path);                     // 없으면 NoSuchFileException, 비지 않은 폴더면 DirectoryNotEmptyException
Files.deleteIfExists(path);

try (Stream<Path> s = Files.list(dir)) { … }                 // 바로 아래만
try (Stream<Path> s = Files.walk(dir)) {                      // 아래 전부
    s.filter(Files::isRegularFile)
     .filter(p -> p.toString().endsWith(".txt"))
     .count();
}
try (var ds = Files.newDirectoryStream(dir, "*.{txt,bin}")) { … }   // glob 으로 거르기

try (Stream<Path> s = Files.walk(dir)) {                      // 폴더째 지우기 — 깊은 것부터
    s.sorted(Comparator.reverseOrder()).forEach(p -> {
        try { Files.delete(p); } catch (IOException e) { throw new UncheckedIOException(e); }
    });
}

Path tmp = Files.createTempFile("app", ".tmp");               // 임시 파일

문자 집합

Files 의 글자 메서드는 기본이 UTF-8 이다. 다른 인코딩의 파일은 문자 집합을 준다.

Files.readString(path);                                   // EUC-KR 파일이면 MalformedInputException: Input length = 1
Files.readString(path, Charset.forName("EUC-KR"));        // "한글"
  • 윈도우에서 만든 옛 한글 파일 · CSV 는 EUC-KR(CP949) 인 경우가 많다

설정 파일

var props = new Properties();
try (var reader = Files.newBufferedReader(Path.of("app.properties"))) {
    props.load(reader);
}
props.getProperty("port");                  // "8080"
props.getProperty("host", "localhost");     // 없으면 기본값

예전에는

  • java.io.File 로 경로를 다뤘다. 실패하면 예외 대신 false 를 돌려줘 까닭을 알 수 없었다. Java 7 부터 Path · Files 다
  • new BufferedReader(new InputStreamReader(new FileInputStream(f), "UTF-8")) 처럼 겹겹이 감싸 열었다. 지금은 Files.newBufferedReader(path) 다
  • FileReader · FileWriter 는 OS 기본 문자 집합을 썼다. Java 18 부터 기본 문자 집합이 어디서나 UTF-8 이다
