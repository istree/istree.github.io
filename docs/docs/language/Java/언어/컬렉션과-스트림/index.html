값을 여럿 담을 때는 컬렉션(List · Set · Map …) 을 쓴다. 인터페이스 타입으로 받고 구현(ArrayList · HashMap …) 은 만들 때만 고른다. 거르고 바꾸고 모으는 일은 반복문 대신 스트림으로 이어 쓴다.

List

List<String> names = new ArrayList<>(List.of("kim", "lee"));
names.add("park");
names.add(0, "choi");
names.remove("lee");               // [choi, kim, park]
names.get(1);                      // "kim"
names.contains("park");            // true
names.getFirst();                  // "choi" — Java 21
names.reversed();                  // [park, kim, choi] — 뒤집어 보기 (Java 21)

List<Integer> nums = new ArrayList<>(List.of(5, 3, 8, 1));
nums.removeIf(n -> n < 3);         // 조건으로 지우기
Collections.sort(nums);            // [3, 5, 8]
  • List.of(…) · Map.of(…) · Set.of(…) 는 고칠 수 없는 컬렉션이다. add 하면 UnsupportedOperationException, null 을 넣으면 NullPointerException 이다. 고칠 목록은 new ArrayList<>(List.of(…)) 로 만든다
  • 돌면서 지우면 ConcurrentModificationException 이 난다. removeIf 나 Iterator.remove() 로 지운다

Map

Map<String, Integer> stock = new HashMap<>();
stock.put("pen", 3);
stock.merge("pen", 2, Integer::sum);     // 있으면 더한다 — 5
stock.putIfAbsent("note", 5);
stock.get("bag");                        // null — 없으면 null
stock.getOrDefault("bag", 0);            // 0

Map<String, List<String>> groups = new TreeMap<>();
groups.computeIfAbsent("a", k -> new ArrayList<>()).add("apple");    // 없으면 만들고 넣기
groups.computeIfAbsent("a", k -> new ArrayList<>()).add("avocado");  // {a=[apple, avocado]}

for (var e : stock.entrySet())
    IO.println(e.getKey() + "=" + e.getValue());
구현 순서 쓰는 곳
ArrayList 넣은 순서 목록 — 기본
ArrayDeque 앞 · 뒤 스택(push · pop) · 큐(offer · poll)
PriorityQueue 우선순위 가장 작은(큰) 것부터 꺼내기
HashMap · HashSet 없음 표 · 집합 — 기본
LinkedHashMap · LinkedHashSet 넣은 순서 순서를 지켜야 하는 표
TreeMap · TreeSet 키 순서 정렬된 표 · 범위 찾기
  • HashMap 의 순서는 정해져 있지 않다. 출력 순서에 기대지 않는다
  • 스레드 여럿이 함께 쓰는 표는 ConcurrentHashMap 을 쓴다

스트림

컬렉션에서 stream() 으로 시작해 단계를 잇고, toList() · collect · sum 같은 마지막 단계에서 결과를 만든다.

record Order(String customer, String item, int qty, int price) {
    int total() { return qty * price; }
}
List<Order> orders = List.of(
    new Order("kim", "펜", 2, 1500), new Order("lee", "공책", 1, 3000),
    new Order("kim", "가방", 1, 25000), new Order("park", "펜", 5, 1500));

orders.stream().mapToInt(Order::total).sum();                        // 38500

orders.stream()
    .filter(o -> o.total() >= 5000)
    .map(Order::item)
    .toList();                                                       // [가방, 펜]

orders.stream().map(Order::customer).distinct().sorted()
    .collect(Collectors.joining(", ", "[", "]"));                    // "[kim, lee, park]"

orders.stream().max(Comparator.comparingInt(Order::total))
    .map(Order::item).orElse("없음");                                 // "가방"

orders.stream().anyMatch(o -> o.qty() > 3);                          // true
IntStream.rangeClosed(1, 5).map(x -> x * x).boxed().toList();         // [1, 4, 9, 16, 25]
Stream.of("a,b", "c").flatMap(s -> Arrays.stream(s.split(","))).toList();   // [a, b, c]

모아서 표로 만들 때는 Collectors 를 쓴다.

Map<String, Integer> byCustomer = orders.stream()
    .collect(Collectors.groupingBy(Order::customer, TreeMap::new, Collectors.summingInt(Order::total)));
// {kim=28000, lee=3000, park=7500}

Map<String, Long> countByItem = orders.stream()
    .collect(Collectors.groupingBy(Order::item, Collectors.counting()));   // {가방=1, 공책=1, 펜=2}

Map<Boolean, List<String>> byPrice = orders.stream()
    .collect(Collectors.partitioningBy(o -> o.price() >= 3000,
             Collectors.mapping(Order::item, Collectors.toList())));      // {false=[펜, 펜], true=[공책, 가방]}

orders.stream().collect(Collectors.toMap(Order::item, Order::qty));
// IllegalStateException: Duplicate key 펜 (attempted merging values 2 and 5)
orders.stream().collect(Collectors.toMap(Order::item, Order::qty, Integer::sum));   // 겹치면 더한다
  • 스트림은 한 번만 쓴다. 다시 쓰면 IllegalStateException: stream has already been operated upon or closed 다
  • toList()(Java 16) 는 고칠 수 없는 목록을 돌려준다. 고칠 목록이 필요하면 collect(Collectors.toCollection(ArrayList::new)) 다
  • 스트림 안에서 바깥 변수 · 컬렉션을 고치지 않는다. 결과는 마지막 단계로 모은다

Optional

없을 수 있는 결과를 돌려줄 때 null 대신 쓴다.

Optional<String> none = Optional.empty();
none.isPresent();                        // false
none.orElse("기본");                     // "기본"
none.orElseGet(() -> load());            // 없을 때만 계산
none.orElseThrow();                      // NoSuchElementException: No value present
Optional.of("x").map(String::toUpperCase).get();   // "X"
  • 반환 타입에만 쓴다. 필드 · 매개변수 · 컬렉션의 원소로 쓰지 않는다

예전에는

  • Arrays.asList · Collections.unmodifiableList 로 고정 목록을 만들었다. Java 9 부터 List.of 다
  • 첫 · 끝 원소를 list.get(0) · list.get(list.size() - 1) 로 꺼냈다. Java 21 부터 getFirst · getLast · reversed 다
  • 스트림이 없던 때(Java 7) 는 for 로 돌며 Map 에 직접 모았다
  • collect(Collectors.toList()) 를 썼다. Java 16 부터 toList() 다
