JDK(Java Development Kit) 는 컴파일러(javac) · JVM(java) · 진단 도구를 묶은 것이다. 소스는 모두 OpenJDK 하나이고, 여러 회사가 그것을 빌드해 배포판으로 낸다. 일은 LTS 판으로 하고, 프로젝트마다 판이 다르면 여러 판을 설치해 두고 바꿔 쓴다.

판 고르기

6 개월마다(3 월 · 9 월) 새 판이 나오고, 2 년마다 하나가 LTS(오래 지원하는 판) 가 된다.

판 나온 때 지금
25 2025-09 최신 LTS — 새 프로젝트
21 2023-09 LTS — 가상 스레드 · 패턴 매칭 · record
17 2021-09 LTS — Spring Boot 3 의 최소 판
11 · 8 2018 · 2014 오래된 LTS — 옛 시스템
  • LTS 사이의 판(26 · 27) 은 다음 판이 나오면 지원이 끝난다. 새 기능을 미리 써 볼 때만 쓴다

배포판

배포판 만든 곳 쓰는 곳
Eclipse Temurin Eclipse Adoptium 무료 · 기본으로 권한다
Amazon Corretto AWS AWS 에서
Microsoft Build of OpenJDK Microsoft Azure 에서
Azul Zulu Azul 옛 판(6 · 7) 까지 받을 수 있다
Oracle JDK Oracle 라이선스 조건을 확인하고 쓴다
  • 같은 판이면 배포판끼리 동작은 같다. 지원 기간 · 패치 속도 · 라이선스가 다르다

설치

brew install --cask temurin@25        # macOS — /Library/Java/JavaVirtualMachines 에 설치 (관리자 암호)
sudo apt install temurin-25-jdk       # Ubuntu — Adoptium 저장소를 더한 뒤
winget install EclipseAdoptium.Temurin.25.JDK   # Windows

java -version

관리자 권한 없이 설치하려면 압축 파일을 받아 사용자 폴더에 푼다. macOS 는 ~/Library/Java/JavaVirtualMachines 에 두면 시스템이 찾는다.

mkdir -p ~/Library/Java/JavaVirtualMachines && cd ~/Library/Java/JavaVirtualMachines
curl -L "https://api.adoptium.net/v3/binary/latest/25/ga/mac/aarch64/jdk/hotspot/normal/eclipse" | tar xz
$ java -version
openjdk version "25.0.5" 2026-10-20 LTS
OpenJDK Runtime Environment Temurin-25.0.5+8 (build 25.0.5+8-LTS)

여러 판 바꾸기

macOS 는 /usr/libexec/java_home 이 설치된 JDK 를 찾는다.

/usr/libexec/java_home -V             # 설치된 판 목록
export JAVA_HOME=$(/usr/libexec/java_home -v 21)    # 21 로 — ~/.zshrc 에 두면 기본값
export PATH="$JAVA_HOME/bin:$PATH"
  • macOS 의 /usr/bin/java 는 JAVA_HOME 의 JDK 를 부르는 껍데기다. java · javac · jcmd 같은 명령만 있고 jfr · jwebserver 는 없다. $JAVA_HOME/bin 을 PATH 에 넣으면 모두 쓴다
  • Maven · Gradle · IDE 도 JAVA_HOME 을 본다. 터미널과 IDE 의 판이 다르면 빌드 결과가 달라진다

판을 자주 바꾸면 버전 관리 도구를 쓴다.

curl -s "https://get.sdkman.io" | bash     # SDKMAN — macOS · Linux
sdk list java                              # 받을 수 있는 배포판 · 판
sdk install java 25.0.5-tem
sdk use java 21.0.9-tem                    # 이 터미널만
sdk default java 25.0.5-tem
  • 프로젝트 폴더에 .sdkmanrc(java=21.0.9-tem) 를 두고 sdk env 하면 그 판을 쓴다

컴파일 판 맞추기

새 JDK 로 옛 JVM 에서 돌 바이트코드를 만들 때는 --release 를 준다.

javac --release 17 -d out src/…      # Java 17 JVM 에서 돈다 — 18 이후 API 를 쓰면 컴파일 오류
  • 판이 높은 .class 를 낮은 JVM 에서 돌리면 UnsupportedClassVersionError: … has been compiled by a more recent version of the Java Runtime (class file version 69.0) 이 난다. class 파일 판 69 는 Java 25, 65 는 21, 61 은 17 이다
