AWT(Abstract Window Toolkit) 는 Java 의 첫 GUI 툴킷이다. 버튼 · 목록 같은 컴포넌트를 OS 의 진짜 위젯으로 그리고(heavyweight), 창 · 이벤트 · 그리기(Java 2D) · 이미지 · 글꼴의 바탕을 맡는다. 지금 화면은 Swing · JavaFX 로 만들지만, Swing 은 AWT 의 창 · 이벤트 · 그리기 위에서 돈다. 여기의 예제는 JDK 25 로 띄워 확인했다.

창 하나

import java.awt.*;
import java.awt.event.*;

public class AwtHello {
    public static void main(String[] args) {
        Frame frame = new Frame("메모");
        frame.setLayout(new BorderLayout(8, 8));

        Panel top = new Panel(new FlowLayout(FlowLayout.LEFT));
        TextField input = new TextField(20);
        Button add = new Button("추가");
        top.add(new Label("할 일"));
        top.add(input);
        top.add(add);

        List items = new List(8);                    // java.awt.List — 목록 컴포넌트
        Label status = new Label("0 개");

        ActionListener onAdd = e -> {
            String text = input.getText().trim();
            if (text.isEmpty()) return;
            items.add(text);
            input.setText("");
            status.setText(items.getItemCount() + " 개");
        };
        add.addActionListener(onAdd);                // 버튼 누르기
        input.addActionListener(onAdd);              // 입력 칸에서 엔터
        items.addItemListener(e -> status.setText("선택: " + items.getSelectedItem()));

        frame.add(top, BorderLayout.NORTH);
        frame.add(items, BorderLayout.CENTER);
        frame.add(status, BorderLayout.SOUTH);

        frame.addWindowListener(new WindowAdapter() {
            @Override public void windowClosing(WindowEvent e) { frame.dispose(); }   // 없으면 닫기 단추가 안 듣는다
        });
        frame.setSize(360, 260);
        frame.setLocationRelativeTo(null);           // 화면 가운데
        frame.setVisible(true);
    }
}
java AwtHello.java
  • AWT Frame 은 닫기 단추를 눌러도 저절로 닫히지 않는다. windowClosing 에서 dispose() 한다. 마지막 창을 dispose 하면 프로그램이 끝난다
  • java.awt.List 와 java.util.List 는 이름이 같다. 둘 다 import 하면 한쪽을 패키지째 쓴다

컴포넌트

컴포넌트 하는 일 주로 쓰는 이벤트
Label 글자 —
Button 단추 ActionListener
TextField · TextArea 한 줄 · 여러 줄 입력 ActionListener(엔터) · TextListener
Checkbox · CheckboxGroup 체크 · 라디오 ItemListener
Choice · List 펼침 목록 · 목록 ItemListener
Canvas 직접 그리는 빈 칸 paint 를 바꾼다
Panel 컴포넌트를 묶는 칸 —
Frame · Dialog 창 · 대화상자 WindowListener

레이아웃

컨테이너마다 레이아웃 매니저가 컴포넌트의 자리 · 크기를 정한다. 창 크기가 바뀌면 다시 배치한다.

레이아웃 배치 기본으로 쓰는 곳
BorderLayout 동 · 서 · 남 · 북 · 가운데. 가운데가 남는 자리를 모두 차지한다 Frame · Dialog
FlowLayout 한 줄로 흘려 놓고, 넘치면 다음 줄 Panel
GridLayout 같은 크기의 칸 계산기 단추
GridBagLayout 칸마다 크기 · 늘어남을 따로 입력 폼
CardLayout 여러 장 중 하나만 보인다 단계별 화면
  • 레이아웃을 바꿔 가며 Panel 을 겹쳐 쓴다. 위의 예는 창이 BorderLayout, 위쪽 칸이 FlowLayout 이다
  • setLayout(null) 로 좌표를 직접 주면 글꼴 · DPI · OS 가 바뀔 때 어긋난다

이벤트

이벤트는 이벤트 디스패치 스레드(EDT) 하나가 차례로 처리한다. 리스너 안에서 오래 걸리는 일을 하면 그동안 창이 멈춘다.

button.addActionListener(e -> {
    new Thread(() -> {                                  // 오래 걸리는 일은 다른 스레드에서
        String result = download();
        EventQueue.invokeLater(() -> label.setText(result));   // 화면은 EDT 에서 고친다
    }).start();
});
리스너 받는 것
ActionListener 단추 · 엔터 · 메뉴
MouseListener · MouseMotionListener 누르기 · 놓기 · 움직이기 · 끌기
KeyListener 키 누르기 (포커스가 있는 컴포넌트)
WindowListener 열기 · 닫기 · 활성화
ComponentListener 크기 · 자리 바뀜
  • 메서드가 여럿인 리스너는 MouseAdapter · WindowAdapter 를 물려받아 필요한 것만 바꾼다

AWT 와 Swing

AWT Swing
컴포넌트 OS 위젯 (Button) Java 가 직접 그린다 (JButton)
모양 OS 마다 다르다 Look and Feel 로 바꾼다
컴포넌트 수 적다 (표 · 트리 없음) 많다 (JTable · JTree …)
바탕 — AWT 의 창 · 이벤트 · Java 2D 를 쓴다
  • 새 화면은 Swing · JavaFX 로 만든다. AWT 의 컴포넌트를 Swing 컴포넌트와 한 창에 섞으면 겹치는 자리에서 그리기 순서가 어긋난다
  • 창 없이 이미지 · 글자를 그리는 일(서버에서 차트 · 썸네일 만들기) 은 지금도 AWT 의 Java 2D 로 한다. -Djava.awt.headless=true 로 화면 없이 돈다
