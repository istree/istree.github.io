AWT 의 Java 2D 는 Graphics2D 하나로 도형 · 선 · 글자 · 이미지를 그린다. 창의 컴포넌트에 그릴 때도, 화면 없이 이미지에 그릴 때도 같은 API 다. 도형은 Shape 객체(Rectangle2D · Ellipse2D · Path2D …) 로 만들고, 색 · 선 굵기 · 변환은 Graphics2D 의 상태로 정한 뒤 fill · draw 한다. 아래 그림은 이 글의 코드가 그린 것이다.

어디에 그리나

// 창에 — Canvas 의 paint 를 바꾼다 (Swing 에서는 JComponent 의 paintComponent)
class Board extends Canvas {
    @Override public void paint(Graphics g) {
        Graphics2D g2 = (Graphics2D) g;
        draw(g2, getWidth(), getHeight());
    }
}

// 이미지에 — 화면 없이 (서버 · 파일 만들기)
var img = new BufferedImage(300, 260, BufferedImage.TYPE_INT_ARGB);
Graphics2D g = img.createGraphics();
try {
    draw(g, 300, 260);
} finally {
    g.dispose();                                  // 직접 만든 Graphics 는 닫는다
}
ImageIO.write(img, "png", new File("shapes.png"));
  • 받은 Graphics 는 실제로 Graphics2D 다. 캐스팅해서 쓴다
  • 서버처럼 화면이 없는 곳에서는 -Djava.awt.headless=true 로 돌린다. 창은 못 띄우지만 이미지 그리기는 된다
  • 좌표는 왼쪽 위가 (0, 0) 이고 y 가 아래로 커진다

도형 · 색 · 선

g.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);   // 매끄럽게 — 늘 켠다

g.setColor(new Color(0x4E79A7));
g.fill(new RoundRectangle2D.Double(20, 20, 120, 80, 16, 16));     // 둥근 사각형 채우기

g.setColor(new Color(0xE15759));
g.setStroke(new BasicStroke(4, BasicStroke.CAP_ROUND, BasicStroke.JOIN_ROUND));
g.draw(new Ellipse2D.Double(170, 20, 80, 80));                    // 원 테두리

g.setStroke(new BasicStroke(2, BasicStroke.CAP_BUTT, BasicStroke.JOIN_MITER,
                            10, new float[]{8, 6}, 0));           // 점선 — 8 그리고 6 비우기
g.setColor(Color.DARK_GRAY);
g.draw(new Line2D.Double(20, 130, 280, 130));
도형 만드는 것
Rectangle2D · RoundRectangle2D 사각형 · 둥근 사각형
Ellipse2D · Arc2D 원 · 타원 · 부채꼴
Line2D · QuadCurve2D · CubicCurve2D 선 · 곡선
Path2D 점을 이어 만드는 아무 모양
Area 도형끼리 더하기 · 빼기 · 겹친 곳
  • Color(0x59A14F, true) 의 두 번째 인자는 "앞 바이트가 알파" 라는 뜻이다. 0x59A14F 는 알파가 0 이라 아무것도 그려지지 않는다. 반투명은 new Color(0x9959A14F, true) 처럼 앞 두 자리에 알파를 넣거나 AlphaComposite 를 쓴다
  • 정수 좌표 메서드(fillRect(int…) · drawOval) 도 있다. 선이 반 픽셀씩 어긋나지 않게 하려면 Double 도형을 쓴다

Path2D · 그라데이션

Path2D star = new Path2D.Double();
for (int i = 0; i < 10; i++) {                                    // 별 — 바깥 · 안쪽 점을 번갈아
    double r = i % 2 == 0 ? 40 : 16;
    double a = Math.PI / 5 * i - Math.PI / 2;
    double x = 80 + r * Math.cos(a), y = 200 + r * Math.sin(a);
    if (i == 0) star.moveTo(x, y); else star.lineTo(x, y);
}
star.closePath();

g.setPaint(new GradientPaint(40, 160, new Color(0xF28E2B), 120, 240, new Color(0xEDC948)));
g.fill(star);

Area half = new Area(new Ellipse2D.Double(150, 160, 50, 50));
half.subtract(new Area(new Rectangle2D.Double(175, 160, 25, 50)));   // 원에서 오른쪽 반 빼기
g.setColor(Color.GRAY);
g.fill(half);

star.contains(80, 200);           // true — 그 점이 도형 안인지 (마우스로 고르기)
star.getBounds();                 // Rectangle[x=41,y=160,width=78,height=73]

변환 · 투명도

AffineTransform saved = g.getTransform();             // 지금 상태를 받아 둔다
g.translate(210, 200);                                // 원점 옮기기
g.rotate(Math.toRadians(30));                         // 돌리기 (원점 기준)
g.setComposite(AlphaComposite.getInstance(AlphaComposite.SRC_OVER, 0.6f));   // 60% 불투명
g.setColor(new Color(0x59A14F));
g.fillRect(-35, -25, 70, 50);                         // (210, 200) 을 가운데로 30° 기운 사각형
g.setTransform(saved);                                // 돌려놓는다
g.setComposite(AlphaComposite.SrcOver);
  • 변환 · 색 · 선은 그 뒤에 그리는 것 모두에 걸린다. 바꿨으면 돌려놓거나, Graphics2D g2 = (Graphics2D) g.create(); 로 복사본에 그리고 dispose 한다
  • scale(2, 2) 로 크게 그리면 선 굵기도 두 배가 된다
