AWT · Java 2D 로 글자를 그린다. 한 가지 모양이면 drawString, 한 줄에 여러 모양을 섞으면 AttributedString, 정해진 폭에서 줄을 바꾸거나 글자 자리를 알아야 하면 TextLayout 을 쓴다.

그리기

@Override
protected void paintComponent(Graphics g) {
    super.paintComponent(g);
    Graphics2D g2 = (Graphics2D) g;
    g2.setRenderingHint(RenderingHints.KEY_TEXT_ANTIALIASING,
                        RenderingHints.VALUE_TEXT_ANTIALIAS_ON);   // 매끄럽게
    g2.setFont(new Font("맑은 고딕", Font.BOLD, 16));
    g2.setColor(Color.DARK_GRAY);
    g2.drawString("제목", 10, 30);
}
  • drawString 의 y 는 글자의 바탕선(baseline) 이다. 글자 윗부분은 y 위로 올라간다

크기 재고 가운데 맞추기

FontMetrics 로 글자 폭과 높이를 잰다.

FontMetrics fm = g2.getFontMetrics();
int w = fm.stringWidth(text);
int x = (getWidth() - w) / 2;
int y = (getHeight() - fm.getHeight()) / 2 + fm.getAscent();   // 바탕선 자리
g2.drawString(text, x, y);

한 줄에 여러 모양

AttributedString 에 글자 범위마다 속성을 준다. 범위는 [시작, 끝) 이다.

AttributedString as = new AttributedString("굵게 밑줄 빨강");
as.addAttribute(TextAttribute.FAMILY, "맑은 고딕");
as.addAttribute(TextAttribute.SIZE, 14f);
as.addAttribute(TextAttribute.WEIGHT, TextAttribute.WEIGHT_BOLD, 0, 2);       // 굵게
as.addAttribute(TextAttribute.UNDERLINE, TextAttribute.UNDERLINE_ON, 3, 5);   // 밑줄
as.addAttribute(TextAttribute.FOREGROUND, Color.RED, 6, 8);                   // 빨강

g2.drawString(as.getIterator(), 10, 30);
  • TextAttribute.FONT 로 Font 를 통째로 주면 그 범위의 다른 글꼴 속성(WEIGHT · SIZE …) 은 무시된다. 섞어 쓸 때는 FAMILY · SIZE 로 나눠 준다
  • 취소선은 STRIKETHROUGH_ON, 배경색은 BACKGROUND

정해진 폭에서 줄 바꾸기

LineBreakMeasurer 가 폭에 맞춰 한 줄씩 잘라 TextLayout 으로 준다.

AttributedCharacterIterator it = as.getIterator();
LineBreakMeasurer lbm = new LineBreakMeasurer(it, g2.getFontRenderContext());
float width = getWidth() - 20, y = 10;

while (lbm.getPosition() < it.getEndIndex()) {
    TextLayout line = lbm.nextLayout(width);
    y += line.getAscent();
    line.draw(g2, 10, y);
    y += line.getDescent() + line.getLeading();
}
  • 줄바꿈 문자(\n) 에서는 끊지 않는다. 문단마다 나눠서 각각 돌린다

글자 정보와 마우스 자리

TextLayout 은 그린 글자의 실제 크기와, 마우스가 가리키는 글자를 알려 준다.

TextLayout layout = new TextLayout("Hello 글자", font, g2.getFontRenderContext());

Rectangle2D ink = layout.getBounds();          // 실제로 칠해지는 영역
float ascent    = layout.getAscent();

TextHitInfo hit = layout.hitTestChar(mx - x, my - y);   // 그린 자리 기준 좌표
int index = hit.getInsertionIndex();                    // 커서가 들어갈 자리
Shape caret = layout.getCaretShapes(index)[0];
