JavaFX 의 모양은 CSS 로 꾸민다. 웹의 CSS 와 문법은 같지만 속성 이름이 -fx- 로 시작한다. 움직임은 Transition(정해진 움직임) 과 Timeline(키 프레임) 으로 속성 값을 시간에 따라 바꾼다. 아래 그림은 이 글의 CSS 를 입힌 카드다.

CSS 입히기

/* src/main/resources/app.css */
.root {                                   /* Scene 의 맨 위 — 전체 기본값 */
    -fx-font-size: 13px;
    -accent: #E15759;                     /* 이름 붙인 색 — 아래에서 다시 쓴다 */
}
.card {
    -fx-background-color: white;
    -fx-background-radius: 10;
    -fx-padding: 12;
    -fx-effect: dropshadow(gaussian, rgba(0,0,0,0.15), 10, 0, 0, 2);
}
.title { -fx-font-size: 16px; -fx-font-weight: bold; }
.button.primary {
    -fx-background-color: -accent;
    -fx-text-fill: white;
    -fx-background-radius: 6;
}
.button.primary:hover { -fx-background-color: derive(-accent, -15%); }   /* 15% 어둡게 */
#badge { -fx-text-fill: -accent; }
var title = new Label("주문 3 건");
title.getStyleClass().add("title");               // class="title"
var badge = new Label("새 주문");
badge.setId("badge");                             // id="badge"
var pay = new Button("결제");
pay.getStyleClass().add("primary");               // 컨트롤은 이미 "button" 클래스를 갖고 있다
var card = new VBox(8, title, badge, pay);
card.getStyleClass().add("card");

var scene = new Scene(root, 220, 170);
scene.getStylesheets().add(getClass().getResource("/app.css").toExternalForm());
  • 컨트롤마다 기본 스타일 클래스가 있다(.button · .text-field · .list-view …). 기본 테마 Modena 의 CSS 가 그 이름으로 짜여 있다
  • 한 노드만 바꿀 때는 node.setStyle("-fx-background-color: #F2F2F2;") 다. 많아지면 CSS 파일로 옮긴다
  • 상태 선택자 :hover · :pressed · :focused · :disabled · :selected 를 쓴다. 직접 만든 상태는 pseudoClassStateChanged(PseudoClass.getPseudoClass("error"), true) 로 켠다
  • 웹 CSS 와 달리 margin · display · flex 는 없다. 배치는 레이아웃 판이 맡는다

Transition

var fade = new FadeTransition(Duration.millis(300), badge);    // 투명도
fade.setFromValue(1);
fade.setToValue(0.2);
fade.setCycleCount(2);
fade.setAutoReverse(true);                                       // 흐려졌다 돌아오기

var move = new TranslateTransition(Duration.millis(300), pay);  // 자리 옮기기
move.setByX(20);

var both = new SequentialTransition(fade, move);                 // 차례로 — 모두 900 ms
both.setOnFinished(e -> IO.println("끝"));
both.play();
Transition 바꾸는 것
FadeTransition 투명도
TranslateTransition · RotateTransition · ScaleTransition 자리 · 회전 · 크기
FillTransition · StrokeTransition 도형의 채우기 · 선 색
PathTransition 경로를 따라 움직이기
ParallelTransition · SequentialTransition · PauseTransition 함께 · 차례로 · 쉬기

Timeline

아무 속성이나 키 프레임으로 바꾼다.

var showTitle = new Timeline(
    new KeyFrame(Duration.ZERO, new KeyValue(title.opacityProperty(), 0)),
    new KeyFrame(Duration.millis(200), new KeyValue(title.opacityProperty(), 1, Interpolator.EASE_OUT)));
showTitle.play();

var clock = new Timeline(new KeyFrame(Duration.seconds(1), e -> label.setText(LocalTime.now().toString())));
clock.setCycleCount(Animation.INDEFINITE);       // 1 초마다 — JavaFX 스레드에서 돈다
clock.play();
  • 화면을 정해진 시간마다 고칠 때는 스레드 · sleep 대신 Timeline 을 쓴다. 동작이 JavaFX 스레드에서 돈다
  • 프레임마다 직접 그려야 하는 게임 · 시뮬레이션은 AnimationTimer 의 handle(long now) 를 쓴다
