JavaFX 의 이미지는 Image(데이터) 와 ImageView(화면에 놓는 노드) 로 나뉜다. 같은 Image 를 여러 ImageView 가 크기 · 잘라 보기를 달리해 보여 준다. 픽셀을 직접 만들거나 읽을 때는 WritableImage · PixelReader 를 쓰고, 화면을 그대로 이미지로 뜨려면 snapshot 을 쓴다.

읽어 보이기

var photo = new Image(getClass().getResource("/photo.png").toExternalForm());   // 리소스
var remote = new Image("https://example.com/a.png", true);                        // true — 백그라운드에서 받기
var thumb = new Image(url, 100, 0, true, true);       // 폭 100 · 높이 비율대로 · 부드럽게 줄여 읽기

var view = new ImageView(photo);
view.setFitWidth(240);
view.setPreserveRatio(true);                          // 비율 지키기
view.setSmooth(true);
  • Image 는 URL 문자열을 받는다. 파일은 "file:/경로" 나 file.toURI().toString() 으로 준다. 경로만 쓰면 리소스로 찾는다
  • 읽기에 실패해도 예외가 나지 않는다. isError() 가 true 이고 getException() 에 까닭이 있다: java.io.FileNotFoundException: nope.png (No such file or directory)
  • 백그라운드로 읽으면 처음에는 폭 · 높이가 0 이다. progressProperty() 가 1 이 되면 다 읽힌 것이다
  • 큰 사진을 썸네일로만 쓸 때는 읽을 때 크기를 주면(new Image(url, 100, 0, true, true)) 메모리를 덜 쓴다

잘라 보기 · 효과

var crop = new ImageView(photo);
crop.setViewport(new Rectangle2D(0, 0, 60, 40));      // 이미지의 이 부분만
crop.setFitWidth(120);
crop.setPreserveRatio(true);
crop.setEffect(new ColorAdjust(0, -1, 0, 0));         // 흑백

픽셀

아래 그림의 왼쪽은 픽셀마다 색을 넣어 만든 이미지를 크게 보인 것이고, 오른쪽은 그 왼쪽 위를 잘라 흑백으로 보인 것이다.

var img = new WritableImage(120, 80);
PixelWriter pw = img.getPixelWriter();
for (int y = 0; y < 80; y++)
    for (int x = 0; x < 120; x++)
        pw.setColor(x, y, Color.hsb(x * 3, 0.6, 0.9 - y / 200.0));   // 색상 · 채도 · 밝기

Color c = img.getPixelReader().getColor(0, 0);       // 0.90 0.36 0.36 — 빨강 · 초록 · 파랑 (0 ~ 1)
  • 많은 픽셀을 바꿀 때는 setPixels(x, y, w, h, PixelFormat.getIntArgbInstance(), int[] buf, 0, w) 로 배열째 넣는다

화면을 이미지로

WritableImage shot = node.snapshot(null, null);      // 노드 하나 — scene.snapshot(null) 은 창 내용 전체

BufferedImage bi = SwingFXUtils.fromFXImage(shot, null);   // javafx.swing 모듈
ImageIO.write(bi, "png", new File("shot.png"));
  • 파일로 저장은 JavaFX 에 없다. javafx.swing 모듈의 SwingFXUtils 로 AWT 이미지로 바꿔 ImageIO 로 쓴다
  • snapshot 은 JavaFX 스레드에서, 노드가 그려진 뒤에 부른다. 창을 띄운 직후라면 Platform.runLater 안에서 한다
