JavaFX 의 화면은 컨트롤(입력 · 목록 · 표) 을 레이아웃 판(VBox · HBox · GridPane · BorderPane …) 에 넣어 만든다. 레이아웃 판도 노드라서 판 안에 판을 겹쳐 쓴다. 아래 그림은 이 글의 폼과 표를 캡처한 것이다.

입력 컨트롤

var name = new TextField("geon");
var status = new ComboBox<>(FXCollections.observableArrayList("초안", "공개"));
status.getSelectionModel().selectFirst();
var notify = new CheckBox("알림 받기");

var size = new ToggleGroup();                              // 라디오 단추 묶음 — 하나만 고른다
var s = new RadioButton("S");  s.setToggleGroup(size);
var m = new RadioButton("M");  m.setToggleGroup(size);
m.setSelected(true);

var qty = new Spinner<Integer>(1, 10, 2);                  // 최소 · 최대 · 처음 값
var due = new DatePicker(LocalDate.of(2026, 11, 7));       // 날짜 고르기
var volume = new Slider(0, 100, 60);
컨트롤 값
TextField · TextArea · PasswordField textProperty()
CheckBox · RadioButton · ToggleButton selectedProperty()
ComboBox · ChoiceBox · ListView getSelectionModel().selectedItemProperty()
Spinner · Slider · DatePicker valueProperty()
  • 값은 모두 속성(property) 이다. 리스너를 달거나 다른 속성과 묶는다

단추 · 상태

var save = new Button("저장");
save.setDefaultButton(true);                                   // 엔터
var cancel = new Button("취소");
cancel.setCancelButton(true);                                  // Esc

save.disableProperty().bind(name.textProperty().isEmpty());    // 이름이 비면 저장을 막는다
save.setOnAction(e -> saveForm());

레이아웃 판

var form = new GridPane(8, 8);                     // 가로 · 세로 간격
form.addRow(0, new Label("이름"), name);
form.addRow(1, new Label("상태"), status);
form.addRow(2, new Label("크기"), new HBox(8, s, m));
form.add(notify, 1, 6);                            // 칸 · 줄
var grow = new ColumnConstraints();
grow.setHgrow(Priority.ALWAYS);                    // 둘째 칸이 남는 폭을 차지
form.getColumnConstraints().addAll(new ColumnConstraints(), grow);

var buttons = new HBox(8, cancel, save);
buttons.setAlignment(Pos.CENTER_RIGHT);

var root = new VBox(12, form, table, buttons);
root.setPadding(new Insets(12));
판 배치
VBox · HBox 세로 · 가로로 쌓기
GridPane 칸 · 줄 — 폼
BorderPane 위 · 아래 · 왼쪽 · 오른쪽 · 가운데 — 앱의 큰 틀
StackPane 겹쳐 놓기 — 그림 위에 글자
FlowPane · TilePane 흘려 놓기 · 같은 크기 타일
AnchorPane 가장자리에서 떨어진 거리로
SplitPane · TabPane · ScrollPane 나눈 창 · 탭 · 스크롤
  • 늘어날 자리는 HBox.setHgrow(node, Priority.ALWAYS) · VBox.setVgrow 로 정한다. 기본은 늘어나지 않는다
  • 간격 · 여백은 판의 spacing · padding 과 setMargin 으로 준다. CSS 의 -fx-spacing · -fx-padding 로도 된다

TableView

행 데이터는 ObservableList 에, 칸마다 값을 꺼내는 법은 cellValueFactory 에, 칸을 어떻게 그릴지는 cellFactory 에 적는다.

public record Order(String item, int qty, int price) {}

var table = new TableView<Order>(FXCollections.observableArrayList(
    new Order("펜", 2, 1500), new Order("공책", 1, 3000), new Order("가방", 1, 25000)));

var item = new TableColumn<Order, String>("상품");
item.setCellValueFactory(d -> new ReadOnlyStringWrapper(d.getValue().item()));
var price = new TableColumn<Order, Integer>("가격");
price.setCellValueFactory(d -> new ReadOnlyObjectWrapper<>(d.getValue().price()));
price.setCellFactory(col -> new TableCell<>() {
    @Override protected void updateItem(Integer v, boolean empty) {
        super.updateItem(v, empty);
        setText(empty || v == null ? null : String.format("%,d원", v));   // 빈 줄도 이 칸으로 그린다 — 늘 지운다
        setAlignment(Pos.CENTER_RIGHT);
    }
});
table.getColumns().addAll(List.of(item, price));
table.setColumnResizePolicy(TableView.CONSTRAINED_RESIZE_POLICY_FLEX_LAST_COLUMN);

price.setSortType(TableColumn.SortType.DESCENDING);     // 가격이 큰 순서로
table.getSortOrder().add(price);
table.sort();
  • updateItem 은 칸 객체를 다시 쓰며 부른다. empty 일 때 글자 · 그림을 지우지 않으면 스크롤할 때 엉뚱한 값이 남는다
  • 값이 바뀌는 행은 record 대신 StringProperty · IntegerProperty 필드를 가진 클래스로 만들면 표가 알아서 다시 그린다
  • 거르기는 FilteredList, 정렬은 SortedList 로 감싸고 sortedList.comparatorProperty().bind(table.comparatorProperty()) 한다

var alert = new Alert(Alert.AlertType.CONFIRMATION, "지울까요?", ButtonType.YES, ButtonType.NO);
alert.showAndWait()
     .filter(b -> b == ButtonType.YES)
     .ifPresent(b -> delete());

var chooser = new FileChooser();
chooser.getExtensionFilters().add(new FileChooser.ExtensionFilter("이미지", "*.png", "*.jpg"));
File file = chooser.showOpenDialog(stage);          // 취소하면 null — OS 의 파일 창이다
