JavaFX 에서 글자는 Text 노드로 그린다. 서식이 다른 Text 여러 개를 TextFlow 에 넣으면 한 문단으로 이어 흘리고, 폭에 맞춰 줄을 바꾼다. 입력은 TextField · TextArea 컨트롤로 받고, 글꼴은 Font 로 정하거나 파일에서 읽는다.

Text · TextFlow

아래 그림은 이 코드가 그린 문단이다.

var title = new Text("제목\n");
title.setFont(Font.font("System", FontWeight.BOLD, 18));
var red = new Text("빨간 글자");
red.setFill(Color.web("#E15759"));
var code = new Text("code()");
code.setFont(Font.font("Monospaced", 13));

var flow = new TextFlow(
    title, new Text("보통 글자와 "), red, new Text(", 그리고 "), code,
    new Text(" 를 섞어 한 문단으로 흘려 쓴다. 폭이 좁으면 줄이 바뀐다."));
flow.setPrefWidth(260);
flow.setLineSpacing(4);
flow.setPadding(new Insets(10));
  • Text 는 도형 노드라 채우기 · 테두리 · 효과 · 애니메이션을 그대로 받는다
  • TextFlow 에는 Text 말고 다른 노드(ImageView · Hyperlink) 도 넣는다. 글 사이에 아이콘 · 링크를 섞는다
  • 한 Text 만 줄 바꿈하려면 text.setWrappingWidth(260) 이다

글꼴

Font.font(14);                                         // 기본 글꼴 · 14
Font.font("Apple SD Gothic Neo", FontWeight.BOLD, 16);
Font.getDefault();                                     // Font[name=System Regular, family=System, …, size=13.0]
Font.getFamilies();                                    // 쓸 수 있는 글꼴 이름

Font custom = Font.loadFont(getClass().getResourceAsStream("/fonts/NanumGothic.ttf"), 14);   // 앱에 넣은 글꼴
  • 기본 글꼴 System 은 OS 의 화면 글꼴이라 macOS · Windows 에서 한글이 잘 나온다. 리눅스는 한글 글꼴이 없으면 네모로 나와 글꼴을 앱에 넣는다
  • 앱 전체 글꼴은 CSS 로 정한다: .root { -fx-font-family: "NanumGothic"; -fx-font-size: 13px; }. loadFont 한 뒤에는 그 이름으로 쓴다

크기 재기

var measure = new Text("한글 abc");
measure.setFont(Font.font(14));
double w = measure.getLayoutBounds().getWidth();       // 화면에 놓지 않아도 잰다
double h = measure.getLayoutBounds().getHeight();
  • Canvas 에 글자를 가운데 맞출 때 이렇게 잰 폭을 쓰거나 g.setTextAlign(TextAlignment.CENTER) · g.setTextBaseline(VPos.CENTER) 를 준다

입력

var field = new TextField();
field.setPromptText("이름");
field.textProperty().addListener((obs, oldV, newV) -> count.setText(newV.length() + " 자"));

field.setTextFormatter(new TextFormatter<String>(change ->           // 숫자만 받기
    change.getControlNewText().matches("\\d*") ? change : null));

var area = new TextArea();
area.setWrapText(true);
area.setPrefRowCount(4);
area.appendText("덧붙이기\n");
  • 입력을 거르고 바꾸는 일은 TextFormatter 에 건다. 붙여넣기 · 한글 조합까지 한 곳에서 처리한다
  • 서식 있는 편집기는 JavaFX 에 HTMLEditor(javafx.web) 뿐이다. 코드 · 문서 편집기는 RichTextFX 라이브러리를 쓴다
