JavaFX 에서 그리는 길은 둘이다. 도형을 노드(Rectangle · Circle · Polygon …) 로 만들어 화면에 놓으면, 각 도형이 이벤트 · CSS · 애니메이션을 받는 객체가 된다. 도형이 아주 많거나 매번 새로 그리는 그림(차트 · 게임) 은 Canvas 에 명령으로 그린다.

도형 노드 Canvas
그린 것 객체로 남는다 픽셀만 남는다
마우스 · CSS · 애니메이션 도형마다 직접 계산
고칠 때 속성만 바꾼다 다 지우고 다시 그린다
알맞은 양 수백 개까지 수만 개

도형 노드

아래 그림은 이 코드가 그린 것이다.

var rect = new Rectangle(20, 20, 120, 80);
rect.setArcWidth(16);
rect.setArcHeight(16);
rect.setFill(Color.web("#4E79A7"));

var circle = new Circle(210, 60, 40);             // 가운데 x · y · 반지름
circle.setFill(null);
circle.setStroke(Color.web("#E15759"));
circle.setStrokeWidth(4);

var line = new Line(20, 130, 280, 130);
line.getStrokeDashArray().addAll(8.0, 6.0);       // 점선
line.setStroke(Color.DARKGRAY);

var star = new Polygon();
for (int i = 0; i < 10; i++) {
    double r = i % 2 == 0 ? 40 : 16, a = Math.PI / 5 * i - Math.PI / 2;
    star.getPoints().addAll(80 + r * Math.cos(a), 200 + r * Math.sin(a));
}
star.setFill(new LinearGradient(0, 0, 1, 1, true, CycleMethod.NO_CYCLE,
        new Stop(0, Color.web("#F28E2B")), new Stop(1, Color.web("#EDC948"))));
star.setOnMouseClicked(e -> IO.println("별 클릭"));    // 도형마다 이벤트

var box = new Rectangle(-35, -25, 70, 50);
box.setFill(Color.web("#59A14F"));
box.setOpacity(0.6);
box.setTranslateX(210);                            // 자리 · 회전은 노드의 속성
box.setTranslateY(200);
box.setRotate(30);                                 // 노드의 가운데를 기준으로 돈다

var pane = new Pane(rect, circle, line, star, box);  // Pane — 좌표 그대로 놓는다
  • 그 밖의 도형: Ellipse · Arc · Polyline · CubicCurve · Path(이어 그리기) · SVGPath(SVG 의 d 문자열)
  • Shape.union · subtract · intersect 로 도형끼리 더하고 뺀다
  • 레이아웃 판(VBox …) 에 넣으면 판이 자리를 정한다. 좌표대로 놓으려면 Pane · Group 에 넣는다

Canvas

GraphicsContext 에 그리기 명령을 내린다. 아래 그림은 요일별 걸음 수를 막대로 그리고 목표 선을 그은 것이다.

var canvas = new Canvas(300, 120);
GraphicsContext g = canvas.getGraphicsContext2D();

g.setFill(Color.WHITE);
g.fillRect(0, 0, 300, 120);

double[] steps = {6.2, 8.1, 4.5, 9.8, 7.3, 11.2, 5.6};
for (int i = 0; i < steps.length; i++) {
    g.setFill(steps[i] >= 8 ? Color.web("#59A14F") : Color.LIGHTGRAY);
    g.fillRect(10 + i * 40, 110 - steps[i] * 8, 32, steps[i] * 8);
}

g.setStroke(Color.web("#E15759"));
g.setLineWidth(2);
g.strokeLine(0, 110 - 64, 300, 110 - 64);          // 목표 선
g.setFill(Color.DARKGRAY);
g.setFont(Font.font(12));
g.fillText("목표 8", 250, 110 - 68);
  • 다시 그릴 때는 g.clearRect(0, 0, w, h) 로 지우고 처음부터 그린다
  • 크기가 바뀌는 판에 맞추려면 canvas.widthProperty().bind(parent.widthProperty()) 하고 크기가 바뀔 때마다 다시 그린다
  • 변환은 g.save() · g.translate · g.rotate · g.restore() 로 한다
  • 움직이는 그림은 AnimationTimer 의 handle 에서 프레임마다 다시 그린다

효과

node.setEffect(new DropShadow(10, Color.rgb(0, 0, 0, 0.3)));   // 그림자
node.setEffect(new GaussianBlur(4));                           // 흐리게
node.setEffect(new ColorAdjust(0, -1, 0, 0));                  // 채도 -1 — 흑백
