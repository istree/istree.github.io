JavaFX 는 Swing 다음에 나온 Java 의 GUI 툴킷이다. 화면을 노드 트리(scene graph) 로 만들고, CSS 로 꾸미고, FXML 로 화면을 코드와 나누고, 속성 바인딩으로 값과 화면을 잇는다. GPU 로 그려 애니메이션 · 효과가 매끄럽다. JDK 11 부터 JDK 에서 빠져 OpenJFX 로 따로 받는다. 여기의 예제는 JDK 25 · JavaFX 27 로 띄워 확인했고, 아래 그림은 그 창을 캡처한 것이다.

창 하나

Application 을 물려받아 start 에서 화면을 만든다. Stage 가 창, Scene 이 창의 내용, 그 안의 노드(컨트롤 · 레이아웃) 가 화면이다.

import javafx.application.Application;
import javafx.beans.binding.Bindings;
import javafx.collections.FXCollections;
import javafx.geometry.Insets;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.layout.*;
import javafx.stage.Stage;

public class HelloFx extends Application {
    @Override
    public void start(Stage stage) {                       // JavaFX 스레드에서 불린다
        var input = new TextField();
        input.setPromptText("할 일");                       // 빈 칸에 흐린 글자
        var add = new Button("추가");
        add.setDefaultButton(true);                         // 엔터 = 추가

        var items = FXCollections.<String>observableArrayList("장보기", "운동");
        var list = new ListView<>(items);                   // 목록이 바뀌면 화면도 바뀐다
        var status = new Label();
        status.textProperty().bind(Bindings.size(items).asString("%d 개"));   // 개수를 늘 따라간다

        add.setOnAction(e -> {
            String text = input.getText().trim();
            if (text.isEmpty()) return;
            items.add(text);
            input.clear();
        });

        var top = new HBox(8, input, add);
        HBox.setHgrow(input, Priority.ALWAYS);              // 입력 칸이 남는 폭을 차지
        var root = new BorderPane(list, top, null, status, null);   // 가운데 · 위 · 오른쪽 · 아래 · 왼쪽
        root.setPadding(new Insets(10));
        BorderPane.setMargin(list, new Insets(8, 0, 8, 0));

        stage.setTitle("메모");
        stage.setScene(new Scene(root, 360, 260));
        stage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
  • 화면은 JavaFX Application Thread 에서만 고친다. 다른 스레드에서 고칠 때는 Platform.runLater(() -> …) 다
  • 목록 · 표의 데이터는 ObservableList 에 둔다. 더하고 지우면 컨트롤이 알아서 다시 그린다
  • 개수 글자를 리스너로 고치지 않고 bind 로 묶었다. 목록이 바뀌면 글자가 따라 바뀐다

설치 · 실행

JavaFX 는 JDK 에 없으므로 빌드 도구로 받거나 SDK 를 내려받는다. Gradle 은 OpenJFX 플러그인이 OS 에 맞는 JavaFX 를 받아 모듈 설정까지 해 준다.

// build.gradle.kts
plugins {
    application
    id("org.openjfx.javafxplugin") version "0.1.0"
}

java { toolchain { languageVersion = JavaLanguageVersion.of(25) } }
repositories { mavenCentral() }

javafx {
    version = "27.0.1"
    modules("javafx.controls", "javafx.fxml")
}

application {
    mainClass = "com.example.HelloFx"
    applicationDefaultJvmArgs = listOf("--enable-native-access=javafx.graphics")
}
./gradlew run

Maven 은 의존성과 javafx-maven-plugin 을 넣는다.

<properties>
  <maven.compiler.release>25</maven.compiler.release>
  <javafx.version>27.0.1</javafx.version>
</properties>
<dependencies>
  <dependency>
    <groupId>org.openjfx</groupId>
    <artifactId>javafx-controls</artifactId>
    <version>${javafx.version}</version>
  </dependency>
</dependencies>
<build>
  <plugins>
    <plugin>
      <groupId>org.openjfx</groupId>
      <artifactId>javafx-maven-plugin</artifactId>
      <version>0.0.8</version>
      <configuration>
        <mainClass>com.example.HelloFx</mainClass>
      </configuration>
    </plugin>
  </plugins>
</build>
mvn javafx:run

빌드 도구 없이 SDK 로 돌릴 때는 모듈 경로를 준다.

# https://gluonhq.com/products/javafx/ 에서 OS 에 맞는 SDK 를 받아 푼다
javac --module-path javafx-sdk-27.0.1/lib --add-modules javafx.controls -d out HelloFx.java
java  --module-path javafx-sdk-27.0.1/lib --add-modules javafx.controls -cp out HelloFx
  • 모듈 없이 클래스 경로로만 실행하면 Error: JavaFX runtime components are missing, and are required to run this application 으로 멈춘다. 모듈 경로 · --add-modules 를 준다
  • JavaFX 27 · JDK 25 에서는 WARNING: A restricted method in java.lang.System has been called … Use --enable-native-access=javafx.graphics 가 나온다. 그 옵션을 주면 사라진다

모듈

모듈 들어 있는 것
javafx.controls 컨트롤 · 레이아웃 (javafx.graphics · javafx.base 를 함께 끌어온다)
javafx.fxml FXML 읽기
javafx.web WebView — 웹 화면
javafx.media 소리 · 영상
javafx.swing Swing 과 섞기 · SwingFXUtils(이미지 바꾸기)

예전에는

  • JDK 8 에는 JavaFX 가 들어 있어 java -jar 로 바로 돌았다. JDK 11 부터 빠져 OpenJFX 를 따로 받는다
  • public static void main 없이 Application 만으로 실행하던 코드가 많다. 지금은 main 에서 launch(args) 를 부른다
