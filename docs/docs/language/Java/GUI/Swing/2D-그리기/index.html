Swing 에서 직접 그리는 화면(차트 · 편집기 · 게임 판) 은 JComponent 를 물려받아 paintComponent 를 바꾼다. 그리기 자체는 AWT 의 Graphics2D(도형 · 색 · 변환) 를 그대로 쓰고, Swing 이 정하는 것은 언제 그리는지 · 다시 그리게 하는 법 · 마우스와 엮는 법이다. 아래 그림은 이 글의 컴포넌트에 점 셋을 찍고 하나를 끌어 옮긴 것이다.

paintComponent

public class Board extends JComponent {
    private final List<Ellipse2D> dots = new ArrayList<>();

    Board() {
        setPreferredSize(new Dimension(320, 200));       // 레이아웃이 볼 크기
    }

    @Override
    protected void paintComponent(Graphics g) {
        super.paintComponent(g);                         // 바탕 지우기 (JPanel 이면 꼭)
        Graphics2D g2 = (Graphics2D) g.create();         // 복사본 — 바꾼 설정이 밖으로 새지 않는다
        try {
            g2.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);
            g2.setColor(Color.WHITE);
            g2.fillRect(0, 0, getWidth(), getHeight());

            g2.setColor(new Color(0xDDDDDD));            // 모눈
            for (int x = 0; x < getWidth(); x += 20) g2.drawLine(x, 0, x, getHeight());
            for (int y = 0; y < getHeight(); y += 20) g2.drawLine(0, y, getWidth(), y);

            g2.setColor(new Color(0x4E79A7));
            for (var d : dots) g2.fill(d);
            g2.setColor(Color.DARK_GRAY);
            g2.drawString(dots.size() + " 개", 8, getHeight() - 8);
        } finally {
            g2.dispose();
        }
    }
}
  • paint 가 아니라 paintComponent 를 바꾼다. paint 는 테두리 · 자식 컴포넌트까지 그리는 순서를 정한다
  • paintComponent 는 Swing 이 필요할 때(창이 가려졌다 보일 때 · 크기가 바뀔 때) 부른다. 직접 부르지 않는다
  • 그리는 동안 무거운 계산 · 파일 읽기를 하지 않는다. 데이터는 미리 준비하고 그리기만 한다
  • Swing 은 기본으로 이중 버퍼에 그려 깜빡이지 않는다. AWT Canvas 처럼 따로 버퍼를 만들지 않아도 된다

다시 그리기

데이터가 바뀌면 repaint() 를 부른다. 바로 그리지 않고 "다시 그려 달라" 고 EDT 에 맡기며, 여러 번 불러도 한 번으로 합쳐진다.

dots.add(new Ellipse2D.Double(x - 15, y - 15, 30, 30));
repaint();                                   // 전체

repaint(oldBounds.union(newBounds));         // 바뀐 자리만 — 큰 화면에서 빠르다
  • 다른 스레드에서 데이터를 바꿨으면 repaint() 는 불러도 되지만, 데이터 자체를 EDT 와 함께 쓰지 않게 한다(invokeLater 로 넘긴다)
  • 움직임은 javax.swing.Timer 로 일정 시간마다 값을 바꾸고 repaint() 한다. Thread.sleep 으로 EDT 를 재우지 않는다

마우스로 그리고 옮기기

var mouse = new MouseAdapter() {
    private Ellipse2D dragging;
    private Point2D offset;

    @Override public void mousePressed(MouseEvent e) {
        for (int i = dots.size() - 1; i >= 0; i--)                     // 위에 그린 것부터
            if (dots.get(i).contains(e.getPoint())) {                    // 점을 눌렀으면 끌기 시작
                dragging = dots.get(i);
                offset = new Point2D.Double(e.getX() - dragging.getX(), e.getY() - dragging.getY());
                return;
            }
        dots.add(new Ellipse2D.Double(e.getX() - 15, e.getY() - 15, 30, 30));   // 빈 곳이면 새 점
        repaint();
    }
    @Override public void mouseDragged(MouseEvent e) {
        if (dragging == null) return;
        Rectangle old = dragging.getBounds();
        dragging.setFrame(e.getX() - offset.getX(), e.getY() - offset.getY(), 30, 30);
        repaint(old.union(dragging.getBounds()));
    }
    @Override public void mouseReleased(MouseEvent e) { dragging = null; }
};
addMouseListener(mouse);              // 누르기 · 놓기
addMouseMotionListener(mouse);        // 움직이기 · 끌기 — 따로 등록한다
  • 도형 객체(Shape) 로 갖고 있으면 contains 로 고르기, getBounds 로 다시 그릴 자리를 바로 얻는다
  • 확대 · 이동이 있는 화면은 AffineTransform 하나를 두고 그릴 때 g2.transform(view), 마우스 좌표는 view.inverseTransform(e.getPoint(), null) 으로 바꿔 쓴다
  • 마우스 휠은 MouseWheelListener 다. e.getPreciseWheelRotation() 으로 확대 비율을 정한다

이미지로 저장

화면에 그린 것을 그대로 이미지로 남길 때는 컴포넌트를 이미지에 그린다.

var img = new BufferedImage(board.getWidth(), board.getHeight(), BufferedImage.TYPE_INT_ARGB);
Graphics2D g = img.createGraphics();
board.paint(g);                      // 자식까지 그린다
g.dispose();
ImageIO.write(img, "png", new File("board.png"));
