Swing 에서 그림은 Icon 으로 다룬다. ImageIcon 이 이미지를 읽어 JLabel · JButton · 메뉴 · 트리에 붙이고, 크게 보거나 확대하는 화면은 직접 그리는 컴포넌트에 drawImage 한다. 이미지 파일은 jar 안의 리소스로 넣고 클래스 경로로 읽는다.

ImageIcon

var url = App.class.getResource("/icons/shapes.png");   // src/main/resources/icons/shapes.png
var icon = new ImageIcon(Objects.requireNonNull(url, "icons/shapes.png"));
icon.getIconWidth();                                    // 300

var label = new JLabel("도형", icon, SwingConstants.LEFT);
label.setHorizontalTextPosition(SwingConstants.CENTER);
label.setVerticalTextPosition(SwingConstants.BOTTOM);    // 그림 아래에 글자

var button = new JButton(icon);
button.setToolTipText("도형 넣기");
  • 리소스 경로가 틀리면 getResource 가 null 을 돌려준다. 그대로 new ImageIcon(null) 하면 NullPointerException 이니 requireNonNull 로 경로를 알려 준다
  • new ImageIcon("nope.png") 처럼 파일 경로로 만들면 파일이 없어도 예외가 없다. 크기가 -1 이고 getImageLoadStatus() 가 MediaTracker.ERRORED 다. 파일 경로는 실행한 폴더에 따라 달라지므로 앱의 그림은 리소스로 넣는다
  • 단추를 setEnabled(false) 하면 흐린 아이콘(GrayFilter) 을 알아서 만든다

크기 바꾸기

Image small = icon.getImage().getScaledInstance(48, -1, Image.SCALE_SMOOTH);   // 폭 48, 높이는 비율대로 — 48x41
var smallIcon = new ImageIcon(small);
  • getScaledInstance 는 짧지만 느리다. 목록 · 표의 썸네일처럼 많이 만들 때는 BufferedImage 에 drawImage(src, 0, 0, w, h, null) 로 그리고(보간 힌트를 켜고) 결과를 캐시한다

HiDPI 아이콘

Retina · 배율 화면에서는 아이콘이 두 배로 늘어나 흐려진다. 크기별 그림을 함께 주면 화면에 맞는 것을 고른다.

var icon16 = ImageIO.read(App.class.getResource("/icons/save.png"));
var icon32 = ImageIO.read(App.class.getResource("/icons/save@2x.png"));
var icon = new ImageIcon(new BaseMultiResolutionImage(icon16, icon32));   // 크기는 16 으로 잡히고, 2 배 화면에서는 32 를 그린다
  • SVG 아이콘은 어떤 배율에서도 선명하다. FlatLaf 를 쓰면 new FlatSVGIcon("icons/save.svg", 16, 16) 으로 바로 쓴다(flatlaf-extras)

이미지 보기 · 확대

class ImageView extends JComponent {
    private BufferedImage image;
    private double zoom = 1.0;

    void setImage(BufferedImage img) { image = img; revalidate(); repaint(); }
    double zoom() { return zoom; }
    void setZoom(double z) { zoom = Math.max(0.1, Math.min(z, 8)); revalidate(); repaint(); }

    @Override public Dimension getPreferredSize() {           // 스크롤 판이 이 크기로 스크롤바를 정한다
        return image == null ? new Dimension(200, 200)
             : new Dimension((int) (image.getWidth() * zoom), (int) (image.getHeight() * zoom));
    }
    @Override protected void paintComponent(Graphics g) {
        super.paintComponent(g);
        if (image == null) return;
        Graphics2D g2 = (Graphics2D) g.create();
        g2.setRenderingHint(RenderingHints.KEY_INTERPOLATION,
            zoom < 1 ? RenderingHints.VALUE_INTERPOLATION_BILINEAR
                     : RenderingHints.VALUE_INTERPOLATION_NEAREST_NEIGHBOR);   // 크게 볼 때는 픽셀 그대로
        g2.scale(zoom, zoom);
        g2.drawImage(image, 0, 0, null);
        g2.dispose();
    }
}

var view = new ImageView();
frame.add(new JScrollPane(view));
view.addMouseWheelListener(e -> {
    if (e.isControlDown() || e.isMetaDown()) view.setZoom(view.zoom() * Math.pow(1.1, -e.getPreciseWheelRotation()));
});
  • 크기가 바뀌는 컴포넌트는 revalidate() 로 레이아웃 · 스크롤 판에 알리고 repaint() 로 다시 그린다
  • 아주 큰 이미지는 보이는 부분(g.getClipBounds()) 만 그리면 빠르다

이미지 끌어 놓기

view.setTransferHandler(new TransferHandler() {
    @Override public boolean canImport(TransferSupport s) { return s.isDataFlavorSupported(DataFlavor.javaFileListFlavor); }
    @Override public boolean importData(TransferSupport s) {
        try {
            @SuppressWarnings("unchecked")
            var files = (List<File>) s.getTransferable().getTransferData(DataFlavor.javaFileListFlavor);
            view.setImage(ImageIO.read(files.getFirst()));
            return true;
        } catch (Exception e) {
            return false;
        }
    }
});
