Swing 은 JDK 에 들어 있는 GUI 툴킷이다. AWT 의 창 · 이벤트 · 그리기 위에서, 버튼 · 표 · 트리 같은 컴포넌트를 Java 가 직접 그린다(lightweight). 그래서 OS 와 상관없이 같은 컴포넌트를 쓰고, 모양은 Look and Feel 로 바꾼다. 컴포넌트 이름은 AWT 와 구별하려고 J 로 시작한다. 여기의 예제는 JDK 25 로 띄워 확인했고, 아래 그림은 macOS 기본 모양으로 캡처한 것이다.

창 하나

import javax.swing.*;
import java.awt.*;

public class SwingHello {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(SwingHello::createAndShow);   // 화면은 EDT 에서 만든다
    }

    static void createAndShow() {
        var frame = new JFrame("메모");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);  // 닫기 단추로 닫는다

        var input = new JTextField(20);
        var add = new JButton("추가");
        var model = new DefaultListModel<String>();               // 목록의 데이터
        var list = new JList<>(model);
        var status = new JLabel("0 개");

        Runnable onAdd = () -> {
            String text = input.getText().trim();
            if (text.isEmpty()) return;
            model.addElement(text);                               // 모델을 고치면 목록이 따라 바뀐다
            input.setText("");
            status.setText(model.size() + " 개");
        };
        add.addActionListener(e -> onAdd.run());
        list.addListSelectionListener(e -> {
            if (!e.getValueIsAdjusting()) status.setText("선택: " + list.getSelectedValue());
        });

        var top = new JPanel(new FlowLayout(FlowLayout.LEFT));
        top.add(new JLabel("할 일"));
        top.add(input);
        top.add(add);

        var content = new JPanel(new BorderLayout(8, 8));
        content.setBorder(BorderFactory.createEmptyBorder(8, 8, 8, 8));   // 바깥 여백
        content.add(top, BorderLayout.NORTH);
        content.add(new JScrollPane(list), BorderLayout.CENTER);        // 넘치면 스크롤
        content.add(status, BorderLayout.SOUTH);

        frame.setContentPane(content);
        frame.getRootPane().setDefaultButton(add);                      // 엔터 = 추가
        frame.setSize(400, 280);
        frame.setLocationRelativeTo(null);
        frame.setVisible(true);
    }
}
  • 목록 · 표 · 트리는 데이터를 모델(DefaultListModel · TableModel) 에 두고, 컴포넌트는 그것을 그리기만 한다. 데이터를 바꿀 때는 모델을 고친다
  • JList · JTextArea · JTable 은 스스로 스크롤하지 않는다. JScrollPane 에 넣는다
  • 닫기 동작: DISPOSE_ON_CLOSE(창만 닫고, 마지막 창이면 프로그램도 끝난다) · EXIT_ON_CLOSE(바로 System.exit) · HIDE_ON_CLOSE(기본 — 숨기기만, 프로그램은 계속 돈다)

레이아웃

AWT 의 레이아웃(BorderLayout · FlowLayout · GridLayout · GridBagLayout · CardLayout) 에 Swing 의 것이 더해진다.

var box = Box.createVerticalBox();             // BoxLayout — 한 줄로 쌓기
box.add(new JLabel("이름"));
box.add(Box.createVerticalStrut(4));           // 고정 틈
box.add(new JTextField());
box.add(Box.createVerticalGlue());             // 남는 자리를 차지하는 빈칸

var form = new JPanel(new GridBagLayout());    // 입력 폼 — 이름 칸은 좁게, 값 칸은 늘어나게
var c = new GridBagConstraints();
c.insets = new Insets(4, 4, 4, 4);
c.gridx = 0; c.gridy = 0; c.anchor = GridBagConstraints.LINE_END;
form.add(new JLabel("이메일"), c);
c.gridx = 1; c.weightx = 1; c.fill = GridBagConstraints.HORIZONTAL;
form.add(new JTextField(), c);
  • 폼이 많으면 MigLayout 같은 레이아웃 라이브러리를 쓴다. GridBag 보다 짧다
  • 컴포넌트의 크기는 직접 정하지 않고 레이아웃이 getPreferredSize 를 보고 정한다. frame.pack() 은 창을 그 크기에 맞춘다

EDT

Swing 의 컴포넌트는 스레드에 안전하지 않다. 만들고 고치는 일은 모두 이벤트 디스패치 스레드(EDT) 에서 한다.

규칙 방법
화면은 EDT 에서 만든다 SwingUtilities.invokeLater(…) 안에서 JFrame 을 만든다
오래 걸리는 일은 EDT 밖에서 SwingWorker · 스레드 · 가상 스레드
다른 스레드에서 화면을 고칠 때 SwingUtilities.invokeLater(() -> label.setText(…))
정해진 시간마다 화면을 고칠 때 javax.swing.Timer — 동작이 EDT 에서 돈다

리스너 안에서 파일 · 네트워크 일을 하면 그동안 창이 멈춘다. SwingWorker 가 백그라운드에서 일하고, 중간 값 · 끝 결과를 EDT 로 넘겨준다.

var worker = new SwingWorker<Integer, Integer>() {          // <결과, 중간 값>
    @Override protected Integer doInBackground() throws Exception {   // 백그라운드 스레드
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            Thread.sleep(50);
            sum += i;
            publish(i * 20);                                 // 중간 값 보내기
        }
        return sum;
    }
    @Override protected void process(List<Integer> chunks) { // EDT — 모아서 온다
        bar.setValue(chunks.getLast());
    }
    @Override protected void done() {                        // EDT — 끝났을 때
        try {
            label.setText("합 " + get());                    // 합 15
        } catch (Exception e) {
            label.setText("실패: " + e.getCause());          // doInBackground 의 예외
        }
    }
};
worker.execute();
  • SwingWorker 는 한 번만 execute 한다. 다시 하려면 새로 만든다
  • EDT 를 막고 있는지는 창이 멈추는 것으로 알 수 있다. 스레드 덤프(jcmd <pid> Thread.print) 의 AWT-EventQueue-0 스레드를 본다

예전에는

  • main 에서 바로 new JFrame() 하고 setVisible(true) 했다. 대개 돌지만 EDT 규칙을 어겨 가끔 그리기가 깨졌다. 지금은 invokeLater 안에서 만든다
  • JList · JComboBox 가 제네릭이 아니었다(Java 6). 지금은 JList<String> 이다
  • 화면 빌더(NetBeans GUI Builder · WindowBuilder) 가 만든 GroupLayout 코드가 많다. 손으로 고치기 어려워 새 화면은 손으로 짜거나 MigLayout 을 쓴다
