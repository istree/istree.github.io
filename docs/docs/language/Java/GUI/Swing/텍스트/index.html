Swing 의 글자 입력 컴포넌트는 모두 JTextComponent 이고, 내용은 Document 모델에 있다. 한 줄은 JTextField, 여러 줄은 JTextArea, 굵게 · 색 같은 서식이 섞이면 JTextPane 을 쓴다. 입력을 지켜보거나 막는 일은 컴포넌트가 아니라 Document 에 건다. 글자를 직접 그리는 일은 AWT 의 Font · TextLayout 으로 한다.

입력 칸

var field = new JTextField(12);                     // 열 수 — 보이는 폭
field.setText("안녕하세요");
field.getText();

var area = new JTextArea(4, 20);                    // 4 줄 · 20 열
area.setLineWrap(true);                             // 폭에서 줄 바꾸기
area.setWrapStyleWord(true);                        // 낱말 단위로
area.append("\n덧붙이기");
frame.add(new JScrollPane(area));

var password = new JPasswordField(12);
char[] pw = password.getPassword();                 // String 이 아니라 char[] — 쓰고 나서 지운다
Arrays.fill(pw, '\0');

입력 지켜보기

글자가 바뀔 때마다 알림을 받으려면 DocumentListener 를 단다. 붙여넣기 · 프로그램에서 setText 한 것도 모두 잡힌다.

var count = new JLabel("0 자");
field.getDocument().addDocumentListener(new DocumentListener() {
    void update() { count.setText(field.getText().length() + " 자"); }
    public void insertUpdate(DocumentEvent e) { update(); }
    public void removeUpdate(DocumentEvent e) { update(); }
    public void changedUpdate(DocumentEvent e) {}          // 서식만 바뀔 때 (JTextPane)
});
field.setText("안녕하세요");                             // 5 자
  • 리스너 안에서 같은 Document 를 고치면 IllegalStateException: Attempt to mutate in notification 이다. 고칠 일은 invokeLater 로 미루거나 아래 DocumentFilter 로 한다
  • KeyListener 로 입력을 지켜보지 않는다. 붙여넣기 · 한글 조합(IME) 을 놓친다

입력 막기 · 형식

들어오는 글자를 거르려면 DocumentFilter 를 건다.

var digits = new JTextField(6);
((AbstractDocument) digits.getDocument()).setDocumentFilter(new DocumentFilter() {
    @Override public void insertString(FilterBypass fb, int off, String s, AttributeSet a) throws BadLocationException {
        if (s.matches("\\d*")) super.insertString(fb, off, s, a);
    }
    @Override public void replace(FilterBypass fb, int off, int len, String s, AttributeSet a) throws BadLocationException {
        if (s == null || s.matches("\\d*")) super.replace(fb, off, len, s, a);
    }
});
digits.setText("12a3");          // "" — 통째로 막힌다
digits.setText("123");           // "123"

var money = new JFormattedTextField(NumberFormat.getIntegerInstance());
money.setValue(1234567);         // 보이는 글자 "1,234,567", getValue() 는 1234567
  • JSpinner 는 숫자 · 날짜를 단추로 올리고 내리며 입력한다. 범위가 정해진 값에 쓴다

되돌리기

var undo = new UndoManager();
area.getDocument().addUndoableEditListener(undo);

area.getInputMap().put(KeyStroke.getKeyStroke(KeyEvent.VK_Z,
        Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx()), "undo");
area.getActionMap().put("undo", new AbstractAction() {
    @Override public void actionPerformed(ActionEvent e) { if (undo.canUndo()) undo.undo(); }
});
  • Swing 의 입력 칸은 되돌리기를 기본으로 갖고 있지 않다. 위처럼 단다

서식 있는 글

JTextPane 에 속성(굵게 · 크기 · 색 · 글꼴) 을 붙여 글자를 넣는다. 아래 그림은 이 코드가 그린 것이다.

var pane = new JTextPane();
StyledDocument doc = pane.getStyledDocument();

var bold = new SimpleAttributeSet();
StyleConstants.setBold(bold, true);
StyleConstants.setFontSize(bold, 16);
var red = new SimpleAttributeSet();
StyleConstants.setForeground(red, new Color(0xE15759));
var code = new SimpleAttributeSet();
StyleConstants.setFontFamily(code, Font.MONOSPACED);
StyleConstants.setBackground(code, new Color(0xF0F0F0));

doc.insertString(doc.getLength(), "제목\n", bold);           // BadLocationException — 자리가 틀리면
doc.insertString(doc.getLength(), "보통 글자와 ", null);
doc.insertString(doc.getLength(), "빨간 글자", red);
doc.insertString(doc.getLength(), ", 그리고 ", null);
doc.insertString(doc.getLength(), "code()", code);
doc.insertString(doc.getLength(), " 를 섞는다.", null);

int i = pane.getText().indexOf("보통");                       // 찾은 곳 강조 — 문서는 그대로
pane.getHighlighter().addHighlight(i, i + 2,
        new DefaultHighlighter.DefaultHighlightPainter(new Color(0xFFF59D)));
  • 이미 넣은 글자의 서식을 바꿀 때는 doc.setCharacterAttributes(시작, 길이, 속성, false) 다
  • 로그 창처럼 계속 덧붙이는 글은 doc.getLength() 자리에 넣고, 너무 길어지면 앞에서 지운다

HTML 보기

var view = new JEditorPane("text/html", "<html><b>굵게</b> <a href='https://example.com'>링크</a></html>");
view.setEditable(false);
view.addHyperlinkListener(e -> {
    if (e.getEventType() == HyperlinkEvent.EventType.ACTIVATED)
        Desktop.getDesktop().browse(e.getURL().toURI());        // 기본 브라우저로 — 예외 처리를 한다
});
  • HTML 3.2 와 CSS 일부만 그린다. 도움말 · 정보 창 정도에 쓴다. 제대로 된 웹 화면은 JavaFX 의 WebView 다
