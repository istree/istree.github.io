Swing 은 컴포넌트를 Java 가 직접 그리므로, 모양 전체를 Look and Feel(LaF) 로 바꾼다. JDK 에 들어 있는 것은 오래된 모양이라, 요즘 앱처럼 보이려면 FlatLaf 를 쓴다. 고해상도(HiDPI) 화면은 Java 9 부터 저절로 맞추고, 한글이 깨지면 글꼴을 직접 정한다. 아래 그림은 같은 폼을 Look and Feel 만 바꿔 캡처한 것이다.

Look and Feel 바꾸기

창을 만들기 전에(EDT 에서 가장 먼저) 정한다.

SwingUtilities.invokeLater(() -> {
    try {
        UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());   // OS 모양
    } catch (Exception e) {
        // 실패하면 기본(Metal) 으로 둔다
    }
    createAndShow();
});
Look and Feel 클래스 모양
Metal javax.swing.plaf.metal.MetalLookAndFeel 기본 — OS 와 상관없이 같다
Nimbus javax.swing.plaf.nimbus.NimbusLookAndFeel 벡터로 그린 둥근 모양
시스템 UIManager.getSystemLookAndFeelClassName() macOS 는 Aqua, Windows 는 Windows 모양
FlatLaf com.formdev.flatlaf.FlatLightLaf … 요즘 앱 모양 · 다크 모드 (라이브러리)
  • 창이 떠 있는 동안 바꾸려면 바꾼 뒤 SwingUtilities.updateComponentTreeUI(frame) 로 다시 그린다
  • 설치된 목록은 UIManager.getInstalledLookAndFeels() 로 본다

FlatLaf

IntelliJ 계열 IDE 의 모양을 Swing 에 입힌다. 라이트 · 다크 · macOS 풍 테마가 있다.

// build.gradle.kts
implementation("com.formdev:flatlaf:3.8")
import com.formdev.flatlaf.FlatLightLaf;
import com.formdev.flatlaf.FlatDarkLaf;
import com.formdev.flatlaf.themes.FlatMacLightLaf;

FlatLightLaf.setup();                                         // 창을 만들기 전에 한 줄

UIManager.put("Button.arc", 999);                             // 단추를 알약 모양으로
UIManager.put("Component.accentColor", Color.decode("#E15759"));   // 강조 색
  • 다크 모드는 FlatDarkLaf.setup() 이다. OS 설정을 따라가려면 시작할 때 OS 의 다크 모드 여부를 읽어 고른다
  • 테마 값(색 · 둥글기 · 간격) 은 UIManager.put 이나 .properties 파일로 바꾼다. 키 목록은 FlatLaf 문서의 Theme Editor · UI Defaults 에 있다

HiDPI

Java 9 부터 macOS Retina · Windows 배율(125% · 150% …) 을 읽어 컴포넌트 · 글자를 크게 그린다.

java -Dsun.java2d.uiScale=2 -jar app.jar      # 배율을 강제로 — 시험할 때
  • 직접 그린 그림(paintComponent) 은 논리 좌표로 그리면 저절로 커진다. 크기가 정해진 비트맵 아이콘은 흐려지므로, 크기별 이미지(MultiResolutionImage) · SVG 아이콘(FlatLaf 의 FlatSVGIcon) 을 쓴다
  • 좌표 · 크기를 픽셀로 박은 화면(setBounds(10, 10, 80, 24)) 은 배율이 바뀌면 글자가 잘린다. 레이아웃 매니저에 맡긴다

한글 글꼴

Swing 의 기본 글꼴(Dialog) 은 논리 글꼴이라 OS 의 한글 글꼴을 빌려 쓴다. macOS 는 Apple SD Gothic Neo, Windows 는 맑은 고딕으로 대개 잘 나온다. 리눅스 서버 · 컨테이너처럼 한글 글꼴이 없는 곳에서는 네모(□) 로 나온다.

new Font("Dialog", Font.PLAIN, 13).canDisplayUpTo("한글 abc");   // -1 — 모두 그릴 수 있다 (아니면 처음 못 그리는 자리)

var base = new FontUIResource("맑은 고딕", Font.PLAIN, 13);     // 모든 컴포넌트의 글꼴을 한 번에
var keys = UIManager.getDefaults().keys();
while (keys.hasMoreElements()) {
    Object key = keys.nextElement();
    if (UIManager.get(key) instanceof FontUIResource) UIManager.put(key, base);
}
  • 글꼴 이름은 OS 마다 다르다. GraphicsEnvironment.getLocalGraphicsEnvironment().getAvailableFontFamilyNames() 에 있는지 보고 고른다
  • 리눅스에서는 fonts-nanum 같은 한글 글꼴 패키지를 설치한다
  • 글꼴 파일을 앱에 넣어 쓰려면 Font.createFont(Font.TRUETYPE_FONT, stream) 뒤 GraphicsEnvironment.registerFont(font) 한다
