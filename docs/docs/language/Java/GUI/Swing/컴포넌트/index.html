Swing 의 복잡한 컴포넌트(JTable · JList · JTree · JComboBox) 는 모델 · 뷰 · 렌더러로 나뉜다. 데이터는 모델에 두고, 컴포넌트는 그리기 · 고르기만 하며, 칸 하나를 어떻게 그릴지는 렌더러가 정한다. 그 밖에 대화상자 · 메뉴 · 단축키를 다룬다. 아래 그림은 이 글의 표 · 트리 예제를 캡처한 것이다.

JTable

표는 AbstractTableModel 을 물려받아 내 데이터를 연결한다. 몇 줄 · 몇 칸 · 칸의 값만 알려 주면 된다.

import javax.swing.table.*;

record Order(String item, int qty, int price) {}

class OrderModel extends AbstractTableModel {
    private final List<Order> rows = new ArrayList<>();
    private final String[] cols = {"상품", "수량", "가격"};

    public int getRowCount() { return rows.size(); }
    public int getColumnCount() { return cols.length; }
    public String getColumnName(int c) { return cols[c]; }
    public Class<?> getColumnClass(int c) { return c == 0 ? String.class : Integer.class; }   // 숫자로 정렬 · 오른쪽 정렬
    public Object getValueAt(int r, int c) {
        Order o = rows.get(r);
        return switch (c) { case 0 -> o.item(); case 1 -> o.qty(); default -> o.price(); };
    }
    public boolean isCellEditable(int r, int c) { return c == 1; }                 // 수량만 고친다
    public void setValueAt(Object v, int r, int c) {
        Order o = rows.get(r);
        rows.set(r, new Order(o.item(), (Integer) v, o.price()));
        fireTableCellUpdated(r, c);                                                // 바뀌었다고 알린다
    }
    void add(Order o) {
        rows.add(o);
        fireTableRowsInserted(rows.size() - 1, rows.size() - 1);
    }
}

var model = new OrderModel();
model.add(new Order("펜", 2, 1500));
var table = new JTable(model);
frame.add(new JScrollPane(table));            // 머리줄이 보이려면 스크롤 판에 넣는다
  • 모델을 고친 뒤에는 fireTable… 로 알려야 화면이 바뀐다. 데이터가 통째로 바뀌면 fireTableDataChanged() 다
  • 간단한 표는 new DefaultTableModel(data, columnNames) 로 만들어도 된다. 모든 칸이 고칠 수 있고 값이 Object 다

정렬 · 거르기

table.setAutoCreateRowSorter(true);                          // 머리줄을 눌러 정렬
var sorter = (TableRowSorter<?>) table.getRowSorter();
sorter.setRowFilter(RowFilter.regexFilter("펜|가방", 0));    // 0 번 칸이 맞는 줄만 — 보이는 줄 2, 모델 줄 3
sorter.setSortKeys(List.of(new RowSorter.SortKey(2, SortOrder.DESCENDING)));   // 가격이 큰 순서

int modelRow = table.convertRowIndexToModel(table.getSelectedRow());   // 화면 줄 → 모델 줄
  • 정렬 · 거르기를 켜면 화면의 줄 번호와 모델의 줄 번호가 달라진다. 선택한 줄의 데이터를 꺼낼 때는 늘 convertRowIndexToModel 로 바꾼다

렌더러

table.getColumnModel().getColumn(2).setCellRenderer(new DefaultTableCellRenderer() {
    @Override protected void setValue(Object v) {
        setHorizontalAlignment(RIGHT);
        setText(String.format("%,d원", (Integer) v));              // 25,000원
    }
});
  • 렌더러는 도장처럼 컴포넌트 하나로 모든 칸을 찍는다. 칸마다 상태를 들고 있지 않는다

JList · JComboBox

var model = new DefaultListModel<String>();
var list = new JList<>(model);
list.setSelectionMode(ListSelectionModel.MULTIPLE_INTERVAL_SELECTION);
list.getSelectedValuesList();                           // 고른 것들

var combo = new JComboBox<>(new String[]{"초안", "공개"});
combo.addActionListener(e -> status = (String) combo.getSelectedItem());

JTree

import javax.swing.tree.*;

var root = new DefaultMutableTreeNode("docs");
var img = new DefaultMutableTreeNode("img");
root.add(new DefaultMutableTreeNode("a.md"));
root.add(img);
img.add(new DefaultMutableTreeNode("b.png"));

var treeModel = new DefaultTreeModel(root);
var tree = new JTree(treeModel);
treeModel.insertNodeInto(new DefaultMutableTreeNode("c.png"), img, img.getChildCount());   // 화면에도 바로
tree.expandRow(1);                                     // img 펼치기

tree.addTreeSelectionListener(e -> {
    var node = (DefaultMutableTreeNode) tree.getLastSelectedPathComponent();
    if (node != null) status.setText(node.getUserObject().toString());
});
  • 노드를 더하고 지울 때는 노드에 직접 add 하지 않고 모델의 insertNodeInto · removeNodeFromParent 를 쓴다. 그래야 트리가 다시 그려진다
  • 폴더 내용을 펼칠 때 읽으려면(lazy) TreeWillExpandListener 에서 자식을 채운다

대화상자

JOptionPane.showMessageDialog(frame, "저장했다");
int answer = JOptionPane.showConfirmDialog(frame, "지울까요?", "확인", JOptionPane.YES_NO_OPTION);
if (answer == JOptionPane.YES_OPTION) { … }
String name = JOptionPane.showInputDialog(frame, "이름?");     // 취소하면 null

var chooser = new JFileChooser();
chooser.setFileFilter(new FileNameExtensionFilter("이미지", "png", "jpg"));
if (chooser.showOpenDialog(frame) == JFileChooser.APPROVE_OPTION) {
    File file = chooser.getSelectedFile();
}
  • 대화상자는 닫힐 때까지 그 줄에서 기다린다(모달). EDT 에서 부른다
  • macOS 에서 OS 와 같은 파일 창을 쓰려면 AWT 의 FileDialog 를 쓴다

메뉴 · 단축키

var bar = new JMenuBar();
var file = new JMenu("파일");
file.setMnemonic(KeyEvent.VK_F);                                    // Alt+F (Windows)

var open = new JMenuItem("열기…");
open.setAccelerator(KeyStroke.getKeyStroke(KeyEvent.VK_O,
        Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx()));   // macOS ⌘O · Windows Ctrl+O
open.addActionListener(e -> openFile());

file.add(open);
file.addSeparator();
file.add(new JMenuItem("끝내기"));
bar.add(file);
frame.setJMenuBar(bar);

같은 일을 메뉴 · 단추 · 단축키에서 함께 쓸 때는 Action 하나로 만든다. 켜고 끄기(setEnabled) 가 모두에 함께 걸린다.

Action save = new AbstractAction("저장") {
    @Override public void actionPerformed(ActionEvent e) { saveFile(); }
};
save.putValue(Action.ACCELERATOR_KEY, KeyStroke.getKeyStroke(KeyEvent.VK_S,
        Toolkit.getDefaultToolkit().getMenuShortcutKeyMaskEx()));
fileMenu.add(save);
toolbar.add(save);
save.setEnabled(false);             // 메뉴 · 단추가 함께 흐려진다
  • 단축키 수정 키는 getMenuShortcutKeyMaskEx() 로 받는다. CTRL_DOWN_MASK 로 박으면 macOS 에서 ⌘ 대신 Ctrl 이 된다
  • 창 어디서나 듣는 단축키는 getRootPane().getInputMap(JComponent.WHEN_IN_FOCUSED_WINDOW) · getActionMap() 에 건다. KeyListener 는 포커스가 있는 컴포넌트에서만 듣는다
