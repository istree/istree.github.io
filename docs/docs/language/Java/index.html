Java 는 JVM(Java Virtual Machine) 위에서 도는 객체 지향 언어다. 한 번 컴파일한 바이트코드가 운영체제와 상관없이 돌고, 서버 · 안드로이드 · 데스크톱에 두루 쓴다. 6 개월마다 새 버전이 나오고, 2 년마다 오래 지원하는 LTS 버전(8 · 11 · 17 · 21 · 25) 이 나온다.

여기에는 언어, 가상머신(JDK · JVM), 빌드 도구(Maven · Gradle), GUI, 스크립팅(Java 안에서 JavaScript 돌리기), 쓸 만한 라이브러리를 정리한다.
