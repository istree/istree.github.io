Scripting API

목록 · JS on Java
  • 개요
  • Scripting API

엔진과 상관없이 Java 에서 스크립트를 돌리는 표준 API(javax.script, JSR 223) 다. Java 6 부터 들어 있다. 어떤 엔진이 붙는지는 Java 버전과 넣은 라이브러리에 따라 다르다.

엔진 얻기

Java 버전마다 함께 들어 있는 엔진이 다르다.

Java 들어 있는 엔진
6 · 7 Rhino 를 바탕으로 한 엔진
8 ~ 14 Nashorn (11 부터 사라질 예정으로 표시)
15 ~ 없음 — Rhino · Nashorn 독립판 · GraalJS 를 따로 넣는다 
ScriptEngineManager manager = new ScriptEngineManager();
ScriptEngine js = manager.getEngineByName("javascript");
if (js == null)
    throw new IllegalStateException("JavaScript 엔진이 없다");   // Java 15 부터는 엔진을 따로 넣어야 한다

값 넘기고 돌리기

put 으로 Java 값을 스크립트 변수로 넘기고, eval 의 결과를 받는다.

js.put("price", 1200);
Object total = js.eval("price * 2");
System.out.println(total);   // 2400 또는 2400.0 (엔진에 따라 숫자 형이 다르다)

함수 부르기

스크립트에 정의한 함수를 Java 에서 부른다. 엔진이 Invocable 을 지원해야 한다.

js.eval("function tax(v) { return v * 0.1; }");
Invocable inv = (Invocable) js;
Object t = inv.invokeFunction("tax", 1200);

한 번 컴파일해 여러 번

같은 스크립트를 자주 돌리면 Compilable 로 한 번만 컴파일한다.

CompiledScript calc = ((Compilable) js).compile("price * 2");
Bindings b = js.createBindings();
for (int price : prices) {
    b.put("price", price);
    System.out.println(calc.eval(b));
}
