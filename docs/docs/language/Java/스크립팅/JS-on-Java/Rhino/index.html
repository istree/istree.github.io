Mozilla 가 Java 로 만든 JavaScript 엔진이다. Java 6 · 7 에 들어 있던 엔진의 바탕이고, 지금도 GitHub 에서 따로 관리된다(org.mozilla:rhino). Scripting API 를 거치지 않고 자체 API 로 쓴다.

돌리기

스크립트는 Context 안에서 돌린다. Context 는 스레드마다 들어가고(enter) 나와야 한다. 새 버전은 try 로 닫는다.

try (Context cx = Context.enter()) {
    Scriptable scope = cx.initStandardObjects();
    ScriptableObject.putProperty(scope, "price", 1200);      // Java 값을 스크립트 변수로
    Object r = cx.evaluateString(scope, "price * 2", "calc", 1, null);
    System.out.println(Context.toString(r));                // 2400
}

옛 버전은 finally 에서 Context.exit() 를 부른다.

Context cx = Context.enter();
try {
    // ...
} finally {
    Context.exit();
}

Java 객체 넘기기

Java 객체를 넘기면 스크립트에서 그 메서드를 부를 수 있다.

ScriptableObject.putProperty(scope, "out", Context.javaToJS(System.out, scope));
cx.evaluateString(scope, "out.println('스크립트에서 찍는다')", "print", 1, null);

64KB 제약

Rhino 는 스크립트를 JVM 바이트코드로 컴파일해 빠르게 돌린다. 그런데 JVM 의 메서드 하나는 64KB 를 넘을 수 없어서, 아주 큰 스크립트는 컴파일하다 실패한다(generated bytecode for method exceeds 64K limit). 큰 스크립트는 컴파일하지 않고 해석 모드로 돌린다.

cx.setInterpretedMode(true);     // 새 버전
cx.setOptimizationLevel(-1);     // 옛 버전
  • 해석 모드는 조금 느리지만 크기 제한이 없다
