Java 는 표준 라이브러리가 넓지만, JSON · 로그 · HTTP 클라이언트 · DB 연결 · 테스트 같은 일은 라이브러리를 쓰는 것이 보통이다. 라이브러리는 Maven Central 에 있고, Maven 의 pom.xml 이나 Gradle 의 build.gradle.kts 에 좌표(groupId:artifactId:version) 를 적으면 받아 온다. 고를 때는 최근에 갱신했는지, 쓰는 Java 판을 지원하는지, 같은 일을 하는 라이브러리끼리 섞이지 않는지(로그 · JSON) 를 본다. 아래는 분류마다 많이 쓰고 지금도 관리되는 것을 모았다 (2026-11 기준).

범용

  • Guava — Google 의 컬렉션 · 캐시 · 문자열 · 해시 도우미. 일부는 표준(Optional · java.time) 에 들어갔다
  • Apache Commons Lang — StringUtils · ObjectUtils 같은 작은 도우미 모음

코드 줄이기

  • Lombok — @Getter · @Builder · @Slf4j 같은 어노테이션으로 반복 코드를 컴파일할 때 만든다. 값 클래스는 record 로 대신한다
  • MapStruct — 엔티티 ↔ DTO 변환 코드를 컴파일할 때 만든다

JSON · 직렬화

  • Jackson — 가장 많이 쓰는 JSON 라이브러리. Spring 의 기본. 3 판부터 패키지가 tools.jackson 이다
  • Gson — Google 의 가벼운 JSON
  • Protocol Buffers — .proto 로 정한 메시지를 이진으로. gRPC 가 쓴다

로그

  • SLF4J — 로그 API. 코드는 이것만 쓰고 구현은 따로 고른다
  • Logback — SLF4J 의 기본 구현. Spring Boot 의 기본
  • Log4j 2 — 비동기 로그가 빠른 구현

HTTP · 네트워크

  • OkHttp — HTTP 클라이언트. 연결 재사용 · 가로채기(interceptor) · 안드로이드
  • Retrofit — 인터페이스에 어노테이션을 달면 REST 클라이언트를 만들어 준다
  • Netty — 비동기 네트워크 서버 · 클라이언트의 바탕. 많은 서버 프레임워크가 그 위에서 돈다

데이터베이스

  • HikariCP — 빠른 JDBC 연결 풀. Spring Boot 의 기본
  • Hibernate ORM — JPA 구현. 객체와 테이블을 이어 SQL 을 만들어 준다
  • jOOQ — SQL 을 타입 검사되는 Java 코드로 쓴다
  • MyBatis — SQL 을 XML · 어노테이션에 직접 쓰고 결과를 객체로 받는다
  • Flyway — DB 스키마 변경을 SQL 파일 순서대로 적용한다

테스트

  • JUnit — 표준 테스트 프레임워크 (JUnit 6)
  • AssertJ — assertThat(list).hasSize(3).contains("a") 처럼 읽히는 단언
  • Mockito — 가짜 객체 만들기 · 호출 확인
  • Testcontainers — 테스트에서 Docker 로 진짜 DB · Kafka 를 띄운다
  • ArchUnit — 패키지 의존 규칙을 테스트로 검사한다

명령줄 · 설정

  • picocli — 어노테이션으로 명령줄 인자 · 하위 명령 · 도움말을 만든다

안정성 · 캐시

  • Caffeine — 빠른 메모리 캐시. 만료 · 크기 제한
  • Resilience4j — 재시도 · 서킷 브레이커 · 속도 제한

반응형

  • Project Reactor — Mono · Flux. Spring WebFlux 의 바탕
  • RxJava — Observable 로 비동기 이벤트를 잇는다. 가상 스레드가 생긴 뒤로 새로 쓸 일은 줄었다

문서 · 파일

  • Apache POI — 엑셀 · 워드 파일 읽기 · 쓰기
  • Apache PDFBox — PDF 만들기 · 글자 꺼내기
  • Apache Commons CSV — CSV 읽기 · 쓰기
  • jsoup — HTML 을 읽고 CSS 선택자로 꺼낸다. 크롤링 · 정리

게임 · 그래픽

  • libGDX — 데스크톱 · 안드로이드 · 웹으로 내는 게임 프레임워크
  • dyn4j — 2D 물리 엔진 · 충돌 검사
  • JFreeChart — Swing · 이미지로 그리는 차트
