Ruby 는 실행 중에 클래스와 메서드를 고치고 만들 수 있다. 코드를 만드는 코드로 반복을 줄이고, 읽기 쉬운 작은 언어(DSL) 를 만든다.

열린 클래스

이미 있는 클래스에 메서드를 더한다. 표준 클래스도 된다.

class NilClass
  def blank?
    true
  end
end

class String
  def blank?
    empty?
  end
end

['', 'person', nil].each { |e| puts e unless e.blank? }   # person

숫자에 단위를 붙이면 문장처럼 읽힌다.

class Numeric
  def inches = self
  def feet   = self * 12.inches
  def back   = self * -1
end

puts 10.feet.back                # -120
  • 표준 클래스를 고치면 프로그램 전체가 바뀐다. 이름이 다른 라이브러리와 겹치지 않게 조심한다

method_missing

없는 메서드를 부르면 method_missing 이 불린다. 메서드 이름을 값처럼 읽어 처리한다.

class Roman
  def self.method_missing(name, *args)
    roman = name.to_s
      .gsub('IV', 'IIII').gsub('IX', 'VIIII')
      .gsub('XL', 'XXXX').gsub('XC', 'LXXXX')
    roman.count('I') + roman.count('V') * 5 + roman.count('X') * 10 +
      roman.count('L') * 50 + roman.count('C') * 100
  end
end

puts Roman.XII                   # 12
puts Roman.XC                    # 90
  • 처리하지 않을 이름은 super 로 넘긴다. 그래야 오타가 NoMethodError 로 드러난다
  • respond_to_missing? 도 함께 정의하면 respond_to? 가 맞게 답한다

define_method

메서드를 이름을 받아 만든다. 비슷한 메서드를 여럿 찍어 낼 때 쓴다.

class Config
  %w[host port user].each do |key|
    define_method(key) { @values[key] }
    define_method("#{key}=") { |v| @values[key] = v }
  end

  def initialize
    @values = {}
  end
end

included 훅

모듈이 include 될 때 불리는 self.included 로, 섞어 넣는 쪽 클래스에 클래스 메서드를 더한다. Rails 의 acts_as_… 같은 선언이 이렇게 만들어진다.

module ActsAsCsv
  def self.included(base)
    base.extend ClassMethods
  end

  module ClassMethods
    def acts_as_csv
      include InstanceMethods        # 선언하면 인스턴스 메서드가 섞인다
    end
  end

  module InstanceMethods
    attr_accessor :headers, :rows

    def read
      lines = File.readlines(self.class.to_s.downcase + '.txt', chomp: true)
      @headers = lines.first.split(', ')
      @rows = lines.drop(1).map { |l| l.split(', ') }
    end
  end
end

class RubyCsv
  include ActsAsCsv
  acts_as_csv                        # 클래스 안에서 한 줄로 선언
end
