rbenv 로 Ruby 를 깔고 버전을 바꾼다. 시스템에 딸린 Ruby 는 건드리지 않는다.

macOS

Homebrew 로 rbenv 와 ruby-build 를 깐다.

brew install rbenv ruby-build
rbenv install -l              # 깔 수 있는 버전
rbenv install 3.3.6
rbenv global 3.3.6            # 기본 버전

셸이 rbenv 의 Ruby 를 쓰게 ~/.zshrc 에 한 줄 넣고 터미널을 다시 연다.

echo 'eval "$(rbenv init - zsh)"' >> ~/.zshrc
  • ~/.rbenv/versions/3.3.6/bin 을 PATH 에 직접 넣어도 돌지만, 버전을 바꿀 때마다 고쳐야 한다. rbenv init 은 버전을 바꿔도 그대로다

Linux (Debian · Ubuntu)

빌드에 필요한 패키지를 깔고 rbenv 를 넣는다.

sudo apt update
sudo apt install git curl autoconf bison build-essential libssl-dev libyaml-dev \
     libreadline-dev zlib1g-dev libncurses5-dev libffi-dev libgdbm-dev
curl -sL https://github.com/rbenv/rbenv-installer/raw/HEAD/bin/rbenv-installer | bash -
echo 'eval "$(~/.rbenv/bin/rbenv init - bash)"' >> ~/.bashrc
source ~/.bashrc

확인

rbenv versions      # 깔린 버전 (* 가 지금 버전)
ruby -v
  • 폴더마다 다른 버전을 쓰려면 그 폴더에서 rbenv local 3.2.4 — .ruby-version 파일이 생긴다

M1 맥에서 설치가 실패할 때

Inspect or clean up the working tree 로 시작하는 메시지와 함께 make 오류가 나면 readline 위치를 알려 준다.

RUBY_CONFIGURE_OPTS="--with-readline-dir=$(brew --prefix readline)" rbenv install 3.1.2
