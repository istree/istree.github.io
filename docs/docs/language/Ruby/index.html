Ruby 는 마츠모토 유키히로(Matz) 가 만든 객체 지향 스크립트 언어다. 숫자까지 모든 값이 객체이고, 블록으로 반복 · 자원 관리를 짧게 쓰며, 실행 중에 클래스를 고치는 메타프로그래밍이 쉽다. 웹 프레임워크 Ruby on Rails 와 정적 사이트 도구 Jekyll 이 Ruby 로 만들어졌다.

여기에는 세븐 랭귀지의 Ruby 장을 따라 공부한 것을 정리한다.
