클래스로 객체를 만들고, 모듈로 여러 클래스가 같이 쓸 기능을 묶는다. 다중 상속 대신 모듈을 섞어 넣는다(믹스인).

클래스

class Person
  attr_accessor :name            # name · name= 를 만든다

  def initialize(name)           # new 할 때 불린다
    @name = name                 # @ 는 인스턴스 변수
  end

  def to_s
    "Person(#{name})"
  end
end

p = Person.new('matz')
puts p                           # Person(matz)
  • attr_reader 는 읽기만, attr_writer 는 쓰기만 만든다

상속

class Developer < Person
  def to_s
    super + ' · 개발자'           # 부모의 같은 메서드
  end
end

모듈 믹스인

모듈의 메서드를 include 로 클래스에 섞어 넣는다. 섞인 메서드는 그 클래스의 self 로 돈다.

module ToFile
  def filename
    "object_#{object_id}.txt"
  end

  def to_f
    File.open(filename, 'w') { |f| f.write(to_s) }
  end
end

class Person
  include ToFile
end

Person.new('matz').to_f          # object_….txt 에 "Person(matz)" 를 쓴다

Enumerable · Comparable

표준 모듈은 메서드 하나만 만들면 나머지를 채워 준다.

class Team
  include Enumerable

  def initialize(*members)
    @members = members
  end

  def each(&block)               # each 만 만들면
    @members.each(&block)
  end
end

team = Team.new('kim', 'lee', 'park')
team.sort                        # sort · map · select · include? … 가 생긴다
team.select { |m| m.start_with?('k') }
  • Comparable 은 <=> 하나로 < · > · between? 을 채운다
