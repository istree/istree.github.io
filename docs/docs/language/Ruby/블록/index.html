블록은 메서드에 넘기는 코드 덩어리다. 반복 · 자원 관리 · 콜백을 블록으로 쓴다. 한 줄이면 { } 로, 여러 줄이면 do … end 로 쓴다.

블록 넘기기

[1, 2, 3].each { |x| puts x }

File.open('memo.txt') do |f|
  puts f.read
end                            # 블록이 끝나면 파일을 닫는다

yield

메서드 안에서 yield 를 부르면 넘겨받은 블록이 돈다.

def twice
  yield
  yield
end

twice { puts '안녕' }

블록에 값을 넘기고, 블록이 돌려준 값을 받는다.

def each_pair_sum(a, b)
  yield(a + b)
end

each_pair_sum(3, 4) { |sum| puts sum }   # 7

&block — 블록을 받아 넘기기

블록을 이름으로 받아 다른 메서드에 그대로 넘긴다. 트리를 돌며 노드마다 같은 블록을 부르는 식이다.

class Tree
  attr_accessor :children, :name

  def initialize(name, children = [])
    @name = name
    @children = children
  end

  def visit_all(&block)
    block.call(self)
    children.each { |c| c.visit_all(&block) }
  end
end

tree = Tree.new('Ruby', [Tree.new('Reia'), Tree.new('MacRuby')])
tree.visit_all { |node| puts node.name }
  • &block 은 블록을 Proc 객체로 받는다. 부를 때는 block.call, 넘길 때는 다시 &block
  • 블록이 왔는지는 block_given? 으로 본다
