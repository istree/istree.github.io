Ruby 에서는 숫자까지 모든 값이 객체라, 값 뒤에 바로 메서드를 붙인다. 괄호는 헷갈리지 않으면 뺀다.

출력과 문자열

puts 'hello, world'
name = 'matz'
puts "hello, #{name}"        # 큰따옴표 안의 #{} 는 값으로 바뀐다
puts 4.class                 # Integer — 숫자도 객체
puts 'abc'.upcase.reverse    # CBA

조건

if 와 반대인 unless 가 있고, 한 줄짜리는 문장 뒤에 붙인다.

puts '어른' if age >= 20
puts '빈 값' unless value
x = age >= 20 ? '어른' : '아이'
  • 거짓은 false 와 nil 뿐이다. 0 과 '' 는 참이다

반복

for 보다 메서드를 쓴다.

3.times { |i| puts i }            # 0 1 2
1.upto(3) { |i| puts i }          # 1 2 3
[1, 2, 3].each { |x| puts x * 2 }

배열과 해시

langs = ['ruby', 'io', 'prolog']
langs << 'scala'                  # 뒤에 붙이기
langs[0]                          # "ruby"
langs[-1]                         # "scala" — 뒤에서부터
langs.map(&:upcase)               # ["RUBY", "IO", "PROLOG", "SCALA"]

numbers = { one: 1, two: 2 }      # 키가 심볼인 해시
numbers[:one]                     # 1
numbers.each { |k, v| puts "#{k}=#{v}" }

심볼

:one 같은 심볼은 이름표다. 같은 심볼은 늘 같은 객체라, 해시의 키나 메서드 이름에 쓴다.

:one.object_id == :one.object_id     # true
'one'.object_id == 'one'.object_id   # false — 글자열은 매번 새 객체
