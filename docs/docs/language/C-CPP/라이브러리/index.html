  • 라이브러리

C · C++ 은 표준 라이브러리가 작아서, JSON · 네트워크 · GUI · 로그 같은 일은 따로 받은 라이브러리로 한다. 라이브러리를 받는 길은 셋이다. vcpkg · Conan 같은 패키지 매니저로 설치하고 CMake 의 find_package 로 찾거나, CMake 의 FetchContent 로 소스째 받아 같이 빌드하거나, stb 처럼 헤더 파일 하나를 프로젝트에 복사한다. 고를 때는 최근에 갱신했는지, CMake 로 쓰기 쉬운지, 라이선스(MIT · BSD · Apache 는 자유롭고 GPL · LGPL 은 조건이 있다) 를 본다. 아래는 분류마다 많이 쓰고 지금도 관리되는 것을 모았다 (2026-11 기준). C 로 된 것은 (C) 로 적었고, C++ 에서도 그대로 쓴다.

범용

  • Boost — 컨테이너 · 문자열 · 파일 시스템 · 네트워크 · 날짜까지 100 개가 넘는 라이브러리 모음. 표준 라이브러리에 들어간 것(shared_ptr · optional · filesystem) 이 여기서 먼저 나왔다
  • Abseil — Google 이 쓰는 C++ 기본 라이브러리. 빠른 해시 맵(flat_hash_map) · 문자열 · 시간

문자열 · 로그

  • fmt — std::format · std::print 의 바탕이 된 형식 라이브러리. 표준보다 기능이 많고 옛 컴파일러에서도 돈다
  • spdlog — 빠른 로그. 파일 · 콘솔 · 날짜별 파일로 쓰고 fmt 형식을 쓴다

JSON · 설정

  • nlohmann/json — json j = {{"name", "geon"}}; 처럼 쓰기 가장 편한 JSON
  • simdjson — CPU 의 SIMD 로 아주 빠르게 읽는 JSON 파서. 큰 로그 · 데이터에
  • RapidJSON — 빠르고 메모리를 적게 쓰는 JSON 읽기 · 쓰기
  • yyjson (C) — C 로 된 빠른 JSON
  • cJSON (C) — 파일 두 개로 된 작은 JSON. 임베디드에 많다
  • toml++ — TOML 설정 파일 읽기 · 쓰기

직렬화

  • Protocol Buffers — .proto 로 메시지를 정의하고 여러 언어 코드를 만든다. gRPC 가 쓴다
  • FlatBuffers — 읽을 때 풀지 않고 바로 접근하는 직렬화. 게임 · 모바일에

네트워크

  • libcurl (C) — HTTP · FTP 등 거의 모든 프로토콜의 클라이언트. curl 명령의 라이브러리
  • cpp-httplib — 헤더 하나로 된 HTTP 서버 · 클라이언트. 작은 도구 · 테스트 서버에
  • Asio — 비동기 소켓 · 타이머. Boost.Asio 와 같고 따로도 쓴다
  • libuv (C) — Node.js 의 이벤트 루프. 비동기 I/O · 파일 · 프로세스
  • Drogon — 빠른 웹 프레임워크. 라우팅 · ORM · WebSocket

명령줄 인자

  • CLI11 — 하위 명령 · 설정 파일까지 되는 인자 파서
  • cxxopts — 가벼운 인자 파서. 헤더 하나
  • argparse — Python 의 argparse 와 같은 모양

테스트 · 벤치마크

  • GoogleTest — 가장 많이 쓰는 테스트 프레임워크 · 가짜 객체(gMock)
  • Catch2 — REQUIRE(a == b) 처럼 식 그대로 쓰는 테스트. BDD 꼴도 된다
  • doctest — Catch2 와 비슷하고 컴파일이 빠른 헤더 하나짜리
  • Google Benchmark — 함수 실행 시간을 반복해 잰다
  • nanobench — 헤더 하나로 된 간단한 벤치마크

GUI

  • Qt — Windows · macOS · Linux · 모바일 데스크톱 앱. 위젯 · QML · 네트워크까지 (LGPL · 상용)
  • Dear ImGui — 프레임마다 다시 그리는 즉시 모드 GUI. 게임 · 도구의 디버그 화면에
  • wxWidgets — OS 의 기본 위젯으로 그리는 데스크톱 GUI

게임 · 그래픽

  • SDL (C) — 창 · 입력 · 소리 · 2D 그리기. 많은 게임 · 에뮬레이터의 바탕 (SDL3)
  • raylib (C) — 배우기 쉬운 2D · 3D 게임 라이브러리
  • GLFW (C) — OpenGL · Vulkan 용 창 · 입력
  • SFML — C++ 로 된 2D 그래픽 · 소리 · 네트워크

수학

  • Eigen — 행렬 · 선형대수. 헤더만 있다
  • GLM — GLSL 과 같은 꼴의 벡터 · 행렬. 그래픽에

이미지 · 비전

  • stb (C) — stb_image.h 처럼 파일 하나로 된 라이브러리 모음. 이미지 읽기 · 쓰기 · 글꼴
  • OpenCV — 영상 처리 · 컴퓨터 비전 · 카메라

데이터베이스

  • SQLite (C) — 파일 하나로 된 SQL 데이터베이스. sqlite3.c 를 그대로 넣어 빌드한다
  • SQLiteCpp — SQLite 를 C++ 클래스 · 예외로 감싼 것
  • libpqxx — PostgreSQL 공식 C++ 클라이언트

압축 · 암호

  • zlib (C) — gzip · zip 의 deflate 압축
  • Zstandard (C) — 빠르고 잘 줄이는 압축 (zstd)
  • LZ4 (C) — 아주 빠른 압축 · 풀기
  • OpenSSL (C) — TLS · 인증서 · 암호 함수
  • libsodium (C) — 실수하기 어렵게 만든 암호 · 서명 · 해시

동시성

  • oneTBB — 병렬 반복 · 작업 스케줄러 · 동시 컨테이너 (Intel TBB)
  • Taskflow — 작업 사이의 의존을 그래프로 적고 병렬로 돌린다

찾아보기

  • vcpkg — Microsoft 의 패키지 매니저. CMake 와 잘 붙고, 패키지 목록에서 이름을 찾는다
  • Conan — 바이너리를 미리 빌드해 나눠 주는 패키지 매니저
  • awesome-cpp · awesome-c — 분류별 C++ · C 라이브러리 목록
