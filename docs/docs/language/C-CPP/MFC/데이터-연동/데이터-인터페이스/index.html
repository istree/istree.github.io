대화상자는 데이터(모델) 를 직접 건드리지 않고, get · set 만 가진 인터페이스를 통해서만 읽고 쓴다. 화면과 데이터를 따로 만들고 고칠 수 있다.

속성 인터페이스

고칠 대상의 속성을 순수 가상 함수로 밝힌다. 페이지는 이 인터페이스만 안다.

// IFontProp.h — 데이터 쪽 모듈
struct IFontProp
{
    virtual CString  GetName() = 0;
    virtual void     SetName(LPCTSTR name) = 0;
    virtual int      GetSize() = 0;
    virtual void     SetSize(int size) = 0;
    virtual COLORREF GetColor() = 0;
    virtual void     SetColor(COLORREF color) = 0;
    virtual ~IFontProp() {}
};
// FontPage.cpp — 화면 쪽 DLL
void CFontPage::LoadProp()
{
    m_strName = m_pProp->GetName();
    m_nSize   = m_pProp->GetSize();
    UpdateData(FALSE);
}

void CFontPage::OnCbnSelchangeName()
{
    UpdateData(TRUE);
    m_pProp->SetName(m_strName);
    GetParent()->SendMessage(WM_PROPCHANGED);   // 미리보기 갱신
}
  • 화면 DLL 은 데이터 쪽 헤더(인터페이스) 만 포함한다. 데이터 쪽 구현이 바뀌어도 화면은 다시 빌드하지 않는다
  • 같은 페이지를 여러 대상이 같이 쓴다. 제목의 글꼴 · 범례의 글꼴 모두 IFontProp 이다. 트리·탭 페이지 에 정리했다

편집 시작 · 확정 · 취소

대화상자에서 고치다 취소하면 원래대로 돌아가야 한다. 인터페이스에 편집 시작 · 확정 · 취소를 둔다.

struct IChartData
{
    virtual void Start()  = 0;   // 지금 상태를 남겨 둔다
    virtual void End()    = 0;   // 고친 것을 확정한다
    virtual void Cancel() = 0;   // 남겨 둔 상태로 되돌린다
    // 계열 · 축 …
};
BOOL CDataDlg::OnInitDialog() { CDialog::OnInitDialog(); m_pData->Start(); return TRUE; }
void CDataDlg::OnOK()         { m_pData->End();    CDialog::OnOK(); }
void CDataDlg::OnCancel()     { m_pData->Cancel(); CDialog::OnCancel(); }

기본 구현

인터페이스마다 메모리에만 값을 들고 있는 기본 구현(CChartDataDefault) 을 둔다. 실제 데이터가 없을 때 · 화면만 따로 시험할 때 쓴다.
