차트 만들기처럼 여러 단계를 차례로 거치는 화면은 CPropertySheet 를 마법사 모드로 쓴다. 단계마다 페이지(CPropertyPage) 를 두고, 뒤로 · 다음 · 마침 버튼으로 오간다.

시트와 페이지

// ChartWizard.h
class CChartWizard : public CPropertySheet
{
public:
    CChartWizard(CWnd* pParent)
        : CPropertySheet(_T("차트 만들기"), pParent)
    {
        AddPage(&m_pageType);    // 1. 종류
        AddPage(&m_pageField);   // 2. 데이터
        AddPage(&m_pageStyle);   // 3. 모양
        SetWizardMode();
    }
    CTypePage  m_pageType;
    CFieldPage m_pageField;
    CStylePage m_pageStyle;
};
CChartWizard wiz(this);
if (wiz.DoModal() == ID_WIZFINISH) {
    // 만들기
}

단계마다 버튼

페이지가 보일 때마다 불리는 OnSetActive 에서 그 단계의 버튼을 정한다.

BOOL CFieldPage::OnSetActive()
{
    CPropertySheet* pSheet = (CPropertySheet*)GetParent();
    pSheet->SetWizardButtons(PSWIZB_BACK | PSWIZB_NEXT);
    return CPropertyPage::OnSetActive();
}
  • 첫 페이지는 PSWIZB_NEXT, 마지막 페이지는 PSWIZB_BACK | PSWIZB_FINISH
  • 마칠 수 있는 단계가 여럿이면 중간 페이지에도 PSWIZB_FINISH 를 준다

넘어가기 전에 검사

OnWizardNext 에서 -1 을 돌려주면 다음으로 가지 않는다. 다른 페이지의 ID 를 돌려주면 그 페이지로 건너뛴다.

LRESULT CFieldPage::OnWizardNext()
{
    if (!Validate())
        return -1;                        // 머문다
    if (m_bSkipStyle)
        return IDD_PAGE_FINISH;           // 건너뛴다
    return CPropertyPage::OnWizardNext();
}

고치기에 다시 쓰기

만든 것을 고칠 때도 같은 마법사를 쓴다. 고칠 단계로 바로 가서 그 페이지에서 마치게 한다.

CChartWizard wiz(this);
wiz.m_mode = MODE_EDIT;
wiz.SetActivePage(&wiz.m_pageField);      // DoModal 전에 시작 페이지를 정한다
wiz.DoModal();
BOOL CFieldPage::OnSetActive()
{
    CChartWizard* pWiz = (CChartWizard*)GetParent();
    pWiz->SetWizardButtons(pWiz->m_mode == MODE_EDIT ? PSWIZB_FINISH
                                                     : PSWIZB_BACK | PSWIZB_NEXT);
    return CPropertyPage::OnSetActive();
}

미리보기 곁들이기

시트의 OnInitDialog 에서 미리보기 창을 모덜리스로 만들어 옆에 붙이면, 단계를 거치며 결과를 바로 본다. 옆에 붙이는 법은 자석 윈도우 에 정리했다.
