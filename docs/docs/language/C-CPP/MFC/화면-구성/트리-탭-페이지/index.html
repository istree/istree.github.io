왼쪽 트리에서 대상을 고르면, 오른쪽 탭에 그 대상의 페이지들이 나오는 속성 창이다. 대상이 많고 대상마다 고칠 것이 여러 묶음일 때 쓴다.

페이지는 한 번만 만든다

같은 페이지를 여러 대상이 같이 쓴다. 제목의 글꼴과 범례의 글꼴은 대상만 다르고 페이지는 같다. 페이지는 템플릿 ID 마다 한 번만 만들어 두고, 보일 때 대상을 넘긴다.

// OnInitDialog
m_pages[IDD_PAGE_FONT]   = &m_pageFont;
m_pages[IDD_PAGE_FILL]   = &m_pageFill;
m_pages[IDD_PAGE_BORDER] = &m_pageBorder;
for (auto& p : m_pages)
    p.second->Create(p.first, this);   // 패널 윈도우로

패널 윈도우를 만드는 법은 대화상자 의 "패널 윈도우" 에 정리했다.

트리 항목에 페이지 목록 달기

트리 항목마다 "어느 페이지를 어느 대상으로 보일지" 목록을 달아 둔다.

struct PageInfo { CString title; UINT idd; IProp* pTarget; };
struct ItemInfo { std::vector<PageInfo> pages; };

HTREEITEM hTitle = m_tree.InsertItem(_T("제목"), hChart);
ItemInfo* pInfo = new ItemInfo;
pInfo->pages.push_back({ _T("글꼴"),   IDD_PAGE_FONT,   pChart->GetTitleFont() });
pInfo->pages.push_back({ _T("배경"),   IDD_PAGE_FILL,   pChart->GetTitleFill() });
m_tree.SetItemData(hTitle, (DWORD_PTR)pInfo);

고르면 탭 다시 채우기

void CPropDlg::OnTvnSelchanged(NMHDR* pNMHDR, LRESULT* pResult)
{
    NMTREEVIEW* p = reinterpret_cast<NMTREEVIEW*>(pNMHDR);
    m_pCur = (ItemInfo*)m_tree.GetItemData(p->itemNew.hItem);

    m_tab.DeleteAllItems();
    for (size_t i = 0; i < m_pCur->pages.size(); i++)
        m_tab.InsertItem((int)i, m_pCur->pages[i].title);
    ShowPage(0);
    *pResult = 0;
}

탭을 바꾸면 페이지 보이기

탭의 페이지 영역(AdjustRect) 에 맞춰 페이지를 놓고, 대상을 넘겨 값을 읽게 한다. 나머지 페이지는 숨긴다.

void CPropDlg::ShowPage(int nTab)
{
    m_tab.SetCurSel(nTab);
    const PageInfo& info = m_pCur->pages[nTab];

    CRect rc;
    m_tab.GetWindowRect(&rc);
    ScreenToClient(&rc);
    m_tab.AdjustRect(FALSE, &rc);           // 탭 머리를 뺀 안쪽

    for (auto& p : m_pages) {
        if (p.first == info.idd) {
            p.second->SetTarget(info.pTarget);
            p.second->LoadProp();           // 대상의 값을 컨트롤에
            p.second->SetWindowPos(&m_tab, rc.left, rc.top, rc.Width(), rc.Height(), SWP_SHOWWINDOW);
        } else {
            p.second->ShowWindow(SW_HIDE);
        }
    }
}
  • 페이지를 탭 위에 보이게 SetWindowPos 의 순서 기준으로 탭을 준다
  • 트리 항목이 지워질 때(TVN_DELETEITEM) 달아 둔 ItemInfo 를 지운다

경로로 찾아가기

"트리 항목 + 탭 번호" 를 경로로 삼으면 다른 곳에서 특정 페이지로 바로 보낼 수 있다. 미리보기에서 범례를 누르면 범례 › 글꼴 페이지를 여는 식이다.

void CPropDlg::Select(HTREEITEM hItem, int nTab)
{
    m_tree.SelectItem(hItem);   // TVN_SELCHANGED 로 탭이 다시 채워진다
    ShowPage(nTab);
}
