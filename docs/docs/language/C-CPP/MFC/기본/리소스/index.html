대화상자 · 문자열 · 그림 같은 화면 재료는 코드 밖 리소스 파일(.rc) 에 둔다. 빌드하면 실행 파일이나 DLL 안에 들어간다.

rc 와 resource.h

resource.h 에 리소스 ID 를 정하고, 코드와 rc 가 함께 읽는다. 머리글자로 종류를 가린다.

// resource.h
#define IDD_FONT            101     // 대화상자
#define IDB_TREE_ICONS      201     // 비트맵
#define IDS_TITLE_FONT      301     // 문자열
#define IDC_COMBO_FONT      1001    // 컨트롤
#define IDC_COMBO_SIZE      1002
#define IDC_CHECK_BOLD      1003

.rc 는 리소스 편집기로 고치지만 텍스트 파일이다.

// MyApp.rc
#include "resource.h"

IDD_FONT DIALOGEX 0, 0, 200, 64
STYLE DS_SETFONT | WS_CHILD
FONT 9, "맑은 고딕"
BEGIN
    LTEXT       "글꼴", IDC_STATIC, 7, 9, 30, 8
    COMBOBOX    IDC_COMBO_FONT, 40, 7, 150, 100, CBS_DROPDOWNLIST | WS_VSCROLL | WS_TABSTOP
    LTEXT       "크기", IDC_STATIC, 7, 27, 30, 8
    COMBOBOX    IDC_COMBO_SIZE, 40, 25, 50, 100, CBS_DROPDOWNLIST | WS_VSCROLL | WS_TABSTOP
    CONTROL     "굵게", IDC_CHECK_BOLD, "Button", BS_AUTOCHECKBOX | WS_TABSTOP, 7, 45, 40, 10
END

IDB_TREE_ICONS  BITMAP  "res\\tree_icons.bmp"

STRINGTABLE
BEGIN
    IDS_TITLE_FONT  "글꼴"
END
  • 대화상자의 자리 · 크기는 픽셀이 아니라 대화상자 단위(DLU) 다. 글꼴 크기에 따라 늘고 준다
  • 컨트롤 줄의 순서가 Tab 키 순서다

인코딩

rc 는 UTF-16 으로 저장해 두면 여러 언어의 글자가 한 파일에서 깨지지 않는다. 멀티바이트로 두면 언어마다 코드 페이지를 맞춰야 하고 편집기에서 깨져 보이기 쉽다.

#pragma code_page(949)    // 이 아래는 한국어 (CP949)

문자열

화면에 보이는 글자는 코드에 박지 않고 스트링 테이블(String Table) 에 둔다. 번역할 때 rc 만 고치면 된다.

CString str;
str.LoadString(IDS_TITLE_FONT);
SetWindowText(str);

비트맵

IDB_LOGO  BITMAP  "res\\logo.bmp"
CBitmap bmp;
bmp.LoadBitmap(IDB_LOGO);

그리는 법은 GDI 에 정리했다.

아이콘

IDR_MAINFRAME  ICON  "res\\app.ico"

대화상자 제목 표시줄과 작업 표시줄의 아이콘을 바꾼다.

HICON hIcon = AfxGetApp()->LoadIcon(IDR_MAINFRAME);
SetIcon(hIcon, TRUE);    // 큰 아이콘
SetIcon(hIcon, FALSE);   // 작은 아이콘

커서

IDC_CURSOR_PICK  CURSOR  "res\\pick.cur"

화면의 색을 집는 스포이트 커서 같은 것을 넣어 쓴다. 커서는 마우스가 움직일 때마다 창 클래스의 커서로 돌아가므로 OnSetCursor 에서 바꾼다.

ON_WM_SETCURSOR()

BOOL CMyWnd::OnSetCursor(CWnd* pWnd, UINT nHitTest, UINT message)
{
    if (m_bPicking) {
        ::SetCursor(AfxGetApp()->LoadCursor(IDC_CURSOR_PICK));
        return TRUE;
    }
    return CWnd::OnSetCursor(pWnd, nHitTest, message);
}

여러 언어의 리소스는 다국어 에 정리했다.
