창에 오는 메시지(WM_*) 와 컨트롤 알림을 클래스의 함수에 연결하는 표가 메시지 맵(Message Map) 이다.

메시지 맵

선언은 헤더에, 표는 cpp 에 둔다.

// MyDlg.h
class CMyDlg : public CDialog
{
    // ...
protected:
    afx_msg void OnSize(UINT nType, int cx, int cy);
    afx_msg void OnBnClickedApply();
    afx_msg void OnCbnSelchangeStyle();
    DECLARE_MESSAGE_MAP()
};

// MyDlg.cpp
BEGIN_MESSAGE_MAP(CMyDlg, CDialog)
    ON_WM_SIZE()
    ON_BN_CLICKED(IDC_APPLY, &CMyDlg::OnBnClickedApply)
    ON_CBN_SELCHANGE(IDC_COMBO_STYLE, &CMyDlg::OnCbnSelchangeStyle)
END_MESSAGE_MAP()
  • ON_WM_* 는 함수 이름과 인자가 정해져 있다. ON_WM_SIZE 는 OnSize 를 부른다
  • 컨트롤 알림은 ON_BN_* (버튼) · ON_CBN_* (콤보) · ON_EN_* (에디트) 에 컨트롤 ID 와 함수를 준다
  • BEGIN_MESSAGE_MAP 의 두 번째 인자는 부모 클래스다. 이 표에 없으면 부모의 표에서 찾는다

공용 컨트롤 알림

트리 · 리스트 · 탭 같은 공용 컨트롤의 알림(ON_NOTIFY) 과 반사 메시지는 공용 컨트롤 에 정리했다.

사용자 메시지

정해진 메시지로 안 되는 알림은 직접 만든다. WM_USER 대역은 창 클래스가 저마다 쓰는 자리라 대화상자도 WM_USER + 0 · + 1 을 쓴다. 겹치지 않게 WM_APP 부터 쓴다.

#define WM_COLORCHANGED (WM_APP + 1)

ON_MESSAGE(WM_COLORCHANGED, &CMyDlg::OnColorChanged)

LRESULT CMyDlg::OnColorChanged(WPARAM wParam, LPARAM lParam)
{
    COLORREF color = (COLORREF)wParam;
    // ...
    return 0;
}

자식은 부모 클래스를 몰라도 메시지로 알릴 수 있다. 패널의 값이 바뀌면 위로 알리고, 가운데 창은 받아서 다시 위로 넘기고, 맨 위 대화상자가 미리보기를 다시 그린다.

#define WM_PROPCHANGED (WM_APP + 2)

// 패널
void CMyPanel::OnCbnSelchangeStyle()
{
    UpdateData(TRUE);
    m_pModel->SetStyle(m_nStyle);
    GetParent()->SendMessage(WM_PROPCHANGED);
}

// 가운데 창 (탭 등)
LRESULT CMyTab::OnPropChanged(WPARAM, LPARAM)
{
    GetParent()->SendMessage(WM_PROPCHANGED);
    return 0;
}

// 맨 위 대화상자
LRESULT CMyDlg::OnPropChanged(WPARAM, LPARAM)
{
    UpdatePreview();
    return 0;
}

받을 창과 메시지를 바깥에서 정해 주면 한 컨트롤을 여러 곳에 쓸 수 있다.

m_btnColor.SetReceiver(this, WM_COLORCHANGED);   // 색이 바뀌면 이 창에 이 메시지

메시지 가로채기

PreTranslateMessage 를 오버라이딩 하여 메시지가 창에 전달되기 전에 먼저 처리할 수 있다. 대화상자 안의 컨트롤로 가는 메시지도 대화상자를 거친다. 키보드 · 마우스처럼 메시지 큐를 거치는 메시지만 오고, SendMessage 로 바로 보낸 메시지는 오지 않는다.

대화상자에서 Enter · Esc 를 누르면 IDOK · IDCANCEL 로 닫히는 것을 막을 때 쓴다. Enter 를 IDOK 로 바꾸는 일은 기본 CDialog::PreTranslateMessage 안에서 일어나므로, 그 전에 가로채면 닫히지 않는다.

BOOL CMyPage::PreTranslateMessage(MSG* pMsg)
{
    if (pMsg->message == WM_KEYDOWN &&
        (pMsg->wParam == VK_RETURN || pMsg->wParam == VK_ESCAPE))
        return TRUE;   // 여기서 끝낸다
    return CDialog::PreTranslateMessage(pMsg);
}

셀 편집 컨트롤에서 Enter 를 편집 끝, Esc 를 취소로 쓸 때도 여기서 가로챈다.

메시지 보내기

  • SendMessage — 받는 창이 처리할 때까지 기다리고 결과를 돌려받는다
  • PostMessage — 메시지 큐에 넣고 바로 돌아온다. 받는 창은 나중에 처리한다

SendMessage

결과가 필요하거나 처리 순서가 중요할 때 쓴다.

#define WM_GETCURCOLOR (WM_APP + 2)

// 부모에게 묻고 답을 받는다
COLORREF color = (COLORREF)GetParent()->SendMessage(WM_GETCURCOLOR);

돌아올 때까지 기다리므로 지역 변수의 주소를 넘겨도 된다.

CRect rc;
GetParent()->SendMessage(WM_GETPAGERECT, 0, (LPARAM)&rc);   // 부모가 rc 를 채운다

받는 창이 다른 스레드에 있으면 그 스레드가 처리할 때까지 멈춘다. 그 스레드가 이쪽을 기다리고 있으면 둘 다 멈춘다.

PostMessage

기다리지 않아도 될 때, 지금 하던 처리가 끝난 뒤에 하고 싶을 때 쓴다.

#define WM_LOADDATA (WM_APP + 3)

BOOL CMyDlg::OnInitDialog()
{
    CDialog::OnInitDialog();
    PostMessage(WM_LOADDATA);   // 대화상자가 화면에 보인 뒤에 불러온다
    return TRUE;
}

받는 쪽은 돌아온 뒤에 처리하므로 지역 변수의 주소를 넘기면 안 된다. 힙에 만들어 넘기고 받는 쪽이 지운다.

#define WM_STATUS (WM_APP + 4)

// 보내는 쪽
CString* pText = new CString(_T("완료"));
if (!::PostMessage(hWnd, WM_STATUS, 0, (LPARAM)pText))
    delete pText;   // 못 보냈으면 여기서 지운다

// 받는 쪽
LRESULT CMyDlg::OnStatus(WPARAM wParam, LPARAM lParam)
{
    CString* pText = reinterpret_cast<CString*>(lParam);
    m_staticStatus.SetWindowText(*pText);
    delete pText;
    return 0;
}

다른 스레드에서 화면에 알릴 때도 이렇게 쓴다.
