대화상자는 리소스의 대화상자 템플릿과 CDialog 를 상속한 클래스 한 쌍이다. 템플릿이 모양을, 클래스가 동작을 맡는다.

템플릿과 클래스

클래스는 템플릿 ID 를 IDD 로 갖는다.

// MyDlg.h
class CMyDlg : public CDialog
{
public:
    enum { IDD = IDD_MYDLG };
    CMyDlg(CWnd* pParent = NULL) : CDialog(IDD, pParent) {}
    // ...
};

모달

DoModal() 로 띄운다. 닫힐 때까지 돌아오지 않고, 그동안 부모 창은 막힌다. 누른 버튼(IDOK · IDCANCEL)을 돌려준다.

CMyDlg dlg(this);
if (dlg.DoModal() == IDOK) {
    // dlg 의 값을 읽는다
}

값을 검사해서 맞을 때만 닫는다.

void CMyDlg::OnOK()
{
    if (!Validate())
        return;          // 잘못된 값이면 닫지 않는다
    CDialog::OnOK();
}

모덜리스

띄운 뒤에도 부모 창을 그대로 쓸 수 있다. Create() 로 만들고 ShowWindow() 로 보인다. 띄운 함수가 끝나도 살아 있어야 하므로 new 로 만든다.

CMyDlg* pDlg = new CMyDlg;
pDlg->Create(CMyDlg::IDD, this);
pDlg->ShowWindow(SW_SHOW);

닫을 때는 EndDialog 대신 DestroyWindow() 를 부르고, 창이 받는 마지막 메시지 뒤에 불리는 PostNcDestroy 에서 자신을 지운다.

void CMyDlg::OnOK()     { UpdateData(TRUE); DestroyWindow(); }
void CMyDlg::OnCancel() { DestroyWindow(); }
void CMyDlg::PostNcDestroy() { delete this; }

OnInitDialog

컨트롤을 채우는 곳은 생성자가 아니라 OnInitDialog 다. 생성자에서는 아직 창이 없다. 컨트롤을 다루는 법은 컨트롤 에 정리했다.

BOOL CMyDlg::OnInitDialog()
{
    CDialog::OnInitDialog();   // 여기서 DoDataExchange 가 한 번 불려 컨트롤이 변수에 붙는다 (컨트롤 › 컨트롤과 변수 값 연결)

    m_comboSize.AddString(_T("8"));
    m_comboSize.AddString(_T("10"));
    m_comboSize.SetCurSel(0);
    return TRUE;   // 포커스를 직접 옮겼으면 FALSE
}

패널 윈도우

대화상자 안에 다른 대화상자를 자식 창(Child) 으로 끼워 패널처럼 쓴다. 탭 페이지처럼 자리를 바꿔 가며 보이는 화면에 쓴다.

템플릿은 Style 을 Child, Border 를 None 으로 두고 제목 표시줄을 끈다. 부모가 Create 하고 자리를 잡는다.

m_panel.Create(CMyPanel::IDD, this);

CRect rc;
GetDlgItem(IDC_PANEL_AREA)->GetWindowRect(&rc);   // 자리만 잡아 둔 Picture Control
ScreenToClient(&rc);
m_panel.MoveWindow(&rc);
m_panel.ShowWindow(SW_SHOW);

템플릿의 Control 속성(DS_CONTROL) 을 켜면 Tab 키가 부모와 자식의 컨트롤 사이를 이어서 돈다.

여러 패널을 만들어 두고 하나만 보인다.

// OnInitDialog
m_panelGeneral.Create(IDD_PANEL_GENERAL, this);
m_panelSeries .Create(IDD_PANEL_SERIES , this);

m_panels[IDD_PANEL_GENERAL] = &m_panelGeneral;   // std::map<UINT, CDialog*>
m_panels[IDD_PANEL_SERIES ] = &m_panelSeries;
void CMyDlg::ShowPanel(UINT nID)
{
    CRect rc;
    GetDlgItem(IDC_PANEL_AREA)->GetWindowRect(&rc);   // 자리만 잡아 둔 Picture Control
    ScreenToClient(&rc);

    for (std::map<UINT, CDialog*>::iterator it = m_panels.begin(); it != m_panels.end(); ++it) {
        if (it->first == nID)
            it->second->SetWindowPos(NULL, rc.left, rc.top, rc.Width(), rc.Height(), SWP_NOZORDER | SWP_SHOWWINDOW);
        else
            it->second->ShowWindow(SW_HIDE);
    }
}

패널 안에서 Enter · Esc 를 누르면 패널의 OnOK · OnCancel 이 불려 패널이 닫힌다. 빈 함수로 막는다.

void CMyPanel::OnOK()     {}
void CMyPanel::OnCancel() {}

트리 · 탭으로 패널을 고르는 방법은 트리·탭 페이지 에 정리했다.
