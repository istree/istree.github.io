리스트 컨트롤(CListCtrl, Report 보기) 의 아무 칸이나 그 자리에서 고친다. CListCtrl 은 첫 열만 고칠 수 있어(LVS_EDITLABELS), 칸 위에 에디트 · 콤보를 겹쳐 띄워 만든다.

누른 칸 찾기

SubItemHitTest 로 줄과 열을, GetSubItemRect 로 그 칸의 자리를 구한다.

// CellList.cpp — CListCtrl 파생
void CCellList::OnLButtonDblClk(UINT nFlags, CPoint point)
{
    LVHITTESTINFO hit = {};
    hit.pt = point;
    if (SubItemHitTest(&hit) < 0 || hit.iSubItem == 0)
        return;                      // 칸이 아니거나 첫 열

    CRect rc;
    GetSubItemRect(hit.iItem, hit.iSubItem, LVIR_LABEL, rc);
    ShowEdit(hit.iItem, hit.iSubItem, rc);
}

에디트 띄우기

에디트는 처음에 한 번만 만들고, 그 뒤로는 옮겨서 다시 쓴다.

void CCellList::ShowEdit(int nItem, int nSub, CRect rc)
{
    if (!m_edit.GetSafeHwnd()) {
        m_edit.Create(WS_CHILD | ES_AUTOHSCROLL | WS_BORDER, rc, this, IDC_CELL_EDIT);
        m_edit.SetFont(GetFont());
    }
    m_nItem = nItem;
    m_nSub  = nSub;
    m_edit.SetWindowText(GetItemText(nItem, nSub));
    m_edit.MoveWindow(&rc);
    m_edit.ShowWindow(SW_SHOW);
    m_edit.SetFocus();
    m_edit.SetSel(0, -1);
}

끝내기

Enter 는 확정, Esc 는 취소다. 다른 곳을 눌러 포커스를 잃어도 확정한다. 키는 에디트의 PreTranslateMessage 에서 가로챈다.

// CellEdit.cpp — CEdit 파생
BOOL CCellEdit::PreTranslateMessage(MSG* pMsg)
{
    if (pMsg->message == WM_KEYDOWN) {
        if (pMsg->wParam == VK_RETURN) { GetParent()->SetFocus(); return TRUE; }                  // 확정
        if (pMsg->wParam == VK_ESCAPE) { m_bCancel = TRUE; GetParent()->SetFocus(); return TRUE; } // 취소
    }
    return CEdit::PreTranslateMessage(pMsg);
}

void CCellEdit::OnKillFocus(CWnd* pNewWnd)
{
    CEdit::OnKillFocus(pNewWnd);
    if (!m_bCancel)
        Commit();                    // 아래 "알리기"
    m_bCancel = FALSE;
    ShowWindow(SW_HIDE);
}
  • 리스트를 스크롤하면 칸이 움직이므로, 리스트의 OnHScroll · OnVScroll 에서 편집을 끝낸다

알리기

고친 값은 첫 열을 고칠 때와 같은 LVN_ENDLABELEDIT 모양으로 리스트의 부모에 보낸다. 부모는 첫 열과 같은 방법으로 받는다.

void CCellEdit::Commit()
{
    CString str;
    GetWindowText(str);

    CListCtrl* pList = (CListCtrl*)GetParent();
    NMLVDISPINFO info = {};
    info.hdr.hwndFrom    = pList->GetSafeHwnd();
    info.hdr.idFrom      = pList->GetDlgCtrlID();
    info.hdr.code        = LVN_ENDLABELEDIT;
    info.item.mask       = LVIF_TEXT;
    info.item.iItem      = m_nItem;
    info.item.iSubItem   = m_nSub;
    info.item.pszText    = (LPTSTR)(LPCTSTR)str;
    pList->GetParent()->SendMessage(WM_NOTIFY, info.hdr.idFrom, (LPARAM)&info);
}
// 부모 대화상자
void CMyDlg::OnLvnEndlabeledit(NMHDR* pNMHDR, LRESULT* pResult)
{
    NMLVDISPINFO* p = reinterpret_cast<NMLVDISPINFO*>(pNMHDR);
    if (p->item.pszText) {
        m_list.SetItemText(p->item.iItem, p->item.iSubItem, p->item.pszText);
        m_pModel->SetValue(p->item.iItem, p->item.iSubItem, p->item.pszText);
    }
    *pResult = 0;
}

콤보로 고치기

값이 정해진 칸은 같은 방법으로 Drop List 콤보를 띄운다. 칸 높이보다 목록 높이를 넉넉히 주고(rc.bottom += 150), 고르면(CBN_CLOSEUP) 확정한다.
