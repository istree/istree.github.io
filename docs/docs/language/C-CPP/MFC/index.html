MFC

목록 · MFC
  • 개요

MFC(Microsoft Foundation Class Library) 는 Win32 API 를 C++ 클래스로 감싼 Microsoft 의 라이브러리다. 창 · 대화상자 · 컨트롤 · GDI 를 클래스로 다루고, 메시지 맵으로 Windows 메시지를 클래스의 함수에 연결한다. Visual C++ 에 들어 있다.

여기에는 MFC 로 대화상자 기반의 편집 화면(속성 창 · 마법사 · 미리보기) 을 만들며 쓴 패턴을 정리한다.
