트리 · 리스트 · 탭 같은 공용 컨트롤은 부모 창에 WM_NOTIFY 로 알린다. 받는 곳은 두 가지다.

  • 대화상자에서 받기 — 처리가 짧을 때 쓴다
  • 서브클래스에서 받기 — 알림이 많고 직접 처리할 것이 많을 때 쓴다

대화상자에서 받기

대화상자의 메시지 맵에 ON_NOTIFY 로 컨트롤 ID 와 함수를 준다. 받은 NMHDR* 를 그 알림의 구조체로 바꿔 읽고, *pResult 로 답을 돌려준다.

// MyDlg.cpp
ON_NOTIFY(TVN_SELCHANGED, IDC_TREE, &CMyDlg::OnTvnSelchanged)

void CMyDlg::OnTvnSelchanged(NMHDR* pNMHDR, LRESULT* pResult)
{
    NMTREEVIEW* p = reinterpret_cast<NMTREEVIEW*>(pNMHDR);
    HTREEITEM hItem = p->itemNew.hItem;
    // ...
    *pResult = 0;
}

서브클래스에서 받기

컨트롤 클래스를 상속하고, 그 안에서 자기 알림을 받는다(반사, Reflection). 이유는 두 가지다.

  • 재사용 — 같은 컨트롤을 다른 대화상자에서도 그대로 쓴다
  • 책임 나누기 — 컨트롤의 동작(그리기 · 편집 · 정렬 · 글자 주기) 은 컨트롤 클래스가 맡고, 그 결과로 무엇을 할지는 대화상자가 맡는다
// DataList.h
class CDataList : public CListCtrl
{
protected:
    afx_msg void OnLvnGetdispinfo(NMHDR* pNMHDR, LRESULT* pResult);
    afx_msg void OnLvnEndlabeledit(NMHDR* pNMHDR, LRESULT* pResult);
    DECLARE_MESSAGE_MAP()
};

// DataList.cpp
BEGIN_MESSAGE_MAP(CDataList, CListCtrl)
    ON_NOTIFY_REFLECT(LVN_GETDISPINFO,  &CDataList::OnLvnGetdispinfo)
    ON_NOTIFY_REFLECT(LVN_ENDLABELEDIT, &CDataList::OnLvnEndlabeledit)
END_MESSAGE_MAP()

대화상자에서는 변수의 형만 바꿔 붙인다.

CDataList m_listData;                          // CListCtrl 대신
DDX_Control(pDX, IDC_LIST_DATA, m_listData);
  • ON_NOTIFY_REFLECT 는 WM_NOTIFY 알림을, ON_CONTROL_REFLECT 는 WM_COMMAND 알림(CBN_SELCHANGE 등) 을 받는다
  • 대화상자도 같은 알림을 받아야 하면 ON_NOTIFY_REFLECT_EX 로 하고 FALSE 를 돌려준다
  • 컨트롤 안의 자식 창(리스트의 헤더) 이 보내는 알림은 ON_NOTIFY(HDN_…, 0, …) 로 받는다. 헤더 에 정리했다
