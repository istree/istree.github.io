끌어서 값을 고른다. 움직이면 부모에 WM_HSCROLL (세로면 WM_VSCROLL) 이 간다.

범위

m_sliderOffset.SetRange(0, 200);
m_sliderOffset.SetPos(100);

슬라이더는 음수 범위가 어색하다. 0 부터 잡고 쓸 때 빼면 -100 ~ 100 을 쓸 수 있다.

움직임 받기

WM_HSCROLL 은 대화상자의 모든 가로 슬라이더 · 스크롤 막대가 같이 쓴다. pScrollBar 로 어느 것인지 가린다.

ON_WM_HSCROLL()

void CMyDlg::OnHScroll(UINT nSBCode, UINT nPos, CScrollBar* pScrollBar)
{
    if (pScrollBar && pScrollBar->GetSafeHwnd() == m_sliderOffset.GetSafeHwnd()) {
        int nValue = m_sliderOffset.GetPos() - 100;
        m_pModel->SetOffset(nValue);
        SetDlgItemInt(IDC_EDIT_OFFSET, nValue, TRUE);   // 옆 에디트도 맞춘다
        UpdatePreview();
    }
    CDialog::OnHScroll(nSBCode, nPos, pScrollBar);
}
