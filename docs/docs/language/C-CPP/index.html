C 는 운영체제 · 임베디드처럼 하드웨어에 가까운 곳에서 쓰는 언어다. C++ 은 C 에 클래스 · 템플릿 · 예외를 더한 언어로, C++11 부터 3 년마다 새 표준(14 · 17 · 20 · 23) 이 나오며 많이 바뀌었다.

여기에는 Windows 화면 프로그래밍(MFC) 과 빌드 도구(CMake) 를 정리한다.
