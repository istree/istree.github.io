람다는 그 자리에서 만드는 이름 없는 함수다. 알고리즘의 조건 · 콜백 · 이벤트 처리를 짧게 넘긴다. 바깥 변수를 잡아(capture) 함께 들고 다니고, 어떤 함수든 담아 두려면 std::function 에 넣는다.

람다

auto square = [](int x) { return x * x; };     // [잡을 것](매개변수) { 본문 }
square(4);                                     // 16

std::vector<int> v{5, 1, 4, 2};
int limit = 3;
auto n = std::ranges::count_if(v, [limit](int x) { return x > limit; });   // 2

int total = 0;
std::ranges::for_each(v, [&total](int x) { total += x; });                 // total = 12

auto less = [](const auto& a, const auto& b) { return a < b; };   // auto 매개변수 — 어떤 타입이든 (C++14)
  • 반환 타입은 추론한다. 갈래마다 타입이 다르면 -> int 처럼 적는다

잡기

쓰기 뜻
[] 아무것도 잡지 않는다
[x] x 를 복사해 둔다 — 람다를 만든 때의 값
[&x] x 를 참조한다 — 부를 때의 값, 바꾸면 바깥도 바뀐다
[=] · [&] 쓰는 것을 모두 복사 · 참조
[this] · [*this] 멤버 함수 안에서 객체를 참조 · 복사
[p = std::move(p)] 새 이름으로 옮겨 넣기 (C++14) — unique_ptr 처럼 복사할 수 없는 것 
auto make_counter() {
    int n = 0;
    return [n]() mutable { return ++n; };      // mutable — 복사해 잡은 값을 람다 안에서 바꾼다
}
auto next = make_counter();
next(); next();                                // 1, 2 — 람다마다 따로 센다

auto p = std::make_unique<int>(7);
auto owns = [p = std::move(p)] { return *p; };   // 람다가 p 를 갖는다

참조로 잡은 변수보다 람다가 오래 살면, 사라진 변수를 가리킨다. 컴파일러는 경고하지 않는다.

std::function<int()> make() {
    int local = 42;
    return [&local] { return local; };   // 함수가 끝나면 local 은 없다
}
make()();   // 42 가 나오기도 해서 더 위험하다
==48682==ERROR: AddressSanitizer: stack-use-after-return on address 0x000104465020 …
  • 돌려주거나 저장하는 람다(콜백 · 스레드 · 비동기) 는 복사로 잡는다. 참조로 잡는 것은 그 자리에서 바로 부르는 람다(알고리즘의 조건) 에만 쓴다
  • 위 실수는 ASAN_OPTIONS=detect_stack_use_after_return=1 을 주고 AddressSanitizer 로 돌려야 잡힌다

함수를 돌려주는 함수

auto make_adder(int k) {
    return [k](int x) { return x + k; };
}
template <typename F>
auto twice(F f) {
    return [f](auto x) { return f(f(x)); };
}

auto add5 = make_adder(5);
add5(10);              // 15
twice(add5)(0);        // 10

auto add100 = std::bind_front(std::plus<>{}, 100);   // 앞쪽 인자 채우기 (C++20)
add100(1);             // 101

함수 객체

operator() 가 있는 객체는 함수처럼 부른다. 람다도 컴파일러가 이런 클래스를 만들어 준 것이다. 상태 · 설정을 멤버로 들고 있을 때 직접 만든다.

struct Discount {
    double rate;
    double operator()(double price) const { return price * (1 - rate); }
};

Discount tenOff{0.1};
tenOff(1000);                                 // 900

std::ranges::sort(v, std::greater<>{});       // 표준 함수 객체 — 큰 순서 [5, 4, 2, 1]
  • std::plus<> · std::less<> · std::greater<> · std::equal_to<> 가 <functional> 에 있다

std::function

타입이 서로 다른 람다 · 함수 · 함수 객체를 한 타입에 담는다. 콜백을 멤버로 들고 있거나 표에 넣을 때 쓴다.

#include <functional>

struct Button {
    std::string label;
    std::function<void()> on_click;            // 비어 있을 수 있다
    void click() const { if (on_click) on_click(); }
};
Button save{"저장", [] { std::println("저장했다"); }};
save.click();

std::map<std::string, std::function<int(int, int)>> ops{
    {"+", std::plus<>{}},
    {"*", [](int a, int b) { return a * b; }},
};
ops["*"](2, 3);                                // 6
  • std::function 은 담을 때 힙을 쓸 수 있고 부를 때 한 번 더 건너간다. 알고리즘에 바로 넘기는 조건처럼 담아 둘 필요가 없으면 템플릿(template <typename F>) · auto 로 받는다

재귀 람다

C++23 에서는 람다가 첫 매개변수 this auto self 로 자기 자신을 받는다.

auto fact = [](this auto self, int n) -> int {
    return n <= 1 ? 1 : n * self(n - 1);
};
fact(5);    // 120

예전에는

  • 람다가 없던 때(C++03) 는 조건 하나를 넘기려고 operator() 가 있는 구조체를 따로 만들었다
  • std::bind(f, _1, 10) 으로 인자를 채웠다. 지금은 람다나 std::bind_front 를 쓴다
  • 재귀 람다는 std::function 에 담고 자기를 참조로 잡아 만들었다
