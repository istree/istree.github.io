C++ 은 C 의 문법 위에 타입 추론(auto) · 참조 · 범위 for · 표준 문자열 · 컨테이너를 더했다. 지금 C++ 에서는 C 의 배열 · char * · printf 대신 이것들을 쓴다.

컴파일 · 실행

// hello.cpp
#include <print>

int main() {
    std::println("Hello, {}!", "C++");
}
clang++ -std=c++23 -Wall -Wextra -o hello hello.cpp    # g++ 도 옵션이 같다
./hello
  • main 은 return 을 빼도 0 을 돌려준다
  • Visual Studio 는 cl /std:c++latest /EHsc /W4 hello.cpp 로 컴파일한다

auto

초기값에서 타입을 추론한다. 긴 타입 이름(반복자 · 람다) 을 쓰지 않아도 된다.

auto count = 3;                    // int
auto price = 1500.0;               // double
auto name = std::string{"geon"};   // std::string
const auto& ref = name;            // 복사하지 않고 참조로
  • auto 는 const · & 를 떼고 값 타입으로 추론한다. 참조가 필요하면 auto& · const auto& 로 쓴다
  • 중괄호 초기화(int n{3.9}) 는 값이 잘리는 변환을 막는다: error: type 'double' cannot be narrowed to 'int' in initializer list. 일부러 바꿀 때는 static_cast<int>(d) 로 쓴다

참조

참조는 이미 있는 변수의 다른 이름이다. 포인터와 달리 NULL 이 없고, 다른 것을 가리키게 바꿀 수 없다.

void add_one(int& n) { ++n; }                        // 호출한 쪽의 변수를 바꾼다
void show(const std::vector<int>& v) { /* … */ }     // 큰 값은 복사하지 않고 읽기만

int n = 1;
add_one(n);          // 2
int& alias = n;
alias = 10;          // n 도 10
  • 함수 매개변수는 작은 값(int · double) 은 값으로, 큰 값(string · vector) 은 const T& 로, 바꿀 것은 T& 로 받는다

범위 for · 구조 분해

std::vector<int> nums{3, 1, 2};
for (int x : nums) std::print("{} ", x);     // 3 1 2
for (auto& x : nums) x *= 10;                // 참조로 받아 고친다 — [30, 10, 20]

std::map<std::string, int> stock{{"pen", 3}, {"note", 5}};
for (const auto& [item, qty] : stock)        // 구조 분해 (C++17)
    std::print("{}={} ", item, qty);         // note=5 pen=3 — map 은 키 순서

if (auto it = stock.find("pen"); it != stock.end())   // if 안에서 변수 만들기 (C++17)
    std::println("{}", it->second);

string · string_view

#include <string>
#include <string_view>

std::string s = "Hello";
s += ", C++";                  // "Hello, C++" — 메모리는 알아서 늘어난다
s.size();                      // 10
s.substr(0, 5);                // "Hello"
s.find("C++");                 // 7 — 없으면 std::string::npos
s.starts_with("Hell");         // true (C++20)

void greet(std::string_view name) {          // 읽기만 하는 문자열 매개변수
    std::println("Hello, {}!", name);
}
greet("world");                // 리터럴도, string 도 복사 없이 받는다
greet(s);
  • string_view 는 남의 문자열을 들여다보기만 한다. 원래 문자열이 사라진 뒤에 쓰면 정의되지 않은 동작이므로, 돌려주거나 멤버로 오래 들고 있지 않는다

출력 — print · format

#include <print>
#include <format>

std::println("{} {:.1f}", 16, 1100.0);                            // 16 1100.0
std::println("{:>8}|{:<8}|{:^8}|{:08.2f}", "r", "l", "c", 3.14159);
//        r|l       |   c    |00003.14
std::println("{:x} {:#b}", 255, 5);                               // ff 0b101
std::println("{}", std::vector{30, 10, 20});                      // [30, 10, 20] — 컨테이너도 된다

auto msg = std::format("{}개 {}원", 3, 1500);                    // 문자열로 만들기 (C++20)
  • {} 의 형식은 Python 의 format 과 같다. 인자 타입을 컴파일할 때 검사한다
  • std::cout << x << '\n'; 도 여전히 쓴다. 형식을 많이 쓰면 print 가 읽기 쉽다

const · constexpr · namespace

namespace shop {
constexpr double tax_rate = 0.1;                  // 컴파일할 때 정해지는 상수
constexpr int square(int x) { return x * x; }     // 컴파일할 때도 부를 수 있는 함수
double with_tax(double price) { return price * (1 + tax_rate); }
}

constexpr int sq = shop::square(4);
static_assert(sq == 16);                          // 컴파일할 때 검사
shop::with_tax(1000);                             // 1100

enum class Color { Red, Green };                  // 이름이 Color:: 안에 갇힌다
auto c = Color::Green;
static_cast<int>(c);                              // 1 — 정수로 저절로 바뀌지 않는다
  • 헤더에 using namespace std; 를 두지 않는다. 그 헤더를 include 한 모든 파일의 이름과 부딪힌다. .cpp 안에서는 필요한 것만 using std::string; 처럼 쓴다
  • enum class 를 기본으로 쓴다. C 의 enum 은 이름이 바깥에 퍼지고 정수와 섞인다

예전에는

  • printf · std::cout 으로 출력했다. std::format(C++20) · std::print(C++23) 가 형식 문자열을 타입 검사하며 쓴다
  • 반복자를 std::map<std::string, int>::iterator it = m.begin(); 처럼 적었다. C++11 부터 auto 로 쓴다
  • NULL · 0 으로 빈 포인터를 나타냈다. C++11 부터 nullptr 를 쓴다
  • typedef std::vector<int> IntList; 는 using IntList = std::vector<int>; 로 쓴다
