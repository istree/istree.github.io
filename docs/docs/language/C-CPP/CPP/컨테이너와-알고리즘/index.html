  • 라이브러리

표준 라이브러리는 값을 담는 컨테이너(vector · map …) 와, 컨테이너를 돌며 일하는 알고리즘(sort · find …) 을 따로 준다. 둘은 반복자로 이어지고, C++20 의 ranges 로 컨테이너를 통째로 넘기거나 단계를 | 로 이어 쓴다.

vector

크기가 늘어나는 배열이다. 따로 까닭이 없으면 이것을 쓴다.

#include <vector>

std::vector<int> v{5, 3, 8, 1};
v.push_back(4);                 // 끝에 더하기
v.insert(v.begin(), 9);         // 앞에 끼우기 — 뒤를 모두 민다
v.pop_back();                   // 끝 빼기
v.front(); v.back(); v.size();  // 9 1 5
v[2];                           // 범위를 검사하지 않는다
v.at(2);                        // 범위 밖이면 std::out_of_range
v.erase(v.begin() + 1);         // 하나 지우기
std::erase_if(v, [](int x) { return x < 5; });   // 조건으로 지우기 (C++20) — [9, 8]

v.reserve(1000);                // 미리 자리를 잡아 다시 잡기를 줄인다
  • 원소를 더하거나 지우면 그 vector 를 가리키던 반복자 · 포인터 · 참조가 무효가 될 수 있다. 돌면서 더하고 지우지 않는다. 지울 것은 erase_if 로 한 번에 지운다
  • 크기가 정해진 배열은 std::array<int, 3> 를 쓴다. C 배열과 같은 크기 · 속도에 size() · 비교 · 복사가 된다

그 밖의 컨테이너

컨테이너 쓰는 곳
std::array<T, N> 크기가 정해진 배열
std::deque<T> 앞 · 뒤 양쪽에 더하고 빼기
std::map<K, V> 키 순서로 정렬된 표 (트리)
std::unordered_map<K, V> 순서 없는 표 (해시) — 찾기가 더 빠르다
std::set<T> · std::unordered_set<T> 겹치지 않는 값 모음
std::span<T> 남의 배열 · vector 를 복사 없이 들여다보기 (C++20) 
#include <map>
#include <unordered_map>

std::map<std::string, int> stock{{"pen", 3}};
stock["note"] = 5;                    // 없으면 만들고 넣는다
stock["pen"] += 2;                    // {"note": 5, "pen": 5}
stock.contains("bag");                // false (C++20)
stock["bag"];                         // 0 — 읽기만 해도 "bag" 이 생긴다
stock.at("cup");                      // 없으면 std::out_of_range: map::at:  key not found

if (auto it = stock.find("note"); it != stock.end())   // 있는지 보고 읽기
    it->second;

std::unordered_map<std::string, int> counts;
for (std::string w : {"a", "b", "a", "c", "a"}) counts[w]++;   // 개수 세기 — counts["a"] 는 3
  • map[key] 는 키가 없으면 기본값으로 만든다. 있는지만 볼 때는 contains · find 를 쓴다
  • 함수가 배열을 받을 때는 std::span<const int> 로 받으면 vector · array · C 배열을 모두 받는다

알고리즘

<algorithm> · <numeric> 의 함수는 반복으로 할 일을 이름으로 쓴다. std::ranges:: 판은 컨테이너를 통째로 받고, 무엇으로 견줄지(projection) 를 멤버로 줄 수 있다.

#include <algorithm>
#include <numeric>

struct Order { std::string item; int qty; int price; };
std::vector<Order> orders{{"펜", 2, 1500}, {"공책", 1, 3000}, {"가방", 1, 25000}, {"펜", 5, 1500}};

std::ranges::sort(orders, {}, &Order::price);       // price 로 정렬 — 펜 · 펜 · 공책 · 가방
std::ranges::sort(orders, [](const Order& a, const Order& b) {
    return a.qty * a.price > b.qty * b.price;       // 금액이 큰 순서
});

auto it = std::ranges::find(orders, "공책", &Order::item);     // item 이 "공책" 인 것
auto n = std::ranges::count_if(orders, [](const Order& o) { return o.item == "펜"; });   // 2

int total = std::accumulate(orders.begin(), orders.end(), 0,
    [](int sum, const Order& o) { return sum + o.qty * o.price; });                      // 38500

std::vector<int> nums{4, 1, 3};
*std::ranges::max_element(nums);         // 4
std::ranges::contains(nums, 3);          // true (C++23)
auto [lo, hi] = std::ranges::minmax(nums);   // 1 4
하는 일 알고리즘
정렬 sort · stable_sort · partial_sort
찾기 find · find_if · binary_search(정렬된 것) · contains
세기 · 검사 count_if · any_of · all_of · none_of
바꾸기 · 복사 transform · copy_if · fill · reverse
모으기 accumulate · reduce (<numeric>)
지우기 std::erase · std::erase_if (컨테이너 함수)

ranges · views

views 는 컨테이너를 복사하지 않고, 값을 꺼낼 때 하나씩 거르고 바꾼다. | 로 단계를 잇는다.

#include <ranges>

auto big_items = orders
    | std::views::filter([](const Order& o) { return o.price >= 3000; })
    | std::views::transform(&Order::item);           // ["가방", "공책"]

auto names = big_items | std::ranges::to<std::vector>();   // vector 로 만들기 (C++23)

std::views::iota(1, 6) | std::views::reverse;      // [5, 4, 3, 2, 1]
  • view 는 원래 컨테이너를 가리킨다. 원래 것이 사라진 뒤에 쓰면 안 된다. 오래 들고 있을 값은 ranges::to 로 만든다
  • std::views::enumerate · zip 같은 C++23 view 는 표준 라이브러리마다 들어온 때가 다르다. macOS 의 clang 17(libc++) 에는 아직 enumerate 가 없다

예전에는

  • std::sort(v.begin(), v.end()) 처럼 반복자 한 쌍을 넘겼다. C++20 의 std::ranges::sort(v) 로 짧게 쓴다
  • 조건으로 지울 때 v.erase(std::remove_if(v.begin(), v.end(), pred), v.end()); 를 썼다(erase-remove). C++20 부터 std::erase_if(v, pred) 다
  • map 에 키가 있는지 m.count(k) > 0 · m.find(k) != m.end() 로 봤다. C++20 부터 contains 다
