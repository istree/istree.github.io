C 의 문자열은 따로 있는 타입이 아니라, 끝에 '\0'(널 문자) 이 붙은 char 배열이다. 길이는 '\0' 을 만날 때까지 세고, 배열 크기는 프로그래머가 챙긴다. 버퍼 넘침이 가장 흔한 C 의 보안 문제라, 크기를 받는 함수(snprintf · fgets) 를 쓴다.

만들기

char name[16] = "kim";          // 'k' 'i' 'm' '\0' + 빈칸 12 — 고칠 수 있다
const char *lit = "hello";      // 문자열 리터럴 — 고칠 수 없다

strlen(name);                   // 3 — '\0' 앞까지
sizeof name;                    // 16 — 배열 크기
  • 리터럴을 char * 로 받아 고치면 정의되지 않은 동작이다. macOS 에서는 BUS 오류로 죽는다. 리터럴은 늘 const char * 로 받는다
  • "한글" 의 strlen 은 6 이다. UTF-8 에서 한글 한 글자가 3 바이트라서, 길이는 글자 수가 아니라 바이트 수다

만들어 넣기 — snprintf

char buf[8];
int need = snprintf(buf, sizeof buf, "%s-%d", "item", 12345);
// buf = "item-12" (7 글자 + '\0'), need = 10 — 다 쓰려면 필요했던 길이
if (need >= (int)sizeof buf) puts("잘렸다");

char greeting[32];
snprintf(greeting, sizeof greeting, "%s, %s!", "Hello", name);   // "Hello, kim!"
  • snprintf 는 크기를 넘지 않고, 잘라도 늘 '\0' 을 붙인다. 문자열을 이어 붙이고 복사하는 일은 이것으로 한다
  • strcpy · strcat · sprintf 는 크기를 모른다. 클랑은 넘칠 것이 보이면 'strcpy' will always overflow; destination buffer has size 4, but the source string has length 9 (including NUL byte) 로 경고한다
  • strncpy 는 다 차면 '\0' 을 붙이지 않는다. 쓴다면 마지막 칸에 직접 넣는다: dst[sizeof dst - 1] = '\0';

견주기 · 찾기

#include <string.h>

strcmp("apple", "banana") < 0;           // 사전 순서 — 같으면 0
strcmp(name, "kim") == 0;                // 같은지 — == 로 견주면 주소를 견준다
strstr("a,b,c", ",b");                   // ",b,c" — 처음 나온 곳의 포인터, 없으면 NULL
strchr("path/to/file.txt", '/');         // "/to/file.txt"
strrchr("path/to/file.txt", '.');        // ".txt" — 뒤에서부터
strcspn(line, "\n");                     // 처음 나온 '\n' 의 자리

나누기 · 숫자로 바꾸기

char csv[] = "pen,note,,bag";            // 고칠 수 있는 배열이어야 한다
for (char *tok = strtok(csv, ","); tok; tok = strtok(NULL, ","))
    printf("[%s]", tok);                 // [pen][note][bag] — 빈 칸은 건너뛴다

char *end;
errno = 0;
long v = strtol("42abc", &end, 10);      // 42, end = "abc" — 어디서 멈췄는지 안다
long w = strtol("99999999999999999999", &end, 10);   // LONG_MAX, errno == ERANGE
atoi("x");                               // 0 — 실패를 알 수 없다
  • strtok 은 원래 문자열에 '\0' 을 써 넣고, 안에 상태를 둬서 두 문자열을 번갈아 나눌 수 없다. 스레드에서는 strtok_r 를 쓴다
  • 숫자는 atoi 대신 strtol · strtod 로 바꾼다. 남은 글자와 넘침을 확인할 수 있다

한 줄 읽기

char line[64];
if (fgets(line, sizeof line, stdin)) {    // 크기를 넘지 않는다. '\n' 까지 들어온다
    line[strcspn(line, "\n")] = '\0';     // 끝의 '\n' 떼기
    printf("[%s]\n", line);
}

글자 다루기

#include <ctype.h>

char word[] = "Hello";
for (char *c = word; *c; c++)
    *c = (char)toupper((unsigned char)*c);   // "HELLO"

char *copy = strdup("copy");                 // 힙에 복사 — free 해야 한다
free(copy);
  • isdigit · isalpha · toupper 에는 unsigned char 로 바꿔 넘긴다. 음수 char(한글 바이트) 를 넘기면 정의되지 않은 동작이다
  • strdup 은 C23 부터 표준이고, 그 전에도 POSIX · Windows 에 있다
