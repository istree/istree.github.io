파일은 fopen 으로 열어 FILE * 을 받고, 읽고 쓴 뒤 fclose 로 닫는다. 글자 파일은 fprintf · fgets 로, 이진 파일은 fwrite · fread 로 다룬다. 실패하면 함수가 NULL · 0 · EOF 를 돌려주고 까닭은 errno 에 남는다.

열기 · 닫기

#include <stdio.h>

FILE *f = fopen("notes.txt", "w");
if (f == NULL) {
    perror("notes.txt");        // notes.txt: No such file or directory — errno 를 글로
    return 1;
}
fprintf(f, "1,장보기\n2,운동\n");
fputs("3,청소\n", f);
if (fclose(f) != 0) perror("fclose");   // 쓴 것을 디스크로 내보내는 것도 여기서 — 실패할 수 있다
모드 하는 일
"r" 읽기. 없으면 실패
"w" 쓰기. 없으면 만들고, 있으면 비운다
"a" 끝에 덧붙이기
"r+" · "w+" 읽기 + 쓰기
"rb" · "wb" … 이진 모드 — Windows 에서 \n ↔ \r\n 바꾸기를 하지 않는다
"wx" 이미 있으면 실패 (C11) — 남의 파일을 덮어쓰지 않는다
  • 연 파일은 모든 갈래에서 닫는다. 오류로 일찍 return 하는 곳을 빠뜨리기 쉽다
  • stdin · stdout · stderr 도 FILE * 이다. 오류 메시지는 fprintf(stderr, …) 로 쓴다

줄씩 읽기

FILE *f = fopen("notes.txt", "r");
char line[128];
while (fgets(line, sizeof line, f) != NULL) {
    line[strcspn(line, "\n")] = '\0';
    int id;
    char text[64];
    if (sscanf(line, "%d,%63s", &id, text) == 2)     // %63s — text 크기보다 하나 적게
        printf("%d:%s ", id, text);                  // 1:장보기 2:운동 3:청소
}
if (ferror(f)) perror("read");          // 끝까지 읽어서 멈춘 것인지, 오류인지
fclose(f);
  • fgets 는 줄이 버퍼보다 길면 나눠서 읽는다. 아주 긴 줄을 다루면 POSIX 의 getline 이 메모리를 알아서 늘린다
  • while (!feof(f)) 로 돌지 않는다. 마지막 줄을 두 번 처리하게 된다. 읽기 함수의 결과로 멈춘다

이진 파일

구조체 · 배열을 메모리 모양 그대로 쓰고 읽는다.

#include <stdint.h>

struct Record { int32_t id; double price; char name[16]; };

struct Record out[2] = {{1, 1.5, "펜"}, {2, 3.0, "공책"}};
FILE *b = fopen("items.bin", "wb");
size_t written = fwrite(out, sizeof out[0], 2, b);   // 쓴 개수 — 2
fclose(b);

struct Record in[2];
b = fopen("items.bin", "rb");
size_t got = fread(in, sizeof in[0], 2, b);          // 읽은 개수 — 2
fclose(b);
  • 구조체 사이의 빈칸(padding) · 바이트 순서 · int 크기가 컴파일러 · CPU 마다 달라, 이렇게 쓴 파일은 다른 플랫폼에서 못 읽을 수 있다. 다른 곳과 주고받는 파일은 필드를 하나씩 정해진 순서로 쓰거나 JSON 같은 글자 형식을 쓴다

통째로 읽기

FILE *f = fopen("notes.txt", "rb");
fseek(f, 0, SEEK_END);
long len = ftell(f);                    // 파일 크기
rewind(f);                              // 처음으로

char *all = malloc((size_t)len + 1);
size_t n = fread(all, 1, (size_t)len, f);
all[n] = '\0';                          // 글자로 쓰려면 끝을 붙인다
fclose(f);
/* … */
free(all);

오류

#include <errno.h>
#include <string.h>

FILE *f = fopen("nope/x.txt", "r");
if (f == NULL)
    printf("errno=%d %s\n", errno, strerror(errno));   // errno=2 No such file or directory
  • errno 는 실패했을 때만 뜻이 있다. 성공한 함수가 0 으로 돌려놓지 않으므로, 결과를 먼저 보고 실패했을 때 읽는다
  • remove("a.txt") · rename("a.txt", "b.txt") 도 stdio.h 에 있고, 실패하면 0 이 아닌 값을 돌려준다
  • 폴더 만들기 · 목록 보기는 표준 C 에 없다. POSIX 의 mkdir · opendir, Windows 의 CreateDirectory 를 쓴다
