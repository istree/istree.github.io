이미 설치된 라이브러리는 find_package 로 찾고, 설치하지 않고 소스째 같이 빌드하려면 FetchContent 로 받는다. 어느 쪽이든 결과는 이름::이름 형식의 타깃이고, 그것을 target_link_libraries 하면 include 경로 · 링크 옵션이 따라온다.

find_package

find_package(ZLIB REQUIRED)
target_link_libraries(apple PRIVATE ZLIB::ZLIB)

find_package(Boost 1.80 REQUIRED COMPONENTS filesystem)
target_link_libraries(apple PRIVATE Boost::filesystem)
CMake Error at CMakeLists.txt:3 (find_package):
  By not providing "FindFoo.cmake" in CMAKE_MODULE_PATH this project has
  asked CMake to find a package configuration file provided by "Foo", but
  CMake did not find one.
  • 찾지 못하면 이 오류로 멈춘다. 그 라이브러리를 설치하거나, 설치한 곳을 -DCMAKE_PREFIX_PATH=/opt/foo 로 알려 준다
  • brew · apt · vcpkg · Conan 이 설치한 라이브러리를 찾는다. vcpkg 는 -DCMAKE_TOOLCHAIN_FILE=…/vcpkg/scripts/buildsystems/vcpkg.cmake 를 준다

FetchContent

설치하지 않고 소스를 받아 같이 빌드하려면 FetchContent 를 쓴다. configure 할 때 받아 온다.

include(FetchContent)
FetchContent_Declare(fmt
  GIT_REPOSITORY https://github.com/fmtlib/fmt.git
  GIT_TAG 12.2.0                     # 태그 · 커밋을 정해 둔다
  GIT_SHALLOW TRUE)
FetchContent_MakeAvailable(fmt)      # fmt::fmt 타깃이 생긴다
// banana/main.cpp
#include <fmt/core.h>
#include "common/greet.h"
int main() { fmt::print("{} ({})\n", common::greet("Banana"), 42); }   // Hello, Banana! (42)
  • 받은 소스는 build/_deps/ 에 있다. 빌드 폴더를 지우면 다시 받는다
