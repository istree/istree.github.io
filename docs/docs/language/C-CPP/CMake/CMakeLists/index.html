  • 라이브러리

CMakeLists.txt 에 무엇을 만들지(타깃) 와 타깃마다 쓸 설정을 적는다. 설정은 프로젝트 전체가 아니라 타깃에 걸고, 그 설정이 링크하는 쪽으로 퍼질지를 PUBLIC · PRIVATE 로 정한다.

라이브러리 common 하나를 실행 파일 apple · banana 가 같이 쓰는 프로젝트다.

CMakeLists.txt
common/include/common/greet.h
common/src/greet.cpp
apple/main.cpp
banana/main.cpp
tests/greet_test.cpp
cmake_minimum_required(VERSION 3.25)
project(examples VERSION 1.0 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)          # 20 을 못 쓰는 컴파일러면 멈춘다
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)        # build/compile_commands.json — clangd · 에디터가 읽는다

# common — 정적 라이브러리
add_library(common common/src/greet.cpp)
target_include_directories(common PUBLIC common/include)   # common 을 쓰는 쪽도 이 경로를 받는다
target_compile_options(common PRIVATE
  $<$<CXX_COMPILER_ID:GNU,Clang,AppleClang>:-Wall -Wextra>
  $<$<CXX_COMPILER_ID:MSVC>:/W4>)

# 실행 파일
add_executable(apple apple/main.cpp)
target_link_libraries(apple PRIVATE common)

add_executable(banana banana/main.cpp)
target_link_libraries(banana PRIVATE common fmt::fmt)       # fmt — FetchContent 로 받은 라이브러리

install(TARGETS apple banana RUNTIME DESTINATION bin)
$ cmake -S . -B build -G Ninja && cmake --build build
$ ./build/apple
Hello, Apple!

설정은 타깃(add_library · add_executable 로 만든 것) 마다 target_… 명령으로 건다. 뒤의 낱말이 그 설정이 어디까지 퍼지는지 정한다.

낱말 그 타깃 그 타깃을 링크하는 쪽
PRIVATE 쓴다 받지 않는다
PUBLIC 쓴다 받는다
INTERFACE 쓰지 않는다 받는다 (헤더만 있는 라이브러리)
  • common 의 include 경로를 PUBLIC 으로 두었으므로 apple 은 target_link_libraries 만으로 #include "common/greet.h" 를 찾는다
  • 헤더가 공개 API 에 쓰는 라이브러리는 PUBLIC, .cpp 안에서만 쓰는 라이브러리는 PRIVATE 으로 링크한다
  • add_library 는 기본이 정적(.a · .lib) 이다. 공유 라이브러리는 add_library(common SHARED …) 이거나 -DBUILD_SHARED_LIBS=ON 이다
  • $<…> 는 생성기 식이다. 빌드 파일을 만들 때 컴파일러 · 설정에 따라 값이 정해진다

소스 파일 적기

소스는 파일 이름을 하나씩 적는다.

add_library(common
  common/src/greet.cpp
  common/src/format.cpp)
target_sources(common PRIVATE common/src/extra.cpp)   # 나중에 더하기
  • file(GLOB SRC "src/*.cpp") 로 모으면 파일을 새로 더해도 configure 를 다시 하기 전에는 빌드에 들어가지 않는다. 공식 문서도 권하지 않는다
  • 꼭 쓰려면 file(GLOB SRC CONFIGURE_DEPENDS "src/*.cpp") 로 빌드할 때마다 다시 찾게 한다. 생성기에 따라 되지 않을 수 있다

예전에는

  • include_directories(common) · link_directories · add_definitions 는 그 폴더 아래 모든 타깃에 걸린다. 무엇이 어디에 걸렸는지 따라가기 어려워 지금은 target_include_directories · target_link_libraries · target_compile_definitions 로 타깃마다 건다
  • target_link_libraries(apple common) 처럼 PRIVATE · PUBLIC 없이 쓰던 옛 문법도 돌지만, 한 타깃에 두 문법을 섞으면 The plain signature for target_link_libraries has already been used with the target "apple". All uses of target_link_libraries with a target must be either all-keyword or all-plain. 로 멈춘다
