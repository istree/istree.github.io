구조체로 관련된 값을 묶고 메서드를 붙인다. 열거형으로 여러 경우 중 하나인 값을 만들고 match 로 경우마다 나눈다.

구조체

#[derive(Debug)]                  // {:?} 로 찍을 수 있게
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {       // 메서드 — 첫 인자가 self
        self.width * self.height
    }

    fn square(size: u32) -> Self {   // 연관 함수 — Rectangle::square(3) 로 부른다
        Self { width: size, height: size }
    }
}

let width = 30;
let r = Rectangle { width, height: 50 };     // 이름이 같으면 줄여 쓴다
let r2 = Rectangle { height: 10, ..r };      // 나머지는 r 에서
println!("{:?} {}", r2, r.area());

열거형

경우마다 다른 값을 실을 수 있다.

enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
}

값이 없을 수 있으면 null 대신 Option<T> 를 쓴다. Some(값) 이거나 None 이다.

let some: Option<i32> = Some(5);
let none: Option<i32> = None;

match

모든 경우를 다뤄야 컴파일된다. 실린 값은 풀어서 받는다.

fn handle(msg: Message) {
    match msg {
        Message::Quit => println!("끝"),
        Message::Move { x, y } => println!("{x}, {y} 로"),
        Message::Write(text) => println!("{text}"),
    }
}

fn plus_one(x: Option<i32>) -> Option<i32> {
    match x {
        Some(i) => Some(i + 1),
        None => None,
    }
}
  • 나머지 경우는 _ => … 로 받는다

if let

한 경우만 볼 때 줄여 쓴다.

if let Some(max) = config_max {
    println!("최대 {max}");
} else {
    println!("없음");
}
