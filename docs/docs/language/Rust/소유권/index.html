Rust 가 가비지 컬렉터 없이 메모리를 관리하는 규칙이다. 컴파일러가 이 규칙을 검사해서, 해제한 메모리를 쓰거나 두 번 해제하는 오류를 컴파일할 때 막는다.

  • 값마다 주인(소유자) 변수가 하나 있다
  • 주인은 한 번에 하나뿐이다
  • 주인이 범위를 벗어나면 값이 해제된다

이동

힙에 있는 값(String · Vec …) 을 다른 변수에 넣거나 함수에 넘기면 주인이 옮겨 간다. 옛 변수는 더 쓸 수 없다.

let s1 = String::from("hello");
let s2 = s1;                  // s1 의 주인 자리가 s2 로 옮겨 감
// println!("{s1}");          // 컴파일 오류: 옮겨 간 값을 썼다

let s3 = s2.clone();          // 힙까지 복사하려면 clone

정수 · 실수 · bool · char 처럼 스택에만 있는 값은 복사된다(Copy). 옛 변수도 그대로 쓸 수 있다.

참조와 빌림

값을 옮기지 않고 빌려준다. & 는 읽기만, &mut 는 고치기까지 빌려준다.

fn len(s: &String) -> usize {       // 빌려 받는다 — 주인은 그대로
    s.len()
}

fn push_world(s: &mut String) {
    s.push_str(", world");
}

let mut s = String::from("hello");
let n = len(&s);
push_world(&mut s);
  • 한 번에 &mut 하나, 또는 & 여럿 — 둘을 섞을 수 없다. 데이터 경쟁을 컴파일할 때 막는 규칙이다
  • 참조는 가리키는 값보다 오래 살 수 없다 (매달린 참조 금지)

슬라이스

배열 · 문자열의 일부를 빌린다.

fn first_word(s: &str) -> &str {
    match s.find(' ') {
        Some(i) => &s[..i],
        None => s,
    }
}

let s = String::from("hello world");
let w = first_word(&s);       // "hello"
let part = &[1, 2, 3, 4][1..3];   // [2, 3]
  • 문자열 매개변수는 &String 보다 &str 로 받으면 String 과 글자 상수를 모두 받는다
