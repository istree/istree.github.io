클로저는 둘레의 변수를 붙잡는 이름 없는 함수다. 반복자는 값을 하나씩 내놓는 것으로, 클로저와 함께 리스트를 거르고 바꾼다.

클로저

let add_one = |x: i32| x + 1;       // 타입은 대개 생략한다
let offset = 10;
let shift = |x| x + offset;         // offset 을 붙잡는다
println!("{} {}", add_one(1), shift(1));

붙잡는 방식은 쓰는 모양에 따라 정해진다. 값을 옮겨 붙잡게 하려면 move 를 붙인다. 스레드에 넘길 때 쓴다.

let list = vec![1, 2, 3];
std::thread::spawn(move || println!("{list:?}")).join().unwrap();
  • Fn 은 빌려 읽기, FnMut 는 빌려 고치기, FnOnce 는 옮겨 가져 한 번만 부르는 클로저다. 함수가 받을 클로저의 종류를 이것으로 밝힌다

반복자

iter() 로 만들고, 바꾸는 메서드를 이은 뒤, 마지막에 모은다. 모으기 전까지는 아무것도 계산하지 않는다(게으름).

let v = vec![1, 2, 3, 4, 5];

let doubled: Vec<i32> = v.iter().map(|x| x * 2).collect();
let evens: Vec<&i32>  = v.iter().filter(|x| *x % 2 == 0).collect();
let total: i32        = v.iter().sum();
  • iter() 는 빌려 돌고, into_iter() 는 옮겨 가져 돌고, iter_mut() 는 고치며 돈다

직접 만든 반복자

Iterator 트레이트의 next 하나만 만들면 map · filter · sum 을 모두 쓸 수 있다.

struct Counter { count: u32 }

impl Iterator for Counter {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.count < 5 {
            self.count += 1;
            Some(self.count)
        } else {
            None
        }
    }
}

let sum: u32 = Counter { count: 0 }.zip(Counter { count: 0 }.skip(1))
    .map(|(a, b)| a * b)
    .filter(|x| x % 3 == 0)
    .sum();                          // 18
