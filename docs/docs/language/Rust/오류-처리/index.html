되돌릴 수 없는 오류는 panic! 으로 멈추고, 되돌릴 수 있는 오류는 Result 로 돌려준다. 예외(try · catch) 는 없다.

panic!

panic!("여기서 멈춘다");
  • 실행할 때 RUST_BACKTRACE=1 을 주면 호출 스택이 찍힌다

Result

Ok(값) 이거나 Err(오류) 다. match 로 나눈다.

use std::fs::File;
use std::io::ErrorKind;

let f = match File::open("hello.txt") {
    Ok(file) => file,
    Err(e) if e.kind() == ErrorKind::NotFound => File::create("hello.txt").unwrap(),
    Err(e) => panic!("열 수 없다: {e:?}"),
};

unwrap · expect

Ok 면 값을 꺼내고 Err 면 panic 한다. 시험 코드나 절대 실패하지 않는 곳에서 쓴다.

let f = File::open("hello.txt").expect("hello.txt 가 있어야 한다");   // 메시지를 남긴다

? 연산자

Err 면 그 자리에서 함수를 끝내고 오류를 돌려준다. 오류를 위로 넘기는 코드가 한 글자로 준다.

use std::io::{self, Read};

fn read_username() -> Result<String, io::Error> {
    let mut s = String::new();
    File::open("hello.txt")?.read_to_string(&mut s)?;
    Ok(s)
}
  • ? 는 Result(또는 Option) 를 돌려주는 함수 안에서만 쓴다
  • main 도 fn main() -> Result<(), Box<dyn std::error::Error>> 로 하면 ? 를 쓸 수 있다
