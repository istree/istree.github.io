코드가 커지면 모듈로 나눈다. 패키지(Cargo 프로젝트) 안에 크레이트(라이브러리 · 실행 파일) 가 있고, 크레이트 안을 모듈로 나눈다.

모듈과 공개

모듈 안의 것은 기본으로 감춰져 있다. 밖에서 쓰게 하려면 pub 을 붙인다.

mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}

pub fn eat_at_restaurant() {
    crate::front_of_house::hosting::add_to_waitlist();   // 절대 경로
    front_of_house::hosting::add_to_waitlist();          // 상대 경로
}
  • super:: 는 부모 모듈
  • 구조체는 pub 을 붙여도 필드는 감춰져 있다. 필드마다 pub 을 붙인다. 열거형은 pub 이면 경우가 모두 공개된다

use

긴 경로를 범위로 가져온다.

use std::collections::HashMap;
use std::io::{self, Write};          // 여럿을 한 번에
use std::fmt::Result as FmtResult;   // 이름이 겹치면 다른 이름으로

let mut map = HashMap::new();
  • 함수는 부모 모듈까지만 가져와 hosting::add_to_waitlist() 처럼 부르고, 구조체 · 열거형은 이름까지 가져오는 것이 관례다

파일로 나누기

mod 이름; 이라고만 쓰면 같은 이름의 파일에서 읽는다.

// src/main.rs
mod front_of_house;              // src/front_of_house.rs (또는 src/front_of_house/mod.rs)
