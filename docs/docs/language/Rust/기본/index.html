변수 · 자료형 · 함수 · 제어 흐름을 다룬다. 대부분은 다른 언어와 비슷하지만, 변수가 기본으로 바뀌지 않고 거의 모든 것이 값을 내는 식이라는 점이 다르다.

변수와 가변성

let x = 5;              // 바꿀 수 없다
let mut y = 5;          // mut 을 붙여야 바꿀 수 있다
y += 1;

const MAX_POINTS: u32 = 100_000;   // 상수는 타입을 꼭 적는다

let spaces = "   ";
let spaces = spaces.len();          // 같은 이름으로 다시 선언 (shadowing) — 타입도 바꿀 수 있다

자료형

let a: i32 = -5;        // 정수 i8 ~ i128, u8 ~ u128, isize · usize
let b = 2.5;            // f64 (f32 도 있다)
let c = true;
let d = '한';           // char 는 4 바이트 유니코드 한 글자

let tup = (500, 6.4, 'z');
let (p, q, r) = tup;    // 풀어 받기
let first = tup.0;

let arr = [1, 2, 3, 4, 5];
let zeros = [0; 3];     // [0, 0, 0]
let second = arr[1];    // 범위 밖이면 실행 중에 panic

함수

매개변수 타입을 꼭 적는다. 마지막 식(세미콜론 없음) 이 돌려주는 값이다.

fn plus_one(x: i32) -> i32 {
    x + 1               // ; 를 붙이면 문장이 되어 () 를 돌려준다 — 컴파일 오류
}

제어 흐름

if · loop 는 식이라 값을 낸다.

let size = if n > 100 { "큼" } else { "작음" };

let mut count = 0;
let result = loop {
    count += 1;
    if count == 10 {
        break count * 2;          // loop 에서 값을 들고 나온다
    }
};

for i in (1..4).rev() {           // 3, 2, 1
    println!("{i}");
}
for v in arr.iter() { println!("{v}"); }
