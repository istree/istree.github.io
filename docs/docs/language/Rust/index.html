Rust 는 C · C++ 만큼 빠르면서 메모리를 안전하게 쓰게 해 주는 시스템 언어다. 가비지 컬렉터 없이, 컴파일러가 소유권 규칙으로 메모리 오류와 데이터 경쟁을 컴파일할 때 잡는다. 빌드 · 패키지 도구 Cargo 가 함께 온다.
