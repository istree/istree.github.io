Rust 는 소유권 규칙으로 스레드 사이의 데이터 경쟁을 컴파일할 때 막는다. 스레드를 띄우고, 채널로 메시지를 주고받거나, Mutex 로 상태를 나눠 쓴다.

스레드

use std::thread;
use std::time::Duration;

let handle = thread::spawn(|| {
    for i in 1..5 {
        println!("스레드 {i}");
        thread::sleep(Duration::from_millis(1));
    }
});
handle.join().unwrap();             // 끝날 때까지 기다린다
  • 스레드에서 바깥 변수를 쓰려면 move 클로저로 옮겨 준다

채널

보내는 쪽(tx) 과 받는 쪽(rx) 으로 메시지를 넘긴다. 보낸 값은 받는 쪽으로 옮겨 간다.

use std::sync::mpsc;

let (tx, rx) = mpsc::channel();
let tx2 = tx.clone();                       // 보내는 쪽은 여럿 둘 수 있다

thread::spawn(move || tx.send(String::from("안녕")).unwrap());
thread::spawn(move || tx2.send(String::from("반가워")).unwrap());

for msg in rx {                             // 보내는 쪽이 모두 사라지면 끝난다
    println!("{msg}");
}

Mutex 와 Arc

여러 스레드가 같은 값을 고칠 때는 Mutex 로 잠그고, 여러 스레드가 주인이 되도록 Arc 로 감싼다.

use std::sync::{Arc, Mutex};

let counter = Arc::new(Mutex::new(0));
let mut handles = vec![];

for _ in 0..10 {
    let counter = Arc::clone(&counter);
    handles.push(thread::spawn(move || {
        let mut num = counter.lock().unwrap();   // 잠그고 값을 빌린다
        *num += 1;
    }));                                          // num 이 사라지면 풀린다
}
for h in handles { h.join().unwrap(); }
println!("{}", *counter.lock().unwrap());         // 10
  • Rc 는 스레드 사이에 넘길 수 없다(Send 가 아니다). 스레드에서는 Arc 를 쓴다
  • Mutex 하나를 그냥 여러 스레드에 옮기면 컴파일 오류다 — 첫 스레드가 가져가 버리기 때문이다
