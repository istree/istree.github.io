표준 라이브러리의 자주 쓰는 컬렉션 셋이다. 모두 힙에 있어서 크기가 늘고 준다.

Vec

let mut v: Vec<i32> = Vec::new();
v.push(1);
let v2 = vec![1, 2, 3];

let third = &v2[2];                 // 범위 밖이면 panic
match v2.get(10) {                  // 범위 밖이면 None
    Some(x) => println!("{x}"),
    None => println!("없다"),
}

for x in &mut v {                   // 고치며 돌기
    *x += 50;
}
  • 요소를 빌려 둔 채로 push 할 수 없다. 늘어나며 자리를 옮기면 빌린 참조가 매달리기 때문이다

String

UTF-8 바이트를 담는다.

let mut s = String::from("안녕");
s.push_str("하세요");
let t = s.clone() + "!";            // + 는 왼쪽 값을 옮겨 받는다
let u = format!("{s}-{t}");         // 아무것도 옮기지 않는다

for c in "안녕".chars() { println!("{c}"); }   // 글자 단위
for b in "안녕".bytes() { println!("{b}"); }   // 바이트 단위
  • s[0] 처럼 번호로 꺼낼 수 없다. 한 글자가 여러 바이트일 수 있어서다. 범위로 자를 때도 글자 경계에 맞아야 한다

HashMap

use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Blue"), 25);              // 덮어쓰기

scores.entry(String::from("Red")).or_insert(50);      // 없을 때만 넣기

let text = "hello world wonderful world";
let mut count = HashMap::new();
for word in text.split_whitespace() {
    *count.entry(word).or_insert(0) += 1;             // 옛 값으로 새 값 만들기
}
