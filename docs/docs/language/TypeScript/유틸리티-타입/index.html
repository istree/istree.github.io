유틸리티 타입은 있는 타입을 바꿔 새 타입을 만드는 내장 제네릭이다. 같은 모양을 여러 번 적지 않고, 원래 타입 하나를 고치면 따라 바뀐다. 직접 만들 때는 매핑 타입 · 템플릿 리터럴 타입을 쓴다.

아래는 이 타입 하나에서 시작한다.

type User = {
  id: number;
  name: string;
  email: string;
  role: "admin" | "member";
  createdAt: Date;
};

속성 고르기 · 바꾸기

타입 만드는 것
Partial<T> 모든 속성을 선택(?) 으로
Required<T> 모든 속성을 필수로
Readonly<T> 모든 속성을 읽기 전용으로
Pick<T, K> 키 K 만 남긴다
Omit<T, K> 키 K 를 뺀다
Record<K, V> 키가 K, 값이 V 인 객체 
type NewUser = Omit<User, "id" | "createdAt">;                 // 만들 때 받는 값 — 서버가 채우는 것은 뺀다
type UserPatch = Partial<Omit<User, "id" | "createdAt">>;      // 고칠 때 — 바꿀 것만
type UserSummary = Pick<User, "id" | "name">;                  // 목록에 보일 것만
type RoleMembers = Record<User["role"], string[]>;             // { admin: string[]; member: string[] }

function updateUser(id: number, patch: UserPatch) { /* … */ }
updateUser(1, { name: "kim" });       // 된다
updateUser(1, { id: 2 });
// TS2353: Object literal may only specify known properties, and 'id' does not exist in type 'Partial<Omit<User, "createdAt" | "id">>'.

declare const frozen: Readonly<User>;
frozen.name = "x";    // TS2540: Cannot assign to 'name' because it is a read-only property.
  • Omit 의 키는 오타를 잡지 않는다(Omit<User, "emial"> 도 통과한다). 남길 것이 적으면 Pick 이 안전하다
  • Readonly 는 한 겹만 막는다. 안쪽 객체 · 배열은 그대로 고쳐진다

유니온 거르기

타입 만드는 것
Exclude<U, X> 유니온 U 에서 X 를 뺀다
Extract<U, X> 유니온 U 에서 X 에 맞는 것만 남긴다
NonNullable<T> null · undefined 를 뺀다 
type Member = Exclude<User["role"], "admin">;              // "member"
type Primitive = Extract<string | number | Date, string | number>;   // string | number
type Name = NonNullable<string | null | undefined>;        // string

함수에서 타입 뽑기

타입 만드는 것
ReturnType<F> 함수의 반환 타입
Parameters<F> 매개변수 타입의 튜플
Awaited<T> Promise 를 벗긴 타입 
function createUser(name: string) {
  return { id: 1, name, createdAt: new Date() };
}
type Created = ReturnType<typeof createUser>;          // { id: number; name: string; createdAt: Date }
type UpdateArgs = Parameters<typeof updateUser>;       // [id: number, patch: UserPatch]

async function loadIds() { return [1, 2]; }
type Ids = Awaited<ReturnType<typeof loadIds>>;        // number[]
  • 라이브러리가 타입을 내보내지 않을 때 이것으로 꺼내 쓴다: type Options = Parameters<typeof someLib.init>[0]

매핑 타입

{ [K in keyof T]: … } 로 키마다 속성 타입을 바꾼다. 위의 Partial · Readonly 가 이렇게 만들어져 있다.

type Nullable<T> = { [K in keyof T]: T[K] | null };

type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];    // as 로 키 이름을 바꾼다
};
type UserGetters = Getters<Pick<User, "name" | "email">>;
// { getName: () => string; getEmail: () => string }

const g: UserGetters = { getName: () => "a" };
// TS2741: Property 'getEmail' is missing in type '{ getName: () => string; }' but required in type 'Getters<…>'.

템플릿 리터럴 타입

문자열 리터럴 타입을 이어 붙여 새 리터럴 유니온을 만든다.

type EventName = `on${Capitalize<"click" | "focus">}`;    // "onClick" | "onFocus"
const e: EventName = "onHover";    // TS2322: Type '"onHover"' is not assignable to type '"onClick" | "onFocus"'.

type CssSize = `${number}px` | `${number}%`;
const w: CssSize = "120px";        // 된다
  • Uppercase · Lowercase · Capitalize · Uncapitalize 가 들어 있다

자주 만드는 것

type PartialBy<T, K extends keyof T> = Omit<T, K> & Partial<Pick<T, K>>;   // 몇 개만 선택으로
const draft: PartialBy<User, "email" | "role"> = { id: 1, name: "a", createdAt: new Date() };

type ValueOf<T> = T[keyof T];                                               // 값 타입의 유니온
  • 타입이 길어지면 에디터에서 마우스를 올려 펼쳐진 모양을 본다. 너무 복잡하면 펼친 모양을 그대로 적는 편이 읽기 쉽다
