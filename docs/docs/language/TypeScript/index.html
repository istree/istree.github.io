TypeScript 는 JavaScript 에 타입을 더한 언어다. 변수 · 함수 · 객체에 타입을 적거나 추론하게 두면, 실행하기 전에 컴파일러(tsc) 가 잘못 쓴 곳을 찾는다. 타입은 검사에만 쓰고 지운 뒤 JavaScript 로 돌리므로, 실행 환경 · 라이브러리는 JavaScript 의 것을 그대로 쓴다. 에디터의 자동 완성 · 이름 바꾸기도 이 타입 정보로 돈다.

여기의 예제는 TypeScript 7 기준이다. TypeScript 7 은 컴파일러를 Go 로 새로 짠 판으로, 문법과 검사는 6 과 같고 빌드가 크게 빨라졌다.
