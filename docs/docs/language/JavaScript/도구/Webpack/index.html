Webpack 은 import · require 로 얽힌 JavaScript 파일들(과 CSS · 이미지) 을 따라가며 브라우저가 읽을 파일 몇 개로 묶는 번들러다. 새 프로젝트는 Vite 로 시작하는 경우가 많고, Webpack 은 오래된 프로젝트 · 세밀한 설정이 필요한 곳에서 쓴다.

설치

npm 이 설치되어 있어야 한다.

npm i webpack webpack-cli --save-dev

사용

index.js 와 test.js 를 dist/main.js 하나로 합친다.

npx webpack ./src/index.js ./src/test.js -o dist --mode production
  • webpack 5 에서 -o 는 출력 디렉토리 다. 파일 이름은 main.js 가 된다. webpack 4 때는 -o dist/bundle.js 처럼 파일 이름을 줬다
  • --mode development 는 줄이지 않고 디버그하기 쉽게 묶는다

설정 파일

옵션이 늘면 프로젝트 맨 위의 webpack.config.js 에 적고 npx webpack 만 실행한다.

// webpack.config.js
const path = require("path");

module.exports = {
  mode: "production",
  entry: "./src/index.js",
  output: {
    path: path.resolve(__dirname, "dist"),
    filename: "bundle.js",
    clean: true,                 // 빌드 전에 dist 비우기
  },
  module: {
    rules: [
      { test: /\.css$/, use: ["style-loader", "css-loader"] },   // import "./a.css"
    ],
  },
};

Watch 및 Watch 옵션

파일이 변경될 때마다 다시 컴파일한다. 참고

npx webpack --watch
