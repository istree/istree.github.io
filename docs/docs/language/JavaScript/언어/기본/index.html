변수 · 타입 · 비교 · 배열 · 객체 리터럴처럼 매일 쓰는 문법을 정리한다. 책(핵심 가이드 · 패턴) 이 var 시절에 피하라고 한 것들은 지금 문법으로 대부분 풀렸다. 풀린 방법을 같이 적는다.

변수

const max = 10;        // 다시 대입하지 않는다 — 기본으로 쓴다
let count = 0;         // 다시 대입한다
count += 1;

const list = [1, 2];
list.push(3);          // const 라도 안의 값은 바꿀 수 있다
  • let · const 는 블록({}) 안에서만 산다. var 는 함수 단위이고 선언이 함수 맨 위로 끌어올려진다(호이스팅). 새 코드에서는 var 를 쓰지 않는다
  • 선언하지 않고 대입하면 전역 변수가 생긴다. 파일 맨 위에 "use strict"; 를 두거나 모듈(type="module") 로 쓰면 오류가 난다

타입

원시 타입은 string · number · bigint · boolean · undefined · null · symbol 이고, 나머지는 모두 객체다.

typeof "a"         // "string"
typeof 1           // "number"
typeof undefined   // "undefined"
typeof null        // "object"   ← 오래된 버그. null 은 === null 로 확인한다
typeof []          // "object"   ← 배열은 Array.isArray([]) 로 확인한다
typeof function(){}// "function"
  • "monkey".slice(3) 처럼 원시 값에서 메서드를 부르면 잠깐 래퍼 객체(String) 가 만들어진다. new String("a") 처럼 래퍼를 직접 만들지 않는다

같음

=== 는 타입까지 같아야 참이다. == 는 타입을 바꿔서 비교하므로 쓰지 않는다.

0 == ""            // true
0 == "0"           // true
"" == "0"          // false  ← 서로 맞지 않는다
null == undefined  // true   ← == 를 쓰는 유일한 관용구 (둘 다 확인)

0 === ""           // false

조건문에서는 값이 거짓(falsy) 으로 바뀌는지 본다. 거짓은 false · 0 · -0 · 0n · "" · null · undefined · NaN 뿐이고, 나머지("0" · [] · {}) 는 참이다.

if (name) { ... }          // 빈 문자열도 거른다
if (count != null) { ... } // 0 은 통과시키고 null · undefined 만 거른다

없는 값 다루기

const city = user?.address?.city;        // 중간이 null · undefined 면 undefined
const size = options.size ?? 10;         // null · undefined 일 때만 기본값
const name = input || "이름 없음";       // 거짓이면 모두 기본값 (0 · "" 도)
user.onSave?.();                         // 함수가 있을 때만 부른다
  • 예전에는 a = a || 1 로 기본값을 줬다. 0 · "" 을 넣어도 기본값으로 바뀌므로, 숫자 · 문자열이면 ?? 를 쓴다

숫자 바꾸기

parseInt("08", 10)    // 8      — 진수(10) 를 꼭 준다
parseInt("12px", 10)  // 12     — 앞에서부터 숫자만 읽는다
Number("12px")        // NaN    — 전체가 숫자여야 한다
Number("")            // 0      ← 빈 문자열은 0 이 된다
+"3.5"                // 3.5    — 단항 + 도 Number() 와 같다

Number.isNaN(x)                 // NaN 확인. x === NaN 은 늘 false 다
(22 / 7).toFixed(2)             // "3.14" — 문자열이 된다
0.1 + 0.2                       // 0.30000000000000004 — 돈은 정수(원 · 센트) 로 계산한다

문자열

const msg = `${name} 님, ${count} 건이 있습니다`;   // 템플릿 리터럴
const lines = `첫 줄
둘째 줄`;                                            // 여러 줄

"a,b,c".split(",")          // ["a", "b", "c"]
"  hi ".trim()              // "hi"
"abc".includes("b")         // true
"abc".startsWith("ab")      // true
"7".padStart(3, "0")        // "007"
"a-b-c".replaceAll("-", "") // "abc"

다국어 정렬은 localeCompare · Intl.Collator 로 한다. 기본 sort() 는 문자 코드 순서다.

const words = ["b", "가", "z", "나", "ä"];
words.sort();                                 // ["b", "z", "ä", "가", "나"] — 문자 코드 순서
words.sort(new Intl.Collator("en").compare);  // ["ä", "b", "z", "가", "나"]
words.sort(new Intl.Collator("ko").compare);  // ["가", "나", "ä", "b", "z"] — 한글이 앞에 온다
"가".localeCompare("나", "ko")                // -1

배열

반복은 for...of 로 하고, 바꾸기 · 거르기 · 모으기는 메서드를 쓴다. 메서드는 새 배열을 돌려주고 원래 배열은 그대로 둔다.

const items = [{ name: "a", price: 300 }, { name: "b", price: 100 }];

for (const item of items) { ... }
items.forEach((item, i) => { ... });

items.map(x => x.name)                        // ["a", "b"]
items.filter(x => x.price > 200)              // [{ name: "a", ... }]
items.find(x => x.name === "b")               // { name: "b", ... } (없으면 undefined)
items.some(x => x.price > 200)                // true
items.reduce((sum, x) => sum + x.price, 0)    // 400
items.toSorted((a, b) => a.price - b.price)   // 복사해서 정렬 (sort 는 원래 배열을 바꾼다)
[1, 2, 3].includes(2)                         // true
[1, 2, 3].at(-1)                              // 3 — 뒤에서 첫째
  • new Array(3) 은 길이 3 인 빈 배열이다. 값이 들어간 배열은 [3] 처럼 리터럴로 만든다. 채운 배열은 Array.from({ length: 3 }, (_, i) => i) 로 만든다

객체 리터럴

const name = "Benji", key = "color";
const dog = {
  name,                         // name: name
  [key]: "white",               // 계산한 키
  say() { return "Woof"; },     // 메서드
};

const { name: n, age = 3 } = dog;       // 구조 분해 · 기본값
const copy = { ...dog, age: 5 };        // 얕은 복사 + 덮어쓰기
const [first, ...rest] = [1, 2, 3];     // 배열 구조 분해 · 나머지

Object.keys(dog)       // ["name", "color", "say"]
Object.entries(dog)    // [["name", "Benji"], ...]
delete dog.color;      // 속성 지우기
"name" in dog          // true

함수에서 여러 값을 돌려줄 때도 객체 · 배열을 돌려주고 받는 쪽에서 구조 분해한다.

function minMax(list) {
  return { min: Math.min(...list), max: Math.max(...list) };
}
const { min, max } = minMax([3, 1, 4]);

세미콜론

세미콜론을 빼면 줄 끝에 자동으로 넣어 준다. return 바로 뒤에서 줄을 바꾸면 거기서 끝나 버린다.

function get() {
  return          // return; 으로 끝난다 → undefined
  {
    name: "Batman"
  };
}
  • 여는 괄호 { 는 같은 줄에 둔다

콘솔

console.log({ user, count });        // 객체로 감싸면 변수 이름이 같이 나온다
console.table(items);                // 배열 · 객체를 표로
console.error(err);                  // 빨간 표시 + 호출 스택
console.time("load"); load(); console.timeEnd("load");   // 걸린 시간
