정규식은 문자열에서 꼴(패턴) 을 찾는 작은 언어다. 날짜 · 버전 · 로그 줄처럼 모양이 정해진 글자를 나누고, 검사하고, 바꿀 때 쓴다. JavaScript 에서는 RegExp 객체이고, 문자열 메서드(match · replace · split …) 에 넘겨 쓴다.

만들기

const re1 = /\d{4}-\d{2}-\d{2}/g;                 // 리터럴 — 보통 이것을 쓴다
const re2 = new RegExp("\\d{4}-\\d{2}", "g");      // 문자열로 — 역슬래시를 두 번 쓴다
const re3 = new RegExp(String.raw`\d+\.\d+`);      // String.raw 면 한 번만 쓴다

const word = "c++";                                // 사용자가 넣은 글자
new RegExp(RegExp.escape(word)).test("I like c++");   // true — 특수 문자를 글자로
  • 패턴이 바뀌지 않으면 리터럴, 실행 중에 만들면 new RegExp 를 쓴다
  • new RegExp("\d+") 는 /d+/ 가 된다. 문자열 안의 \d 는 그냥 d 다
  • 사용자 입력을 그대로 넣으면 c++ 에서 SyntaxError: Invalid regular expression: /c++/: Nothing to repeat 이 난다. RegExp.escape 로 감싼다
플래그 뜻
g 모두 찾는다 (없으면 처음 하나)
i 대소문자를 가리지 않는다
m ^ · $ 가 줄마다 맞는다
s . 이 줄바꿈도 맞는다
u 유니코드로 읽는다 — 이모지 · \p{…}
v u 의 새 판 — 집합 빼기 · 이모지 묶음(\p{RGI_Emoji})
y lastIndex 자리에서만 맞춘다
d 맞은 자리를 indices 에 남긴다

문법

쓰기 맞는 것
. 줄바꿈 밖의 한 글자
\d · \w · \s 숫자 · 영문자 숫자 _ · 공백. 대문자(\D …) 는 그 반대
[abc] · [a-z] · [^0-9] 이 중 하나 · 범위 · 이것 말고
^ · $ · \b 처음 · 끝 · 단어 경계
a* · a+ · a? 0 번 이상 · 1 번 이상 · 0 이나 1 번
a{3} · a{2,4} · a{2,} 3 번 · 2–4 번 · 2 번 이상
*? · +? 될 수 있는 대로 적게 (게으른 수량자)
(…) · (?:…) · (?<name>…) 잡는 그룹 · 잡지 않는 그룹 · 이름 붙은 그룹
\1 · \k<name> 앞에서 잡은 것과 같은 글자 (되참조)
a|b a 또는 b
x(?=y) · x(?!y) 뒤에 y 가 오는 · 오지 않는 x (앞 보기)
(?<=y)x · (?<!y)x 앞에 y 가 있는 · 없는 x (뒤 보기)
\p{Script=Hangul} 한글 (u · v 가 있어야 한다)
(?i:…) 이 부분만 대소문자 무시 
"color colour".match(/colou?r/g);                  // ["color", "colour"]
"<b>a</b><b>c</b>".match(/<b>.*<\/b>/)[0];         // "<b>a</b><b>c</b>" — 욕심: 끝까지 먹는다
"<b>a</b><b>c</b>".match(/<b>.*?<\/b>/)[0];        // "<b>a</b>"          — 게으름: 처음 닫는 데까지

`say "hi" and 'bye'`.match(/(["'])(.*?)\1/g);       // ['"hi"', "'bye'"] — 연 따옴표로 닫는다

"가격 $30, 배송 $5".match(/(?<=\$)\d+/g);           // ["30", "5"]  — $ 는 빼고 숫자만
"a.js b.ts c.js".match(/\w+(?=\.js)/g);            // ["a", "c"]   — .js 앞의 이름만
"안녕 hello 123".match(/\p{Script=Hangul}+/gu);      // ["안녕"]
/^(?i:error):/.test("Error: disk full");           // true

쓰기

메서드 돌려주는 것
re.test(s) 맞는지 — true · false
s.match(re) g 없으면 첫째 결과(그룹 · index · groups), g 있으면 맞은 글자 배열. 없으면 null
s.matchAll(re) 결과마다 그룹까지 — 이터레이터. g 가 있어야 한다
s.replace(re, 바꿀것) · s.replaceAll(re, 바꿀것) 바꾼 새 문자열. replaceAll 은 g 가 있어야 한다
s.split(re) 나눈 배열
s.search(re) 처음 맞은 자리 — 없으면 -1
re.exec(s) match(g 없음) 와 같은 결과 하나. g 면 부를 때마다 다음 것 
const m = "2026-11-07".match(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/);
m[0];              // "2026-11-07"
m[1];              // "2026"
m.groups.month;    // "11"
m.index;           // 0

"v1.2.3, v2.0.10".match(/\d+/g);                   // ["1", "2", "3", "2", "0", "10"]
"abc".match(/\d/);                                 // null — 결과를 바로 쓰려면 ?. 를 붙인다

마크다운 링크를 모두 뽑는다. 결과마다 그룹이 필요하면 matchAll 을 쓴다.

const md = "[블로그](https://istree.github.io) 와 [MDN](https://developer.mozilla.org)";
for (const { groups } of md.matchAll(/\[(?<text>[^\]]+)\]\((?<url>[^)]+)\)/g)) {
  console.log(groups.text, groups.url);
}
// 블로그 https://istree.github.io
// MDN https://developer.mozilla.org

바꾸기에서는 $1 · $<name> 으로 그룹을, 함수로 계산한 값을 넣는다.

"2026-11-07".replace(/(\d{4})-(\d{2})-(\d{2})/, "$3/$2/$1");                    // "07/11/2026"
"2026-11-07".replace(/(?<y>\d+)-(?<m>\d+)-(?<d>\d+)/, "$<d>.$<m>.$<y>");          // "07.11.2026"
"price: 1200, 3500".replace(/\d+/g, n => (n * 1.1).toFixed(0));                  // "price: 1320, 3850"
"camelCaseText".replace(/[A-Z]/g, c => "-" + c.toLowerCase());                  // "camel-case-text"
"kebab-case-text".replace(/-(\w)/g, (_, c) => c.toUpperCase());                 // "kebabCaseText"

"a, b,c ,  d".split(/\s*,\s*/);                   // ["a", "b", "c", "d"]
"2026-11-07".split(/(-)/);                        // ["2026", "-", "11", "-", "07"] — 그룹은 결과에 남는다
  • 함수의 인자는 (맞은 글자, 그룹1, 그룹2, …, 자리, 원래 문자열, groups) 순서다
  • 바꿀 글자에 $ 를 그대로 넣으려면 $$ 로 쓴다

함정

g 정규식을 되풀이해 쓰기

g · y 정규식은 lastIndex 에 다음에 찾을 자리를 남긴다. 같은 정규식으로 test 를 되풀이하면 결과가 번갈아 나온다.

const hasDigit = /\d/g;
hasDigit.test("1");    // true  — lastIndex 가 1 이 된다
hasDigit.test("1");    // false — 1 자리부터 찾는다
hasDigit.test("1");    // true  — 못 찾으면 0 으로 돌아간다
  • 맞는지만 볼 때는 g 를 빼고 만든다
  • exec 로 모두 돌 때는 이것을 쓴다: while ((m = re.exec(s)) !== null) { … }. 지금은 matchAll 이 낫다

이모지와 u

u 가 없으면 글자를 UTF-16 코드 단위로 센다. 이모지 하나가 두 단위라 . 하나로 맞지 않는다.

"😀".length;                      // 2
/^.$/.test("😀");                 // false
/^.$/u.test("😀");                // true
"a😀b".split("");                 // ["a", "\ud83d", "\ude00", "b"] — 깨진다
[..."a😀b"];                      // ["a", "😀", "b"]

/^\p{RGI_Emoji}$/v.test("👨‍👩‍👧");   // true — 여러 글자를 붙인 이모지도 하나로
  • 한글 · 이모지가 들어갈 수 있으면 u 나 v 를 붙인다

여러 줄

^ · $ 는 문자열 전체의 처음 · 끝이다. 줄마다 맞추려면 m, . 이 줄바꿈을 넘게 하려면 s 를 준다.

const text = "first\nsecond";
text.match(/^\w+$/g);             // null
text.match(/^\w+$/gm);            // ["first", "second"]
/first.second/.test(text);        // false
/first.second/s.test(text);       // true

자주 쓰는 패턴

// 로그 줄 나누기
"[ERROR] 12:30:01 db timeout after 3000ms".match(/^\[(?<level>\w+)\] (?<time>[\d:]+) (?<msg>.*)$/).groups;
// { level: "ERROR", time: "12:30:01", msg: "db timeout after 3000ms" }

// 버전 나누기 — 맞지 않으면 undefined
const parseVersion = v => v.match(/^v?(\d+)\.(\d+)\.(\d+)$/)?.slice(1).map(Number);
parseVersion("v1.2.10");          // [1, 2, 10]
parseVersion("1.2");              // undefined

// 공백 정리
"  여러   칸의\t공백  ".replace(/\s+/g, " ").trim();          // "여러 칸의 공백"

// 숫자만 남기기 · 전화번호 꼴 검사
"010-1234-5678".replace(/\D/g, "");                         // "01012345678"
/^01[016789]-?\d{3,4}-?\d{4}$/.test("010-1234-5678");       // true

// 한글 · 공백만 남기기
"안녕 hello!".replace(/[^\p{Script=Hangul}\s]/gu, "").trim();   // "안녕"

// 천 단위 쉼표 — 앞 보기로 세 자리마다
"1234567".replace(/\B(?=(\d{3})+(?!\d))/g, ",");           // "1,234,567"
(1234567).toLocaleString("ko");                             // "1,234,567" — 숫자면 이것이 낫다
  • 메일 주소는 /^[^\s@]+@[^\s@]+\.[^\s@]+$/ 처럼 꼴만 대강 본다. 정확한 검사는 메일을 보내 확인하는 것뿐이다. 폼에서는 <input type="email"> 을 쓴다
  • URL 은 정규식으로 나누지 않는다. new URL("https://ex.com/search?q=정규식&page=2") 의 hostname · searchParams.get("q") 를 쓴다
  • HTML 은 정규식으로 읽지 않는다. 브라우저는 DOMParser, Node 는 HTML 파서 패키지를 쓴다
