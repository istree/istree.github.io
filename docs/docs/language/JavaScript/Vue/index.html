Vue.js

빠른 시작

vue cli 설치

npm install -g @vue/cli

프로젝트 생성

vue create any-site

any-site 디렉토리가 생성된다.

cd any-site

any-site 디렉토리로 이동한다.

서버로 실행

npm run serve

배포

npm run build

dist 디렉토리에 결과물이 출력된다.

Electron 앱

electron 빌더 설치

vue add electron-builder

서버로 실행

npm run electron:serve

배포(실행파일)

npm run electron:build

문제해결

Error: Electron failed to install correctly 발생시

Electron을 재설치한다.

npm uninstall electron
npm install electron
