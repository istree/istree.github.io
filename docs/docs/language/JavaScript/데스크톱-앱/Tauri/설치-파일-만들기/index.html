tauri build 가 화면을 빌드(beforeBuildCommand) 하고, Rust 를 릴리스로 컴파일하고, OS 에 맞는 설치 파일을 만든다. 따로 패키징 도구를 설치하지 않는다. 설정은 tauri.conf.json 의 bundle 에 둔다.

빌드 실행

npm run tauri build                          # 이 OS 의 설치 파일 모두
npm run tauri build -- --bundles app,dmg     # 지정한 형식만
npm run tauri build -- --debug               # 디버그 빌드 (빨리 빌드되고, 개발자 도구를 쓸 수 있다)

결과는 src-tauri/target/release/bundle/ 아래에 형식마다 나온다.

OS 형식 (--bundles) 결과
macOS app · dmg bundle/macos/my-app.app · bundle/dmg/my-app_0.1.0_aarch64.dmg
Windows nsis · msi bundle/nsis/my-app_0.1.0_x64-setup.exe · bundle/msi/….msi
Linux deb · rpm · appimage bundle/deb/….deb · bundle/appimage/….AppImage
  • 설치 파일 없이 실행 파일만 만들려면 --no-bundle 을 준다. 실행 파일은 target/release/my-app 이다
  • 버전은 tauri.conf.json 의 version 을 쓴다. 없으면 Cargo.toml 의 version 을 쓴다
  • dmg 는 Finder 를 AppleScript 로 움직여 창을 꾸민다. 터미널에 Finder 제어 권한이 없으면(시스템 설정 → 개인정보 보호 및 보안 → 자동화) 멈추므로, 꾸미기를 건너뛰려면 CI=true npm run tauri build 로 한다

설정

{
  "bundle": {
    "active": true,
    "targets": "all",
    "icon": ["icons/32x32.png", "icons/128x128.png", "icons/128x128@2x.png", "icons/icon.icns", "icons/icon.ico"],
    "category": "DeveloperTool",
    "copyright": "© 2026 geon",
    "macOS": { "minimumSystemVersion": "11.0" },
    "windows": { "webviewInstallMode": { "type": "downloadBootstrapper" } }
  }
}
  • targets 에 ["dmg", "nsis"] 처럼 주면 그 형식만 만든다
  • Windows 에 WebView2 가 없을 때를 정하는 것이 webviewInstallMode 다. 기본(downloadBootstrapper) 은 설치할 때 내려받고, 인터넷이 없는 곳이면 offlineInstaller(약 127 MB 늘어남) 를 준다

아이콘

정사각형 PNG(1024 × 1024) 나 SVG 한 장으로 모든 크기 · 형식(icns · ico · png) 을 만든다.

npm run tauri icon app-icon.png      # src-tauri/icons/ 에 만든다. 파일 이름을 빼면 ./app-icon.png
  • Windows 스토어 로고(Square*Logo.png) · Android · iOS 아이콘도 함께 만든다. bundle.icon 목록은 그대로 둔다

다른 OS

설치 파일은 그 OS 에서 만드는 것이 기본이다.

  • mac 에서 Windows 설치 파일은 NSIS 만 만들 수 있다. MSI 는 Windows 에서만 된다 
    brew install nsis llvm
rustup target add x86_64-pc-windows-msvc
cargo install --locked cargo-xwin
npm run tauri build -- --runner cargo-xwin --target x86_64-pc-windows-msvc
  • 공식 문서는 이것을 마지막 방법으로 본다. 보통은 GitHub Actions 에서 OS 마다 빌드한다. tauri-action 이 빌드하고 릴리스에 올린다
  • Apple Silicon 과 Intel 을 함께 돌리는 앱은 --target universal-apple-darwin 으로 만든다 (rustup target add x86_64-apple-darwin 먼저)

서명

  • macOS 에서 서명하지 않은 앱을 내려받으면 "손상되었거나 확인할 수 없는 개발자" 로 막힌다. 배포하려면 Developer ID 인증서로 서명하고 공증한다
    • 환경 변수 APPLE_SIGNING_IDENTITY(또는 bundle.macOS.signingIdentity) 로 서명하고, APPLE_ID · APPLE_PASSWORD(앱 암호) · APPLE_TEAM_ID 를 주면 빌드할 때 공증까지 한다
    • 인증서가 없으면 "signingIdentity": "-" 로 ad-hoc 서명만 한다. Apple Silicon 에서 돌리려면 최소한 이것은 필요하다
  • Windows 는 코드 서명 인증서로 서명하지 않으면 SmartScreen 경고가 뜬다
