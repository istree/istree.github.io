Vite 는 개발 서버와 빌드를 함께 맡는 도구다. 개발할 때는 묶지 않고 브라우저의 ES 모듈 그대로 파일을 하나씩 내주므로 프로젝트가 커도 바로 뜨고, 고친 모듈만 바꿔 끼운다(HMR). 빌드할 때는 묶고 줄여 dist 에 낸다. React · Vue · Svelte 의 기본 프로젝트 도구이고, Tauri 앱의 화면도 Vite 로 만든다.

여기의 예제는 Vite 8 기준이다. Vite 8 은 묶기를 Rolldown(Rust) 하나로 한다. 예전(Vite 7 까지) 에는 개발 서버의 변환을 esbuild 가, 빌드의 묶기를 Rollup 이 맡았다.

프로젝트 만들기

npm create vite@latest my-app                       # 프레임워크 · 언어를 묻는다
npm create vite@latest my-app -- --template react   # 바로 (vanilla · vue · svelte · react-ts …)
cd my-app
npm install
npm run dev          # 개발 서버 — http://localhost:5173
npm run build        # dist 에 결과물
npm run preview      # dist 를 띄워 확인
  • 진입점은 index.html 이다. 그 안의 <script type="module" src="/src/main.js"> 부터 import 를 따라간다
  • Node 20.19 이상 · 22.12 이상이 있어야 한다

설정

// vite.config.js
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { fileURLToPath } from "node:url";

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: { "@": fileURLToPath(new URL("./src", import.meta.url)) },   // import x from "@/x"
  },
  server: {
    port: 3000,
    proxy: { "/api": "http://localhost:8080" },    // /api/… 요청을 백엔드로 넘긴다 (CORS 없이)
  },
  base: "./",                                      // 결과의 경로를 상대로 (file:// · 하위 폴더 배포)
  build: { outDir: "dist", sourcemap: true },
});
  • base 기본은 / 다. https://user.github.io/repo/ 처럼 하위 폴더에 올리면 base: "/repo/", Electron 처럼 file:// 로 열면 "./" 을 준다
  • 설정을 고치면 개발 서버가 알아서 다시 뜬다

파일 가져오기

import "./style.css";                        // CSS 를 페이지에 넣는다
import styles from "./card.module.css";      // CSS 모듈 — styles.title
import logoUrl from "./logo.png";            // 빌드 후 주소 (/assets/logo-a1b2c3.png)
import svgText from "./icon.svg?raw";        // 파일 내용을 문자열로
import workerUrl from "./worker.js?url";     // 주소만
import data from "./data.json";              // JSON 은 객체로

const modules = import.meta.glob("./pages/*.js");   // { "./pages/a.js": () => import(…) }
  • public/ 의 파일은 바꾸지 않고 그대로 dist 맨 위에 복사된다. /favicon.svg 처럼 절대 경로로 부른다
  • 작은 파일(4 KB 미만) 은 주소 대신 data URL 로 넣는다(build.assetsInlineLimit)
  • Sass 는 npm install -D sass 만 하면 import "./a.scss" 가 된다

환경 변수

.env 파일의 VITE_ 로 시작하는 값만 import.meta.env 로 화면 코드에 들어간다.

# .env                  모든 모드
VITE_API_URL=https://api.example.com
DB_PASSWORD=secret      # VITE_ 가 없으면 화면에 들어가지 않는다

# .env.development      npm run dev 때
VITE_API_URL=http://localhost:8080
console.log(import.meta.env.VITE_API_URL);
console.log(import.meta.env.MODE, import.meta.env.DEV, import.meta.env.PROD);   // "development" true false
  • .env.production 은 vite build 때, .env.local 은 git 에 올리지 않는 내 값이다. 뒤에 읽는 것이 앞의 것을 덮는다
  • 값은 빌드할 때 코드에 글자로 박힌다. 비밀번호 · 키는 VITE_ 로 두지 않는다
  • vite build --mode staging 이면 .env.staging 을 읽는다

라이브러리 빌드

앱이 아니라 npm 패키지로 낼 때는 build.lib 을 준다.

export default defineConfig({
  build: {
    lib: { entry: "src/index.js", name: "MyLib", fileName: "my-lib" },   // my-lib.js (es) · my-lib.umd.cjs
    rolldownOptions: { external: ["vue"] },                               // 묶지 않을 의존성
  },
});

예전에는

  • Vite 7 까지의 build.rollupOptions 는 build.rolldownOptions, esbuild 설정은 oxc 로 이름이 바뀌었다. 옛 이름도 알아서 바꿔 읽는다
  • 줄이기는 Oxc(JS) · Lightning CSS(CSS) 가 기본이다. esbuild 로 줄이려면 npm install -D esbuild 뒤에 build.minify: "esbuild" 를 준다
  • 예전에는 Create React App · Vue CLI(둘 다 Webpack) 로 프로젝트를 만들었다. 지금은 둘 다 Vite 를 권한다
