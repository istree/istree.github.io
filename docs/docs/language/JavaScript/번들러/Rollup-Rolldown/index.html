Rollup 은 ES 모듈(import · export) 을 따라가며 묶는 번들러다. 쓰지 않는 코드를 빼는 일(tree shaking) 을 처음 널리 쓰게 했고, 결과가 깔끔해 라이브러리를 npm 에 낼 때 많이 쓴다. 기본은 ES 모듈만 묶고, node_modules 찾기 · CommonJS · TypeScript 는 플러그인으로 더한다.

Rolldown 은 Rollup 의 설정 · 플러그인 API 를 그대로 따르게 만든 Rust 판이다. 같은 설정으로 수십 배 빠르고, Rollup 에서 플러그인이 하던 일(찾기 · CommonJS · TypeScript · JSX · 줄이기) 을 안에 갖고 있다. Vite 8 이 묶기를 Rolldown 으로 한다.

Rollup 4 Rolldown 1
언어 JavaScript Rust
설정 파일 rollup.config.js rolldown.config.js
node_modules 찾기 · CommonJS · JSON 플러그인 (@rollup/plugin-node-resolve · -commonjs · -json) 안에 있다
TypeScript · JSX 플러그인 (@rollup/plugin-typescript · babel) 안에 있다 (Oxc, 타입 검사는 안 한다)
줄이기 플러그인 (@rollup/plugin-terser) output.minify: true
값 바꿔 넣기 플러그인 (@rollup/plugin-replace) transform.define
아래 예제 빌드 시간 0.9 초 0.05 초

설치

npm install -D rollup        # Rollup
npm install -D rolldown      # Rolldown

Rollup

TypeScript 에서 npm 패키지 · CommonJS 모듈 · JSON 을 가져오는 코드를 ES 모듈 하나, 줄인 iife 하나로 묶는다.

// rollup.config.js — npx rollup -c
import { nodeResolve } from "@rollup/plugin-node-resolve";
import commonjs from "@rollup/plugin-commonjs";
import typescript from "@rollup/plugin-typescript";
import json from "@rollup/plugin-json";
import replace from "@rollup/plugin-replace";
import terser from "@rollup/plugin-terser";

export default {
  input: "src/main.ts",
  output: [
    { file: "dist/app.js", format: "es", sourcemap: true },
    { file: "dist/app.min.js", format: "iife", name: "App", plugins: [terser()] },   // 이 출력만 줄인다
  ],
  plugins: [
    nodeResolve(),                                   // node_modules 에서 찾기
    commonjs(),                                      // require · module.exports 를 ESM 으로
    json(),                                          // import pkg from "../package.json"
    typescript(),                                    // .ts — tsconfig.json 을 읽는다
    replace({ __VERSION__: JSON.stringify("1.0"), preventAssignment: true }),
  ],
};
npx rollup -c            # 설정대로
npx rollup -c -w         # 고칠 때마다 다시
npx rollup src/main.js -o dist/app.js -f es     # 설정 없이 (-o 파일 · -d 폴더 · -f 형식)
  • format 은 es · cjs · iife · umd 가 있다. 브라우저에 <script> 로 넣을 것은 iife 로 하고 name 에 전역 이름을 준다
  • 플러그인을 output 안에 두면 그 출력에만, 밖에 두면 모두에 적용된다
  • @rollup/plugin-typescript 는 typescript 와 tslib 도 설치해야 한다

Rolldown

같은 일을 플러그인 없이 한다.

// rolldown.config.js — npx rolldown -c
import { defineConfig } from "rolldown";

export default defineConfig({
  input: "src/main.ts",
  transform: { define: { __VERSION__: JSON.stringify("1.0") } },
  output: [
    { file: "dist/app.js", format: "esm", sourcemap: true },
    { file: "dist/app.min.js", format: "iife", name: "App", minify: true },
  ],
});
npx rolldown -c
npx rolldown src/main.ts -o dist/app.js -m -p node   # -m 은 줄이기, -p 는 platform
  • Rollup 플러그인은 대부분 그대로 쓴다. plugins: [replace({…})] 처럼 넣는다
  • platform 은 browser · node · neutral 이고, 출력이 cjs 면 node, 아니면 browser 가 기본이다
  • 이 예제에서는 CommonJS 를 감싸는 코드 때문에 Rollup 결과보다 조금 컸다 (줄인 것 4.7 KB · Rollup 3.5 KB)

라이브러리 내기

라이브러리는 의존성을 묶지 않고 ES 모듈 · CommonJS 둘로 낸다. 두 도구 모두 설정이 같다.

export default {
  input: "src/index.js",
  external: ["vue", /^lodash-es/],               // 묶지 않고 import 로 남긴다
  output: [
    { file: "dist/index.mjs", format: "es" },
    { file: "dist/index.cjs", format: "cjs" },
  ],
};
{
  "exports": {
    ".": { "import": "./dist/index.mjs", "require": "./dist/index.cjs" }
  }
}
  • 의존성을 package.json 의 dependencies · peerDependencies 에 두고 external 에도 적는다. 묶으면 쓰는 쪽에서 같은 패키지가 두 번 들어간다
