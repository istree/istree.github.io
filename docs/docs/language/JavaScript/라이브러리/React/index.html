React 는 화면을 컴포넌트(함수) 로 나눠 만드는 UI 라이브러리다. 컴포넌트는 props 와 상태(state) 를 받아 JSX 를 돌려주고, 상태가 바뀌면 React 가 바뀐 부분만 다시 그린다.

빠른시작

프로젝트 생성 후 실행

npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev
  • 예전에는 npx create-react-app my-app 으로 만들었다. Create React App 은 2025 년에 지원이 끝났다. 라우팅 · 서버 렌더링까지 필요하면 Next.js · React Router 같은 프레임워크로 시작한다
  • 빌드는 npm run build 이고, dist 에 결과물이 나온다

문제해결

Check failed: allocator->SetPermissions ... 오류가 나면 node 의 버전을 15.9 이상으로 높인다. (애플 실리콘 맥에서 옛 Node 로 돌릴 때 났다)

컴포넌트 파라미터

부모가 넘긴 속성(props) 을 객체 하나로 받는다. 구조 분해로 받고 기본값을 준다.

function Hello({ name = "world", children }) {
  return <h1>Hello {name} {children}</h1>;
}

<Hello name="React">!</Hello>       // children 은 태그 사이의 내용이다
  • props 는 읽기만 한다. 바꿀 값은 부모의 상태로 두고, 바꾸는 함수를 props 로 내려 준다: <Counter value={n} onChange={setN} />
  • 목록은 map 으로 그리고, 항목마다 바뀌지 않는 key 를 준다: items.map(item => <Row key={item.id} {...item} />)

useState

컴포넌트가 기억하는 값이다. 바꾸면 컴포넌트를 다시 그린다.

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>;
}
  • 이전 값으로 계산할 때는 함수를 넘긴다: setCount(c => c + 1)
  • 객체 · 배열은 고치지 않고 새로 만들어 넣는다: setUser({ ...user, name }) · setList([...list, item])

useEffect

그린 뒤에 할 일(데이터 받기 · 구독 · 타이머) 을 둔다. 두 번째 인자의 값이 바뀔 때만 다시 돈다.

import { useEffect, useState } from "react";

function User({ id }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    const controller = new AbortController();
    fetch(`/api/users/${id}`, { signal: controller.signal })
      .then(res => res.json())
      .then(setUser)
      .catch(() => {});
    return () => controller.abort();     // 정리 — id 가 바뀌거나 사라질 때
  }, [id]);                              // id 가 바뀔 때만

  return user ? <p>{user.name}</p> : <p>읽는 중</p>;
}
  • [] 를 주면 처음 한 번만 돈다. 빼면 그릴 때마다 돈다
  • 개발 모드(StrictMode) 에서는 확인하려고 두 번 돈다. 정리 함수가 맞으면 문제없다
  • props · 상태로 계산만 하는 값은 effect 없이 그리는 중에 계산한다

프라그먼트

JSX 는 맨 바깥이 하나여야 한다. 감쌀 태그를 더하고 싶지 않으면 프라그먼트로 감싼다.

function Columns() {
  return (
    <>
      <td>이름</td>
      <td>나이</td>
    </>
  );
}

// key 가 필요하면 Fragment 로 쓴다
items.map(item => <Fragment key={item.id}><dt>{item.term}</dt><dd>{item.desc}</dd></Fragment>)

CSS

import "./App.css";                          // 전역 CSS — 클래스는 className 으로
import styles from "./Button.module.css";    // CSS 모듈 — 이 파일 안에서만 쓰는 클래스

<div className="app">…</div>
<button className={styles.primary}>저장</button>
<p style={{ color: "red", fontSize: 14 }}>경고</p>         // 인라인 — 객체, 속성은 camelCase
<li className={done ? "item done" : "item"}>{text}</li>   // 조건에 따라 클래스

부트스트랩

CSS 만 쓰면 패키지를 설치하고 진입 파일에서 가져온다.

npm install bootstrap
// main.jsx
import "bootstrap/dist/css/bootstrap.min.css";

<button className="btn btn-primary">저장</button>
  • 모달 · 드롭다운처럼 동작이 있는 것은 React Bootstrap 컴포넌트를 쓴다: import { Button, Modal } from "react-bootstrap";

외부 라이브러리

DOM 을 직접 다루는 라이브러리(D3 · 차트 · 에디터) 는 useRef 로 DOM 을 받아 effect 안에서 붙이고, 정리 함수에서 뗀다.

import { useEffect, useRef } from "react";

function Chart({ data }) {
  const ref = useRef(null);
  useEffect(() => {
    const chart = createChart(ref.current, data);   // 라이브러리가 ref.current 안을 그린다
    return () => chart.destroy();
  }, [data]);
  return <div ref={ref} />;
}
