대부분의 예제는 node 로 프로젝트를 만들어 빌드하지만, 단순히 실행만 해 보기 위해서이므로 HTML 한 장으로 다음과 같이 작성한다. JSX 는 브라우저에서 Babel 이 바꾼다.

main.js

const element = (
  <div>
    <h1>Hello, world!</h1>
  </div>
);

ReactDOM.createRoot(document.getElementById('hello')).render(element);
  • React 17 까지는 ReactDOM.render(element, document.getElementById('hello')) 로 그렸다. React 19 에서 빠졌다

index.html

<html>
<head>
  <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
  <script src="https://unpkg.com/react@18/umd/react.development.js"></script>
  <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
  <script type="text/babel" src="main.js"></script>
</head>
<body>
  <div id="hello"></div>
</body>
</html>
  • 한 파일로 바로 쓰는 UMD 빌드는 React 18 까지 있다. React 19 는 빠르게 시작하기 처럼 Vite 로 프로젝트를 만든다

실행

file:// 로 열면 main.js 를 읽지 못한다. 소스가 있는 디렉토리에서 웹 서버를 띄운다.

python3 -m http.server      # 또는 npx serve

웹브라우저로 확인한다. http://localhost:8000
