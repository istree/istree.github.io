on 으로 이벤트를 달고 off 로 뗀다. 처리 함수에서 this 는 이벤트가 걸린 DOM 요소이고, 첫 인자는 브라우저마다 다른 점을 맞춘 이벤트 객체다.

달기 · 떼기

$("#save").on("click", function (e) {
  e.preventDefault();               // 기본 동작(링크 이동 · 폼 제출) 막기
  $(this).prop("disabled", true);   // this 는 누른 요소
});

$("#search").on("input", e => console.log(e.target.value));
$("#name").on("keydown", e => { if (e.key === "Enter") save(); });
$("#ok").one("click", () => …);     // 한 번만
$("#save").off("click");            // 떼기
$("#save").trigger("click");        // 코드로 일으키기
  • 화살표 함수로 넘기면 this 가 요소가 아니다. e.currentTarget 을 쓴다
  • e.stopPropagation() 은 위 요소로 올라가지 않게 막는다. 처리 함수에서 return false 를 하면 preventDefault 와 stopPropagation 을 함께 한다
  • 예전(1.7 전) 에는 bind · live · delegate 를 썼다. 지금은 모두 on 이다. .click(f) 같은 줄임 메서드도 3.3 부터 쓰지 않기로 했다

위임

부모에 한 번 달고, 두 번째 인자의 선택자에 맞는 자식에서 일어난 이벤트만 받는다.

$("#list").on("click", "li", function () {
  $(this).toggleClass("done");      // this 는 누른 li
});

$("#list").append("<li>새 항목</li>");   // 나중에 붙인 li 에도 걸린다
  • 목록처럼 요소가 자주 바뀌는 곳은 위임으로 단다. 요소마다 다는 것보다 한 번이면 되고, 새로 붙인 요소에도 걸린다
  • 위임할 부모는 가까운 것으로 한다. $(document).on(…) 은 페이지의 모든 클릭을 검사한다

이름공간

이름에 점을 붙이면 묶어서 뗄 수 있다. 플러그인이 단 것만 뗄 때 쓴다.

$("#list").on("click.myPlugin", "li", f);
$(window).on("resize.myPlugin", g);

$("#list").off(".myPlugin");        // myPlugin 이 단 것만 뗀다

직접 만든 이벤트

이름을 지어 일으키고, 값은 배열로 넘긴다.

$("#cart").on("cart:add", (e, item, count) => console.log(item, count));
$("#cart").trigger("cart:add", ["사과", 2]);
  • 위 요소로 올라가므로 위에서 위임으로 받아도 된다

4 에서 바뀐 것

  • 포커스 이벤트 순서가 표준(blur → focusout → focus → focusin) 이 되었다. 예전에는 focusout → blur → focusin → focus 였다
