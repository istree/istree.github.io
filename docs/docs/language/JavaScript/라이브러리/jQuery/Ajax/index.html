jQuery 의 Ajax 함수는 jqXHR 을 돌려준다. jqXHR 은 Deferred 라서 .done() · .fail() · .always() 로 결과를 받고, jQuery 3 부터는 Promise 와 맞물리므로 await 로도 기다린다.

요청 보내기

$.getJSON("/api/users", { page: 1 })          // GET + JSON, 두 번째 인자는 쿼리
  .done(users => console.log(users))
  .fail((xhr, status, err) => console.error(status, err))
  .always(() => $("#spinner").hide());

$.post("/api/users", { name: "geon" });       // 폼 방식(x-www-form-urlencoded) 으로 보낸다

$.ajax({
  url: "/api/users/3",
  method: "PUT",
  contentType: "application/json",            // JSON 으로 보내려면 둘 다 준다
  data: JSON.stringify({ name: "geon" }),
  dataType: "json",                           // 받는 형식
  timeout: 5000,
});

// 파일 올리기
const form = new FormData($("#upload")[0]);
$.ajax({ url: "/upload", method: "POST", data: form, processData: false, contentType: false });

// 받은 HTML 을 요소 안에 넣기
$("#detail").load("/users/3 #profile");       // 응답에서 #profile 부분만
  • 모든 요청에 같은 헤더(토큰) 를 붙이려면 $.ajaxSetup({ headers: { Authorization: Bearer ${token} } }) 를 한 번 부른다
  • 예전에는 .success() · .error() 를 썼다. 3 에서 빠졌고 .done() · .fail() 을 쓴다
  • 4 에서는 JSON 요청을 JSONP 로 바꿔 주지 않는다. JSONP 가 필요하면 dataType: "jsonp" 를 직접 준다
  • 4 에서는 받은 스크립트를 dataType: "script" 를 주지 않으면 실행하지 않는다

여러 요청 기다리기

Promise.all 로 기다리면 data 만 온다.

const results = await Promise.all(urls.map(url => $.get(url)));
results.forEach(data => console.log(data));

$.when 으로도 기다린다. 이때 done 은 요청마다 [data, status, xhr] 를 따로 받는다.

$.when($.get("a.txt"), $.get("b.txt"))
  .done(([a], [b]) => console.log(a, b));

$.when(...urls.map(url => $.get(url)))              // 배열은 전개로 넘긴다
  .done((...results) => {
    for (const [data] of results) console.log(data);
  });
  • 요청이 하나뿐이면 done 이 [data, status, xhr] 배열이 아니라 data, status, xhr 를 따로 받는다. 개수가 바뀌는 목록이면 Promise.all 이 안전하다
  • 예전에는 배열을 $.when.apply($, acts) 로 넘기고 arguments 를 배열로 바꿔 썼다 (Stack Overflow)
  • 직접 만든 비동기 일은 Deferred 대신 new Promise 로 만든다. slim 판에는 Deferred 가 없다
