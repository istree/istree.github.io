$ 에 선택자를 주면 맞는 요소를 묶음(jQuery 객체) 으로 돌려준다. 묶음의 메서드는 묶음 안의 요소 모두에 적용되고, 다시 묶음을 돌려주므로 줄줄이 연결한다.

불러오기

<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>
<script>
  $(() => {                     // 문서를 다 읽은 뒤 실행 (= $(document).ready)
    $("h1").text("준비됨");
  });
</script>
// npm install jquery — 번들러(Vite · webpack) 에서
import $ from "jquery";
  • slim 판(jquery-4.0.0.slim.min.js) 은 Ajax · 효과(animate) · Deferred 를 뺀 판이다. 선택 · 이벤트만 쓰면 이것으로 충분하다
  • 4 에서 지원을 끊은 것: IE 10 이하, Edge Legacy, Android Browser. IE 11 은 아직 지원한다
  • 4 에서 빠진 함수는 표준으로 바꾼다: $.trim → str.trim(), $.isArray → Array.isArray, $.parseJSON → JSON.parse, $.now → Date.now(), $.isFunction → typeof f === "function"
  • 3 에서 4 로 올릴 때는 jQuery Migrate 를 함께 불러 콘솔 경고로 바꿀 곳을 찾는다

선택

$("#list li.active")               // CSS 선택자
$("#list").find("li")              // 안에서 찾기
$(this).closest("tr")              // 위로 올라가며 처음 맞는 것
$("li").parent()                   // .children() · .siblings() 도 있다
$("li").eq(2)                      // 묶음에서 하나 — .first() · .last() 도 있다
$("li").filter(".done")            // 묶음을 거르기, .not(".done") 은 반대
$("li").is(".done")                // 하나라도 맞으면 true
  • 찾은 것이 없어도 오류가 나지 않고 빈 묶음이 된다. 있는지는 .length 로 본다
  • 묶음의 DOM 요소는 $("li")[0] 또는 .get(0) 으로 꺼낸다. DOM 요소를 묶음으로 바꾸려면 $(el) 로 감싼다

조작

$("#title").text("제목");           // 글자 (HTML 은 그대로 글자로 들어간다)
$("#box").html("<b>굵게</b>");      // HTML
$("#name").val();                   // 입력값 읽기, .val("값") 은 쓰기
$("a").attr("href");                // HTML 속성
$("#agree").prop("checked");        // DOM 속성 — checked · disabled · selected 는 prop 으로
$("#item").data("id");              // data-id="3" → 3 (숫자로 바꿔 준다)

$("#box").addClass("on").removeClass("off").toggleClass("open");
$("#box").css({ width: 100, color: "red" });   // 숫자는 px 로 붙인다
$("#box").toggle();                 // .show() · .hide() 도 있다

$("<li>", { text: "새 항목", class: "item" }).appendTo("#list");   // 만들어 붙이기
$("#list").append("<li>끝</li>").prepend("<li>처음</li>");
$(".item").remove();                // 지우기 (붙은 이벤트 · data 도 지운다)
$("#list").empty();                 // 안만 비우기
  • 읽는 메서드(text() · val() · attr("x")) 는 묶음의 첫 요소 값을, 쓰는 메서드는 묶음 모두에 적용한다
  • 묶음마다 다른 값을 주려면 함수를 준다: $("li").text((i, old) => ${i + 1}. ${old})
  • 묶음을 돌 때는 .each((i, el) => …) 를 쓴다. el 은 DOM 요소라서 jQuery 메서드를 쓰려면 $(el) 로 감싼다
  • 사용자 입력을 넣을 때는 html() 대신 text() 를 쓴다. html() 은 스크립트가 들어갈 수 있다
  • 폼 값을 한 번에 꺼내려면 $("form").serialize()(a=1&b=2) 나 serializeArray()([{ name, value }]) 를 쓴다

플러그인

$.fn 에 함수를 붙이면 모든 묶음에서 쓰는 메서드가 된다. this 는 묶음이고, this 를 돌려주면 연결해서 쓸 수 있다.

$.fn.highlight = function (options) {
  const opts = { color: "yellow", ...options };    // 기본값 + 받은 값
  return this.each(function () {
    $(this).css("background-color", opts.color);
  });
};

$("p.note").highlight({ color: "#ffe" }).fadeIn();
  • 다른 라이브러리가 $ 를 쓰면 즉시 실행 함수로 감싸 안에서만 $ 로 부른다: (function ($) { … })(jQuery);
  • $.noConflict() 를 부르면 $ 를 앞에 있던 라이브러리에 돌려주고, jQuery 는 jQuery 로만 부른다
