JavaScript 는 표준 라이브러리가 작아서, 날짜 · 차트 · 상태 관리 · 에디터 같은 일은 npm 패키지를 가져다 쓴다. 같은 일을 하는 패키지가 여럿이고 유행도 빨리 바뀐다. 고를 때는 최근에 갱신했는지(npm 의 마지막 판 날짜), 크기, 쓰는 프레임워크와 맞는지를 본다. 아래는 분류마다 많이 쓰고 지금도 관리되는 것을 모았다 (2026-11 기준).

유틸리티

  • Lodash — 배열 · 객체 · 함수 도우미 모음. 지금은 표준 메서드로 대부분 된다
  • es-toolkit — Lodash 와 같은 함수를 더 작고 빠르게 만든 것. es-toolkit/compat 은 Lodash 와 똑같이 돈다

날짜

  • Temporal — 표준 날짜 · 시간 API. Chrome 144 · Firefox 139 · Node 26 · Deno 2.7 부터 들어 있고(Safari 는 아직), 없는 곳은 temporal-polyfill 을 쓴다
  • date-fns — Date 를 다루는 함수 모음. 쓰는 함수만 묶인다
  • Day.js — Moment.js 와 같은 API 를 2 KB 로 만든 것
  • Luxon — 시간대 · 국제화를 잘 다루는 날짜 객체. Moment.js 팀이 만들었다

차트 · 시각화

  • Chart.js — canvas 로 그리는 막대 · 선 · 원 차트. 설정 객체만 주면 된다
  • Apache ECharts — 차트 종류가 많고 데이터가 커도 빠르다. 지도 · 대시보드에 쓴다
  • Observable Plot — D3 팀이 만든 짧게 쓰는 차트. 탐색용 그래프에 좋다
  • Mermaid — 글자로 적은 흐름도 · 순서도 · 클래스도를 그림으로 바꾼다
  • Three.js — WebGL · WebGPU 로 3D 장면을 그린다

지도

  • Leaflet — 타일 지도 · 마커 · 팝업. 작고 쓰기 쉽다
  • MapLibre GL JS — 벡터 타일 지도. 회전 · 기울이기 · 스타일을 바꾼다

상태 관리

  • Zustand — 훅 하나로 쓰는 작은 저장소 (React)
  • Redux Toolkit — Redux 를 줄여 쓰는 공식 도구. 큰 앱 · 시간 여행 디버깅
  • Jotai — 값 하나(atom) 씩 나눠 두는 상태 (React)
  • MobX — 객체를 지켜보다 바뀌면 화면을 다시 그린다
  • Recoil 은 개발이 멈췄고 저장소도 보관(archived) 되었다. Jotai 로 옮긴다

서버 데이터 · 요청

  • TanStack Query — 서버에서 받은 값의 캐시 · 다시 받기 · 로딩 상태 (React · Vue · Svelte · Solid)
  • ky — fetch 를 감싼 작은 요청 라이브러리. 재시도 · 시간 제한 · JSON
  • axios — 요청 · 응답 가로채기(interceptor), 업로드 진행률. 오래된 코드에 많다

검증 · 폼

  • Zod — 스키마로 값을 검사하고 TypeScript 타입을 만든다
  • Valibot — Zod 와 같은 일을 함수 조각으로 해 묶은 크기가 작다
  • React Hook Form — 다시 그리기를 줄인 폼 상태 · 검증 (React)

표

  • TanStack Table — 정렬 · 거르기 · 페이지 나누기 로직만 주고 화면은 직접 그린다
  • AG Grid — 엑셀 같은 데이터 표. 행이 많아도 빠르다 (기능 일부는 유료)
  • DataTables — <table> 에 붙이는 정렬 · 검색 · 페이지 (jQuery)

에디터

  • CodeMirror — 브라우저 코드 에디터. 작고 고치기 쉽다
  • Monaco Editor — VS Code 의 에디터. 자동 완성 · 비교 보기
  • Tiptap — ProseMirror 를 바탕으로 한 서식 있는 글 에디터

마크다운 · 코드 강조

  • marked — 빠른 마크다운 → HTML
  • markdown-it — 플러그인으로 문법을 더하는 마크다운 파서
  • Shiki — VS Code 와 같은 문법 강조. 빌드할 때 HTML 로 만든다
  • Prism — 브라우저에서 도는 작은 코드 강조

애니메이션

  • GSAP — 타임라인 · 스크롤에 맞춘 움직임. 무료로 쓴다
  • Motion — 요소 · React 컴포넌트에 붙이는 움직임 (옛 이름 Framer Motion)
  • Anime.js — CSS · SVG · 객체 값을 움직이는 가벼운 라이브러리

HTML 에 붙여 쓰기

  • htmx — HTML 속성으로 요청을 보내고 받은 HTML 을 끼운다. 서버가 화면을 만든다
  • Alpine.js — HTML 속성으로 쓰는 작은 반응형. jQuery 대신 쓴다
  • Lit — 웹 컴포넌트(Custom Elements) 를 짧게 만든다

파일 · 데이터

  • PDF.js — 브라우저에서 PDF 를 그린다. Firefox 의 PDF 보기
  • Papa Parse — 큰 CSV 를 나눠 읽는 파서
  • ExcelJS — xlsx 파일 읽기 · 쓰기 · 서식

그 밖

  • DOMPurify — 남이 넣은 HTML 에서 스크립트를 걷어 낸다. innerHTML 앞에 쓴다
  • Fuse.js — 오타가 있어도 찾는 퍼지 검색
  • SortableJS — 목록을 끌어서 순서 바꾸기
  • i18next — 다국어 문자열 · 복수형
  • Immer — 고치는 것처럼 써서 새 객체를 만든다
  • npm trends — 패키지 내려받기 수를 견준다
  • bundlephobia — 패키지를 넣으면 크기가 얼마나 느는지 본다
