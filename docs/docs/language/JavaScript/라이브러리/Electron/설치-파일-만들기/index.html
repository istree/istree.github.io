electron-builder 로 앱을 운영체제별 설치 파일(macOS dmg · Windows nsis · Linux AppImage 등) 로 만든다. 앱 만들기 의 앱을 그대로 쓴다.

electron-builder 설치

npm install --save-dev electron-builder

package.json

플랫폼별 빌드 명령어와 빌드 옵션(build) 을 추가한다.

{
  "name": "your-app",
  "version": "0.1.0",
  "main": "main.js",
  "scripts": {
    "start": "electron .",
    "pack": "electron-builder --dir",
    "build:mac": "electron-builder --mac",
    "build:win": "electron-builder --win --x64 --arm64",
    "build:linux": "electron-builder --linux"
  },
  "devDependencies": {
    "electron": "^45.2.2",
    "electron-builder": "^26.18.0"
  },
  "build": {
    "productName": "HelloElectron",
    "appId": "com.electron.hello",
    "asar": true,
    "files": ["main.js", "preload.js", "index.html", "renderer.js"],
    "directories": {
      "buildResources": "resources/installer",
      "output": "dist"
    },
    "protocols": {
      "name": "helloElectron",
      "schemes": ["helloelectron"]
    },
    "mac": {
      "target": ["dmg", "zip"],
      "category": "public.app-category.developer-tools"
    },
    "win": {
      "target": ["nsis", "zip"]
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true
    },
    "linux": {
      "target": ["AppImage", "deb", "tar.gz"]
    }
  }
}
  • files — 앱에 넣을 파일이다. 빼면 프로젝트 전체가 들어가므로 정해 준다. devDependencies 는 넣지 않고, dependencies 는 알아서 넣는다
  • asar — 앱 파일을 한 덩어리(app.asar) 로 묶는다
  • protocols — helloelectron://… 주소를 누르면 앱이 열린다
  • 아이콘은 buildResources 폴더에 icon.icns(mac) · icon.ico(win) · icon.png(linux, 512 이상) 로 두면 알아서 쓴다. 1024 크기 icon.png 하나만 두어도 나머지를 만들어 준다
  • 예전 글(electron-builder 20) 의 build --mac 명령은 지금 electron-builder --mac 이다
  • 32 비트(--ia32) 윈도우 빌드는 Electron 43 까지만 된다

빌드 실행

설치 파일 없이 앱 폴더만 만들어 빨리 확인한다.

npm run pack          # dist/mac-arm64/HelloElectron.app 등

Mac

npm run build:mac

Windows

npm run build:win

Linux

npm run build:linux

결과물은 dist 에 나온다.

  • 아키텍처를 정하려면 --x64 · --arm64 를 붙인다. mac 에서 인텔 · 애플 실리콘 둘 다 도는 앱은 --universal 이다
  • 버전은 package.json 의 version 을 쓴다. 파일 이름에도 붙는다

멀티플랫폼 빌드

하나의 OS 에서 다른 OS 용으로 빌드할 수도 있지만, 모든 플랫폼을 한 곳에서 빌드한다고 기대하지 않는다.

  • macOS 용(서명 · 공증 포함) 은 macOS 에서만 만든다
  • Windows · Linux 용은 Docker 이미지 electronuserland/builder:wine 안에서 만들 수 있다. 네이티브 모듈이 있으면 그 플랫폼에서 만든다
  • 보통은 GitHub Actions 같은 CI 에서 OS 마다 따로 돌린다

한 번에 세 플랫폼을 모두 시도하려면 다음과 같이 한다.

npx electron-builder -mwl

서명

서명하지 않은 앱은 처음 열 때 경고가 나온다.

  • macOS — Apple Developer 인증서로 서명하고 공증(notarize) 해야 Gatekeeper 경고 없이 열린다. 키체인에 인증서가 있으면 알아서 서명한다. 서명 없이 시험할 때는 CSC_IDENTITY_AUTO_DISCOVERY=false 를 준다
  • Windows — 코드 서명 인증서가 없으면 SmartScreen 경고가 나온다
