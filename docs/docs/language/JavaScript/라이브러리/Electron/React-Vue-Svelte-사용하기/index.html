React · Vue · Svelte 처럼 Vite 로 만든 웹 앱을 Electron 창에 띄운다. 설정은 셋이 같으므로 React 로 설명하고, 다른 점은 Vue · Svelte 에 정리했다. 개발할 때는 Vite 개발 서버 주소를 열어 고친 것이 바로 보이고, 배포할 때는 빌드한 dist/index.html 을 연다.

때 Electron 이 여는 것 실행
개발 http://localhost:5173 (Vite 서버) npm start
빌드 확인 dist/index.html npm run build → npx electron .
배포 앱 안의 dist/index.html npm run electron:build

프로젝트 생성

React 앱을 생성하거나 기존 앱으로 이동한다.

npm create vite@latest my-app -- --template react
cd my-app
npm install
  • 예전에는 npx create-react-app my-app 으로 만들었다. 지원이 끝났으므로 Vite 를 쓴다

Electron 추가

설치

npm install -D electron electron-builder concurrently wait-on cross-env

electron/main.cjs

메인 프로세스 파일을 만든다. Vite 프로젝트의 package.json 은 "type": "module" 이라서 .js 를 ES 모듈로 읽는다. 메인 · preload 는 .cjs 로 두어 CommonJS(require) 로 쓴다.

const { app, BrowserWindow, ipcMain, dialog } = require("electron");
const path = require("node:path");

const devUrl = process.env.VITE_DEV_SERVER_URL;

function createWindow() {
  const win = new BrowserWindow({
    width: 1000,
    height: 700,
    show: false,
    webPreferences: {
      preload: path.join(__dirname, "preload.cjs"),
    },
  });

  if (devUrl) {
    win.loadURL(devUrl);                   // 개발: Vite 서버
    win.webContents.openDevTools();
  } else {
    win.loadFile(path.join(__dirname, "../dist/index.html"));   // 빌드한 파일
  }

  win.once("ready-to-show", () => win.show());   // 다 그린 뒤에 보여 흰 화면이 번쩍이지 않는다
}

ipcMain.handle("dialog:openFile", async () => {
  const { canceled, filePaths } = await dialog.showOpenDialog({});
  return canceled ? null : filePaths[0];
});

app.whenReady().then(() => {
  createWindow();
  app.on("activate", () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow();
  });
});

app.on("window-all-closed", () => {
  if (process.platform !== "darwin") app.quit();
});
  • 예전 글은 mode=start · mode=dev 로 나눴다. 여기서는 개발 서버 주소(VITE_DEV_SERVER_URL) 가 있으면 개발, 없으면 빌드한 파일로 나눈다

electron/preload.cjs

React 에서 Electron 기능을 쓰기 위해 preload 에서 필요한 함수만 내준다.

const { contextBridge, ipcRenderer } = require("electron");

contextBridge.exposeInMainWorld("api", {
  openFile: () => ipcRenderer.invoke("dialog:openFile"),
});
  • 예전에는 window.ipcRenderer = require('electron').ipcRenderer 와 enableRemoteModule: true 로 했다. contextIsolation 이 기본으로 켜진 뒤로는 preload 의 window 와 페이지의 window 가 달라 이 방법이 통하지 않고, remote 모듈은 Electron 14 에서 빠졌다

vite.config.js

빌드한 파일을 file:// 로 열면 /assets/… 같은 절대 경로를 찾지 못한다. base 를 상대 경로로 바꾼다. (CRA 의 "homepage": "./" 와 같다)

import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react()],
  base: "./",
  server: { port: 5173, strictPort: true },   // 포트가 바뀌면 Electron 이 엉뚱한 곳을 기다린다
});

package.json

main 으로 메인 파일을 연결하고 scripts 를 추가한다.

{
  "name": "my-app",
  "version": "0.1.0",
  "type": "module",
  "main": "electron/main.cjs",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "electron:dev": "wait-on tcp:5173 && cross-env VITE_DEV_SERVER_URL=http://localhost:5173 electron .",
    "start": "concurrently -k \"npm run dev\" \"npm run electron:dev\"",
    "electron:build": "vite build && electron-builder"
  }
}

concurrently

개발할 때는 Vite 서버의 React 앱을 Electron 창으로 보는 방식이기 때문에 React(Vite) 와 Electron 을 동시에 실행해야 한다. 이를 위해 concurrently 를 쓴다.

npm start
  • -k 를 주면 Electron 창을 닫을 때 Vite 서버도 같이 끝난다

wait-on

Electron 이 Vite 서버가 뜰 때까지 기다린 뒤 주소를 열도록 wait-on 을 쓴다. tcp:5173 은 그 포트가 열릴 때까지 기다린다.

cross-env

VITE_DEV_SERVER_URL=… electron . 처럼 명령 앞에 환경 변수를 두는 문법은 Windows 에서 안 된다. cross-env 가 운영체제마다 맞게 넣어 준다.

브라우저 숨김

CRA 는 실행할 때 브라우저를 열어서 .env 에 BROWSER=none 을 두었다. Vite 는 기본으로 브라우저를 열지 않으므로 필요 없다.

React 에서 쓰기

preload 가 내준 window.api 를 부른다. 브라우저(npm run dev 만) 로 열면 window.api 가 없으므로 확인하고 쓴다.

import { useState } from "react";

function OpenButton() {
  const [file, setFile] = useState(null);

  async function open() {
    if (!window.api) return alert("Electron 에서만 됩니다");
    setFile(await window.api.openFile());
  }

  return <button onClick={open}>{file ?? "파일 열기"}</button>;
}

빌드

package.json 에 electron-builder 설정을 추가한다. 앱에 넣을 것은 빌드한 화면(dist) 과 메인 · preload(electron) 다.

  "build": {
    "appId": "com.example.my-app",
    "productName": "MyApp",
    "files": [
      "dist/**/*",
      "electron/**/*"
    ],
    "directories": {
      "output": "release"
    }
  }

빌드 실행

npm run electron:build

빌드에 성공하면 release 디렉토리에 결과물이 저장된다. Vite 의 dist 와 겹치지 않게 출력 디렉토리를 release 로 바꿨다. 설치 파일 설정은 설치 파일 만들기 에 정리했다.

Vue · Svelte

Vite 로 만든 Vue · Svelte 앱도 위 설정 그대로 Electron 에 붙인다. electron/ 의 main · preload, package.json 의 main · scripts · build 는 같고, 다른 것은 셋이다.

React Vue Svelte
프로젝트 생성 --template react npm create vue@latest 또는 --template vue --template svelte
vite.config.js 플러그인 react() vue() svelte()
컴포넌트 파일 .jsx .vue .svelte
  • vite.config.js 에 base: "./" 를 더하는 것도 같다
  • 컴포넌트에서 window.api 를 부르는 것도 같다
<!-- Vue -->
<script setup>
import { ref } from "vue";
const file = ref(null);
async function open() { file.value = await window.api.openFile(); }
</script>

<template>
  <button @click="open">{{ file ?? "파일 열기" }}</button>
</template>
<!-- Svelte -->
<script>
  let file = $state(null);
  async function open() { file = await window.api.openFile(); }
</script>

<button onclick={open}>{file ?? "파일 열기"}</button>
  • 예전 Vue CLI 프로젝트는 vue add electron-builder 플러그인(background.js · app:// 프로토콜) 을 썼고, 예전 Svelte 템플릿은 rollup + sirv 서버(3080 포트) 를 wait-on 으로 기다렸다. 둘 다 Vite 로 바꾸면 위 한 가지 설정으로 모인다

electron-vite

위 설정(동시 실행 · 기다리기 · 경로 · 빌드) 을 한 도구로 묶은 것이 electron-vite 다. 처음부터 만든다면 이것이 간단하다.

npm create @quick-start/electron@latest my-app -- --template react   # vue · svelte
