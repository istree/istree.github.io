Electron 은 Chromium(화면) 과 Node.js(파일 · 시스템) 를 묶어 웹 기술로 데스크톱 앱을 만드는 프레임워크다. 창을 만들고 앱을 관리하는 메인 프로세스 하나와, 창마다 웹 페이지를 그리는 렌더러 프로세스가 있다.

  • 앱 만들기 — main · preload · 페이지, 메인과 주고받기, 보안 경고
  • React · Vue · Svelte 사용하기 — Vite 로 만든 웹 앱을 창에 띄우기
  • 설치 파일 만들기 — electron-builder 로 dmg · nsis · AppImage
