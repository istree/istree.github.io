Electron 앱은 Node.js 앱이다. Node.js 모듈과 마찬가지로 시작점은 package.json 이고, main 에 적은 파일(메인 프로세스) 이 창을 만든다. 창 안의 웹 페이지(렌더러) 는 브라우저처럼 돌고, 둘 사이는 preload 스크립트가 연결한다.

대부분의 Electron 앱은 다음과 같은 구조를 갖는다.

파일 도는 곳 하는 일
package.json — main 으로 시작 파일을 알려 준다
main.js 메인 프로세스 (Node.js) 앱 수명 · 창 · 메뉴 · 파일 · 시스템
preload.js 창마다, 페이지보다 먼저 메인 기능 중 페이지에 내줄 것만 window 에 단다
index.html 렌더러 (Chromium) 화면. Node API 는 쓰지 않는다 
flowchart LR
  M["main.js<br/>메인 프로세스"] -- "창 만들기" --> R["index.html<br/>렌더러"]
  P["preload.js"] -- "window.api" --> R
  R -- "ipcRenderer.invoke" --> M

초기화

빈 폴더를 만든 뒤 폴더 안으로 이동해서 다음 명령어를 실행한다.

npm init -y
npm install --save-dev electron

npm 이 기본 package.json 을 만들고 Electron 을 개발 의존성으로 설치한다.

package.json

main 을 main.js 로 바꾸고, scripts 에 "start": "electron ." 을 추가한다.

{
  "name": "your-app",
  "version": "1.0.0",
  "main": "main.js",
  "scripts": {
    "start": "electron ."
  },
  "devDependencies": {
    "electron": "^45.2.2"
  }
}
  • npm init -y 는 "main": "index.js" 로 만든다. 바꾸지 않으면 실행할 때 오류가 난다. 문제해결 에 정리했다

main.js

다음은 창을 여는 애플리케이션이다.

const { app, BrowserWindow } = require("electron");
const path = require("node:path");

function createWindow() {
  const win = new BrowserWindow({
    width: 800,
    height: 600,
    webPreferences: {
      preload: path.join(__dirname, "preload.js"),
    },
  });
  win.loadFile("index.html");
}

app.whenReady().then(() => {
  createWindow();

  // macOS: 창이 모두 닫혀도 앱은 남는다. 독 아이콘을 누르면 창을 다시 연다
  app.on("activate", () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow();
  });
});

// macOS 가 아니면 창이 모두 닫힐 때 끝낸다 (macOS 는 Cmd+Q 로 끝낸다)
app.on("window-all-closed", () => {
  if (process.platform !== "darwin") app.quit();
});
  • 예전에는 app.on('ready', createWindow) 로 썼다. 지금은 Promise 를 돌려주는 app.whenReady() 를 쓴다
  • contextIsolation(페이지와 preload 를 떼어 둠) 과 sandbox 는 기본으로 켜져 있다. 끄지 않는다

preload.js

페이지에 내줄 것만 contextBridge 로 단다. 여기서는 버전 정보를 내준다.

const { contextBridge } = require("electron");

contextBridge.exposeInMainWorld("versions", {
  node: () => process.versions.node,
  chrome: () => process.versions.chrome,
  electron: () => process.versions.electron,
});

index.html

보여 주고 싶은 웹 페이지를 다음과 같이 만든다. CSP 를 넣어 두면 개발 중 보안 경고가 나오지 않는다.

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self'">
    <title>Hello World!</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p id="info"></p>
    <script src="./renderer.js"></script>
  </body>
</html>
// renderer.js
document.getElementById("info").textContent =
  `Chrome ${versions.chrome()} · Node.js ${versions.node()} · Electron ${versions.electron()}`;

실행

다음 명령어를 실행하면 앱이 동작한다.

npm start

메인과 주고받기

페이지에서 파일 열기 대화상자처럼 메인만 할 수 있는 일을 부탁할 때는 ipcMain.handle · ipcRenderer.invoke 로 주고받는다. 결과는 Promise 로 돌아온다.

// main.js
const { ipcMain, dialog } = require("electron");

ipcMain.handle("dialog:openFile", async () => {
  const { canceled, filePaths } = await dialog.showOpenDialog({});
  return canceled ? null : filePaths[0];
});
// preload.js
const { contextBridge, ipcRenderer } = require("electron");

contextBridge.exposeInMainWorld("api", {
  openFile: () => ipcRenderer.invoke("dialog:openFile"),
});
// renderer.js
button.addEventListener("click", async () => {
  const filePath = await window.api.openFile();
});
  • ipcRenderer 를 통째로 window 에 달지 않는다. 페이지가 아무 채널이나 부를 수 있게 된다
  • 메인에서 페이지로 알릴 때는 win.webContents.send("채널", 값) 을 쓰고, preload 에서 ipcRenderer.on 으로 받아 콜백으로 넘긴다

개발자 도구

창을 만든 뒤 연다. 개발할 때만 열도록 패키징 여부로 나눈다.

if (!app.isPackaged) win.webContents.openDevTools();

문제해결

Unable to find Electron app

npm start 에서 Unable to find Electron app … Cannot find module '…/index.js' 오류가 나면 package.json 의 main 과 실제 파일 이름이 다른 것이다. npm init -y 는 "main": "index.js" 로 만든다.

Electron Security Warning

개발 중 개발자 도구 콘솔에 Electron Security Warning (Insecure Content-Security-Policy) 같은 경고가 나온다. 패키징한 앱에서는 나오지 않지만, 경고가 가리키는 설정을 고친다.

  • CSP 가 없다 — index.html 에 넣는다 (위 index.html 처럼) 
    <meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self'">
  • nodeIntegration: true · contextIsolation: false — 렌더러(웹 페이지) 가 Node API 를 바로 쓰는 설정이다. 옛 예제 · 템플릿에 많다. 지우고(기본값으로 두고), 필요한 기능만 preload 에서 contextBridge 로 내준다. 위 메인과 주고받기 에 정리했다
  • 원격 주소(http://…) 를 읽는다 — https 로 읽거나 loadFile 로 앱 안의 파일을 읽는다
