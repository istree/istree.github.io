Vue 는 HTML 템플릿에 데이터를 연결해 화면을 만드는 UI 프레임워크다. 컴포넌트 하나를 .vue 파일 하나(템플릿 · 스크립트 · 스타일) 로 쓴다.

빠른 시작

프로젝트 생성

npm create vue@latest

프로젝트 이름 · TypeScript · 라우터 같은 것을 묻는다. 이름을 any-site 로 주면 any-site 디렉토리가 생성된다.

cd any-site
npm install

any-site 디렉토리로 이동해 의존성을 설치한다.

  • 예전에는 Vue CLI(npm install -g @vue/cli → vue create any-site) 로 만들었다. Vue CLI 는 유지보수만 하고, 지금은 create-vue(Vite 기반) 를 쓴다

서버로 실행

npm run dev
  • Vue CLI 프로젝트는 npm run serve 다

배포

npm run build

dist 디렉토리에 결과물이 출력된다.

컴포넌트

<script setup>
import { ref, computed } from "vue";

const props = defineProps({ title: String });
const count = ref(0);
const double = computed(() => count.value * 2);
</script>

<template>
  <h1>{{ props.title }}</h1>
  <button @click="count++">{{ count }} · {{ double }}</button>
</template>

<style scoped>
h1 { color: #42b883; }
</style>
  • ref 값은 스크립트에서 .value 로 읽고, 템플릿에서는 그냥 쓴다
  • scoped 스타일은 이 컴포넌트 안에만 적용된다

Electron 앱

Vue CLI 프로젝트

electron 빌더 플러그인을 설치한다.

vue add electron-builder

서버로 실행

npm run electron:serve

배포(실행파일)

npm run electron:build

Vite 프로젝트

vue add 는 Vue CLI 에서만 된다. Vite 로 만든 프로젝트는 React 와 같은 설정으로 Electron 을 붙인다. Electron 의 React · Vue · Svelte 사용하기 에 정리했다.

처음부터 만든다면 electron-vite 가 간단하다.

npm create @quick-start/electron@latest my-app -- --template vue

문제해결

Error: Electron failed to install correctly 이 발생하면 Electron 을 재설치한다.

npm uninstall electron
npm install electron
