      • Java에서 D3.js 사용하기

D3 의 레이아웃 함수는 그리지 않는다. 데이터를 받아 그리기 좋은 값(각도 · 쌓은 높이 · 좌표) 을 붙여 돌려준다. 그린 모양은 경로 생성기(d3.arc · d3.line · d3.geoPath) 가 SVG path 의 d 문자열로 만든다.

파이

d3.pie 가 값마다 시작 · 끝 각도를 붙이고, d3.arc 가 그 각도로 조각 경로를 만든다. 하루 24 시간을 어디에 썼는지 도넛으로 그린다.

const day = [
  { label: "잠", hours: 7 },
  { label: "일", hours: 9 },
  { label: "이동", hours: 2 },
  { label: "운동", hours: 1 },
  { label: "여가", hours: 5 },
];
const size = 260, r = size / 2;

const pie = d3.pie().value(d => d.hours).sort(null);        // sort(null) — 데이터 순서대로
const arc = d3.arc().innerRadius(r * 0.55).outerRadius(r);  // innerRadius 가 0 이면 파이
const color = d3.scaleOrdinal(day.map(d => d.label), d3.schemeTableau10);

const svg = d3.select("#chart").append("svg")
  .attr("width", size).attr("height", size)
  .attr("viewBox", [-r, -r, size, size]);                   // (0, 0) 을 가운데로

const slices = svg.selectAll("g")
  .data(pie(day))                    // { data, value, startAngle, endAngle, … }
  .join("g");

slices.append("path")
  .attr("d", arc)
  .attr("fill", d => color(d.data.label));

slices.append("text")
  .attr("transform", d => `translate(${arc.centroid(d)})`)   // 조각 가운데
  .attr("text-anchor", "middle")
  .attr("dy", "0.35em")
  .attr("fill", "white")
  .text(d => (d.endAngle - d.startAngle > 0.3 ? `${d.data.label} ${d.data.hours}` : ""));   // 좁은 조각은 비운다

svg.append("text")
  .attr("text-anchor", "middle")
  .attr("dy", "0.35em")
  .text(`${d3.sum(day, d => d.hours)}시간`);                // 도넛 가운데
  • pie() 가 돌려준 값의 원래 데이터는 d.data 에 있다
  • 조각이 많으면 라벨이 겹친다. 작은 조각은 묶어 "기타" 로 만들거나, 라벨을 바깥(outerRadius 를 더 크게 준 두 번째 arc 의 centroid) 에 두고 선으로 연결한다

쌓기

d3.stack 이 키(계열) 마다 아래 · 위 값을 붙인다. 쌓은 막대 · 영역 차트에 쓴다. 분기마다 판매 경로별 매출을 쌓는다.

const sales = [
  { quarter: "1분기", 온라인: 30, 매장: 50, 도매: 20 },
  { quarter: "2분기", 온라인: 45, 매장: 40, 도매: 25 },
  { quarter: "3분기", 온라인: 60, 매장: 35, 도매: 15 },
];
const keys = ["온라인", "매장", "도매"];

const series = d3.stack().keys(keys)(sales);
// [ 온라인: [[0, 30], [0, 45], [0, 60]], 매장: [[30, 80], …], 도매: [[80, 100], …] ]

x.domain(sales.map(d => d.quarter));
y.domain([0, d3.max(series, s => d3.max(s, d => d[1]))]);   // 110 — 가장 높이 쌓인 곳

svg.selectAll("g")
  .data(series)
  .join("g")
  .attr("fill", s => color(s.key))
  .selectAll("rect")
  .data(s => s)                      // 계열 안의 칸마다
  .join("rect")
  .attr("x", d => x(d.data.quarter))
  .attr("y", d => y(d[1]))
  .attr("height", d => y(d[0]) - y(d[1]))
  .attr("width", x.bandwidth());
  • 칸마다 d[0] 이 아래, d[1] 이 위, d.data 가 원래 줄이다
  • .offset(d3.stackOffsetExpand) 를 주면 칸마다 합이 1 이 된다 — 100% 쌓은 막대

힘 배치

노드와 연결선을 주면, 서로 밀고 당기는 힘을 계산해 자리를 잡는다. 모듈 사이의 의존 관계를 그린다.

const nodes = [{ id: "app" }, { id: "router" }, { id: "store" }, { id: "api" }, { id: "utils" }];
const links = [
  { source: "app", target: "router" },
  { source: "app", target: "store" },
  { source: "store", target: "api" },
  { source: "api", target: "utils" },
  { source: "router", target: "utils" },
];

const simulation = d3.forceSimulation(nodes)
  .force("link", d3.forceLink(links).id(d => d.id).distance(60))   // id 로 연결
  .force("charge", d3.forceManyBody().strength(-200))             // 서로 밀기
  .force("center", d3.forceCenter(w / 2, h / 2));                  // 가운데로

const line = svg.selectAll("line").data(links).join("line").attr("stroke", "#999");
const node = svg.selectAll("g.node").data(nodes).join("g").attr("class", "node");
node.append("circle").attr("r", 6);
node.append("text").attr("x", 9).attr("dy", "0.35em").text(d => d.id);

simulation.on("tick", () => {                     // 계산이 도는 동안 계속 불린다
  line.attr("x1", d => d.source.x).attr("y1", d => d.source.y)
      .attr("x2", d => d.target.x).attr("y2", d => d.target.y);
  node.attr("transform", d => `translate(${d.x},${d.y})`);
});
  • 계산을 시작하면 연결선의 source · target 이 문자열에서 노드 객체로 바뀐다. id 를 주지 않으면 배열 순서(0, 1 …) 로 연결한다
  • 움직임 없이 자리만 필요하면(서버에서 그릴 때) .stop() 하고 simulation.tick(300) 으로 끝까지 계산한 뒤 한 번 그린다
  • 끌어 옮기기는 d3.drag() 로 단다. 끄는 동안 d.fx · d.fy 로 자리를 고정하고 simulation.alphaTarget(0.3).restart() 로 다시 돌린다
  • 라벨을 겹치지 않게 놓을 때도 힘 배치를 쓴다. 라벨마다 원래 자리로 당기는 힘(forceX · forceY) 과 서로 밀어내는 힘(forceCollide) 을 준다

지도

GeoJSON 의 경계(경도 · 위도) 를 투영법으로 화면 좌표로 바꾸고, d3.geoPath 로 그린다. 시도 경계에 인구로 색을 칠한다(등치 지역도, choropleth).

const geo = await d3.json("sido.geo.json");                   // features[i].properties.name = "서울특별시" …
const rows = await d3.csv("population.csv", d => ({ name: d.name, population: +d.population }));

const projection = d3.geoMercator().fitSize([w, h], geo);     // 화면 크기에 맞춘다
const path = d3.geoPath(projection);

const populationOf = new Map(rows.map(d => [d.name, d.population]));
const color = d3.scaleQuantize()
  .domain(d3.extent(rows, d => d.population))
  .range(d3.schemeBlues[5]);                                  // 5 단계

svg.selectAll("path")
  .data(geo.features)
  .join("path")
  .attr("d", path)
  .attr("stroke", "white")
  .attr("fill", d => {
    const v = populationOf.get(d.properties.name);
    return v == null ? "#ccc" : color(v);                     // 값이 없는 곳은 회색
  });
  • 표의 이름과 GeoJSON 의 properties 이름이 글자까지 같아야 맞는다. 코드로 맞출 수 있으면 이름 대신 코드(properties.code) 를 키로 쓴다
  • 점(도시) 은 projection([경도, 위도]) 로 화면 좌표를 얻어 circle 로 찍는다
  • 세계 지도는 d3.geoNaturalEarth1() · d3.geoEqualEarth() 가 보기 좋다. 미국 지도는 알래스카 · 하와이를 옮겨 그리는 d3.geoAlbersUsa() 를 쓴다
  • 파일이 크면 TopoJSON 으로 줄이고 topojson.feature() 로 GeoJSON 으로 바꿔 쓴다
