D3 의 레이아웃 함수는 그리지 않는다. 데이터를 받아 그리기 좋은 값(각도 · 쌓은 높이 · 좌표) 을 붙여 돌려준다. 그린 모양은 경로 생성기(d3.arc · d3.line · d3.geoPath) 가 SVG path 의 d 문자열로 만든다.

파이

d3.pie 가 값마다 시작 · 끝 각도를 붙이고, d3.arc 가 그 각도로 조각 경로를 만든다.

const dataset = [5, 10, 20, 45, 6, 25];
const w = 300, outer = w / 2, inner = w / 3;    // inner 가 0 이면 파이, 크면 도넛

const pie = d3.pie().sort(null);                // sort(null) — 데이터 순서대로
const arc = d3.arc().innerRadius(inner).outerRadius(outer);
const color = d3.scaleOrdinal(d3.schemeCategory10);

const arcs = svg.selectAll("g.arc")
  .data(pie(dataset))                // { data, value, startAngle, endAngle, … }
  .join("g")
  .attr("class", "arc")
  .attr("transform", `translate(${outer},${outer})`);   // 원점을 가운데로

arcs.append("path")
  .attr("fill", (d, i) => color(i))
  .attr("d", arc);

arcs.append("text")
  .attr("transform", d => `translate(${arc.centroid(d)})`)   // 조각 가운데
  .attr("text-anchor", "middle")
  .attr("fill", "white")
  .text(d => d.value);
  • 객체 배열이면 값을 꺼내는 함수를 준다: d3.pie().value(d => d.count)
  • 조각이 많으면 라벨이 겹친다. 작은 조각은 묶어 "기타" 로 만들거나, 라벨을 바깥(arc.outerRadius 를 더 크게 준 두 번째 arc 의 centroid) 에 두고 선으로 연결한다

쌓기

d3.stack 이 키(계열) 마다 아래 · 위 값을 붙인다. 쌓은 막대 · 영역 차트에 쓴다.

const dataset = [
  { apples: 5, oranges: 10, grapes: 22 },
  { apples: 4, oranges: 12, grapes: 28 },
  { apples: 2, oranges: 19, grapes: 32 },
];
const keys = ["apples", "oranges", "grapes"];

const series = d3.stack().keys(keys)(dataset);   // 계열마다 [[아래, 위], …]
y.domain([0, d3.max(series, s => d3.max(s, d => d[1]))]);

svg.selectAll("g")
  .data(series)
  .join("g")
  .attr("fill", s => color(s.key))
  .selectAll("rect")
  .data(s => s)                      // 계열 안의 칸마다
  .join("rect")
  .attr("x", (d, i) => x(i))
  .attr("y", d => y(d[1]))
  .attr("height", d => y(d[0]) - y(d[1]))
  .attr("width", x.bandwidth());
  • .offset(d3.stackOffsetExpand) 를 주면 칸마다 합이 1 이 된다 — 100% 쌓은 막대

힘 배치

노드와 연결선을 주면, 서로 밀고 당기는 힘을 계산해 자리를 잡는다. 계산은 시간에 걸쳐 돌고, tick 마다 좌표가 바뀐다.

const nodes = [{ name: "Adam" }, { name: "Bob" }, { name: "Carrie" }];
const links = [{ source: 0, target: 1 }, { source: 0, target: 2 }];

const simulation = d3.forceSimulation(nodes)
  .force("link", d3.forceLink(links).distance(40))
  .force("charge", d3.forceManyBody().strength(-100))    // 서로 밀기
  .force("center", d3.forceCenter(w / 2, h / 2));        // 가운데로

const line = svg.selectAll("line").data(links).join("line").attr("stroke", "#999");
const node = svg.selectAll("circle").data(nodes).join("circle").attr("r", 8);

simulation.on("tick", () => {
  line.attr("x1", d => d.source.x).attr("y1", d => d.source.y)
      .attr("x2", d => d.target.x).attr("y2", d => d.target.y);
  node.attr("cx", d => d.x).attr("cy", d => d.y);
});
  • 연결선의 source · target 은 처음에 순서(0, 1 …) 로 주고, 계산을 시작하면 노드 객체로 바뀐다. 이름으로 연결하려면 forceLink(links).id(d => d.name) 을 준다
  • 끌어 옮기기는 d3.drag() 로 단다. 끄는 동안 d.fx · d.fy 로 자리를 고정하고 simulation.alphaTarget(0.3).restart() 로 다시 돌린다

라벨을 겹치지 않게 놓을 때도 힘 배치를 쓴다. 라벨마다 원래 자리로 당기는 힘(forceX · forceY) 과 서로 밀어내는 힘(forceCollide) 을 준다.

지도

GeoJSON 의 경계(위도 · 경도) 를 투영법으로 화면 좌표로 바꾸고, d3.geoPath 로 그린다.

const geo = await d3.json("us-states.json");
const rows = await d3.csv("us-ag-productivity.csv", d => ({ state: d.state, value: +d.value }));

const projection = d3.geoAlbersUsa().fitSize([w, h], geo);   // 화면 크기에 맞춘다
const path = d3.geoPath(projection);

const valueOf = new Map(rows.map(d => [d.state, d.value]));
const color = d3.scaleQuantize()
  .domain(d3.extent(rows, d => d.value))
  .range(d3.schemeGreens[5]);

svg.selectAll("path")
  .data(geo.features)
  .join("path")
  .attr("d", path)
  .attr("fill", d => {
    const v = valueOf.get(d.properties.name);
    return v == null ? "#ccc" : color(v);      // 값이 없는 주는 회색
  });
  • 등치 지역도(choropleth) 는 지역마다 값으로 색을 칠한 지도다. 구간 척도(scaleQuantize) 로 몇 단계 색을 준다. 척도와 축 에 정리했다
  • 책(D3 4) 에서는 CSV 와 GeoJSON 을 이중 반복문으로 맞췄다. Map 으로 한 번 만들어 두면 찾기가 빠르다
  • 세계 지도는 d3.geoMercator() · d3.geoNaturalEarth1(), 점(도시) 은 projection([경도, 위도]) 로 화면 좌표를 얻어 circle 로 찍는다
  • 파일이 크면 TopoJSON 으로 줄이고 topojson.feature() 로 GeoJSON 으로 바꿔 쓴다
