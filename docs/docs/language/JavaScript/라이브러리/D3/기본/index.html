D3 의 기본은 셋이다. 요소를 선택 하고, 선택에 데이터를 연결 하고, 데이터에 따라 속성을 정한다. 메서드가 선택을 돌려주므로 줄줄이 연결해서 쓴다.

선택

d3.select("body")             // 처음 하나
d3.selectAll("p")             // 모두
d3.select("#chart").select("svg")   // 그 안에서 찾기

const svg = d3.select("#chart")
  .append("svg")              // 자식 요소를 붙이고, 붙인 요소를 돌려준다
  .attr("width", 500)
  .attr("height", 120);

svg.append("circle")
  .attr("cx", 50).attr("cy", 50).attr("r", 20)
  .style("fill", "steelblue")         // CSS 속성
  .classed("active", true);           // 클래스 켜고 끄기

d3.select("p").text("글자");           // 글자 바꾸기
selection.remove();                    // 지우기
  • attr · style 에 함수를 주면 요소마다 불러 값을 정한다. 인자는 (d, i) — 연결된 데이터, 순서다
  • d3.create("svg") 는 문서에 붙이지 않은 새 요소를 만든다. 다 그린 뒤 node() 로 꺼내 붙인다

데이터 연결

selectAll 로 (아직 없는) 요소들을 선택하고, data 로 배열을 연결하고, join 으로 모자란 요소를 만든다. 아래는 일주일 걸음 수(천 보) 다.

const steps = [6.2, 8.1, 4.5, 9.8, 7.3, 11.2, 5.6];
const days = ["월", "화", "수", "목", "금", "토", "일"];

d3.select("body").selectAll("p")
  .data(steps)
  .join("p")                          // 데이터 개수만큼 p 를 맞춘다
  .text((d, i) => `${days[i]}: ${d}천 보`)
  .style("color", d => (d >= 8 ? "seagreen" : "gray"));
  • 예전(D3 4 · 5) 에는 .data(steps).enter().append("p") 로 썼다. enter() 는 "데이터는 있는데 요소가 없는 자리" 다. join 이 enter · update · exit 를 한 번에 처리한다
  • 연결된 데이터는 요소에 붙어 남는다(element.__data__). 다음에 selectAll 해도 같은 데이터가 온다

SVG로 그리기

SVG 는 왼쪽 위가 (0, 0) 이고 y 가 아래로 커진다. 막대를 아래에서 위로 세우려면 y = 바닥 - 높이 로 계산한다. 목표(8천 보) 를 넘은 날만 초록으로 칠한다.

const w = 420, h = 150, gap = 4, unit = 10;     // 천 보에 10px
const barW = w / steps.length;

const svg = d3.select("#chart").append("svg")
  .attr("width", w)
  .attr("height", h);

svg.selectAll("rect")
  .data(steps)
  .join("rect")
  .attr("x", (d, i) => i * barW)
  .attr("y", d => h - 20 - d * unit)            // 아래 20px 은 요일 글자 자리
  .attr("width", barW - gap)
  .attr("height", d => d * unit)
  .attr("fill", d => (d >= 8 ? "seagreen" : "lightgray"));

svg.selectAll("text.value")                     // 막대 위의 값
  .data(steps)
  .join("text")
  .attr("class", "value")
  .attr("x", (d, i) => i * barW + (barW - gap) / 2)
  .attr("y", d => h - 20 - d * unit - 4)
  .attr("text-anchor", "middle")                // x 를 글자 가운데로
  .attr("font-size", 11)
  .text(d => d);

svg.selectAll("text.day")                       // 아래의 요일
  .data(days)
  .join("text")
  .attr("class", "day")
  .attr("x", (d, i) => i * barW + (barW - gap) / 2)
  .attr("y", h - 6)
  .attr("text-anchor", "middle")
  .attr("font-size", 11)
  .text(d => d);
  • 글자 묶음이 둘이면 selectAll("text.value") 처럼 클래스로 나눈다. selectAll("text") 를 두 번 하면 앞에서 만든 글자에 뒤의 데이터가 덮인다
  • 막대 크기를 d * unit 처럼 직접 곱하면 데이터 범위가 바뀔 때마다 고쳐야 한다. 척도를 쓴다
  • div 로도 막대를 그릴 수 있다(.style("width", d => ${d * 10}px)). 축 · 글자 · 모양이 필요하면 SVG 로 그린다

데이터 읽기

D3 7 의 읽기 함수는 Promise 를 돌려준다.

// steps.csv — date,steps
const rows = await d3.csv("steps.csv", d => ({   // 줄마다 바꾸는 함수
  date: new Date(d.date),
  steps: +d.steps,                               // CSV 는 모두 문자열이다
}));

const config = await d3.json("chart.json");
const [a, b] = await Promise.all([d3.csv("a.csv"), d3.json("b.json")]);
d3.csvParse("date,steps\n2026-11-02,6200");    // 이미 가진 문자열
  • 예전(D3 4) 에는 d3.csv("steps.csv", function (data) { … }) 처럼 콜백을 넘겼다. D3 5 부터 Promise 다
  • file:// 로 연 페이지에서는 읽기가 막힌다. 로컬 서버로 연다

배열 도우미

d3.max(steps)                         // 11.2
d3.extent(steps)                      // [4.5, 11.2] — 최소, 최대
d3.sum(steps)                         // 52.7
d3.mean(steps)                        // 7.53…
d3.max(rows, d => d.steps)            // 객체 배열은 꺼내는 함수를 준다
d3.group(rows, d => d.type)           // Map — 종류별로 묶기
d3.rollup(rows, v => d3.sum(v, d => d.steps), d => d.type)   // Map { "평일" => 14300, "주말" => 11200 }
d3.range(3)                           // [0, 1, 2]
rows.sort((a, b) => d3.ascending(a.steps, b.steps));
