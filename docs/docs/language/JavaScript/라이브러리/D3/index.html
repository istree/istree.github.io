D3 는 데이터를 DOM(주로 SVG) 요소에 연결해 차트를 그리는 라이브러리다. 막대 · 원 같은 완성된 차트를 주지 않고, 선택 · 척도 · 축 · 모양 · 레이아웃을 조각으로 주어 그리는 방식을 직접 짜게 한다. 그래서 손이 많이 가지만 어떤 모양이든 그린다.

여기의 예제는 「Interactive Data Visualization for the Web」(D3 4) 을 따라 공부한 것을 D3 7 문법으로 옮긴 것이다. 바뀐 문법은 글마다 "예전에는" 으로 적었다.

  • 기본 — 선택 · 데이터 연결 · SVG 로 그리기 · 데이터 읽기
  • 척도와 축 — 데이터 값을 화면 값으로, 눈금 그리기
  • 갱신과 트랜지션 — enter · update · exit, 움직임 · 정렬 · 이벤트 · 툴팁
  • 레이아웃과 지도 — 파이 · 쌓기 · 힘 배치 · 지도
  • Java에서 D3.js 사용하기 — 서버에서 SVG 만들기
