척도(scale) 는 데이터 값(domain) 을 화면 값(range) 으로 바꾸는 함수다. 막대 높이 · 점 위치 · 색을 척도로 정하면 데이터 범위가 바뀌어도 그리는 코드는 그대로 둔다. 축(axis) 은 척도를 받아 눈금과 글자를 그린다.

연속 척도

const y = d3.scaleLinear()
  .domain([0, 100])        // 데이터: 0 ~ 100
  .range([200, 0]);        // 화면: 아래(200) ~ 위(0) — SVG 는 y 가 아래로 커진다

y(0)      // 200
y(50)     // 100
y.invert(100)   // 50 — 화면 값에서 데이터 값으로

d3.scaleLinear().domain([0, 87]).nice()   // [0, 90] — 끝을 깔끔한 수로
d3.scaleSqrt()      // 면적(원 반지름) 에 쓴다 — 넓이가 값에 비례한다
d3.scaleLog()       // 값의 차이가 아주 클 때
d3.scaleTime().domain([new Date(2024, 0, 1), new Date(2024, 11, 31)])   // 날짜
  • .clamp(true) 를 주면 domain 밖의 값도 range 끝에 붙인다

띠 척도 · 서열 척도

이름처럼 순서만 있는 값은 띠 척도로 자리를 나눈다. 막대 차트의 x 에 쓴다.

const x = d3.scaleBand()
  .domain(["1월", "2월", "3월"])   // 또는 d3.range(values.length)
  .range([0, 300])
  .padding(0.2);                   // 막대 사이 틈 (띠 폭의 비율)

x("2월")         // 띠 시작 위치
x.bandwidth()    // 막대 폭

const color = d3.scaleOrdinal(d3.schemeCategory10);   // 이름 → 색
color("문구")    // 처음 보는 이름마다 다음 색을 준다
  • 예전 D3 3 의 d3.scale.ordinal().rangeRoundBands(…) 가 지금의 d3.scaleBand() 다

구간 척도

연속 값을 몇 단계로 나눠 색을 준다. 등치 지역도(choropleth) 에 쓴다.

const color = d3.scaleQuantize()
  .domain(d3.extent(rows, d => d.value))
  .range(d3.schemeGreens[5]);        // 5 단계 초록

const threshold = d3.scaleThreshold()   // 경계를 직접 정한다
  .domain([10, 50, 100])
  .range(["#eee", "#bbb", "#888", "#333"]);

여백

축이 들어갈 자리를 남기려고 바깥 여백을 정하고, 척도의 range 를 그 안쪽으로 준다.

const width = 400, height = 240;
const margin = { top: 10, right: 10, bottom: 30, left: 40 };

const x = d3.scaleBand().domain(names).range([margin.left, width - margin.right]).padding(0.2);
const y = d3.scaleLinear().domain([0, d3.max(values)]).nice()
  .range([height - margin.bottom, margin.top]);

축

축 함수를 g 요소에 call 한다. 축은 (0, 0) 에 그려지므로 transform 으로 옮긴다.

svg.append("g")
  .attr("transform", `translate(0,${height - margin.bottom})`)
  .call(d3.axisBottom(x));

svg.append("g")
  .attr("transform", `translate(${margin.left},0)`)
  .call(d3.axisLeft(y).ticks(5, "~s"));   // 눈금 5 개쯤, 1k · 1M 처럼
축 눈금 방향
d3.axisBottom 아래 (x 축)
d3.axisLeft 왼쪽 (y 축)
d3.axisTop · d3.axisRight 위 · 오른쪽

눈금을 손본다.

d3.axisLeft(y)
  .ticks(5)                              // 눈금 개수 (대략)
  .tickFormat(d3.format(",.0f"))         // 1,200 처럼
  .tickSize(-(width - margin.left - margin.right))   // 안쪽으로 길게 — 격자선

d3.axisBottom(x).tickFormat(d3.timeFormat("%m월"));   // 날짜

// 그린 뒤 고치기
yAxisGroup.call(g => g.select(".domain").remove())   // 축 선 지우기
          .call(g => g.selectAll(".tick text").attr("font-size", 12));
  • 축 제목은 따로 text 를 붙인다

갱신할 때

데이터가 바뀌면 척도의 domain 을 다시 정하고 축을 다시 call 한다. 트랜지션을 붙이면 눈금이 움직인다.

y.domain([0, d3.max(newValues)]).nice();
yAxisGroup.transition().duration(750).call(d3.axisLeft(y));
