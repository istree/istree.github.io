데이터가 바뀌면 같은 선택에 새 데이터를 다시 연결한다. D3 는 요소와 데이터를 맞춰 보고 셋으로 나눈다. 새로 생긴 데이터(enter), 그대로 있는 데이터(update), 없어진 데이터(exit) 다. 트랜지션을 붙이면 바뀌는 과정이 움직임으로 보인다.

flowchart LR
  D["새 데이터"] --> J{"요소와 맞추기<br/>(키 함수)"}
  J -- "데이터만 있다" --> E["enter<br/>요소를 만든다"]
  J -- "둘 다 있다" --> U["update<br/>속성을 고친다"]
  J -- "요소만 있다" --> X["exit<br/>요소를 지운다"]

아래 예제는 상품 판매량 막대를 그리고, 분류 버튼으로 거르고, 판매량 · 이름 순으로 정렬한다.

const products = [
  { name: "펜",     category: "문구", sales: 120 },
  { name: "공책",   category: "문구", sales: 90 },
  { name: "지우개", category: "문구", sales: 40 },
  { name: "머그컵", category: "주방", sales: 75 },
  { name: "접시",   category: "주방", sales: 55 },
  { name: "가방",   category: "잡화", sales: 30 },
];

const w = 420, h = 160;
const svg = d3.select("#chart").append("svg").attr("width", w).attr("height", h);
const x = d3.scaleBand().range([0, w]).padding(0.2);
const y = d3.scaleLinear().range([h, 0]);
const color = d3.scaleOrdinal(d3.schemeTableau10);

키 함수

데이터와 요소를 무엇으로 맞출지 정한다. 주지 않으면 순서(0, 1, 2 …) 로 맞춘다. 거르거나 정렬하면 순서가 바뀌므로, 데이터마다 바뀌지 않는 값(이름 · id) 을 키로 준다.

svg.selectAll("rect").data(list, d => d.name);
  • 키가 없으면 "주방" 으로 거를 때 펜 · 공책 막대에 머그컵 · 접시 데이터가 덮어 써지고 나머지 넷이 빠진다. 막대가 제자리에서 모양만 바뀌어 무엇이 빠졌는지 보이지 않는다

join

join 은 enter · update · exit 를 한 번에 처리하고, 만든 것과 남은 것을 합친 선택을 돌려준다. 셋을 따로 다루려면 함수 셋을 준다. 새 막대는 바닥에서 자라고, 빠지는 막대는 바닥으로 줄어든 뒤 지워진다.

function update(list) {
  x.domain(list.map(d => d.name));
  y.domain([0, d3.max(list, d => d.sales)]).nice();

  svg.selectAll("rect")
    .data(list, d => d.name)
    .join(
      enter => enter.append("rect")
        .attr("x", d => x(d.name))
        .attr("width", x.bandwidth())
        .attr("y", h)                         // 바닥에서 높이 0 으로 시작
        .attr("height", 0)
        .attr("fill", d => color(d.category)),
      update => update,
      exit => exit.transition().duration(300)
        .attr("y", h)
        .attr("height", 0)
        .remove(),                            // 트랜지션이 끝나면 지운다
    )
    .transition().duration(500)               // 새 것 + 남은 것
    .attr("x", d => x(d.name))
    .attr("width", x.bandwidth())
    .attr("y", d => y(d.sales))
    .attr("height", d => h - y(d.sales));
}

const show = category =>
  update(category === "전체" ? products : products.filter(d => d.category === category));

show("전체");
d3.selectAll("button.filter").on("click", event => show(event.currentTarget.textContent));
  • 공통 속성은 join 뒤에 한 번만 쓴다. enter 에는 시작 모양만 둔다
  • exit 의 .remove() 는 트랜지션 뒤에 붙이면 끝난 뒤에 지운다. 트랜지션 동안에는 요소가 남아 있다
  • 예전(D3 4) 에는 const bars = svg.selectAll("rect").data(list, key); 뒤에 bars.enter().append("rect").merge(bars)… 와 bars.exit().remove() 를 따로 썼다. join 이 이 셋을 묶었다

트랜지션

transition() 뒤의 attr · style 은 바로 바뀌지 않고 시간에 걸쳐 바뀐다.

svg.selectAll("rect")
  .transition()
  .duration(500)                      // 0.5 초
  .delay((d, i) => i * 30)            // 막대마다 조금씩 늦게
  .ease(d3.easeCubicInOut)            // 속도 곡선 (기본)
  .attr("y", d => y(d.sales));
  • 트랜지션 뒤에 .on("end", fn) 을 달면 끝난 뒤에 할 일을 둔다
  • 같은 요소에 새 트랜지션을 걸면 앞의 것은 끊긴다. 이어서 하려면 .transition() 을 한 번 더 연결한다
  • 축도 axisGroup.transition().call(axis) 로 움직인다

정렬

막대의 자리는 띠 척도의 domain 순서가 정한다. 정렬한 이름 순서로 domain 을 바꾸고 x 만 다시 준다.

let bySales = true;

function sortBars() {
  const order = svg.selectAll("rect").data()            // 지금 연결된 데이터
    .toSorted((a, b) => (bySales ? d3.descending(a.sales, b.sales) : d3.ascending(a.name, b.name)))
    .map(d => d.name);

  x.domain(order);
  svg.selectAll("rect")
    .transition().duration(500)
    .delay((d, i) => i * 30)
    .attr("x", d => x(d.name));

  bySales = !bySales;                                   // 다음에는 이름순
}
  • 선택의 sort 는 요소의 DOM 순서를 바꾼다. 겹쳐 그린 것의 앞뒤를 바꿀 때 쓴다. 자리는 위처럼 척도로 정한다

이벤트

on 으로 이벤트 함수를 단다. D3 6 부터 함수는 (event, d) 를 받는다.

svg.selectAll("rect")
  .on("click", (event, d) => show(d.category))          // 누른 막대의 분류만
  .on("mouseenter", function (event, d) {
    d3.select(this).attr("opacity", 0.6);               // this 는 그 요소 — 화살표 함수가 아니어야 한다
  })
  .on("mouseleave", function () {
    d3.select(this).attr("opacity", null);              // null 이면 속성을 지운다
  });
  • 예전(D3 4 · 5) 에는 함수가 (d, i) 를 받았고, 이벤트는 전역 d3.event 로 읽었다
  • 색만 바꾸는 hover 는 CSS 로도 된다: rect:hover { opacity: 0.6; }
  • 마우스 자리는 d3.pointer(event, svg.node()) 로 SVG 좌표를 얻는다

툴팁

가장 간단한 것은 SVG title 이다. 브라우저 기본 툴팁이 뜬다.

svg.selectAll("rect")
  .append("title")
  .text(d => `${d.name}: ${d.sales}개`);

모양을 정하려면 차트를 감싼 요소 안에 HTML div 하나를 두고 마우스를 따라 옮긴다.

const wrap = d3.select("#chart").style("position", "relative");
const tip = wrap.append("div")
  .style("position", "absolute")
  .style("pointer-events", "none")      // 없으면 툴팁이 마우스를 가려 mouseleave 가 계속 일어난다
  .style("display", "none");

svg.selectAll("rect")
  .on("mousemove", (event, d) => {
    const [mx, my] = d3.pointer(event, wrap.node());
    tip.style("display", null)
      .style("left", `${mx + 12}px`)
      .style("top", `${my - 12}px`)
      .text(`${d.name}: ${d.sales}개`);
  })
  .on("mouseleave.tip", () => tip.style("display", "none"));
  • 같은 이벤트에 on 을 다시 부르면 앞의 함수가 바뀐다. mouseleave.tip 처럼 점 뒤에 이름을 붙이면 따로 단다
