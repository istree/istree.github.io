데이터가 바뀌면 같은 선택에 새 데이터를 다시 연결한다. D3 는 요소와 데이터를 맞춰 보고 셋으로 나눈다. 새로 생긴 데이터(enter), 그대로 있는 데이터(update), 없어진 데이터(exit) 다. 트랜지션을 붙이면 바뀌는 과정이 움직임으로 보인다.

flowchart LR
  D["새 데이터"] --> J{"요소와 맞추기<br/>(키 함수)"}
  J -- "데이터만 있다" --> E["enter<br/>요소를 만든다"]
  J -- "둘 다 있다" --> U["update<br/>속성을 고친다"]
  J -- "요소만 있다" --> X["exit<br/>요소를 지운다"]

키 함수

데이터와 요소를 무엇으로 맞출지 정한다. 주지 않으면 순서(0, 1, 2 …) 로 맞춘다. 값을 넣고 빼면 순서가 밀리므로, 바뀌지 않는 키를 준다.

const key = d => d.key;

svg.selectAll("rect").data(dataset, key);

join

join 은 enter · update · exit 를 한 번에 처리하고, 만든 것과 남은 것을 합친 선택을 돌려준다. 합친 선택에 공통 속성을 준다.

function update(dataset) {
  x.domain(d3.range(dataset.length));
  y.domain([0, d3.max(dataset, d => d.value)]);

  svg.selectAll("rect")
    .data(dataset, key)
    .join("rect")
    .attr("x", (d, i) => x(i))
    .attr("y", d => y(d.value))
    .attr("width", x.bandwidth())
    .attr("height", d => h - y(d.value));
}

update(dataset);
dataset.push({ key: nextKey++, value: 42 });   // 값 넣기
update(dataset);
dataset.shift();                                // 앞에서 빼기
update(dataset);

셋을 따로 다루려면 함수 셋을 준다. 새 막대는 오른쪽 밖에서 들어오고, 없어진 막대는 왼쪽으로 빠지는 식이다.

svg.selectAll("rect")
  .data(dataset, key)
  .join(
    enter => enter.append("rect")
      .attr("x", w)                               // 오른쪽 밖에서 시작
      .attr("y", d => y(d.value))
      .attr("height", d => h - y(d.value)),
    update => update,
    exit => exit.transition().duration(500)
      .attr("x", -x.bandwidth())                  // 왼쪽 밖으로
      .remove()
  )
  .transition().duration(500)
  .attr("x", (d, i) => x(i))
  .attr("width", x.bandwidth());
  • 예전(D3 4) 에는 const bars = svg.selectAll("rect").data(dataset, key); 뒤에 bars.enter().append("rect").merge(bars)… 와 bars.exit().remove() 를 따로 썼다. join 이 이 셋을 묶었다

트랜지션

transition() 뒤의 attr · style 은 바로 바뀌지 않고 시간에 걸쳐 바뀐다.

svg.selectAll("rect")
  .data(dataset, key)
  .transition()
  .duration(1000)                     // 1 초
  .delay((d, i) => i * 50)            // 막대마다 조금씩 늦게 — 물결처럼
  .ease(d3.easeCubicInOut)            // 속도 곡선 (기본)
  .attr("y", d => y(d.value))
  .attr("height", d => h - y(d.value));
  • 트랜지션 뒤에 .on("end", fn) 을 달면 끝난 뒤에 할 일을 둔다
  • 같은 요소에 새 트랜지션을 걸면 앞의 것은 끊긴다. 이어서 하려면 .transition() 을 한 번 더 연결한다
  • 축도 axisGroup.transition().call(axis) 로 움직인다

정렬

선택의 sort 는 데이터로 요소 순서를 바꾼다. 바뀐 순서(i) 로 자리를 다시 정한다.

let ascending = true;

function sortBars() {
  svg.selectAll("rect")
    .sort((a, b) => ascending ? d3.ascending(a.value, b.value) : d3.descending(a.value, b.value))
    .transition()
    .duration(1000)
    .delay((d, i) => i * 50)
    .attr("x", (d, i) => x(i));
  ascending = !ascending;
}

이벤트

on 으로 이벤트 함수를 단다. D3 6 부터 함수는 (event, d) 를 받는다.

svg.selectAll("rect")
  .on("click", (event, d) => sortBars())
  .on("mouseover", function (event, d) {
    d3.select(this).attr("fill", "orange");     // this 는 그 요소 — 화살표 함수가 아니어야 한다
  })
  .on("mouseout", function (event, d) {
    d3.select(this).transition().duration(250).attr("fill", color(d.value));
  });
  • 예전(D3 4 · 5) 에는 함수가 (d, i) 를 받았고, 이벤트는 전역 d3.event 로 읽었다
  • 색만 바꾸는 hover 는 CSS 로도 된다: rect:hover { fill: orange; }
  • 마우스 자리는 d3.pointer(event, svg.node()) 로 SVG 좌표를 얻는다

툴팁

가장 간단한 것은 SVG title 이다. 브라우저 기본 툴팁이 뜬다.

svg.selectAll("rect")
  .append("title")
  .text(d => `값: ${d.value}`);

모양을 정하려면 HTML div 하나를 띄워 두고 옮긴다.

const tooltip = d3.select("body").append("div")
  .attr("class", "tooltip")              // position: absolute; pointer-events: none;
  .style("opacity", 0);

svg.selectAll("rect")
  .on("mouseover", (event, d) => {
    tooltip.style("opacity", 1).text(`값: ${d.value}`);
  })
  .on("mousemove", event => {
    tooltip.style("left", `${event.pageX + 10}px`).style("top", `${event.pageY - 20}px`);
  })
  .on("mouseout", () => tooltip.style("opacity", 0));
  • 툴팁에 pointer-events: none 을 주지 않으면 툴팁이 마우스를 가려 mouseout 이 계속 일어난다
