Vite 로 Svelte 프로젝트를 만든다. 컴포넌트는 .svelte 파일 하나에 스크립트 · 마크업 · 스타일을 함께 쓰고, Vite 플러그인(@sveltejs/vite-plugin-svelte) 이 이것을 JavaScript 로 컴파일한다.

프로젝트 만들기

화면 하나짜리 앱(SPA) 은 Vite 템플릿으로 만든다.

npm create vite@latest my-app -- --template svelte   # TypeScript 는 svelte-ts
cd my-app
npm install
npm run dev                     # 개발 서버 — http://localhost:5173
npm run build                   # dist 에 결과물
파일 하는 일
index.html <div id="app"> 과 src/main.js 를 불러오는 쪽
src/main.js 맨 위 컴포넌트를 #app 에 붙인다
src/App.svelte 맨 위 컴포넌트
src/lib/ 컴포넌트 · 공유 상태(.svelte.js)
vite.config.js plugins: [svelte()]
svelte.config.js 컴파일러 옵션 (전처리 · 호환 모드) 
// src/main.js
import { mount } from "svelte";
import App from "./App.svelte";

const app = mount(App, {
  target: document.getElementById("app"),
  props: { user: "geon" },       // 맨 위 컴포넌트의 props
});
  • 떼어 낼 때는 unmount(app) 을 부른다
  • 쪽이 여럿이고 주소마다 다른 화면 · 서버 렌더링이 필요하면 SvelteKit 으로 만든다: npx sv create my-app. src/routes/ 아래 폴더가 주소가 되고, 쪽마다 +page.svelte 를 둔다

.svelte 파일

<!-- src/lib/Greeting.svelte -->
<script>
  let { name = "world" } = $props();      // 부모가 넘긴 값
  let count = $state(0);                  // 바뀌면 화면이 따라 바뀐다
</script>

<h1>Hello {name}!</h1>
<button onclick={() => count++}>{count} 번 눌렀다</button>

<style>
  h1 { color: tomato; }                   /* 이 컴포넌트에만 적용된다 */
</style>
<!-- src/App.svelte -->
<script>
  import Greeting from "./lib/Greeting.svelte";
</script>

<Greeting name="Svelte" />
  • <script> · 마크업 · <style> 순서로 쓰고, 셋 다 없어도 된다
  • <style> 은 컴파일러가 클래스 이름을 붙여 이 컴포넌트에만 걸리게 한다. 전역으로 걸려면 :global(body) { … } 로 쓴다
  • $state · $props 처럼 $ 로 시작하는 것은 runes 다. 함수처럼 보이지만 컴파일러가 읽는 표시라 import 하지 않는다. .svelte 와 .svelte.js 파일에서만 쓴다
  • 컴포넌트 이름은 대문자로 시작한다. 소문자는 HTML 요소로 읽는다

Electron · Tauri

Vite 로 만든 프로젝트라 React · Vue 와 같은 설정으로 붙인다.

  • Electron 은 개발할 때 Vite 개발 서버 주소를, 배포할 때 dist/index.html 을 창에 연다. file:// 로 열므로 vite.config.js 에 base: "./" 를 준다
  • Tauri 는 npm create tauri-app@latest 에서 Svelte 를 고르면 된다. SvelteKit 으로 만들어지며, 서버 없이 파일로 내야 하므로 @sveltejs/adapter-static 을 쓴다

예전에는

  • Svelte 3 · 4 는 npx degit sveltejs/template my-app 으로 Rollup 템플릿을 받아 만들었다. npm run dev 가 rollup -c -w 였고 결과는 public/build/bundle.js 에 나왔다. 지금은 Vite 템플릿 · sv create 로 만든다
  • 앱은 new App({ target: document.body }) 로 붙였다. Svelte 5 에서는 new 로 만들면 오류가 난다(개발 모드에서는 component_api_invalid_new … which is no longer valid in Svelte 5). mount 로 바꾸거나 svelte.config.js 에 compilerOptions: { compatibility: { componentApi: 4 } } 를 준다
