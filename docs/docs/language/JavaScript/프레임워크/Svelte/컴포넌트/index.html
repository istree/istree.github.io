컴포넌트는 .svelte 파일 하나다. 부모는 속성으로 값 · 함수를 넘기고(props), 자식은 $props() 로 받는다. 안쪽 내용은 snippet 으로 넘긴다.

props

<!-- Panel.svelte -->
<script>
  let { title, count = 0, onchange, children, footer, ...rest } = $props();
</script>

<section {...rest}>
  <h2>{title} ({count})</h2>
  <button onclick={() => onchange?.(count + 1)}>+</button>
  {@render children?.()}
  {#if footer}{@render footer("끝")}{/if}
</section>
<!-- App.svelte -->
<script>
  import Panel from "./Panel.svelte";
  let n = $state(0);
</script>

<Panel title="카운터" count={n} onchange={v => (n = v)} id="panel" class="card">
  <p>안쪽 내용</p>
  {#snippet footer(text)}<small>{text}</small>{/snippet}
</Panel>
  • 구조 분해로 받고, 기본값(count = 0) 을 준다. 나머지(...rest) 는 id · class 처럼 요소에 그대로 넘길 속성이다
  • props 는 부모가 바꾸면 따라 바뀐다. 자식에서 대입하면 그 자식 안에서만 잠깐 바뀌고, 부모가 다시 넘기면 덮인다

자식이 부모에게 알리기

자식이 부모의 값을 바꾸게 하려면 함수를 props 로 넘긴다. 위의 onchange 처럼 자식은 부르기만 하고, 바꾸는 것은 부모가 한다.

입력 컴포넌트처럼 값 하나를 양쪽으로 주고받으면 $bindable 로 두고 부모에서 bind: 로 연결한다.

<!-- Field.svelte -->
<script>
  let { value = $bindable(""), label } = $props();
</script>
<label>{label} <input bind:value /></label>
<script>
  import Field from "./Field.svelte";
  let name = $state("geon");
</script>

<Field label="이름" bind:value={name} />
<p>{name}</p>                                <!-- 자식에서 고치면 여기도 바뀐다 -->
  • bind: 는 값 하나에만 쓴다. 여러 값을 바꾸거나 바꾸기 전에 검사할 일이 있으면 함수 props 로 넘긴다
  • 예전에는 createEventDispatcher 로 dispatch("change", v) 를 내고 부모가 on:change={e => n = e.detail} 로 받았다. Svelte 5 에서는 함수 props 로 바꾼다

snippet

태그 사이에 쓴 내용은 children 으로, {#snippet 이름(인자)} 로 쓴 것은 같은 이름의 props 로 넘어간다. 자식은 {@render …} 로 그린다.

<!-- List.svelte — 줄 모양을 부모가 정한다 -->
<script>
  let { items, row } = $props();
</script>
<ul>
  {#each items as item}<li>{@render row(item)}</li>{/each}
</ul>
<List items={users}>
  {#snippet row(user)}<b>{user.name}</b> {user.email}{/snippet}
</List>
  • snippet 은 한 파일 안에서도 쓴다. 되풀이되는 마크업을 {#snippet card(x)}…{/snippet} 로 두고 {@render card(a)} 로 부른다
  • 예전에는 <slot /> · <slot name="footer" /> 와 let:item 으로 했다

생명주기

<script>
  import { onMount, onDestroy, tick } from "svelte";
  let el;

  onMount(() => {
    console.log("화면에 붙었다", el.tagName);   // 요소를 쓸 수 있다
    return () => console.log("떨어진다");        // 정리
  });
  onDestroy(() => console.log("사라졌다"));

  async function addAndScroll() {
    items.push(newItem);
    await tick();                                // 화면에 그려질 때까지 기다린다
    el.scrollTop = el.scrollHeight;
  }
</script>

<div bind:this={el}>…</div>
  • onMount 는 화면에 붙은 뒤 한 번 돈다. 서버 렌더링(SvelteKit) 에서는 돌지 않는다
  • 값이 바뀔 때마다 할 일은 $effect 로 한다. 처음 한 번은 onMount 와 같은 때 돈다
  • {#if} 로 빠질 때 정리 함수 · onDestroy 가 차례로 불린다

재귀 컴포넌트

폴더 트리처럼 같은 모양이 안에 또 있으면 컴포넌트가 자기 자신을 import 해 쓴다.

<!-- Tree.svelte -->
<script>
  import Tree from "./Tree.svelte";
  let { node } = $props();
  let open = $state(true);
</script>

<li>
  {#if node.children}
    <button onclick={() => (open = !open)}>{open ? "▾" : "▸"}</button>
  {/if}
  {node.name}
  {#if node.children && open}
    <ul>
      {#each node.children as child (child.name)}
        <Tree node={child} />
      {/each}
    </ul>
  {/if}
</li>
<ul>
  <Tree node={{ name: "docs", children: [{ name: "a.md" }, { name: "img", children: [{ name: "b.png" }] }] }} />
</ul>
  • 펼침 상태(open) 는 줄마다 따로 있다. 모두 펼치기 · 접기를 하려면 상태를 데이터(node.open) 에 두고 $state 로 감싼다
  • 예전에는 <svelte:self node={child} /> 로 썼다
