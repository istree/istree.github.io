컴포넌트는 JSX 를 돌려주는 함수다. 부모가 넘긴 속성(props) 을 객체 하나로 받고, 이름은 대문자로 시작한다. 소문자로 시작하면 JSX 가 HTML 태그로 본다.

JSX 규칙

function Profile({ user }) {
  return (
    <div className="profile">                          {/* class 대신 className */}
      <label htmlFor="name">이름</label>                {/* for 대신 htmlFor */}
      <input id="name" defaultValue={user.name} />     {/* 닫는 / 가 꼭 있어야 한다 */}
      <img src={user.photo} alt="" style={{ width: 40 }} />   {/* {} 안은 JavaScript 식 */}
      <p>{user.age > 19 ? "성인" : "미성년"}</p>
    </div>
  );
}
  • 맨 바깥은 하나여야 한다. 감쌀 태그를 더하고 싶지 않으면 프라그먼트 <>…</> 로 감싼다
  • {} 에는 식 하나만 들어간다. if · for 는 쓰지 못하고, 삼항 · && · map 을 쓴다
  • 속성 이름은 camelCase 다: onClick · tabIndex · aria-* 와 data-* 만 그대로

props

function Hello({ name = "world", children }) {     // 구조 분해 · 기본값
  return <h1>Hello {name} {children}</h1>;
}

<Hello name="React">!</Hello>                       // children 은 태그 사이의 내용이다
<Hello {...user} />                                 // 객체를 펼쳐 모두 넘긴다
  • props 는 읽기만 한다. 바꿀 값은 부모의 상태로 두고, 바꾸는 함수를 props 로 내려 준다: <Counter value={n} onChange={setN} />
  • 몇 단계 아래로 내려 주기 번거로우면 Context 를 쓴다

조건

{loading ? <Spinner /> : <List items={items} />}
{error && <p className="error">{error.message}</p>}
{count > 0 && <Badge count={count} />}             // count 가 0 이면 0 이 그려진다 — 조건을 boolean 으로
  • 아무것도 그리지 않으려면 null 을 돌려준다

목록과 key

<ul>
  {items.map(item => <Row key={item.id} {...item} />)}
</ul>

// 감싸는 태그 없이 key 를 주려면 Fragment
import { Fragment } from "react";
items.map(item => <Fragment key={item.id}><dt>{item.term}</dt><dd>{item.desc}</dd></Fragment>)
  • 항목마다 바뀌지 않는 key 를 준다. 없으면 Each child in a list should have a unique "key" prop 경고가 난다
  • 순서(index) 나 Math.random() 을 key 로 쓰지 않는다. 항목을 지우거나 끼울 때 입력값 · 상태가 엉뚱한 줄로 간다. id 가 없으면 데이터를 만들 때 crypto.randomUUID() 로 붙인다
  • key 는 map 이 돌려주는 맨 바깥 요소에 준다. 안쪽 요소에 주면 경고가 그대로 난다

이벤트

<button onClick={() => setCount(c => c + 1)}>더하기</button>
<button onClick={() => remove(item.id)}>지우기</button>      // 인자를 줄 때는 함수로 감싼다
<form onSubmit={e => { e.preventDefault(); save(); }}>…</form>
  • onClick={remove(item.id)} 처럼 쓰면 그릴 때 바로 불린다. 함수를 넘긴다

폼

입력값을 상태로 두고 value · onChange 로 연결한다 (controlled).

function SignUp({ onSubmit }) {
  const [form, setForm] = useState({ name: "", agree: false });
  const change = e => {
    const { name, type, value, checked } = e.target;
    setForm(f => ({ ...f, [name]: type === "checkbox" ? checked : value }));
  };
  return (
    <form onSubmit={e => { e.preventDefault(); onSubmit(form); }}>
      <input name="name" value={form.name} onChange={change} />
      <input name="agree" type="checkbox" checked={form.agree} onChange={change} />
      <button disabled={!form.agree}>가입</button>
    </form>
  );
}
  • 입력 중에 값을 볼 일이 없으면 상태 없이 defaultValue 로 두고, 제출 때 new FormData(e.currentTarget) 로 꺼낸다
  • value 만 주고 onChange 를 빼면 입력이 되지 않는다
