React 는 화면을 컴포넌트(함수) 로 나눠 만드는 UI 라이브러리다. 컴포넌트는 props 와 상태(state) 를 받아 JSX 를 돌려주고, 상태가 바뀌면 React 가 컴포넌트를 다시 불러 바뀐 부분만 화면에 고친다.

리소스

  • react.dev — 공식 문서 (한국어)
  • 빠르게 시작하기 — 공식 학습. React로 사고하기 에서 화면을 컴포넌트로 나누는 순서를 본다
  • React Developer Tools — 브라우저에서 컴포넌트 트리 · props · 상태를 본다
  • Vite — 프로젝트를 만들고 빌드하는 도구
  • Epic Reactive Programming with Redux-Observable — RxJS 로 Redux 의 비동기 다루기
  • 흔하디 흔한 투두 리스트 — velopert. 할 일 목록을 만들며 컴포넌트 · 상태를 익힌다 (클래스 컴포넌트 때 글)
