React 는 스타일 방법을 정하지 않는다. Vite 프로젝트에서는 CSS 파일을 import 하면 바로 적용되고, 파일 이름을 .module.css 로 하면 그 컴포넌트 안에서만 쓰는 클래스가 된다.

CSS · CSS 모듈 · 인라인

import "./App.css";                          // 전역 CSS — 클래스는 className 으로
import styles from "./Button.module.css";    // CSS 모듈 — 이 파일 안에서만 쓰는 클래스

<div className="app">…</div>
<button className={styles.primary}>저장</button>          // 겹치지 않게 _primary_1m3d5_1 처럼 바뀐다
<p style={{ color: "red", fontSize: 14 }}>경고</p>         // 인라인 — 객체, 속성은 camelCase, 숫자는 px
<li className={done ? "item done" : "item"}>{text}</li>   // 조건에 따라 클래스
  • class 로 쓰면 Invalid DOM property `class`. Did you mean `className`? 경고가 난다
  • 클래스를 여럿 조건으로 붙일 때는 배열을 합치거나 clsx 를 쓴다: className={clsx("item", { done, active })}
  • 테마 색처럼 바꾸는 값은 CSS 변수로 두고 style={{ "--accent": color }} 로 넘긴다

부트스트랩

CSS 만 쓰면 패키지를 설치하고 진입 파일에서 가져온다.

npm install bootstrap
// main.jsx
import "bootstrap/dist/css/bootstrap.min.css";

<div className="row">
  <div className="col-md-8">본문</div>
  <div className="col-md-4 mt-3 mt-md-0">옆</div>     {/* 간격(m · p) 클래스 */}
</div>
<button className="btn btn-primary">저장</button>
  • 모달 · 드롭다운처럼 동작이 있는 것은 React Bootstrap 컴포넌트를 쓴다: import { Button, Modal } from "react-bootstrap";
  • 부트스트랩의 JavaScript(bootstrap.bundle.js) 는 DOM 을 직접 고치므로 React 와 함께 쓰지 않는다
