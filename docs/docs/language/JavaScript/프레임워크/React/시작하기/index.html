Vite 로 프로젝트를 만든다. JSX 를 JavaScript 로 바꾸는 일은 Vite 가 한다. 빌드 없이 HTML 한 장으로 해 볼 수도 있다.

프로젝트 만들기

npm create vite@latest my-app -- --template react   # TypeScript 는 react-ts
cd my-app
npm install
npm run dev                     # 개발 서버
npm run build                   # dist 에 결과물
파일 하는 일
index.html <div id="root"> 와 src/main.jsx 를 불러오는 쪽
src/main.jsx createRoot 로 #root 에 App 을 그린다
src/App.jsx 맨 위 컴포넌트
vite.config.js Vite 설정 (@vitejs/plugin-react) 
// src/main.jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);
  • StrictMode 는 개발 모드에서 컴포넌트 · effect 를 일부러 두 번 돌려 정리 안 한 것을 드러낸다. 배포 빌드에서는 한 번만 돈다
  • 예전에는 npx create-react-app my-app 으로 만들었다. Create React App 은 2025 년에 지원이 끝났다. 라우팅 · 서버 렌더링까지 필요하면 Next.js · React Router 같은 프레임워크로 시작한다

HTML 한 장으로

해 보기만 할 때는 빌드 없이 HTML 한 장으로 쓴다. JSX 는 브라우저에서 Babel 이 바꾼다.

<!-- index.html -->
<html>
<head>
  <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
  <script src="https://unpkg.com/react@18/umd/react.development.js"></script>
  <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
  <script type="text/babel" src="main.js"></script>
</head>
<body>
  <div id="hello"></div>
</body>
</html>
// main.js
function Hello({ name }) {
  return <h1>Hello {name}</h1>;
}

ReactDOM.createRoot(document.getElementById("hello")).render(<Hello name="world!" />);

file:// 로 열면 main.js 를 읽지 못한다. 소스가 있는 디렉토리에서 웹 서버를 띄우고 http://localhost:8000 을 연다.

python3 -m http.server      # 또는 npx serve
  • 한 파일로 바로 쓰는 UMD 빌드는 React 18 까지 있다. React 19 는 위처럼 Vite 로 프로젝트를 만든다
  • React 17 까지는 ReactDOM.render(<Hello />, document.getElementById("hello")) 로 그렸다. React 19 에서 빠졌다
  • 예전에는 컴포넌트를 클래스로 만들었다. 지금도 돌지만 새 코드는 함수 컴포넌트로 쓴다 
    class Hello extends React.Component {
  render() {
    return <h1>Hello {this.props.name}</h1>;
  }
}
