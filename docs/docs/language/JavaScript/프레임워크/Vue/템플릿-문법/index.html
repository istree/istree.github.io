템플릿은 HTML 에 Vue 의 문법({{ }} · v- 로 시작하는 속성) 을 더한 것이다. 안에 적은 식은 <script setup> 의 값을 읽고, 값이 바뀌면 그 부분을 다시 그린다.

글자 · 속성 · 이벤트

<template>
  <h1>{{ title }}</h1>                              <!-- 글자 넣기 -->
  <a :href="url" :class="{ active: isActive }">링크</a>   <!-- :속성 = v-bind -->
  <img :src="src" :style="{ width: size + 'px' }">
  <button @click="count++">{{ count }}</button>     <!-- @이벤트 = v-on -->
  <button @click="remove(item.id)">지우기</button>  <!-- 인자를 줄 때 -->
  <form @submit.prevent="save">…</form>             <!-- .prevent = preventDefault -->
  <input @keyup.enter="search">                     <!-- 엔터 키만 -->
</template>
  • {{ }} · :속성 안에는 식 하나만 들어간다. 길어지면 computed 로 뺀다
  • :class 에는 객체({ 클래스: 조건 }) 나 배열([a, b]) 을 준다. 원래 class 와 합쳐진다
  • 이벤트 처리 함수에 이름만 주면(@click="save") 이벤트 객체를 받는다. 인자와 함께 받으려면 @click="save(id, $event)"
  • HTML 을 그대로 넣으려면 v-html 을 쓴다. 사용자 입력에는 쓰지 않는다

조건 · 반복

<template>
  <p v-if="items.length === 0">비어 있다</p>
  <ul v-else>
    <li v-for="item in items" :key="item.id">{{ item.name }}</li>
  </ul>
  <div v-show="open">열림</div>                     <!-- 지우지 않고 display 만 바꾼다 -->

  <template v-for="(item, i) in items" :key="item.id">   <!-- 감싸는 태그 없이 -->
    <dt>{{ i + 1 }}. {{ item.name }}</dt>
    <dd>{{ item.desc }}</dd>
  </template>
</template>
  • v-for 에는 항목마다 바뀌지 않는 :key 를 준다. 순서(index) 를 key 로 쓰면 항목을 지우거나 끼울 때 엉뚱한 요소를 고쳐 쓴다
  • 자주 켜고 끄면 v-show, 조건이 드물게 바뀌면 v-if 를 쓴다. v-if 는 요소를 만들고 지운다
  • v-if 와 v-for 를 한 요소에 같이 쓰지 않는다. 걸러서 그리려면 computed 로 거른 배열을 만든다
  • v-for="n in 5" 는 1 부터 5 까지 돈다

v-model

입력값과 반응형 값을 양쪽으로 맞춘다.

<template>
  <input v-model="name">                            <!-- 입력값 ↔ name -->
  <input v-model.trim="keyword">                    <!-- 앞뒤 공백 빼기 -->
  <input v-model.number="age" type="number">        <!-- 숫자로 -->
  <input v-model.lazy="memo">                       <!-- 입력 중이 아니라 change 때 -->
  <input type="checkbox" v-model="agree">           <!-- true · false -->
  <input type="checkbox" v-model="tags" value="vue">   <!-- 배열에 넣고 빼기 -->
  <select v-model="color"><option>red</option><option>blue</option></select>
</template>
