반응형 값은 읽힐 때 누가 읽었는지 기억하고, 바뀔 때 그곳(템플릿 · computed · watch) 을 다시 돌린다. 값을 ref · reactive 로 만들어 두면 화면을 직접 고치지 않아도 된다.

ref · reactive · computed

<script setup>
import { ref, reactive, computed } from "vue";

const count = ref(0);                         // 값 하나 — 스크립트에서는 .value
const user = reactive({ name: "geon", age: 3 });   // 객체 — .value 없이
const double = computed(() => count.value * 2);    // 다른 값으로 계산, 결과를 기억한다

function inc() {
  count.value++;
  user.age++;
}
</script>

<template>
  <button @click="inc">{{ count }} · {{ double }} · {{ user.age }}</button>   <!-- 템플릿에서는 .value 없이 -->
</template>
  • 처음에는 모두 ref 로 써도 된다. reactive 는 통째로 바꿔 넣거나(user = {…}) 구조 분해하면 반응성이 끊긴다
  • 배열 · 객체는 고쳐도 된다(list.value.push(x)). React 처럼 새로 만들지 않아도 화면이 바뀐다
  • computed 는 계산에 쓴 값이 바뀔 때만 다시 계산한다. 같은 식을 함수로 부르면 그릴 때마다 계산한다
  • 예전(Options API) 에는 data() { return { count: 0 } }, methods: { inc() { this.count++ } }, computed: { double() { … } } 로 썼다

watch

값이 바뀔 때 할 일(저장 · 요청 · 로그) 을 둔다.

import { watch, watchEffect } from "vue";

watch(count, (now, before) => {
  console.log(before, "→", now);
});
watch(() => user.name, name => localStorage.setItem("name", name));   // 객체 속성은 함수로
watch([a, b], ([a, b]) => …);                                         // 여럿

watchEffect(() => {                           // 안에서 읽은 값이 바뀔 때마다, 처음에도 돈다
  document.title = `${count.value} 개`;
});
  • computed 는 값을 계산만 하고, 요청 · 저장 같은 일은 watch 에서 한다
  • watch 는 처음에는 돌지 않는다. 처음에도 돌리려면 { immediate: true } 를 준다. 객체 안까지 보려면 { deep: true }
  • 값을 바꾼 뒤 바뀐 DOM 을 읽으려면 await nextTick() 을 한다. 화면은 모아서 한 번에 고친다

데이터 받기

props 가 바뀔 때마다 다시 받는다. watch 의 세 번째 인자 onCleanup 으로 앞 요청을 끊는다.

<script setup>
import { ref, watch } from "vue";

const { id } = defineProps({ id: Number });
const user = ref(null);
const error = ref(null);

watch(() => id, async (id, _, onCleanup) => {
  const controller = new AbortController();
  onCleanup(() => controller.abort());        // id 가 다시 바뀌면 앞 요청을 끊는다
  try {
    const res = await fetch(`/api/users/${id}`, { signal: controller.signal });
    user.value = await res.json();
  } catch (e) {
    if (e.name !== "AbortError") error.value = e;
  }
}, { immediate: true });
</script>

<template>
  <p v-if="error">{{ error.message }}</p>
  <p v-else-if="!user">읽는 중…</p>
  <p v-else>{{ user.name }}</p>
</template>
  • 여러 컴포넌트에서 같은 일을 하면 composable 로 뺀다
