props 로 몇 단계를 내려 주기 번거로우면 provide · inject 를 쓰고, 앱 전체에서 쓰는 상태(로그인 · 장바구니) 는 Pinia 에 둔다.

provide · inject

위에서 provide 한 값을 아래 어디서든 inject 로 받는다.

// 위
import { provide, ref } from "vue";
const theme = ref("dark");
provide("theme", theme);                  // ref 를 주면 아래에서도 바뀐 값이 보인다

// 아래
import { inject } from "vue";
const theme = inject("theme", ref("light"));   // 두 번째 인자는 없을 때 기본값
  • 아래에서 값을 바꾸게 하려면 값과 함께 바꾸는 함수를 준다: provide("theme", { theme, toggle })
  • 앱 전체에 주려면 app.provide("key", 값) 을 쓴다

Pinia

npm create vue 에서 Pinia 를 선택하면 설정까지 만든다. 직접 넣을 때는 npm install pinia 뒤에 app.use(createPinia()) 를 한다.

// stores/cart.js
import { defineStore } from "pinia";
import { ref, computed } from "vue";

export const useCartStore = defineStore("cart", () => {
  const items = ref([]);                                 // state
  const total = computed(() => items.value.reduce((sum, i) => sum + i.price, 0));   // getters
  const add = item => items.value.push(item);            // actions

  async function load() {                                // 비동기도 그냥 함수다
    items.value = await (await fetch("/api/cart")).json();
  }
  return { items, total, add, load };
});
<script setup>
import { storeToRefs } from "pinia";
import { useCartStore } from "@/stores/cart";

const cart = useCartStore();
const { items, total } = storeToRefs(cart);    // 구조 분해는 storeToRefs 로 (반응성 유지)
cart.load();
</script>

<template>
  <button @click="cart.add({ name: '사과', price: 1000 })">담기</button> {{ items.length }}개 · {{ total }}원
</template>
  • store 는 처음 부를 때 만들어지고, 어느 컴포넌트에서 불러도 같은 것이 온다
  • cart.$reset() 은 option 방식 store 에서 처음 값으로 되돌린다. setup 방식에서는 직접 만든다
  • cart.$subscribe((mutation, state) => localStorage.setItem("cart", JSON.stringify(state))) 로 바뀔 때마다 저장한다
  • 예전에는 Vuex(state · mutations · actions · getters) 를 썼다. 지금 공식 상태 관리는 Pinia 다
  • defineStore("cart", { state: () => ({ items: [] }), getters: {…}, actions: {…} }) 처럼 객체로도 쓴다 (option 방식)
