부모는 props 로 값을 내려 주고, 자식은 이벤트(emit) 로 알린다. 양쪽으로 맞출 값은 defineModel, 부모가 채울 자리는 slot 으로 둔다.

props · emit · defineModel · slot

<!-- TodoItem.vue -->
<script setup>
const { todo, editable = false } = defineProps({   // 구조 분해 · 기본값 (3.5+)
  todo: { type: Object, required: true },
  editable: Boolean,
});
const emit = defineEmits(["remove"]);
const done = defineModel("done");                    // 부모의 v-model:done 과 연결
</script>

<template>
  <li>
    <input type="checkbox" v-model="done">
    <slot>{{ todo.name }}</slot>                     <!-- 부모가 태그 사이에 넣은 내용, 없으면 이름 -->
    <button v-if="editable" @click="emit('remove', todo.id)">지우기</button>
  </li>
</template>
<!-- 부모 -->
<script setup>
import { ref } from "vue";
import TodoItem from "./TodoItem.vue";

const todos = ref([{ id: 1, name: "장보기", done: false }]);
const remove = id => (todos.value = todos.value.filter(t => t.id !== id));
</script>

<template>
  <ul>
    <TodoItem v-for="t in todos" :key="t.id" :todo="t" editable
              v-model:done="t.done" @remove="remove" />
  </ul>
</template>
  • props 는 읽기만 한다. 바꾸려면 emit 으로 부모에게 알리거나, 양쪽으로 맞추려면 defineModel 을 쓴다
  • defineModel() 처럼 이름을 빼면 부모에서 v-model="값" 으로 쓴다
  • props 로 적지 않은 속성(class · id · @click …) 은 자식의 맨 바깥 요소에 붙는다
  • 예전(3.4 전) 에는 v-model 을 modelValue props + update:modelValue emit 으로 직접 짰다. 3.5 전에는 props 를 구조 분해하면 반응성이 끊겨서 props.todo 로 썼다

이름 있는 slot

<!-- Card.vue -->
<template>
  <section>
    <header><slot name="header" /></header>
    <slot />                                         <!-- 이름 없는 것 -->
    <footer><slot name="footer" :count="3" /></footer>   <!-- 부모에게 값을 넘긴다 -->
  </section>
</template>

<!-- 부모 -->
<Card>
  <template #header>제목</template>
  본문
  <template #footer="{ count }">{{ count }} 개</template>
</Card>

생명주기 · DOM

<script setup>
import { onMounted, onUnmounted, useTemplateRef } from "vue";

const input = useTemplateRef("box");          // ref="box" 인 요소 (3.5+)
let timer;

onMounted(() => {                             // 화면에 붙은 뒤
  input.value.focus();
  timer = setInterval(tick, 1000);
});
onUnmounted(() => clearInterval(timer));      // 사라질 때 정리
</script>

<template>
  <input ref="box">
</template>
  • DOM 을 직접 다루는 라이브러리(D3 · 차트 · 에디터) 는 onMounted 에서 붙이고 onUnmounted 에서 뗀다
  • 예전(3.5 전) 에는 같은 이름의 ref(const box = ref(null)) 를 만들어 요소를 받았다

composable

여러 컴포넌트에서 쓰는 상태와 로직을 함수로 뺀다. 이름은 use 로 시작하고 ref 를 돌려준다.

// composables/useFetch.js
import { ref, watchEffect, toValue } from "vue";

export function useFetch(url) {
  const data = ref(null);
  const error = ref(null);

  watchEffect(async () => {
    data.value = error.value = null;
    try {
      const res = await fetch(toValue(url));    // ref · getter 를 주면 바뀔 때마다 다시 받는다
      data.value = await res.json();
    } catch (e) {
      error.value = e;
    }
  });
  return { data, error };
}
<script setup>
import { useFetch } from "@/composables/useFetch";

const { id } = defineProps({ id: Number });
const { data: user, error } = useFetch(() => `/api/users/${id}`);
</script>
  • 컴포넌트 안에서 부르면 그 컴포넌트가 사라질 때 watchEffect 도 함께 멈춘다
  • 자주 쓰는 것(useLocalStorage · useMouse · useFetch …) 은 VueUse 에 있다
  • 예전(Vue 2) 에는 mixin 으로 나눴다. 어디서 온 값인지 알기 어려워 composable 로 바뀌었다
