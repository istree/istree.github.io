create-vue 로 Vite 프로젝트를 만든다. 컴포넌트는 .vue 파일 하나에 템플릿 · 스크립트 · 스타일을 함께 쓰고, Vite 가 이것을 JavaScript 로 바꾼다.

프로젝트 만들기

npm create vue@latest           # 이름 · TypeScript · Router · Pinia 를 묻는다
cd any-site
npm install
npm run dev                     # 개발 서버
npm run build                   # dist 에 결과물

만들어지는 파일 중 주로 고치는 것은 아래와 같다.

파일 하는 일
index.html <div id="app"> 과 src/main.js 를 불러오는 쪽
src/main.js 앱을 만들어 #app 에 붙인다. 라우터 · Pinia 를 여기서 단다
src/App.vue 맨 위 컴포넌트
src/components/ 컴포넌트
vite.config.js Vite 설정. @ 가 src 를 가리키도록 되어 있다 
// src/main.js
import { createApp } from "vue";
import App from "./App.vue";

createApp(App).mount("#app");
  • 예전에는 Vue CLI(npm install -g @vue/cli → vue create any-site → npm run serve) 를 썼다. Vue CLI 는 유지보수만 한다

.vue 파일

<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>

<style scoped>
button { color: #42b883; }
</style>
  • <script setup> 에서 선언한 변수 · 함수 · 가져온 컴포넌트는 템플릿에서 바로 쓴다
  • scoped 스타일은 이 컴포넌트 안에만 적용된다. 자식 컴포넌트 안까지 고치려면 :deep(.child) 로 쓴다
  • TypeScript 는 <script setup lang="ts"> 로 쓴다

빌드 없이

CDN 을 불러 createApp 에 템플릿을 준다. HTML 한 장으로 해 볼 때 쓴다.

<div id="app"><button @click="count++">{{ count }}</button></div>

<script type="module">
  import { createApp, ref } from "https://unpkg.com/vue@3/dist/vue.esm-browser.js";

  createApp({
    setup() {
      const count = ref(0);
      return { count };         // 템플릿에서 쓸 것을 돌려준다
    },
  }).mount("#app");
</script>

Electron 앱

Vite 로 만든 프로젝트는 React 와 같은 설정으로 Electron 을 붙인다.

처음부터 만든다면 electron-vite 가 간단하다.

npm create @quick-start/electron@latest my-app -- --template vue
  • 예전에는 Vue CLI 프로젝트에 vue add electron-builder 로 플러그인을 넣고 npm run electron:serve · electron:build 로 돌렸다. Vite 프로젝트에서는 안 된다
  • Error: Electron failed to install correctly 가 나면 Electron 을 다시 설치한다: npm uninstall electron && npm install electron
