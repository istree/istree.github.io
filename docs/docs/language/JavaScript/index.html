JavaScript 는 브라우저에서 웹 페이지를 움직이려고 만든 동적 언어다. 함수가 값이고, 클래스 대신 프로토타입으로 객체를 연결하고, 한 스레드에서 이벤트 루프로 비동기 일을 처리한다. 지금은 Node.js 로 서버 · 명령줄 · 데스크톱(Electron) 에서도 돈다. 표준 이름은 ECMAScript 이고, 2015 년(ES6) 부터 해마다 새 판이 나온다.

여기에는 언어, 실행환경(Node.js · Deno · Bun), 번들러, 프레임워크(React · Vue · Svelte), 데스크톱 앱(Electron · Tauri), 써 본 라이브러리를 정리한다.
