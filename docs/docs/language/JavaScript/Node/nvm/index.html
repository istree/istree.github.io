노드 버전 매니저다. Node 를 여러 버전 설치하고, 터미널마다 쓸 버전을 바꾼다. 맥 · 리눅스용이고, 윈도우는 nvm-windows 를 쓴다.

설치

nvm 설치

$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash

최신 LTS 버전의 Node 설치 · 사용

nvm install --lts
nvm use --lts

최신 버전의 Node 설치 · 사용

nvm install node
nvm use node

버전 확인

node -v && npm -v

아키텍처

아키텍처 확인

node -p process.arch

아키텍처를 x64로 변경

arch -x86_64 zsh

아키텍처를 arm64로 변경

arch -arm64 zsh

버전변경

Node 16버전 설치

nvm install 16

Node 16버전 사용

nvm use 16

설치된 Node의 목록을 확인하여 원하는 Node로 변경한다.

nvm ls

터미널 시작시 Node 16버전을 기본으로 사용한다.

nvm alias default 16

프로젝트마다 버전 정하기

프로젝트 맨 위에 .nvmrc 를 두면 그 디렉토리에서 nvm use · nvm install 이 그 버전을 쓴다.

echo "22" > .nvmrc
nvm use

업그레이드

nvm 자체를 새 버전으로 올릴 때는 설치 명령을 다시 실행한다. 설치한 Node 는 그대로 남는다.

  • 최신 버전 번호는 nvm-sh/nvm 의 README 에서 확인한다

Node 를 새 버전으로 올리면서 전역 패키지를 옮긴다.

nvm install --lts --reinstall-packages-from=current
