Claude Code 의 Stop · Notification 훅에 스크립트 하나를 걸어, 세션이 일을 마치거나 승인을 기다릴 때 텔레그램으로 알림을 보낸다. 제목에는 세션 이름을, 본문에는 응답 요약이나 기다리는 내용을, 끝에는 상태 표시줄을 넣는다. 전역 설정에 걸기 때문에 모든 세션에 적용된다. 스크립트는 Node.js 로 쓰고 바깥 패키지는 쓰지 않는다.

✅ 작업 완료 [프로그래밍 노트]
메시지 큐 글 열두 쪽을 썼습니다. 빌드는 526 쪽으로 통과했습니다. (목록 3개 생략)

Opus 5.5 | ctx:45% | 5h:92% rst:15:50 | 7d:23% rst:11/15 | high

봇 만들기

  1. 텔레그램에서 @BotFather 에게 /newbot 을 보낸다
  2. 처음 묻는 것은 표시 이름(name) 이다. 대화창에 보이는 이름이고, 나중에 /setname 으로 바꿀 수 있다
  3. 다음은 사용자 이름(username) 이다. t.me/<사용자 이름> 주소가 되고 bot 으로 끝나야 하며 바꿀 수 없다
  4. 토큰(123456789:AA…) 을 받는다. 토큰이 있으면 누구나 봇을 부릴 수 있으므로 채팅 · 저장소에 붙이지 않는다

봇은 먼저 말을 걸지 못한다. 봇 대화창에서 시작(START) 을 눌러야 봇이 나에게 보낼 수 있다. 새 봇은 검색에 바로 나오지 않을 때가 있어, 주소로 연다.

open "tg://resolve?domain=<사용자 이름>"

시작을 누른 뒤 getUpdates 로 내 대화의 chat_id 를 찾는다.

curl -s "https://api.telegram.org/bot<봇 토큰>/getUpdates" | python3 -c '
import json, sys
for u in json.load(sys.stdin)["result"]:
    c = u.get("message", {}).get("chat", {})
    print(c.get("id"), c.get("type"), c.get("first_name"))'
  • 결과가 비면 시작을 누르지 않았거나, 다른 프로그램이 같은 토큰으로 메시지를 먼저 받아 간 것이다
  • 보낼 때 chat not found 가 나면 그 대화에서 시작을 누르지 않은 것이다

토큰과 chat_id 는 저장소 밖 파일에 두고 권한을 600 으로 둔다.

# ~/.claude/telegram.env
TG_BOT_TOKEN=<봇 토큰>
TG_CHAT_ID=<chat_id>

훅 걸기

~/.claude/settings.json 의 hooks 에 넣는다. 스크립트는 저장소에 두고 ~/.claude/hooks/ 에 링크를 걸어 쓴다.

{
  "hooks": {
    "Stop": [
      { "matcher": "", "hooks": [{ "type": "command", "command": "node ~/.claude/hooks/telegram-notify.mjs", "timeout": 15 }] }
    ],
    "Notification": [
      { "matcher": "", "hooks": [{ "type": "command", "command": "node ~/.claude/hooks/telegram-notify.mjs", "timeout": 15 }] }
    ]
  }
}
  • Stop 은 응답이 끝날 때마다, Notification 은 승인 · 입력을 기다릴 때 돈다
  • /hooks 에서 걸린 훅을 볼 수 있다

훅 입력

훅은 표준 입력으로 JSON 하나를 받는다. 알림에 쓰는 필드는 이렇다.

필드 내용
hook_event_name Stop · Notification
session_id · transcript_path · cwd 세션 id · 대화 기록 파일(JSONL) · 작업 폴더
last_assistant_message Stop 에서 마지막 응답 글
notification_type · message Notification 의 종류(permission_prompt · idle_prompt …) 와 글 
let input = {};
try { input = JSON.parse(fs.readFileSync(0, 'utf8')); } catch {}

const event = input.hook_event_name || '';
if (event === 'Notification' && input.notification_type === 'idle_prompt') return;
  • idle_prompt 는 응답을 마치고 한동안 입력이 없을 때 다시 온다. Stop 알림과 겹쳐서 보내지 않는다
  • 훅이 0 이 아닌 코드로 끝나면 세션에 오류가 보인다. 보내기에 실패해도 조용히 exit 0 으로 끝낸다
main().catch(() => {}).finally(() => process.exit(0));

보내기

sendMessage 하나면 된다. 응답이 느려 훅이 세션을 붙잡지 않게 시간 제한을 둔다.

async function send(token, chatId, text) {
  const res = await fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ chat_id: chatId, text, disable_web_page_preview: true }),
    signal: AbortSignal.timeout(5000),
  });
  return res.ok;
}
  • 한 메시지는 4096 자까지 보낼 수 있다. 4000 자쯤에서 자른다
  • parse_mode 를 주지 않고 평문으로 보낸다. 응답 글의 * · _ 가 마크다운으로 읽히면 보내기가 실패한다

응답 요약

last_assistant_message 에서 코드 블록 · 제목 · 표 · 목록을 건너뛰고, 첫 산문 문단의 1–2 문장을 220 자 안에서 뽑는다. 건너뛴 목록 줄은 개수만 적는다.

const sentences = prose.match(/\S[\s\S]*?(?:[.!?。]+(?=\s|$)|$)/g) || [prose];
  • 마침표 뒤에 공백이나 끝이 올 때만 문장을 끊는다. 그냥 . 로 끊으면 telegram-notify.mjs 같은 파일 이름 안에서 잘린다
  • 백틱 · 굵게 · 링크 같은 인라인 마크다운은 기호를 걷어 평문으로 바꾼다

승인 대기 내용

Notification 의 message 는 Claude needs your permission 뿐이라, 무엇을 승인할지 알 수 없다. 기다리는 도구 호출은 대화 기록에 먼저 써지므로, 결과(tool_result) 가 아직 없는 tool_use 를 찾는다.

function pendingToolUses(transcriptPath) {
  const pending = new Map();
  for (const line of fs.readFileSync(transcriptPath, 'utf8').trim().split('\n').slice(-300)) {
    let obj;
    try { obj = JSON.parse(line); } catch { continue; }
    for (const c of Array.isArray(obj?.message?.content) ? obj.message.content : []) {
      if (obj.type === 'assistant' && c.type === 'tool_use') pending.set(c.id, c);
      else if (c.type === 'tool_result') pending.delete(c.tool_use_id);
    }
  }
  return [...pending.values()];
}

도구마다 읽기 좋은 글로 바꾼다. 질문(AskUserQuestion) 은 선택지에 번호를 붙여, 텔레그램에서 번호로 답할 수 있게 한다.

function describeToolUse({ name, input: i = {} }) {
  if (name === 'AskUserQuestion') {
    return i.questions.map((q) => [
      `질문: ${q.question}`,
      ...q.options.map((o, n) => `${n + 1}. ${o.label}${o.description ? ` — ${o.description}` : ''}`),
    ].join('\n')).join('\n\n');
  }
  if (name === 'Bash') return `Bash: ${i.description || ''}\n$ ${i.command}`;
  if (name === 'Edit' || name === 'Write') return `${name}: ${i.file_path}`;
  return `${name}: ${JSON.stringify(i).slice(0, 400)}`;
}
⏳ 승인 대기 [작업]
Bash: Clean and rebuild
$ rm -rf build && npm run build
  • 머리글은 질문이면 ⏳ 질문 대기, 그 밖은 ⏳ 승인 대기 로 나눈다
  • 기록이 늦게 써질 때를 생각해, 찾지 못하면 0.7 초 뒤 한 번 더 읽는다. 그래도 없으면 message 를 그대로 보낸다
  • 명령 · 질문이 길면 수백 자에서 자른다

제목에 세션 이름

/rename 으로 붙인 세션 이름은 ~/.claude/sessions/<pid>.json 에 있다. 훅 입력의 session_id 로 찾는다.

function sessionName(sessionId) {
  for (const f of fs.readdirSync(path.join(os.homedir(), '.claude', 'sessions'))) {
    const d = JSON.parse(fs.readFileSync(path.join(os.homedir(), '.claude', 'sessions', f), 'utf8'));
    if (d.sessionId === sessionId && d.name) return d.name;
  }
  return '';
}
  • 이름을 정하지 않은 세션은 <폴더>-04 처럼 저절로 붙는다
  • 상태 표시줄 입력의 session_name 은 대화 제목이라 이 이름과 다르다
  • cmux 안에서는 CMUX_WORKSPACE_ID 로 워크스페이스 이름을 찾을 수 있다 (cmux workspace list --id-format both). 세션 이름을 워크스페이스 이름과 같게 두면 제목은 [이름] 하나로 쓴다

상태 표시줄 붙이기

훅은 모델 · 컨텍스트 · 사용량을 받지 않는다. 상태 표시줄 명령은 받으므로, 상태 표시줄 명령이 받은 입력을 세션마다 파일로 남긴다.

// ~/.claude/statusline-command.mjs 앞부분
const raw = fs.readFileSync(0, 'utf8');
const input = JSON.parse(raw);
const cacheDir = path.join(os.homedir(), '.claude', 'cache', 'statusline');
fs.mkdirSync(cacheDir, { recursive: true });
fs.writeFileSync(path.join(cacheDir, `${input.session_id}.json`), raw);

훅은 그 파일을 상태 표시줄 명령에 다시 넣어 같은 한 줄을 만들고, 색 코드를 지운다.

const cmd = JSON.parse(fs.readFileSync(SETTINGS_FILE, 'utf8')).statusLine.command;
const out = execSync(cmd, { input: cacheRaw, encoding: 'utf8', timeout: 3000 });
const status = out.replace(/\x1b\[[0-9;]*m/g, '').trim();

시험

보내지 않고 메시지만 찍게 해 두면, 훅 입력을 손으로 넣어 볼 수 있다.

echo '{"hook_event_name":"Stop","session_id":"<세션 id>","last_assistant_message":"시험입니다. 둘째 문장."}' \
  | TG_DRY=1 node ~/.claude/hooks/telegram-notify.mjs
