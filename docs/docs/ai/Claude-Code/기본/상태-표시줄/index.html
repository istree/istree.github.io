상태 표시줄은 입력칸 아래 한 줄이다. 명령 하나를 걸어 두면 Claude Code 가 세션 정보를 JSON 으로 넣어 주고, 명령이 찍은 글을 그대로 보여 준다. 모델 · 컨텍스트 사용률 · 사용 한도를 늘 보이게 둔다.

Opus 5.5 | ctx:12% | 5h:30% rst:17:50 | 7d:28% rst:11/15 | high

걸기

// ~/.claude/settings.json
{
  "statusLine": { "type": "command", "command": "node ~/.claude/statusline-command.mjs" }
}
  • /statusline 모델이랑 컨텍스트 퍼센트 보여 줘 처럼 말로 시키면 Claude 가 스크립트를 만들어 걸어 준다
  • 세션을 시작할 때, 응답 메시지가 올 때, /compact · 권한 모드를 바꿀 때 다시 돈다. 시계처럼 시간마다 바뀌는 것은 "refreshInterval": 초 를 준다
  • ANSI 색 코드를 쓸 수 있다

입력

필드 내용
model.display_name Opus 5.5 같은 모델 이름
context_window.used_percentage 컨텍스트 창을 쓴 비율
rate_limits.five_hour · rate_limits.seven_day 5 시간 · 7 일 사용 한도의 used_percentage 와 resets_at(유닉스 초)
effort.level 지금 effort (low … max)
session_id · transcript_path · cwd 세션 · 대화 기록 · 작업 폴더

스크립트

// ~/.claude/statusline-command.mjs
import fs from 'node:fs';

const input = JSON.parse(fs.readFileSync(0, 'utf8'));
const CYAN = '\x1b[0;36m', YELLOW = '\x1b[0;33m', GREEN = '\x1b[0;32m', MAGENTA = '\x1b[0;35m', RESET = '\x1b[0m';

const parts = [`${CYAN}${input.model?.display_name ?? 'Claude'}${RESET}`];

const ctx = input.context_window?.used_percentage;
if (ctx != null) parts.push(`ctx:${Math.round(ctx)}%`);

const five = input.rate_limits?.five_hour;
if (five?.used_percentage != null) {
  const t = new Date(five.resets_at * 1000).toTimeString().slice(0, 5);        // 17:50
  parts.push(`${YELLOW}5h:${Math.round(five.used_percentage)}% rst:${t}${RESET}`);
}

const week = input.rate_limits?.seven_day;
if (week?.used_percentage != null) {
  const d = new Date(week.resets_at * 1000);
  const md = `${String(d.getMonth() + 1).padStart(2, '0')}/${String(d.getDate()).padStart(2, '0')}`;  // 11/15
  parts.push(`${GREEN}7d:${Math.round(week.used_percentage)}% rst:${md}${RESET}`);
}

if (input.effort?.level) parts.push(`${MAGENTA}${input.effort.level}${RESET}`);

process.stdout.write(parts.join(' | '));
  • 컨텍스트 비율은 used_percentage 를 그대로 쓴다. 모델 이름으로 창 크기(200K · 1M) 를 짐작해 나누면 틀린다
  • settings.json 의 effortLevel 은 모델에 따라 적용되지 않기도 한다. 실제 값은 입력의 effort.level 이다
  • rate_limits 는 Pro · Max 같은 구독에만 있고, 세션의 첫 응답이 온 뒤에 생긴다. 없는 필드는 빼고 찍는다

시험

예시 입력을 넣어 본다.

echo '{"model":{"display_name":"Opus 5.5"},"context_window":{"used_percentage":12.4},"effort":{"level":"high"}}' \
  | node ~/.claude/statusline-command.mjs

다른 곳에서 쓰기

훅에는 이 정보가 오지 않는다. 상태 표시줄 명령이 받은 입력을 세션마다 파일로 남겨 두면, 알림 훅이 같은 줄을 만들어 붙일 수 있다.

const raw = fs.readFileSync(0, 'utf8');
const input = JSON.parse(raw);
const dir = path.join(os.homedir(), '.claude', 'cache', 'statusline');
fs.mkdirSync(dir, { recursive: true });
fs.writeFileSync(path.join(dir, `${input.session_id}.json`), raw);
