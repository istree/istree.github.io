훅은 Claude Code 가 일하는 도중 정해진 때에 내 명령을 돌린다. 응답이 끝날 때 커밋하고, 위험한 명령을 실행 전에 막고, 승인을 기다릴 때 알림을 보내는 식이다. Claude 에게 부탁하는 것과 달리 빠짐없이 돈다. 설정은 settings.json 의 hooks 에 적고, /hooks 에서 걸린 것을 본다.

언제 도는가

이벤트 때
SessionStart · SessionEnd 세션이 시작 · 재개될 때, 끝날 때
UserPromptSubmit 내가 메시지를 보낸 뒤, Claude 가 읽기 전
PreToolUse · PostToolUse 도구를 실행하기 전 · 성공한 뒤
Notification 승인 · 입력을 기다릴 때
Stop 응답이 끝날 때
PreCompact 대화를 요약하기 전
  • 이 밖에도 SubagentStop · CwdChanged · FileChanged 같은 이벤트가 더 있다
  • matcher 로 좁힌다. 도구 이벤트는 도구 이름(Bash · Edit|Write · mcp__.*), SessionStart 는 시작 방식(startup · resume · compact), Notification 은 종류(permission_prompt · idle_prompt) 다

입력 · 결과

명령은 표준 입력으로 JSON 하나를 받는다. 모든 이벤트에 session_id · transcript_path · cwd · hook_event_name 이 있고, 이벤트마다 더 붙는다 (PreToolUse 는 tool_name · tool_input, Stop 은 last_assistant_message).

종료 코드 결과
0 그대로 진행. UserPromptSubmit · SessionStart 는 표준 출력을 Claude 가 읽는 컨텍스트로 넣는다
2 막는다. 표준 오류가 막은 이유로 Claude 에게 간다 (PreToolUse 는 도구 호출, UserPromptSubmit 은 메시지를 막는다)
그 밖 막지 않는 오류로 화면에만 보인다
  • $CLAUDE_PROJECT_DIR 은 프로젝트 뿌리다. 스크립트 경로는 이것으로 적는다
  • timeout 을 주지 않으면 명령 훅은 600 초까지 기다린다. 알림처럼 바깥에 보내는 훅은 짧게 준다

응답마다 커밋 · push

개인 저장소에서 Claude 가 고친 것을 응답이 끝날 때마다 올린다. 커밋 메시지는 그 턴에 내가 보낸 말로 만든다.

// .claude/settings.json
{
  "hooks": {
    "Stop": [
      { "matcher": "", "hooks": [{ "type": "command", "command": "bash \"$CLAUDE_PROJECT_DIR/.claude/hooks/sync-repo.sh\"" }] }
    ]
  }
}
#!/bin/bash
# .claude/hooks/sync-repo.sh
cd "$CLAUDE_PROJECT_DIR"
input=$(cat)
git add -A
if ! git diff --cached --quiet; then
  msg=$(printf '%s' "$input" | python3 "$CLAUDE_PROJECT_DIR/.claude/hooks/commit-msg.py")
  subject=$(printf '%s\n' "$msg" | head -n 1)
  [ -n "$subject" ] || subject="auto sync"
  git commit -q -m "chore: $subject $(date '+%Y-%m-%d %H:%M')"
fi
git pull --rebase --autostash -X theirs origin main
git push origin main

commit-msg.py 는 transcript_path 를 뒤에서부터 읽어 마지막 사용자 메시지를 찾는다.

def user_text(entry):
    if entry.get("type") != "user" or entry.get("isMeta"):
        return None
    content = entry.get("message", {}).get("content")
    if isinstance(content, list):
        if any(c.get("type") == "tool_result" for c in content if isinstance(c, dict)):
            return None          # 도구 결과도 type 이 user 다
        content = "\n".join(c.get("text", "") for c in content if c.get("type") == "text")
    text = re.sub(r"<system-reminder>.*?</system-reminder>", "", content or "", flags=re.S).strip()
    if not text or text.startswith(("<local-command", "<command-", "[Request interrupted")):
        return None              # 슬래시 명령 · 중단은 건너뛴다
    return text
  • 대화 기록에는 도구 결과 · 시스템 알림도 type: "user" 로 들어 있다. 걸러 내야 내가 친 말이 나온다
  • 바뀐 것이 없으면 커밋하지 않고 pull · push 만 한다
  • 여러 세션이 같은 저장소에서 일하면 서로의 변경이 섞여 한 커밋에 들어간다

위험한 명령 막기

PreToolUse 에서 rm -rf 를 막는다. 권한을 건너뛰는 모드(--dangerously-skip-permissions) 에서도 막힌다.

{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash", "hooks": [{ "type": "command", "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/no-rm-rf.sh" }] }
    ]
  }
}
#!/bin/bash
# .claude/hooks/no-rm-rf.sh
cmd=$(jq -r '.tool_input.command // ""')
if printf '%s' "$cmd" | grep -Eq '\brm[[:space:]]+-[a-zA-Z]*r[a-zA-Z]*f|\brm[[:space:]]+-[a-zA-Z]*f[a-zA-Z]*r'; then
  echo "rm -rf 는 막아 두었다. 지울 파일을 하나씩 지정한다" >&2
  exit 2
fi
exit 0
$ claude -p 'Bash 로 정확히 `rm -rf build` 한 줄만 실행해. 막히면 막힌 이유를 한 줄로 적어' --dangerously-skip-permissions
프로젝트 PreToolUse 훅(`.claude/hooks/no-rm-rf.sh`)이 `rm -rf build`를 막았다. 훅이 남긴 메시지는 "rm -rf 는 막아 두었다. 지울 파일을 하나씩 지정한다"이다.
  • 막은 이유는 Claude 가 읽으므로, 무엇을 대신 하면 되는지 적어 두면 그대로 따른다
  • 명령 문자열을 정규식으로 보는 것이라 find -delete 처럼 다른 길은 막지 못한다. 마지막 안전장치로 쓴다

주의

  • Stop 훅이 2 로 끝나면 Claude 가 멈추지 않고 이어서 일한다. 이어 가는 중에는 입력의 stop_hook_active 가 true 다. 이것을 보지 않으면 끝나지 않는다
  • 훅은 내 권한으로 바로 돈다. 남의 저장소의 .claude/settings.json 은 폴더를 믿기 전에 읽어 본다
