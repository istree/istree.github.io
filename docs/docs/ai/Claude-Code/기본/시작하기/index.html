Claude Code 를 설치하고, 폴더에서 띄워 말로 일을 시킨다. 대화는 폴더마다 저장돼 나중에 이어서 열 수 있고, 세션에 이름을 붙여 부를 수 있다. 무엇을 묻지 않고 할지는 권한 모드로 정한다.

설치

curl -fsSL https://claude.ai/install.sh | bash   # 네이티브 설치. 저절로 업데이트된다
brew install --cask claude-code                  # 또는 Homebrew
claude --version
  • 네이티브 설치는 ~/.local/bin/claude 에 판마다 링크를 건다 (~/.local/share/claude/versions/<판>)
  • 처음 띄우면 브라우저로 로그인한다. Pro · Max 구독이나 Console(API) 계정을 쓴다

띄우기

cd ~/project
claude                       # 대화 시작
claude "테스트가 왜 깨지는지 봐 줘"   # 첫 메시지를 함께 준다
claude -p "README 를 세 줄로 요약해"   # 한 번 답하고 끝낸다 (스크립트용)
  • 띄운 폴더가 작업 폴더다. 그 폴더와 아래 파일을 읽고 고친다
  • 처음 여는 폴더는 믿을지 묻는다. 믿는다고 해야 그 폴더가 가진 설정(훅 · MCP 서버 · 허용 규칙) 이 적용된다
  • -p 는 결과만 표준 출력으로 내보낸다. --output-format json · stream-json 으로 도구 호출까지 받을 수 있다

이어서 열기 · 이름

claude -c                      # 이 폴더의 마지막 대화
claude -r                      # 대화를 골라서
claude -r <세션 id 또는 이름>   # 바로
claude -n 정리                  # 이름을 붙여 시작
  • 대화 중에는 /rename <이름> 으로 바꾼다. 이름은 프롬프트 줄 · 터미널 제목 · /resume 목록에 나온다
  • 대화 기록은 ~/.claude/projects/<폴더>/<세션 id>.jsonl 에 한 줄씩 쌓인다

권한 모드

Shift+Tab 으로 돌려 가며 바꾸거나, 띄울 때 --permission-mode 로 준다.

모드 묻지 않고 하는 것
default (Manual) 읽기만
acceptEdits 읽기 · 파일 고치기 · mkdir · mv 같은 파일 명령
plan 읽기만 하고 계획을 세운다
auto 모두. 뒤에서 분류기가 위험한 명령을 걸러 낸다
bypassPermissions 모두 
claude --dangerously-skip-permissions    # bypassPermissions 와 같다
  • 혼자 쓰는 맥에서 자주 쓰는 명령은 모드 대신 /permissions 의 허용 규칙(Bash(git log:*) 같은) 으로 풀어 둘 수도 있다
  • 권한을 건너뛰어도 PreToolUse 훅은 돈다. 꼭 막을 명령은 훅으로 막는다
  • bypassPermissions 로 띄울 때마다 묻는 경고는 settings.json 의 "skipDangerousModePermissionPrompt": true 로 끈다

자주 쓰는 명령

명령 하는 일
/clear 새 대화로 시작
/compact [지시] 지금까지를 요약해 컨텍스트를 비운다
/context 컨텍스트를 무엇이 얼마나 쓰는지 본다
/model · /effort 모델 · 생각하는 정도를 바꾼다
/rewind 대화 · 코드를 앞 시점으로 되돌린다
/btw <질문> 대화에 남기지 않고 곁가지 질문을 한다
/usage 사용량 · 한도를 본다
/memory · /hooks · /mcp · /permissions 메모리 · 훅 · MCP 서버 · 권한 규칙을 본다
  • ! 로 시작하면 셸 명령을 바로 돌리고 결과를 대화에 넣는다 (! git status)
  • @파일 은 파일을 대화에 붙인다
  • Esc 는 응답을 멈춘다. 입력칸이 빈 채로 Esc 를 두 번 누르면 되감기 메뉴가 열린다
