쓸 만한 스킬을 하려는 일로 나눠 모았다. 스킬은 Claude Code 에 딸려 오거나, 플러그인으로 깔거나, 저장소에서 받아 ~/.claude/skills/ 에 둔다. 줄마다 끝의 괄호에 어디서 오는지 적었다: 딸려 옴 · 공식(Anthropic 공개 스킬) · 플러그인(공식 마켓플레이스 claude-plugins-official) · 저장소. 2026-11-09 기준이다.

/plugin install commit-commands@claude-plugins-official          # 공식 마켓플레이스 (처음부터 들어 있다)
/plugin marketplace add anthropics/skills                        # Anthropic 공개 스킬
/plugin install document-skills@anthropic-agent-skills
/plugin marketplace add trailofbits/skills                       # 다른 마켓플레이스도 같은 식으로 더한다
npx skills add vercel-labs/agent-skills -a claude-code           # 플러그인이 아닌 저장소 (skills.sh)

리뷰 · 커밋

  • /code-review — 바뀐 코드 · PR 을 리뷰한다. low … ultra 로 깊이를 고르고 --fix 로 고치기까지 한다 (딸려 옴)
  • /simplify — 바뀐 코드를 에이전트 넷이 나눠 보고 다듬는다 (딸려 옴)
  • commit-commands — /commit · /commit-push-pr · 지워진 브랜치 정리 (플러그인)
  • pr-review-toolkit — 주석 · 테스트 · 오류 처리 · 타입 설계를 따로 보는 리뷰 에이전트 여섯 (플러그인)
  • code-simplifier — 동작은 두고 읽기 쉽게 고치는 에이전트 (플러그인)

개발 흐름

  • superpowers — 브레인스토밍 → 계획 → TDD → 서브에이전트로 실행 → 리뷰를 스킬로 묶은 개발 방법 (플러그인)
  • feature-dev — 코드 탐색 · 설계 · 리뷰 에이전트를 거쳐 기능 하나를 만든다 (플러그인)
  • /batch — 저장소 전체에 걸친 변경을 5–30 개 단위로 나눠 워크트리에서 함께 돌린다 (딸려 옴)
  • /loop — 세션이 열려 있는 동안 같은 지시를 간격을 두고 되풀이한다 (딸려 옴)
  • ralph-loop — 끝났다고 할 때까지 같은 지시로 다시 돌린다 (플러그인)
  • code-modernization — 오래된 코드를 평가 · 지도 · 규칙 뽑기 · 옮기기 순서로 바꾼다 (플러그인)

실행 · 테스트

  • /run · /verify — 앱을 띄워 바뀐 것이 실제로 되는지 본다. /run-skill-generator 는 띄우는 법을 프로젝트 스킬로 남긴다 (딸려 옴)
  • /debug — 세션의 디버그 로그를 켜고 읽어 Claude Code 문제를 찾는다 (딸려 옴)
  • webapp-testing — Playwright 로 로컬 웹앱을 조작하고 화면을 찍어 확인한다 (공식)
  • playwright-cli — 브라우저 조작을 MCP 대신 명령줄 + 스킬로 한다. 토큰을 덜 쓴다 (저장소)

문서 파일

  • document-skills — Word(docx) · PDF · PowerPoint(pptx) · Excel(xlsx) 을 읽고 만들고 고친다 (공식)
  • doc-coauthoring — 기획서 · 스펙 · 결정 문서를 단계를 밟아 함께 쓴다 (공식)
  • internal-comms — 사내 공지 · 보고 · 뉴스레터를 정한 꼴로 쓴다 (공식)

화면 · 디자인

  • frontend-design — 판에 박힌 AI 화면을 피해 글꼴 · 색 · 배치를 정하고 UI 를 만든다 (공식 · 플러그인)
  • web-artifacts-builder — React · Tailwind · shadcn/ui 로 여러 부품짜리 HTML 페이지를 만든다 (공식)
  • playground — 조절 막대와 미리보기가 있는 HTML 한 장짜리 실험판을 만든다 (플러그인)
  • canvas-design · algorithmic-art — 포스터 · 그림을 PNG · PDF 로, p5.js 생성 그림을 만든다 (공식)
  • theme-factory — 슬라이드 · 문서 · 페이지에 미리 정한 테마 열 가지 중 하나를 입힌다 (공식)
  • web-design-guidelines · react-best-practices — 웹 화면 · React 코드를 Vercel 의 기준으로 점검한다 (저장소)

보안

  • claude-security — 내 코드의 취약점을 세션 안에서 깊게 찾고 고침 패치까지 만든다 (플러그인)
  • security-guidance — 고칠 때마다 위험한 패턴을 경고하고, 응답이 끝나면 diff 를 보안 리뷰한다 (플러그인)
  • trailofbits/skills — Trail of Bits 의 감사 스킬. 차분 리뷰 · Semgrep 규칙 · 속성 기반 테스트 · 공급망 점검 (마켓플레이스 trailofbits/skills)

Claude Code 손보기

  • /doctor — 설치 · 설정 · 확장 · CLAUDE.md 를 점검하고 고칠 것을 제안한다 (딸려 옴)
  • /fewer-permission-prompts — 자주 승인한 읽기 명령을 찾아 허용 목록에 넣는다 (딸려 옴)
  • skill-creator — 스킬을 만들고, 고치고, 시험 세트로 잘 도는지 잰다 (공식 · 플러그인)
  • claude-md-management — CLAUDE.md 를 점검하고 세션에서 배운 것을 옮겨 적는다 (플러그인)
  • claude-code-setup — 저장소를 읽고 알맞은 훅 · 스킬 · MCP 서버 · 서브에이전트를 추천한다 (플러그인)
  • hookify — 대화에서 되풀이된 실수를 찾아 그것을 막는 훅을 만든다 (플러그인)
  • plugin-dev · mcp-server-dev — 플러그인 · MCP 서버를 만드는 안내와 검사 (플러그인)
  • session-report — 세션의 토큰 · 캐시 · 서브에이전트 · 스킬 사용을 HTML 보고서로 만든다 (플러그인)
  • /claude-api — Claude API · Agent SDK 코드를 쓸 때 언어에 맞는 참조를 불러온다 (딸려 옴)
