스킬은 자주 시키는 일을 SKILL.md 하나로 묶어 둔 것이다. /이름 으로 부르거나, 설명을 보고 Claude 가 알맞은 때에 스스로 꺼내 쓴다. 평소에는 이름과 설명만 컨텍스트에 있고 본문은 쓸 때만 읽으므로, CLAUDE.md 에 늘 넣어 두기에는 긴 절차를 두기 좋다.

위치

폴더 적용
~/.claude/skills/<이름>/SKILL.md 모든 프로젝트
.claude/skills/<이름>/SKILL.md 이 프로젝트 (저장소에 올린다)
  • 폴더에 스크립트 · 예시 파일을 함께 두고 본문에서 가리킬 수 있다
  • /skills 에서 쓸 수 있는 스킬을 본다. 플러그인이 넣은 스킬은 플러그인:이름 으로 부른다

만들기

최근 커밋을 보고 한 일을 요약하는 스킬이다.

---
name: recent
description: 최근 커밋을 보고 무슨 일을 했는지 한 줄로 요약한다. 최근 작업을 물을 때 쓴다
argument-hint: "[커밋 수]"
allowed-tools: Bash(git log:*)
---

최근 커밋이다.

!`git log --oneline -n $ARGUMENTS`

위 커밋으로 무슨 일을 했는지 한 줄로 요약한다. 커밋 수도 함께 적는다.
$ claude -p '/recent 3'
최근 3개 커밋에서 글 2, 3, 4를 차례로 추가했습니다.
  • !`명령` 은 Claude 가 읽기 전에 돌아 그 자리가 출력으로 바뀐다. 지금 상태(diff · 로그 · 브랜치) 를 넣어 주는 데 쓴다
  • $ARGUMENTS 는 /recent 뒤에 준 말 전부, $0 · $1 은 그 가운데 몇 번째다
  • !`…` 안에서 ${ARGUMENTS:-5} 처럼 중괄호 변수를 쓰면 권한 검사를 못 해 실패한다. 기본값이 필요하면 본문 말로 적는다

frontmatter

키 쓰임
description 무엇을 · 언제 쓰는지. Claude 는 이것을 보고 스스로 꺼낼지 정한다
argument-hint / 자동 완성에 보일 인수 안내
allowed-tools 이 스킬을 쓰는 동안 묻지 않고 쓸 도구 (Read · Bash(git log:*))
disable-model-invocation true 면 Claude 가 스스로 꺼내지 않고 /이름 으로만 돈다. 배포 · 커밋처럼 내가 정할 일에 쓴다
model · effort 이 스킬을 도는 동안만 바꾼다
context: fork 따로 떨어진 서브에이전트에서 돌려 결과만 받는다
  • description 에는 쓸 때를 앞에 적는다. 길면 목록에서 잘린다
  • 설명이 비슷한 스킬이 여럿이면 엉뚱한 것을 꺼낸다. 하는 일이 겹치지 않게 나눈다

스크립트를 곁들이기

저장소 상태를 보는 스킬은 스크립트를 폴더에 두고 ! 로 돌린다.

.claude/skills/git-stats/
├── SKILL.md
└── scripts/
    ├── repo-stats.sh
    └── branch-status.sh
---
name: git-stats
description: Git 저장소의 통계와 상태를 분석한다. 커밋 현황 · 기여자 · 브랜치 상태를 볼 때 쓴다
allowed-tools: Bash, Read
---

## 저장소 통계
!`bash .claude/skills/git-stats/scripts/repo-stats.sh`

## 브랜치
!`bash .claude/skills/git-stats/scripts/branch-status.sh`

위 결과로 눈여겨볼 것 세 가지를 적는다.
