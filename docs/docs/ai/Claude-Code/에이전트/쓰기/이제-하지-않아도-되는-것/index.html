예전 모델의 약점을 메우던 요령 가운데, 지금은 버려도 되는 것을 모았다. 습관처럼 남아 있으면 오히려 지나친 작업을 부른다.

예전 조언 지금
컨텍스트를 아끼려고 늘 관리한다 1M 창과 자동 요약으로 모자라는 일이 드물다. 일 사이 /clear 는 여전히 좋다
놓치는 지시에 IMPORTANT · 대문자 평이하게 적은 줄도 따른다. 강조는 지나친 적용을 부른다
컨텍스트를 지키려고 서브에이전트 병렬 · 시끄러운 출력 떼기 · 독립 리뷰에는 좋지만 그만큼 토큰을 쓴다
더 나은 답을 얻으려고 서브에이전트에 맡긴다 같은 일을 넘긴다고 나아지지 않는다. 리뷰가 나아지는 것은 새 눈이기 때문이다
think hard · be thorough effort 가 맡는다. ultrathink 는 여전히 한 턴을 깊게 한다
"끝까지 해 · 게으르지 마" 합의한 일은 끝까지 한다. 대신 통과할 확인 수단을 준다
