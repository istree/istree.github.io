설정이 아무리 좋아도, 세션을 지켜보다 엇나갈 때 바로잡는 것을 대신하지 못한다. 이 쪽은 대화 중에 쓰는 손잡이를 모았다.

  • 처음 1 분을 지켜본다 — 엉뚱한 쪽으로 가면 Esc 로 멈추고 방향을 고친다. 멈춰도 한 일은 남는다
  • 되감고 과감하게 — /rewind 로 코드 · 대화를 앞 시점으로 돌릴 수 있으니, 큰 방법을 먼저 해 보고 안 되면 되돌린다
  • 두 번 틀리면 새로 — 같은 것을 두 번 고쳐도 틀리면 /clear 하고, 알게 된 것을 담은 새 프롬프트 하나로 다시 시킨다
  • 일 사이에 비운다 — 작업이 바뀌면 /clear 한다. 집중된 컨텍스트가 답도 낫고 비용도 적다
  • 어려운 일에 effort — 남이 쓴 코드의 버그 · 불안정한 테스트처럼 놓치기 쉬운 일은 /effort high · xhigh 로 올린다. 한 턴만 깊게 하려면 프롬프트에 ultrathink 를 적는다
  • 세션을 나란히 — 일마다 claude -w <이름> 으로 워크트리를 따로 주어 고친 것이 부딪히지 않게 한다
