컨텍스트는 쓸수록 흐려지는 한정된 주의다. 원하는 결과를 낼 가장 적은, 쓸모 있는 토큰을 고른다.

  • 알맞은 높이의 시스템 프롬프트 — if-else 를 늘어놓는 너무 구체적인 것과 막연한 것 사이에서, 판단 기준을 주는 말로 쓴다. 절(XML 태그 · 마크다운 제목) 로 나눈다
  • 예시는 대표적인 몇 개 — 경계 경우를 줄줄이 늘어놓지 말고, 바라는 행동을 보여 주는 다양한 예 몇 개를 둔다
  • 그때그때 불러온다(just in time) — 자료를 미리 다 넣지 말고 파일 경로 · 질의 · 링크 같은 가벼운 이름표를 들고 있다가 필요할 때 도구로 읽는다. 둘러보며 조금씩 알아 가게 한다(progressive disclosure)
  • 요약(compaction) — 창이 차면 대화를 요약해 새 창에서 잇는다. 무엇을 버릴지가 관건이고, 오래된 도구 결과부터 지운다
  • 노트 쓰기 — 에이전트가 진행 상황을 창 밖 파일(NOTES.md · 할 일 목록) 에 적고, 다시 시작할 때 읽어 이어 간다
  • 서브에이전트로 떼어 낸다 — 넓게 찾는 일은 깨끗한 창의 서브에이전트가 하고, 요약만 본 에이전트에게 돌려준다
