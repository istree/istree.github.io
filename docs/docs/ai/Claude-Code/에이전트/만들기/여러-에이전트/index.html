지휘 에이전트가 일을 나눠 일꾼 에이전트들에게 맡기고 결과를 합친다. 넓게 퍼지는 조사에 잘 맞지만, 조율이 어렵고 토큰을 훨씬 많이 쓴다.

  • 지휘 하나 · 일꾼 여럿 — 지휘 에이전트가 질문을 나눠 일꾼에게 맡기고, 일꾼은 각자의 창에서 찾아 요약을 돌려준다. 넓게 퍼지는 조사에 잘 맞지만 토큰을 훨씬 많이 쓴다
  • 맡기는 법을 가르친다 — 일꾼마다 목표 · 출력 꼴 · 쓸 도구 · 일의 경계를 적어 준다. 짧게 맡기면 같은 일을 겹쳐 한다
  • 일의 크기에 맞춰 늘린다 — 단순한 사실 찾기는 일꾼 하나에 도구 호출 몇 번, 복잡한 조사는 일꾼 여럿처럼 규칙을 프롬프트에 둔다
  • 넓게 보고 좁힌다 — 처음에는 짧고 넓은 검색으로 판을 보고, 그다음 좁힌다
  • 함께 부른다 — 일꾼을 동시에 띄우고, 일꾼도 도구를 동시에 부르게 하면 훨씬 빨라진다
  • 에이전트처럼 생각한다 — 같은 프롬프트 · 도구로 돌려 보며 한 단계씩 지켜보고, 실패 사례를 모델에게 주어 프롬프트를 고치게 한다
  • 작게 일찍 평가한다 — 과제 스무 개쯤으로 바로 시작하고, LLM 채점(기준표) 과 사람 시험을 함께 쓴다
  • 오래 도는 것은 이어 갈 수 있게 — 오류가 쌓이므로 중간 상태를 남겨 실패한 곳에서 다시 시작하게 한다
