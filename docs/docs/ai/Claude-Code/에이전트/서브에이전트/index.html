서브에이전트는 한 대화 안에서 일을 떼어 맡기는 또 하나의 Claude 다. Claude 는 필요하면 스스로 서브에이전트를 띄운다. 서브에이전트는 자기 컨텍스트에서 일하고 마지막 답만 돌려주므로, 넓게 찾아보는 일이 본 대화를 채우지 않는다.

기본 에이전트

에이전트 하는 일
Explore 읽기만 하며 파일 · 코드를 찾는다
Plan plan 모드에서 계획에 앞서 코드를 살핀다
general-purpose 찾아보고 고치기까지 여러 단계로 일한다

만들기

내가 만든 에이전트는 마크다운 파일 하나다.

---
name: counter
description: 폴더의 파일 수와 이름을 세어 보고한다. 파일 목록을 셀 때 쓴다
tools: Bash, Glob
model: haiku
---

작업 폴더의 파일(숨김 폴더 제외) 을 세고 `파일 N 개: 이름, 이름…` 한 줄로만 답한다.
$ claude -p 'counter 에이전트에게 맡겨서 결과를 그대로 한 줄로 출력해'
파일 5 개: build/a.o, f1.txt, f2.txt, f3.txt, f4.txt
  • 위치는 .claude/agents/ (이 프로젝트) · ~/.claude/agents/ (모든 프로젝트) 다
  • 본문이 그 에이전트의 시스템 프롬프트다. 본 대화의 내용은 넘어가지 않고, Claude 가 써 준 작업 지시만 받는다
  • tools 로 쓸 도구를 줄이고, model 로 싼 모델에서 돌린다
  • 이름을 말하면 Claude 가 맡기고, @"counter (agent)" 로 부르면 반드시 그 에이전트가 돈다
  • 대화형 세션에서는 서브에이전트가 뒤에서 돈다. 도는 동안 나는 계속 말을 걸 수 있다
