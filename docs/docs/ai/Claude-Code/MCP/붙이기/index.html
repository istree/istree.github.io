MCP(Model Context Protocol) 서버는 Claude Code 에 바깥 도구를 붙이는 프로그램이다. 서버가 도구 이름 · 설명 · 입력 형식을 알려 주면, Claude 는 필요할 때 그 도구를 부른다. GitHub · Notion · 브라우저처럼 이미 만들어진 서버를 claude mcp add 로 붙이고, 범위를 골라 나만 쓰거나 저장소와 함께 나눈다.

명령

claude mcp add hello -- node stdio.js                                  # 내 맥에서 띄우는 서버 (stdio)
claude mcp add --transport http notion https://mcp.notion.com/mcp      # 원격 서버 (HTTP)
claude mcp add --scope project hello -- node stdio.js                  # .mcp.json 에 적어 저장소와 함께 쓴다
claude mcp list

범위

범위 저장 위치 적용
local (기본) ~/.claude.json 의 이 프로젝트 이 프로젝트, 나만
project .mcp.json 이 프로젝트, 저장소에 올린다
user ~/.claude.json 모든 프로젝트, 나만

.mcp.json

저장소와 함께 쓰는 서버는 .mcp.json 에 적힌다. 손으로 적어도 된다.

// .mcp.json
{
  "mcpServers": {
    "hello": { "type": "stdio", "command": "node", "args": ["stdio.js"], "env": {} },
    "hello-http": { "type": "http", "url": "http://127.0.0.1:3000/mcp" }
  }
}
  • .mcp.json 의 서버는 처음에 쓸지 묻는다. 그 전에는 claude mcp list 에 Pending approval 로 나온다
  • 서버 도구는 mcp__<서버>__<도구> 이름이 된다. 권한 규칙 · 훅의 matcher 에도 이 이름을 쓴다
  • 대화 중 /mcp 에서 연결 상태를 보고 다시 연결한다
  • --transport sse 는 예전 방식이다. HTTP 로 붙이면 서버가 SSE 만 받을 때 저절로 SSE 로 바꾼다
