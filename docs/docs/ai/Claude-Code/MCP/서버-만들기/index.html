MCP 서버는 몇십 줄로 직접 만든다. 도구마다 이름 · 설명 · 입력 형식을 등록하고, 내 맥에서 띄우는 stdio 서버나 떨어진 곳에 두는 HTTP 서버로 내보낸다. 예제는 @modelcontextprotocol/sdk 1.32, zod 4, Node.js 26 으로 돌렸다.

도구 만들기

두 서버가 함께 쓰는 도구다. registerTool 에 이름 · 설명 · 입력 형식(zod) 을 주고, 결과는 content 배열로 돌려준다.

// tools.js
import { z } from 'zod';

export function addTools(server) {
  server.registerTool('greet', {
    description: '이름을 받아 인사한다',
    inputSchema: { name: z.string().describe('인사할 사람') },
  }, async ({ name }) => ({
    content: [{ type: 'text', text: `안녕하세요, ${name}님!` }],
  }));

  server.registerTool('now', {
    description: '서울 시각을 돌려준다',
  }, async () => ({
    content: [{ type: 'text', text: new Date().toLocaleString('ko-KR', { timeZone: 'Asia/Seoul' }) }],
  }));
}
npm init -y && npm pkg set type=module
npm install @modelcontextprotocol/sdk zod express
  • description 은 Claude 가 언제 부를지 고르는 근거다. 무엇을 하는지 한 줄로 분명하게 적는다
  • 예전 server.tool(이름, 설명, 형식, 함수) 는 registerTool 로 바뀌었다 (지금은 deprecated)

stdio 서버

Claude Code 가 프로세스를 띄우고 표준 입출력으로 주고받는다. 내 맥에서만 쓸 도구는 이것으로 충분하다.

// stdio.js
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { addTools } from './tools.js';

const server = new McpServer({ name: 'hello', version: '1.0.0' });
addTools(server);
await server.connect(new StdioServerTransport());
$ claude -p 'hello MCP 의 greet 도구로 "길동" 에게 인사하고, 도구가 돌려준 글만 그대로 출력해' --allowedTools mcp__hello__greet
안녕하세요, 길동님!
  • 표준 출력은 프로토콜이 쓴다. 로그는 console.error 로 남긴다
  • JSON-RPC 를 손으로 넣어 봐도 된다: initialize → notifications/initialized → tools/list · tools/call 을 한 줄씩 넣는다

HTTP 서버

떨어진 곳에서 띄워 두고 여럿이 붙는 서버다. 세션을 두지 않는 가장 단순한 형태는 요청마다 서버를 새로 만든다.

// http.js
import express from 'express';
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StreamableHTTPServerTransport } from '@modelcontextprotocol/sdk/server/streamableHttp.js';
import { addTools } from './tools.js';

const app = express();
app.use(express.json());

app.post('/mcp', async (req, res) => {
  const server = new McpServer({ name: 'hello-http', version: '1.0.0' });
  addTools(server);
  const transport = new StreamableHTTPServerTransport({ sessionIdGenerator: undefined });
  res.on('close', () => { transport.close(); server.close(); });
  await server.connect(transport);
  await transport.handleRequest(req, res, req.body);
});

app.listen(3000, '127.0.0.1');
$ node http.js &
$ claude mcp add --transport http hello-http http://127.0.0.1:3000/mcp
$ claude -p 'hello-http MCP 의 now 도구를 불러, 도구가 돌려준 글만 그대로 출력해' --allowedTools mcp__hello-http__now
2026. 11. 9. 오후 5:03:38
  • sessionIdGenerator: undefined 면 세션 없이 돈다. 서버가 상태를 기억해야 하면 세션 id 를 만들고 transport 를 id 마다 남겨 둔다
  • 바깥에 열 때는 인증(OAuth · 헤더 토큰) 을 붙인다. claude mcp add --header 'Authorization: Bearer …' 로 헤더를 줄 수 있다
