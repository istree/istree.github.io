AI 정리는 개발할 때 쓰는 AI 도구를 모았다. 지금은 대형 언어 모델(LLM) 에 말로 일을 시키는 코딩 에이전트가 중심이다. 에이전트는 채팅 창에서 답만 하는 데서 나아가, 터미널에서 파일을 읽고 고치고 명령을 돌리며 일을 끝까지 해 나간다. 사람은 무엇을 할지 정하고, 승인할 것을 승인하고, 결과를 확인한다.

여기서는 Claude Code 를 쓴다. 설정 파일과 훅 · 상태 표시줄 · 플러그인 · 채널로 쓰는 환경을 넓히고, 여러 세션을 띄워 두고 일을 나눠 맡긴다. 바깥 도구와는 MCP(Model Context Protocol) 로 연결한다. 글은 macOS 에서 직접 돌려 본 설정과 스크립트로 썼다.
