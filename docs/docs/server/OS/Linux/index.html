리눅스는 서버에서 가장 많이 쓰는 운영체제다. 웹 서버 · DB · 컨테이너 엔진이 대부분 리눅스 위에서 돌고, 서버는 화면 없이 SSH 로 들어가 셸 명령으로 다룬다. 배포판은 여럿이지만 서버에서 다루는 일 — 파일 찾기 · 권한 · 프로세스 · 서비스(systemd) · 예약 작업 · 네트워크 — 은 거의 같고, 패키지 관리자(apt · dnf) 와 설정 파일의 자리가 조금씩 다르다.
