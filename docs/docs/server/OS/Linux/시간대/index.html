리눅스는 시계를 UTC 로 두고 시간대 설정에 따라 지역 시각으로 바꿔 보인다. 서버 · 컨테이너는 대개 UTC 로 시작해서, 로그 시각이 9 시간 어긋나 보이면 시간대를 맞춘다. 시계 자체가 틀어지지 않게 NTP 로 맞추는 일은 systemd-timesyncd 가 한다. 아래 예제는 colima 의 Ubuntu 24.04 가상 머신과 ubuntu:24.04 컨테이너에서 돌렸다.

보기와 바꾸기

timedatectl
               Local time: Sun 2026-11-08 18:57:30 KST
           Universal time: Sun 2026-11-08 09:57:30 UTC
                 RTC time: Sun 2026-11-08 09:57:30
                Time zone: Asia/Seoul (KST, +0900)
System clock synchronized: yes
              NTP service: active
          RTC in local TZ: no
timedatectl list-timezones | grep Seoul      # Asia/Seoul — 이름은 497 개
sudo timedatectl set-timezone Asia/Seoul
ls -l /etc/localtime
# /etc/localtime -> /usr/share/zoneinfo/Asia/Seoul
  • set-timezone 은 /etc/localtime 링크를 바꾼다. 바꾸면 바로 date 에 반영된다
  • 이미 떠 있는 프로그램(DB · Java 앱) 은 시작할 때의 시간대를 쥐고 있어 다시 띄워야 바뀐다
  • 서버를 UTC 로 두고 앱에서 시간대를 다루는 곳도 많다. 여러 지역의 서버 로그를 맞춰 볼 때 편하다

시계 맞추기 (NTP)

timedatectl timesync-status
       Server: 185.125.190.58 (ntp.ubuntu.com)
Poll interval: 34min 8s (min: 32s; max 34min 8s)
         Leap: normal
      Version: 4
      Stratum: 2
    Reference: 1D586304
    Precision: 1us (-25)
Root distance: 3.776ms (max: 5s)
  • Ubuntu 는 systemd-timesyncd 가 ntp.ubuntu.com 에 맞춘다. System clock synchronized: yes 면 맞춰진 것이다
  • 회사 안의 NTP 서버를 쓰려면 /etc/systemd/timesyncd.conf 의 [Time] 에 NTP=ntp.회사.lan 을 적고 sudo systemctl restart systemd-timesyncd 한다
  • 꺼져 있으면 sudo timedatectl set-ntp true 로 켠다

컨테이너

ubuntu:24.04 이미지에는 /etc/localtime 도 시간대 자료도 없다.

docker run --rm ubuntu:24.04 date                      # Sun Nov  8 09:57:30 UTC 2026
docker run --rm -e TZ=Asia/Seoul ubuntu:24.04 date     # Sun Nov  8 09:57:31 Asia 2026 — 자료가 없어 UTC 시각 그대로

tzdata 를 깔면 TZ 가 먹는다.

apt-get install -y tzdata
TZ=Asia/Seoul date                                      # Sun Nov  8 18:57:43 KST 2026
ln -sf /usr/share/zoneinfo/Asia/Seoul /etc/localtime    # TZ 없이 늘 — Sun Nov  8 18:57:43 KST 2026
  • tzdata 없이 /etc/localtime 링크만 만들면 가리킬 파일(/usr/share/zoneinfo) 이 없어 그대로 UTC 다
  • Dockerfile 에서는 RUN apt-get install -y tzdata 와 ENV TZ=Asia/Seoul 을 함께 둔다. 설치가 시간대를 물어 멈추지 않게 DEBIAN_FRONTEND=noninteractive 를 붙인다
  • 호스트의 시간대를 그대로 쓰려면 -v /etc/localtime:/etc/localtime:ro 로 연결한다. 맥의 Docker 에서는 호스트가 가상 머신이라, 가상 머신의 시간대를 따른다
  • 이미지마다 다르다. nginx:alpine · mysql 처럼 tzdata 가 든 이미지는 TZ 만 주면 된다

예전에는

  • /etc/timezone 파일을 고치고 dpkg-reconfigure tzdata 를 돌렸다. 지금은 timedatectl set-timezone 하나다
  • NTP 는 ntpdate 를 cron 으로 돌리거나 ntpd 를 깔았다. 지금은 기본으로 깔린 systemd-timesyncd 가 한다 (정밀한 서버는 chrony)
