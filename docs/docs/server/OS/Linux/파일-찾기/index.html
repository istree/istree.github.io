find 는 파일을 이름 · 종류 · 시간 · 크기로 찾아 목록을 내거나 파일마다 명령을 돌리고, grep 은 파일 안의 글자를 찾는다. 설정 파일이 어디 있는지, 어떤 설정에 이 값이 들어 있는지, 오래된 로그가 무엇인지를 서버에서 찾을 때 둘을 함께 쓴다. 아래 예제는 Ubuntu 24.04 컨테이너(GNU findutils 4.9 · GNU grep 3.11) 에서 이런 폴더를 만들어 돌렸다.

경로 내용
conf/default.conf server { listen 80; # virtual host }
conf/site.conf <VirtualHost *:80>
conf/.DS_Store · src/.DS_Store 맥이 남긴 파일
logs/big.log · logs/old.log 3 MB · 40 일 전에 고친 것
src/main.py virtual = true

find

find . -name ".DS_Store"                   # 이름으로 — ./conf/.DS_Store, ./src/.DS_Store
find . -type f -name "*.conf"              # 파일만(f), 폴더는 d — ./conf/site.conf, ./conf/default.conf
find . -iname "*.CONF"                     # 대소문자 무시
find . -type f -mtime +30                  # 30 일보다 오래 고치지 않은 것 — ./logs/old.log
find . -type f -size +1M                   # 1 MB 보다 큰 것 — ./logs/big.log
find . -maxdepth 1 -type d                 # 한 단계만 — . ./conf ./src ./logs
find . -type f -not -path "./logs/*"       # 이 경로는 빼고
  • 이름 무늬는 꼭 따옴표로 감싼다. 감싸지 않으면 셸이 먼저 지금 폴더의 파일로 펼쳐 엉뚱한 것을 찾는다
  • 시간은 -mtime(일) · -mmin(분) 이다. +30 은 30 일 넘게, -1 은 하루 안에 고친 것이다
  • 크기 단위는 k · M · G 다

찾은 파일마다 명령

find . -name ".DS_Store" -exec rm {} \;               # 하나마다 rm 을 한 번씩
find . -type f -name "*.conf" -exec wc -l {} +        # 모아서 한 번에
#  2 ./conf/site.conf
#  4 ./conf/default.conf
#  6 total
find . -type f -mtime +30 -delete                     # 지우기는 -delete 가 빠르다
  • {} 자리에 찾은 파일이 들어간다. \; 은 파일마다 한 번, + 는 여럿을 모아 한 번 돌린다. 파일이 많으면 + 가 훨씬 빠르다
  • 끝맺음을 빠뜨리면 find: missing argument to -exec'` 가 난다
  • 지우기 전에는 -delete 를 빼고 돌려 목록을 먼저 본다

폴더는 755, 파일은 644 로 권한을 한 번에 맞출 때도 쓴다.

find . -type d -exec chmod 755 {} +
find . -type f -exec chmod 644 {} +

grep

grep virtual conf/default.conf        #   # virtual host
grep -rn virtual .                    # 하위 폴더까지(-r), 줄 번호(-n)
# ./conf/default.conf:3:  # virtual host
# ./src/main.py:1:virtual = true
grep -rni virtual .                   # 대소문자 무시(-i) — site.conf 의 VirtualHost 도
grep -rli virtual .                   # 파일 이름만(-l)
grep -rn --include="*.conf" -i virtual .    # 이 이름의 파일에서만
옵션 뜻
-r 하위 폴더까지
-n 줄 번호
-i 대소문자 무시
-l 맞는 파일 이름만
-v 맞지 않는 줄 — grep -v "^ *#" 로 주석 빼고 보기
-c 맞는 줄 수
-E 확장 정규식 — + · ? · 묶음 ( ) 을 역슬래시 없이 쓴다
-o 맞은 부분만 — grep -o "[0-9]\+" → 80
-w 단어로만
-A 1 · -B 1 · -C 1 맞은 줄 뒤 · 앞 · 둘레 한 줄도 
grep -n -A1 listen conf/default.conf
# 2:  listen 80;
# 3-  # virtual host
  • 설정 파일에서 주석 · 빈 줄을 빼고 보려면 grep -Ev "^\s*(#|$)" 파일 이다. 여럿 중 하나는 grep -E "listen|server" 다

find 와 grep 을 함께

grep -r 은 이름으로 거르기가 --include 뿐이다. 시간 · 크기로 거른 파일 안을 찾을 때는 find 의 목록을 xargs 로 grep 에 넘긴다.

find . -name "*.conf" | xargs grep -n virtual        # 파일마다 grep — ./conf/default.conf:3:  # virtual host
find . -name "*.conf" | grep default                 # xargs 가 없으면 파일 이름에서 찾는다 — ./conf/default.conf

파일 이름에 공백이 있으면 xargs 가 공백에서 끊는다. -print0 과 -0 을 짝으로 쓴다.

find . -name "*.conf" | xargs grep -l virtual
# grep: ./conf/my: No such file or directory
# grep: site.conf: No such file or directory
find . -name "*.conf" -print0 | xargs -0 grep -l virtual
# ./conf/my site.conf
# ./conf/default.conf
  • find … -exec grep -n virtual {} + 도 같은 일을 하고 공백 걱정이 없다

맥과 다른 점

  • 맥의 find · grep 은 BSD 판이라 옵션 · 메시지가 조금 다르다. -exec 끝맺음을 빠뜨리면 맥은 find: -exec: no terminating ";" or "+" 를 낸다
  • 맥에서는 find 에 경로를 꼭 줘야 한다. 빼면 find: illegal option -- n 이 난다. GNU 판은 빼면 . 으로 본다
  • 같은 옵션을 쓰려면 brew install findutils grep 으로 GNU 판(gfind · ggrep) 을 깐다
