서버의 운영체제는 대부분 리눅스다. 서버 프로그램은 리눅스에 패키지로 깔아 서비스(systemd) 로 돌리거나, 컨테이너(Docker) 로 띄운다. 컨테이너는 가상 머신과 달리 호스트의 리눅스 커널을 함께 쓰는 격리된 프로세스로, 커널의 네임스페이스 · cgroup 기능 위에서 돈다. 그래서 맥 · 윈도우의 Docker 도 속에서는 리눅스 가상 머신을 띄운다.

정보

  • Ubuntu release cycle — LTS 판의 출시 · 지원 기간
  • endoflife.date — 배포판 · 프로그램 버전마다 지원이 끝나는 날
  • Open Container Initiative — 컨테이너 이미지 · 실행의 표준을 정하는 곳

문서

  • Filesystem Hierarchy Standard — /etc · /var · /opt 같은 폴더마다 무엇을 두는지 정한 표준
  • namespaces(7) · cgroups(7) — 컨테이너가 쓰는 커널 기능 설명서

도구

  • Killercoda — 브라우저에서 리눅스 · Docker 시험 환경을 띄워 따라 해 본다
  • Multipass — 맥 · 윈도우에서 Ubuntu 가상 머신을 명령 하나로 띄운다
  • Lima — 맥에서 리눅스 가상 머신을 띄운다. colima 가 이것으로 Docker 엔진을 띄운다
  • crontab.guru — cron 시간 식을 넣으면 언제 도는지 풀어 보인다

책

  • How Linux Works (3판, 2021) — Brian Ward.
