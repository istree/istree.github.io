이미지와 컨테이너

이미지는 프로그램과 그 실행 환경을 담은 읽기 전용 꾸러미이고, 컨테이너는 이미지를 실행한 것이다. 이미지 하나로 컨테이너를 여럿 띄울 수 있고, 컨테이너가 쓴 파일은 그 컨테이너에만 남는다. 컨테이너는 안의 주 프로세스(PID 1) 가 끝나면 함께 멈춘다. 아래 예제는 Nginx 이미지로 웹 서버 컨테이너를 띄우고, 들여다보고, 멈추고, 지우는 순서다.

이미지 받기

docker pull nginx:1.28-alpine       # 이름:태그 — 태그를 빼면 latest
docker images
IMAGE                ID             DISK USAGE   CONTENT SIZE   EXTRA
nginx:1.28-alpine    a8b39bd9cf0f       92.5MB         26.7MB
ubuntu:24.04         fe81560990fa        141MB         30.9MB
  • 태그는 버전이다. latest 는 받을 때마다 바뀔 수 있으므로 서버에서는 1.28-alpine 처럼 버전을 적는다
  • -alpine 은 Alpine 리눅스를 바탕으로 한 작은 이미지다. 셸이 bash 가 아니라 sh 이고 패키지 관리자는 apk 다
  • CONTENT SIZE 는 받은 압축 크기, DISK USAGE 는 풀어 놓은 크기다

실행

docker run -d --name web -p 8080:80 nginx:1.28-alpine
docker ps
CONTAINER ID   IMAGE               COMMAND                   CREATED                  STATUS                  PORTS                                     NAMES
53405c41ee74   nginx:1.28-alpine   "/docker-entrypoint.…"   Less than a second ago   Up Less than a second   0.0.0.0:8080->80/tcp, [::]:8080->80/tcp   web
curl -sI localhost:8080 | head -2
# HTTP/1.1 200 OK
# Server: nginx/1.28.3
옵션 뜻
-d 뒤에서 실행하고 컨테이너 ID 만 찍는다
--name web 이름을 정한다. 빼면 eager_turing 같은 이름이 붙는다
-p 8080:80 호스트 8080 을 컨테이너 80 에 연결한다. 127.0.0.1:8080:80 이면 이 컴퓨터에서만 열린다
-v 호스트경로:컨테이너경로 폴더 · 볼륨을 연결한다
-e KEY=값 환경 변수를 넣는다
--rm 멈추면 컨테이너를 지운다 — 한 번 돌리고 버릴 때
-it 터미널을 붙인다 — bash 같은 대화형 프로그램을 돌릴 때
--restart unless-stopped 죽거나 엔진이 다시 뜨면 다시 시작한다. 손으로 멈춘 것은 그대로 둔다 
docker run --rm ubuntu:24.04 echo hi                              # hi — 찍고 바로 지워진다
docker run --rm -e GREETING=안녕 ubuntu:24.04 sh -c 'echo $GREETING'   # 안녕
docker run --rm -it ubuntu:24.04 bash                             # 안에 들어가 셸을 쓴다. exit 하면 지워진다
  • 이미지가 없으면 run 이 먼저 받는다. pull 을 따로 하지 않아도 된다
  • 할 일이 없는 이미지는 실행하자마자 멈춘다. docker run --name once ubuntu:24.04 는 bash 가 입력 없이 끝나 바로 Exited (0) 이 된다

들여다보기

docker logs --tail 3 web          # -f 를 붙이면 계속 따라 본다
2026/11/08 09:15:01 [notice] 1#1: start worker process 30
2026/11/08 09:15:01 [notice] 1#1: start worker process 31
172.17.0.1 - - [08/Nov/2026:09:15:01 +0000] "HEAD / HTTP/1.1" 200 0 "-" "curl/8.7.1" "-"
docker exec web nginx -v                  # nginx version: nginx/1.28.3
docker exec web cat /etc/os-release       # NAME="Alpine Linux" …
docker exec -it web sh                    # 안에 셸을 띄워 들어간다
  • logs 는 컨테이너의 표준 출력 · 표준 오류를 보인다. 프로그램이 파일에만 로그를 쓰면 여기에 나오지 않는다
  • logs -t 는 줄마다 시각을 붙인다
  • exec 는 실행 중인 컨테이너 안에서 명령을 하나 더 돌린다. 멈춘 컨테이너에는 쓸 수 없다

멈추기 · 다시 시작 · 지우기

docker stop web
docker ps -a --format 'table {{.Names}}\t{{.Image}}\t{{.Status}}'
NAMES     IMAGE               STATUS
web       nginx:1.28-alpine   Exited (0) Less than a second ago
docker start web
docker rename web web-old
docker rm web-old
# Error response from daemon: cannot remove container "web-old": container is running: stop the container before removing or force remove
docker rm -f web-old              # 멈추고 지운다
  • docker ps 는 실행 중인 것만, -a 는 멈춘 것까지 보인다
  • 멈춘 컨테이너는 지울 때까지 남아 있고, 안에서 쓴 파일도 남는다. start 하면 그대로 이어진다
  • 이름은 겹칠 수 없다. 같은 이름으로 다시 run 하려면 옛 컨테이너를 먼저 지우거나 rename 한다

stop 은 PID 1 에 SIGTERM 을 보내고 10 초 기다린 뒤 SIGKILL 로 끝낸다. 셸 스크립트를 PID 1 로 돌리면 SIGTERM 을 받지 않아 늘 10 초가 걸린다.

docker run -d --name loop ubuntu:24.04 sh -c 'while true; do sleep 1; done'
time docker stop loop             # 10.1 초 — SIGTERM 을 무시해 SIGKILL 로 끝남

docker run -d --init --name loop2 ubuntu:24.04 sh -c 'while true; do sleep 1; done'
time docker stop loop2            # 0.08 초 — --init 이 신호를 받아 끝낸다

docker run -d --name nap ubuntu:24.04 sleep 1000
docker stop -t 2 nap              # 2 초만 기다린다 — 2.1 초, 종료 코드 137 (SIGKILL 로 끝남)

이미지 지우기 · 청소

docker rmi ubuntu:24.04
# Error response from daemon: conflict: unable to delete ubuntu:24.04 (must be forced) - container c3dbdf3b3669 is using its referenced image fe81560990fa

docker container prune -f         # 멈춘 컨테이너를 모두 지운다
docker system df                  # 무엇이 자리를 차지하는지
TYPE            TOTAL     ACTIVE    SIZE      RECLAIMABLE
Images          3         1         234MB     141.3MB (60%)
Containers      1         1         81.92kB   0B (0%)
Local Volumes   0         0         0B        0B
Build Cache     0         0         0B        0B
  • 멈춘 컨테이너라도 쓰고 있는 이미지는 지워지지 않는다. 컨테이너를 먼저 지운다
  • docker image prune 은 이름 없는(<none>) 이미지를, -a 를 붙이면 컨테이너가 쓰지 않는 이미지를 모두 지운다
  • docker system prune 은 멈춘 컨테이너 · 쓰지 않는 네트워크 · 이름 없는 이미지 · 빌드 캐시를 한 번에 지운다

예전에는

  • 컨테이너끼리 연결할 때 --link mysql_57:mysql 을 썼다. 지금은 사용자 정의 네트워크에 함께 넣고 이름으로 찾는다
  • docker ps · docker rm 같은 짧은 꼴은 지금도 되지만, 새 꼴은 docker container ls · docker container rm 처럼 대상을 앞에 쓴다
