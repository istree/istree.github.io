Docker 는 프로그램과 그 프로그램이 쓰는 라이브러리 · 설정을 이미지 하나로 묶고, 그 이미지를 어느 서버에서나 같은 모습으로 실행하는 도구다. 실행한 이미지를 컨테이너라고 한다. 컨테이너는 가상 머신과 달리 호스트의 리눅스 커널을 함께 쓰는 격리된 프로세스라서, 몇 초 만에 뜨고 메모리도 프로그램이 쓰는 만큼만 든다. 이미지는 Docker Hub 같은 레지스트리에서 받거나 Dockerfile 로 직접 만들고, 컨테이너 여럿은 Compose 로 함께 띄운다.

서버에 DB · 웹 서버 · 사내 도구를 깔 때 패키지를 하나씩 설치하는 대신 컨테이너로 띄우면, 버전을 바꾸거나 지울 때 서버가 더러워지지 않고 같은 구성을 다른 서버에 그대로 옮길 수 있다.
