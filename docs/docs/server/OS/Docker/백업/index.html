Docker 에서 남길 것은 셋이다. 이미지는 Dockerfile 로 다시 만들거나 레지스트리에서 다시 받으면 되고, 자료는 볼륨에 있으며, 손으로 고친 컨테이너는 이미지로 굳혀 둔다. 인터넷이 없는 서버로 옮길 때는 이미지를 파일 하나로 꺼낸다. 아래 예제는 commit · save / load · export / import · 볼륨 tar 를 차례로 돌린 것이다.

고친 컨테이너를 이미지로 (commit)

docker run --name tool ubuntu:24.04 sh -c 'apt-get update -qq && apt-get install -y -qq curl'
docker commit -m "curl 넣음" tool my-ubuntu:curl
docker run --rm my-ubuntu:curl curl --version | head -1
# curl 8.5.0 (aarch64-unknown-linux-gnu) libcurl/8.5.0 OpenSSL/3.0.13 …
docker image history --format '{{.CreatedBy}} {{.Comment}}' my-ubuntu:curl | head -1
# sh -c apt-get update -qq && apt-get install … curl 넣음
  • 무엇을 바꿨는지는 이미지에 명령 한 줄과 메모로만 남는다. 오래 쓸 이미지는 같은 일을 Dockerfile 로 옮겨 적는다
  • 볼륨에 든 자료는 commit 에 들어가지 않는다

이미지를 파일로 (save · load)

docker save -o my-ubuntu.tar my-ubuntu:curl          # 70M
docker rmi my-ubuntu:curl
docker load -i my-ubuntu.tar                         # Loaded image: my-ubuntu:curl
  • 층 · 태그 · 실행 설정(CMD …) 이 그대로 담긴다. 이미지 여럿을 한 파일에 담을 수 있다 (docker save -o all.tar a:1 b:2)
  • 서버 사이에 바로 옮기려면 docker save my-ubuntu:curl | gzip | ssh 서버 'gunzip | docker load' 로 이어 붙인다

컨테이너의 파일을 통째로 (export · import)

docker run --name box alpine:3.22 sh -c 'echo hello > /note.txt'
docker export -o box.tar box                         # 8.4M — 파일 시스템만
tar -tf box.tar | grep note                          # note.txt
docker import box.tar my-box:1
docker run --rm my-box:1 cat /note.txt               # hello
docker run --rm my-box:1
# docker: Error response from daemon: no command specified
save / load export / import
대상 이미지 컨테이너
담는 것 층 · 태그 · CMD · ENV … 지금의 파일 시스템 한 장
되살린 것 같은 이미지 층 하나짜리 새 이미지 — 실행 설정이 없다
  • import 한 이미지는 CMD 가 비어 있어 명령을 주지 않으면 실행되지 않는다. docker import -c 'CMD ["/bin/sh"]' box.tar my-box:1 로 넣는다
  • 옮기는 목적이면 commit 한 뒤 save 하는 쪽이 설정까지 남는다

볼륨 백업 · 복원

볼륨은 잠깐 띄운 컨테이너로 tar 를 만들어 호스트 폴더로 꺼낸다.

docker run --rm -v data:/data -v "$PWD:/backup" alpine:3.22 tar czf /backup/data.tgz -C /data .
tar -tzf data.tgz
# ./
# ./n

docker volume create data2
docker run --rm -v data2:/data -v "$PWD:/backup" alpine:3.22 tar xzf /backup/data.tgz -C /data
docker run --rm -v data2:/data alpine:3.22 cat /data/n      # 1
  • DB 볼륨은 DB 가 쓰는 중에 tar 로 뜨면 깨질 수 있다. 컨테이너를 멈추고 뜨거나, DB 의 덤프 도구(mysqldump …) 로 백업한다
  • "$PWD" 가 맥의 홈 폴더 밖이면 colima 가상 머신에 연결되지 않아 파일이 생기지 않는다. 홈 폴더 아래에서 돌린다
