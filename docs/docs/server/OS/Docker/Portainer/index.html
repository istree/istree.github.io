Portainer 는 Docker 를 웹 화면으로 다루는 도구다. 컨테이너 · 이미지 · 볼륨 · 네트워크 목록을 보고, 시작 · 멈춤 · 지우기 · 로그 · 콘솔을 단추로 하며, Compose 파일을 붙여 넣어 스택으로 띄운다. Portainer 자신도 컨테이너로 돌고, Docker 소켓을 연결받아 엔진을 다룬다. 아래 화면은 Community Edition 2.45.3 LTS 를 colima 에서 띄운 것이다.

설치

docker volume create portainer_data
docker run -d --name portainer --restart=always \
  -p 127.0.0.1:9443:9443 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v portainer_data:/data \
  portainer/portainer-ce:lts

https://localhost:9443 을 열면 관리자 계정을 만드는 화면이 나온다. 이때 로그에 찍힌 설정 토큰을 넣어야 한다.

docker logs portainer
setup_token=1e68e71e337335a31014c0d5dde25185aed9b8d3394a4cd005c33206165e29e4

Paste it into the setup screen, or send it in the X-Setup-Token header.
Start with --no-setup-token to disable.
  • 자기 서명 인증서라 브라우저가 경고한다. 그대로 들어가거나, 앞에 리버스 프록시를 두고 인증서를 붙인다
  • 띄우고 5 분 안에 관리자를 만들지 않으면 잠긴다. 로그에 the Portainer instance timed out for security purposes 가 남고, 컨테이너는 Up 이지만 화면이 열리지 않는다. docker restart portainer 로 다시 띄운다
  • 9000 포트는 옛 HTTP 화면이다. 지금은 9443(HTTPS) 을 쓴다
  • Docker 소켓을 가진 컨테이너는 호스트의 root 와 같다. 포트를 127.0.0.1 에만 열거나 방화벽 안에 둔다

콘솔

목록의 >_ 단추로 컨테이너 안에 셸을 띄운다(docker exec -it … sh 와 같다). Ubuntu · Debian 이미지에는 편집기가 없고 한글 설정도 없다. Alpine 이미지에는 busybox 의 vi 가 있다.

docker run --rm ubuntu:24.04 sh -c 'command -v vi vim nano || echo "편집기 없음"'   # 편집기 없음
apt-get update && apt-get install -y vim-tiny        # 컨테이너 안에서 — /usr/bin/vi 가 생긴다

LANG 이 비어 있으면 셸이 한글을 바이트로 센다. Ubuntu 이미지에 들어 있는 C.UTF-8 을 주면 글자로 센다.

docker run --rm ubuntu:24.04 bash -c 'x=한글; echo ${#x}'                 # 6
docker run --rm -e LANG=C.UTF-8 ubuntu:24.04 bash -c 'x=한글; echo ${#x}'  # 2
  • 컨테이너를 만들 때 환경 변수 LANG=C.UTF-8 을 넣거나, Dockerfile 에 ENV LANG=C.UTF-8 을 둔다. locales-all 을 깔지 않아도 된다
  • 콘솔에서 고친 파일은 컨테이너를 다시 만들면 사라진다. 설정은 볼륨 · 바인드 마운트로 두고 호스트에서 고친다

예전에는

  • 이미지 이름이 portainer/portainer 였고 9000 포트(HTTP) 로 열었으며, 설정 토큰 없이 바로 관리자를 만들었다. 지금은 portainer/portainer-ce 다
  • 옛 글에 남긴 기록: 콘솔의 vim 에서 한글을 치면 WebSocket is already in CLOSING or CLOSED state. 오류와 함께 콘솔이 멈췄고, vim 대신 vim-tiny 를 깔고 LANG · LC_ALL 을 en_US.UTF-8 로 두고 컨테이너를 「Interactive & TTY (-i -t)」 로 만들어 피했다
