Java 앱

Java 웹 앱은 보통 Spring Boot 로 만들어 jar 파일 하나로 올린다. jar 안에 내장 웹 서버(Tomcat) 와 라이브러리가 모두 들어 있어, 서버에는 JDK(JRE) 만 있으면 java -jar 로 뜬다. 포트 · DB 주소 · 비밀번호 같은 설정은 jar 밖에서 환경 변수나 파일로 준다. 서버에서는 jar 를 systemd 서비스로 띄워 죽으면 다시 뜨게 하고, 앞에 Nginx 를 두어 바깥 요청 · HTTPS 를 받게 한다. Docker 이미지로 만들어 띄우기도 한다. 지금 판은 Spring Boot 4.1 · Java 25(LTS) 다.

이 묶음은 Spring Boot 4.1 의 작은 REST 앱 하나를 빌드해, Ubuntu 서버에 systemd 서비스로 띄우고, Nginx 뒤에 두고, Docker 이미지로 만드는 것을 실제로 돌려 본 순서대로 모았다.
