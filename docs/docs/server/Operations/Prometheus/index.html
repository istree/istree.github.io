Prometheus

목록 · 운영

Prometheus 는 서버 · 앱의 지표를 모아 두는 모니터링 시스템이다. 지켜볼 대상이 /metrics 같은 주소에 지금 값들을 글로 내놓으면, Prometheus 가 15 초쯤마다 찾아가 당겨 와서 시각과 함께 쌓는다(시계열). 값마다 이름과 라벨(job · instance · uri …) 이 붙어, PromQL 로 "지난 5 분의 초당 요청 수를 주소마다" 같은 식을 묻는다. 지표를 스스로 내지 못하는 것(리눅스 서버 · DB) 은 옆에 exporter 를 띄워 대신 내놓게 한다. 식이 정한 조건을 넘으면 경보를 만들어 Alertmanager 로 보내고, Alertmanager 가 묶고 걸러 메일 · 메신저로 알린다. 그래프는 보통 Grafana 로 그린다. 지금 판은 3.16 이고, 오래 지원하는 판(LTS) 은 3.13 이다.

이 묶음은 Docker 로 Prometheus 를 띄워 리눅스 서버(node_exporter) 와 Spring Boot 앱의 지표를 모으고, PromQL 로 묻고, 경보를 받아 본 것을 모았다.
