서버 정리는 웹 서비스 · 사내 도구를 리눅스 서버에 올리고 돌리는 데 쓰는 것을 모았다. 운영체제(Linux) 위에서 프로그램을 컨테이너(Docker) 로 띄우고, 웹 서버(Nginx · Apache2) 가 바깥의 요청을 받아 정적 파일을 내보내거나 앱으로 넘기며, 자료는 데이터베이스(MySQL · MariaDB · PostgreSQL, 캐시는 Redis, 나눠 담을 때는 MongoDB · Cassandra) 에 담는다. 서비스 사이에 메시지를 맡겨 두고 건넬 때는 메시지 큐(Kafka · RabbitMQ) 를 둔다. 글은 모두 Ubuntu 24.04 와 Docker 로 예제를 직접 돌려 나온 출력을 넣었다.
