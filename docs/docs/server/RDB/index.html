관계형 데이터베이스는 자료를 표(행과 열) 로 담고, 표 사이를 키로 엮어 SQL 로 읽고 쓰는 데이터베이스다. 표마다 열의 형식을 미리 정하고(스키마), 여러 표를 함께 고치는 일은 트랜잭션으로 묶어 모두 되거나 모두 안 되게 한다. 웹 서비스 · 사내 시스템의 자료는 대개 여기에 담는다. 서버에서 흔히 쓰는 것은 MySQL · MariaDB · PostgreSQL 이다. 표 · 인덱스 · 트랜잭션은 제품마다 같고, 설치 · 계정 · 백업 명령과 설정 파일, SQL 의 몇몇 문법이 다르다. 운영에서는 앱이 붙을 계정과 권한, 백업과 복원, 바깥에서 붙는 길을 먼저 정한다.
