PostgreSQL 은 오픈 소스 관계형 데이터베이스다. 표준 SQL 을 넓게 따르고, 자료형 · 함수 · 인덱스를 확장으로 더할 수 있어(JSON · 지리 정보 · 벡터 검색) 한 DB 로 여러 쓰임을 맡기기 좋다. MySQL 과 하는 일은 같지만 접속 · 권한의 틀이 다르다 — 사용자는 role 이고, 누가 어디서 들어올지는 pg_hba.conf 가 정하며, 표는 DB 안의 스키마(public) 에 들어간다. 해마다 9 월쯤 큰 판이 나오고 판마다 5 년을 지원한다. 지금 판은 18 이고, Ubuntu 24.04 의 패키지는 16 이다.
