Apache Cassandra 는 여러 서버에 자료를 나눠 담는 넓은 열(wide-column) 데이터베이스다. Facebook 에서 Amazon Dynamo 의 분산 · 복제 방식과 Google Bigtable 의 저장 모델을 합쳐 만들었다. 노드마다 하는 일이 같고 주인(primary) 이 없어, 어느 노드에 붙어도 읽고 쓰며, 노드가 몇 개 죽어도 남은 노드로 계속 받는다. 그 대신 노드마다 값이 잠깐 다를 수 있고, 요청마다 몇 노드의 답을 기다릴지(일관성 수준) 를 골라 맞춘다. SQL 을 닮은 CQL 로 다루지만 조인이 없고, 파티션 키 없이 찾지 못하므로 쿼리마다 표를 따로 만든다. 쓰기가 많고 서버를 늘려 가야 하는 곳(로그 · 이벤트 · 시계열 · 메시지) 에 쓴다. 라이선스는 Apache 2.0, 지금 판은 5.0 이다.
