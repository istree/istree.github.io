NoSQL 은 자료를 표가 아닌 형태로 담는 데이터베이스를 함께 부르는 말이다("Not only SQL"). 형태마다 잘하는 일이 다르다. 키-값(Redis) 은 키 하나로 값을 바로 꺼내 캐시 · 세션 · 카운터에 쓰고, 문서(MongoDB) 는 모양이 제각각인 객체를 JSON 형태 그대로 담고, 넓은 열(Cassandra) 은 서버를 늘려 가며 많은 쓰기를 받는다. 대개 처음부터 여러 서버에 나눠 담고 복제하도록 만들어져, 서버가 죽거나 네트워크가 끊길 때 쓰기를 멈출지(일관성) 받고 나중에 맞출지(가용성) 가 제품 · 설정마다 다르다. 조인 · 여러 표에 걸친 트랜잭션은 약하거나 없으므로, 앱이 할 질의에 맞춰 자료의 형태를 먼저 정한다.
