Redis 는 자료를 메모리에 두는 키-값 저장소다. 디스크를 거치지 않아 읽고 쓰기가 1 ms 안쪽이라, DB 앞에 두는 캐시 · 로그인 세션 · 카운터 · 순위표 · 간단한 큐로 쓴다. 값은 문자열만이 아니라 해시 · 리스트 · 집합 · 정렬 집합 같은 자료형이고, 키마다 만료 시간을 줄 수 있다. 메모리가 차면 정한 정책에 따라 키를 쫓아내거나 쓰기를 거부하고, 디스크에는 스냅숏(RDB) · 명령 기록(AOF) 으로 남긴다.

라이선스가 두 번 바뀌었다. 7.2 까지는 BSD, 7.4 는 RSALv2 · SSPLv1 둘 중 선택, 8 부터는 여기에 AGPLv3 를 더한 셋 중 선택이다. 7.4 로 바뀔 때 Linux Foundation 이 7.2.4 에서 갈라 BSD 로 이어 가는 것이 Valkey 다. 지금 판은 8.10 이고, Ubuntu 24.04 의 패키지는 Redis 7.0 · Valkey 7.2 다.
