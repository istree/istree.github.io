Apache Kafka 는 메시지를 디스크의 로그에 차례로 덧붙여 두는 분산 메시지 시스템이다. 메시지는 토픽에 넣고, 토픽은 파티션 여럿으로 나뉘어 브로커들에 흩어진다. 컨슈머가 읽어 가도 메시지는 지워지지 않고 보존 기간 동안 남아, 여러 서비스가 저마다 처음부터 따로 읽거나 지난 메시지를 다시 읽을 수 있다. 파티션 안에서는 순서가 지켜지고, 파티션을 늘려 쓰기 · 읽기를 여러 서버로 나눈다. 주문 · 결제 이벤트를 여러 서비스에 퍼뜨리거나, 로그 · 클릭 같은 많은 기록을 모으는 데 쓴다. 4.0 부터 ZooKeeper 없이 Kafka 스스로 메타데이터를 관리한다(KRaft). 지금 판은 4.4 다.
