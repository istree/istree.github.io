RabbitMQ

RabbitMQ 는 메시지를 큐에 받아 두었다가 컨슈머에게 건네주는 메시지 브로커다. 프로듀서는 큐에 바로 넣지 않고 교환기(exchange) 에 보내고, 교환기가 라우팅 키와 바인딩 규칙을 보고 알맞은 큐로 나눠 넣는다. 컨슈머가 처리했다고 알리면(ack) 메시지는 큐에서 지워진다. 처리하지 못한 메시지는 다시 넣거나 dead letter 큐로 보내고, 컨슈머마다 한 번에 받을 수를 정해 일을 고르게 나눈다. 작업 큐 · 이메일 보내기처럼 "누군가 한 번 처리하면 끝" 인 일에 맞는다. 표준 프로토콜 AMQP 0-9-1 을 쓰고 Erlang 으로 만들었다. 지금 판은 4.4 이고, 4 부터 큐를 여러 노드에 복제하는 일은 quorum 큐(와 스트림) 가 맡는다.
