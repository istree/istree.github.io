메시지 큐

메시지 큐는 서비스 사이에 두는 우편함이다. 보내는 쪽(프로듀서) 은 메시지를 브로커에 맡기고 바로 제 일로 돌아가고, 받는 쪽(컨슈머) 은 제 속도로 꺼내 처리한다. 그래서 받는 쪽이 잠깐 죽거나 느려도 보내는 쪽은 멈추지 않고, 몰려든 요청은 큐에 쌓였다가 차례로 처리되며, 한 메시지를 여러 서비스에 함께 나눠 줄 수 있다. 방식은 둘로 나뉜다. RabbitMQ 같은 큐는 메시지를 받아 가면 지우고 교환기가 큐마다 나눠 보낸다. Kafka 같은 로그는 메시지를 보존 기간 동안 남기고 컨슈머마다 어디까지 읽었는지(offset) 를 따로 둔다. 어느 쪽이든 메시지는 "적어도 한 번" 오는 것이 보통이라, 받는 쪽은 같은 메시지를 두 번 받아도 괜찮게 만든다.
