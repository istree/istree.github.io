Apache 는 기능을 모듈로 나눠, 필요한 모듈만 켜서 쓰는 웹 서버다. Ubuntu · Debian 패키지(apache2) 는 모듈 · 설정 조각 · 사이트를 …-available 폴더에 두고, 켤 것만 …-enabled 폴더에 링크로 둔다. 링크는 손으로 만들지 않고 a2enmod · a2ensite · a2enconf 로 만든다. 아래 예제는 Ubuntu 24.04 에 apt 로 깐 Apache 2.4.58 로 돌렸다.

설치와 폴더

sudo apt install apache2
apache2 -v        # Server version: Apache/2.4.58 (Ubuntu)
경로 쓰임
/etc/apache2/apache2.conf 공통 설정 — 아래 폴더들을 Include 로 읽는다
/etc/apache2/ports.conf 들을 포트 (Listen 80, ssl 모듈이 켜지면 Listen 443)
mods-available/ · mods-enabled/ 모듈 (이름.load 는 불러오기, 이름.conf 는 그 모듈의 설정)
conf-available/ · conf-enabled/ 서버 전체 설정 조각 (security.conf · charset.conf …)
sites-available/ · sites-enabled/ 사이트(가상 호스트) — 처음에는 000-default.conf 만 켜져 있다
/var/www/html 기본 사이트의 파일
/var/log/apache2/ access.log · error.log · other_vhosts_access.log

켜고 끄기

sudo a2enmod proxy_http
# Considering dependency proxy for proxy_http:
# Enabling module proxy.
# Enabling module proxy_http.
# To activate the new configuration, you need to run:
#   service apache2 restart
ls -l /etc/apache2/mods-enabled/ | grep proxy
# proxy.conf -> ../mods-available/proxy.conf
# proxy.load -> ../mods-available/proxy.load
# proxy_http.load -> ../mods-available/proxy_http.load
명령 하는 일
a2enmod · a2dismod 모듈 켜기 · 끄기 (필요한 모듈까지 함께 켠다)
a2ensite · a2dissite 사이트 켜기 · 끄기 (.conf 를 빼고 이름만 — a2ensite site)
a2enconf · a2disconf 설정 조각 켜기 · 끄기
apache2ctl configtest 설정 검사 — Syntax OK
apache2ctl -M 불러온 모듈 목록 (기본 27 개)
apache2ctl -S 사이트(가상 호스트) 목록과 어느 파일에서 왔는지
sudo systemctl reload apache2 접속을 끊지 않고 다시 읽기 (apache2ctl graceful 과 같다)
  • 모듈을 켜고 끈 뒤에는 restart, 사이트 · 설정 조각만 바꿨으면 reload 로 된다
  • 틀린 설정이면 configtest 가 줄을 알려 준다. 이때 graceful 은 다시 읽지 않고 옛 설정으로 계속 돈다 
    AH00526: Syntax error on line 1 of /etc/apache2/conf-enabled/bad.conf:
Invalid command 'Foo', perhaps misspelled or defined by a module not included in the server configuration
  • 「Invalid command」 는 오타이거나, 그 지시어를 가진 모듈이 꺼져 있다는 뜻이다. ProxyPass 에서 나면 a2enmod proxy_http 다

AH00558 경고

AH00558: apache2: Could not reliably determine the server's fully qualified domain name, using 172.17.0.2. Set the 'ServerName' directive globally to suppress this message
  • 서버 전체의 ServerName 이 없어서 나는 경고다. 동작에는 문제가 없다
  • 설정 조각으로 넣고 켠다 
    echo "ServerName localhost" | sudo tee /etc/apache2/conf-available/servername.conf
sudo a2enconf servername
sudo apache2ctl configtest      # Syntax OK — 경고가 사라진다

폴더 목록 끄기

Ubuntu 의 apache2.conf 는 /var/www/ 에 Options Indexes FollowSymLinks 를 준다. index.html 이 없는 폴더는 파일 목록(Index of /files) 이 보인다.

<Directory /var/www/>
	Options FollowSymLinks
	AllowOverride None
	Require all granted
</Directory>
  • Indexes 를 빼면 목록 대신 403 이고, 오류 로그에 AH01276: Cannot serve directory /var/www/html/files/: No matching DirectoryIndex 가 남는다
  • a2dismod autoindex 로 모듈을 끄면 목록 대신 404 다

.htaccess

폴더 안의 .htaccess 파일로 그 폴더의 설정을 바꾼다. AllowOverride 가 허락해야 읽는다.

echo "Require all denied" > /var/www/html/files/.htaccess
curl -s -o /dev/null -w "%{http_code}\n" localhost/files/a.txt
# 200 — AllowOverride None 이라 .htaccess 를 읽지 않는다
# 403 — AllowOverride All 로 바꾼 뒤
  • 요청마다 폴더를 거슬러 올라가며 .htaccess 를 찾으므로 느려진다. 서버 설정을 고칠 수 있으면 <Directory> 에 적고 AllowOverride None 으로 둔다
  • WordPress 처럼 .htaccess 로 주소를 바꾸는 앱은 AllowOverride All 과 a2enmod rewrite 가 있어야 한다

로그

ErrorLog ${APACHE_LOG_DIR}/error.log
CustomLog ${APACHE_LOG_DIR}/access.log combined
127.0.0.1 - - [08/Nov/2026:10:09:18 +0000] "GET /files/a.txt HTTP/1.1" 200 228 "-" "curl/8.5.0"
  • 로그는 /etc/logrotate.d/apache2 가 매일 돌려 14 개를 남기고 압축한다. 디스크가 걱정이면 이 값을 줄인다
  • 접근 로그가 필요 없는 사이트는 CustomLog 줄을 빼면 된다. 오류 로그는 빼도 서버 전체의 error.log 에 쌓이므로, 정말 버리려면 ErrorLog /dev/null 로 둔다
  • 응답의 Server: Apache/2.4.58 (Ubuntu) 처럼 버전이 드러나는 것은 conf-enabled/security.conf 의 ServerTokens OS · ServerSignature On 때문이다. ServerTokens Prod · ServerSignature Off 로 바꾸면 Apache 만 보인다

MPM

apache2ctl -V | grep MPM     # Server MPM:     event
  • MPM 은 요청을 받는 방식이다. 지금 기본은 event(스레드) 다
  • mod_php 는 스레드에서 안전하지 않아 prefork 와 함께 쓴다. PHP 는 php-fpm + event 로 두는 것이 낫다

Docker 에서

  • 컨테이너는 PID 1 이 앞에서 돌아야 한다. apachectl start 는 뒤로 빠져 컨테이너가 바로 멈추므로 apachectl -D FOREGROUND 로 띄운다
  • 공식 이미지 httpd 는 Debian 패키지가 아니라 소스 빌드라 a2enmod · sites-available 이 없다. /usr/local/apache2/conf/httpd.conf 의 LoadModule 줄을 고친다

예전에는

  • 모듈을 켤 때 ln -s ../mods-available/proxy.load proxy.load 처럼 링크를 손으로 만들었다. 지금도 같은 결과지만 a2enmod 는 필요한 모듈(proxy) 까지 챙긴다
  • Apache 2.2 는 접근 허용을 Order allow,deny · Allow from all 로 썼다. 2.4 부터 Require all granted 다
