웹 서버는 브라우저 · 앱이 보낸 HTTP 요청을 받아 답하는 프로그램이다. 서버의 맨 앞에 서서 정적 파일을 내보내고, HTTPS 의 암호를 풀고, 나머지 요청을 뒤의 앱 서버로 넘긴다(리버스 프록시). 가장 많이 쓰는 것은 Nginx 와 Apache2 다. 둘이 하는 일은 같지만 설정하는 방식이 다르다 — Nginx 는 server · location 블록을 겹쳐 적고, Apache2 는 모듈을 켜고 끄며 폴더마다 .htaccess 로 바꿀 수 있다.

정보

  • W3Techs — Web Servers — 웹 사이트가 쓰는 웹 서버의 비율
  • Let's Encrypt — 무료 인증서를 내주는 기관. 인증서 기간 · 정책이 바뀌는 소식이 여기 올라온다
  • Caddy · HAProxy — 다른 웹 서버 · 프록시. Caddy 는 HTTPS 를 저절로 걸고, HAProxy 는 부하 분산에 많이 쓴다

문서

  • MDN — HTTP — 요청 · 응답 · 헤더 · 상태 코드 · 캐시 설명 (한국어)
  • RFC 9110 — HTTP Semantics — 메서드 · 상태 코드 · 헤더의 표준
  • Mozilla Server Side TLS — 서버에 켤 TLS 버전 · 암호 묶음의 권장안과 그 까닭

도구

  • curl — 명령줄에서 요청을 보내고 응답 헤더(-I · -v) 를 본다
  • nginx playground — 브라우저에서 Nginx 설정을 적고 curl 로 바로 시험한다
  • hey — 요청을 한꺼번에 보내 초당 처리량 · 응답 시간을 잰다

책
