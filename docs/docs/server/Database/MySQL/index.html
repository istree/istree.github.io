MySQL

목록 · MySQL
  • 개요
  • 설치와 접속
  • 사용자와 권한
  • 백업과 복원

MySQL 은 가장 널리 쓰이는 오픈 소스 관계형 데이터베이스다. 웹 서비스 · 사내 시스템의 자료를 표로 담고 SQL 로 다루며, WordPress · GitLab(옛 판) · 많은 웹 프레임워크가 기본으로 지원한다. 지금 판은 장기 지원판(LTS) 인 8.4 이고, Ubuntu 24.04 의 패키지는 8.0 이다. 서버에서는 설치 · 사용자와 권한 · 백업을 손에 익혀 두면 대부분의 운영 일이 된다.

이 묶음은 Ubuntu 패키지와 Docker 이미지로 MySQL 을 띄우고, 앱용 사용자를 만들고, 백업 · 복원하는 법을 모았다.
