MongoDB 는 문서 데이터베이스다. 표와 행 대신 컬렉션과 문서(JSON 꼴, 속은 BSON) 에 자료를 담는다. 문서마다 필드가 달라도 되고, 안에 객체 · 배열을 품을 수 있어 앱의 객체를 그대로 넣고 꺼낸다. SQL 대신 find · updateOne · aggregate 같은 메서드로 다룬다. 운영에서는 노드 셋 이상의 복제 세트로 띄워 하나가 죽어도 저절로 넘어가게 하고, 자료가 한 서버에 담기지 않으면 샤딩으로 여러 복제 세트에 나눈다. 서버는 2018 년부터 SSPL 라이선스이고, Ubuntu 기본 저장소에는 없어 MongoDB 의 저장소나 Docker 이미지로 깐다. 지금 판은 9.0 이다.

이 묶음은 MongoDB 를 띄우고 사용자를 만들고, 문서를 다루고, 복제 세트 · 샤딩을 직접 꾸려 노드를 꺼 보고, 백업 · 복원하는 법을 모았다.
